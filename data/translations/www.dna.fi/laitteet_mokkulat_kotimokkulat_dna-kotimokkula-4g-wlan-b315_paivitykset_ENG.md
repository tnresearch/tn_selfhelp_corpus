## Updates

The device's software is no longer actively updated. We recommend upgrading to a new device to ensure that security and performance are up to date.

#### 6.6.2017 Home Modem B315 received a new update

Changes in the update:

  1. Fix for an issue where connection speed suffers if Wi-Fi is turned off
  2. 2100Mhz lock
  3. Status information added:  
3G: CELL_ID,RSSI,RSCP,  
ECIO 4G: PCI,CELL_ID,RSRQ,RSRP,RSSI,SINR,Band

The version number is: 21.321.03.00.182

  
The update happens by accepting it from the settings page (Web interface) either automatically via the incoming notification or manually by searching for the update in the path Update -> Check for update.

#### 1.6.2016: Critical update for B315 with the following changes:

  1. Preventative fix for an issue where the device may fail to boot and freeze
  2. Added IPV4V6 and IPV4 only options to settings
  3. Bridged mode added as a setting option
  4. Possibility to turn off update notifications in settings
  5. Fixes to the Web interface: speed improved, translation issues and appearance aspects
  6. Antenna settings page added
  7. TR069 enabled (not in use)

#### Special note about bridged mode (bridge mode)

Bridged mode bypasses the device's firewall, NAT and reduces processor load. The mode is intended for special cases where the customer needs ports open, e.g. for online games. Due to LLK subscriptions, in bridged mode B315 receives only one (1) IPv4 address. This means that only one (1) user device can be connected to the device in bridged mode at a time. Connection is done via the device's LAN4/WAN port or via wifi. Resetting the device is the easiest way to switch the mode back to routing. Settings can be changed before switching to bridged mode.  
  
The update happens by accepting it from the settings page (Web interface) either automatically via the incoming notification or manually by searching for the update -> Check for update.  
  
You can also install the update on the device using [this downloadable file](/documents/753910/853450/B315s_update.bin/14940532-32cb-1f2b-29d9-7319c5d66efc) via the same path. The new version number is 21.316.01.01.182.
