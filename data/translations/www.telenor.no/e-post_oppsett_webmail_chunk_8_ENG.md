## Calendar

The calendar in webmail can help you keep track of appointments, plans, and
birthdays

  * #### Settings

To update **Calendar** settings, select **Preferences** in the main menu on the left. Here you will see the following options:

    * **Default calendar view** : Sets the default calendar view to **Agenda**, **Day**, **Week**, or **Month**

    *  **First day of the week:** Choose which day you want the week view in the calendar to start on. You can choose between Sunday or Monday. 

    * **Default event duration** : Allows you to set the default duration for a calendar event

    *  **Do not show weekends in calendar** : Removes weekends from the calendar view. Events are not suggested on weekends

 **Location Services**

    *  **Default location** : Sets the default location for your events.

    *  **Show default location when creating event** : This automatically fills in the location when you create a new event

    *  **Allow retrieval of location used for events** : Entered event locations are remembered and suggested using the autocomplete function

    *  **Remove retrieved locations** : Allows you to remove collected locations

  * #### Add, modify or delete calendar

 **How to create a new calendar:**

    1. In the **Calendar** menu, click the plus icon in the **My calendars** section to create a new calendar. You can choose to create or import a calendar. 

    2. Then fill in calendar information such as name, color, sharing options and permissions for added calendar users

    3. Click on **Save**

 **How to modify a calendar**

    1. In the **My calendars** list, click on the calendar name of the calendar you want to modify.

    2. In the **Edit main/subcalendar** screen, change the calendar details

    3. Click on **Save**

 **How to delete a subcalendar:**

    1. Click on the name of the calendar you want to delete in the calendar list

    2. The **Edit primary/secondary calendar** screen opens for the selected calendar. Select the trash can to delete the calendar. 

    3. Click on **Yes** in the confirmation dialog box

  * #### Create new appointment

 **How to create a new appointment:**

    1. Press **Calendar** in the main menu on the left

    2. Click the **Create a new appointment** icon  

    3. Fill in the following: 

      * Appointment title

      * Click on the calendar icons and select start and end date

      * Click on the clock icons and select start and end time

      * If the appointment lasts all day, select **All day**

      * If this is a recurring appointment, select **Repeat.** A dialog box will open where you can choose the intervals.

    4. Click on the **Details** tab and enter the following:

      *  **Location** - the location where the event will take place

      * Select which calendar you want to add the appointment to

      * Choose whether you want a notification. **Note** : You can add multiple notifications to each appointment

      * Enter a description for the appointment in **Notes**. This description will be sent to participants as an email.

    5. Click on the **Participants** tab

      * In **Add participants**, enter the email addresses of those you want to invite

      * To remove a participant from the event, click **X** next to the name

5\. Click on **Save**

You can now choose whether to send an invitation by email to any participants.

  * #### Modify or delete appointment

 **How to modify an appointment:**

    1. Double-click on an appointment in the calendar to open the **Edit appointment** dialog box

    2. Change the information you want

    3. Click on **Save**  

 **How to delete an appointment:**

    1. Double-click on an appointment in the calendar view

    2. In the **Edit appointment** dialog box, click the trash can at the top. To delete the appointment, press **Yes** in the confirmation screen.
