# TV Guide

In the TV guide, you will find an overview of all programs that are being broadcast or have been broadcast on direct TV. Here you will find tips and information on how to use it.

The TV guide shows you which programs are on TV. The blue line shows the current time, and you can scroll forward and backward in the guide to see what's on now, coming on later tonight, or has been on in the last few days.

## Where to find the TV Guide

You open the TV guide by pressing **GUIDE** on the remote control, or press the T-We button, select ☰ from the menu, and then TV guide.

### How the TV Guide Works

The TV guide displays program information for all channels up to 14 days in advance. Next to the program title, icons will appear indicating whether it is possible to start the program from the beginning, or if it is [available in the weekly archive](/kundeservice/tv/brukerveiledning-t-we/ukesarkiv/). For example, if you want to start a program from the beginning, you can look for this icon: ↺. Press the ↺ button on the remote control to start the program from the beginning.

You can also [start recording programs](/kundeservice/tv/brukerveiledning-t-we/opptak/) that are currently on and programs that are coming up in the future directly from the TV guide.

If you experience that the program information is not loading, you can resolve this by holding down the **yellow button** on the remote control for 5-6 seconds. The data will then be reloaded.  
If this does not work, you can try to reconnect the remote control to the T-We Box. You can find instructions for this here: [Help with the remote control](/kundeservice/tv/dekodere-og-fjernkontroller/t-we-boks-ii/fjernkontroll/)

## Useful Buttons on the Remote Control

Here you can see which buttons on the remote control control the individual functions in the TV guide.

 **Arrow buttons** are used to scroll between channels and programs

 **OK** opens the information page and confirms selections.

 **Rewind and fast forward** are used to scroll back/forward 4 hours. To change the length of the jump, press MENU on the remote control and then select Function menu, Settings and Language and subtitles.

 **Channel change (+ and -)** changes the channel or scrolls through entire pages in the TV guide and other lists.

 **Selection (?** ☰ **)** With this button, you can switch between lists such as all channels and TV favorites, change the TV guide format, or select a specific day.

[More about the remote control](/kundeservice/tv/dekodere-og-fjernkontroller/t-we-boks-ii/fjernkontroll/)

## Watch TV - Information, Sound and Subtitles

When you have selected the program you want to watch from the TV guide or from "Direct TV and weekly archive" in the menu, a channel banner will appear.

The channel banner provides you with information about the program in the same way as the TV guide.

  * Press the INFO button to get more information about the program

  * Press ?☰ or OPTIONS button to bring up the menu to change the sound or subtitles of the program. This menu can also be used to [switch between all channels and favorite channels.](/kundeservice/tv/brukerveiledning-t-we/favorittliste/)

Channel banner: Here you can see which channel you are on, what the program is called, brief information about the program such as a repeat or episode, and what program is coming up next. Note the icons for weekly archive and start from the beginning.
