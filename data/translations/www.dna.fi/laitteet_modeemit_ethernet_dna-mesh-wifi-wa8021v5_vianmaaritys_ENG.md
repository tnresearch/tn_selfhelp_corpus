Troubleshooting

No lights are on on the modem (power cord is connected)

**Possible cause:**

The modem is not receiving power. The transformer or modem may be faulty.

**Proposed solution:**

Connect the power cord according to the instructions and check that the outlet has power. Bring the transformer and modem to a DNA Store for replacement.

All lights indicating the internet connection are on, but you cannot connect to the internet

**Possible cause:**

The modem may be frozen.

**Proposed solution:**

Disconnect the modem's power cord for about a minute and wait for the internet connection status lights to come back on. Restart your computer. Also try with an Ethernet cable. You can also reset the device.

All lights indicating the internet connection are on (Computer reports "limited connection")

**Possible cause:**

The modem is not connecting to the internet.

**Proposed solution:**

Check the connection and connections. Also check the settings of your computer/terminal (e.g., internet settings and network card). If necessary, reset the modem, disconnect the modem's power cord for about a minute and wait for the lights to come back on.

All lights indicating the internet connection are on (settings checked)

**Possible cause:**

The firewall may be blocking traffic.

**Proposed solution:**

Check your computer's firewall settings.

All lights indicating the internet connection are on (settings checked, using your own connection sharing device, e.g., router)

**Possible cause:**

Your connection sharing device is frozen or faulty.

**Proposed solution:**

Connect the modem to the computer with an Ethernet cable or use the modem's wireless connection. You can also try setting the modem to bridge mode. Contact the party selling routers or other additional devices.

Wireless network does not work

**Possible cause:**

If the connection works with an Ethernet cable, the problem is with the WiFi network.

**Proposed solution:**

Restart the modem, check the settings and try the WiFi tips at: [dna.fi/tuki-wifi](http://dna.fi/tuki-wifi). If these don't work, contact customer service.

Unable to pair multiple modems into one mesh network

**Possible cause:**

Before connecting multiple DNA Mesh WiFi modems to a mesh network, you must confirm the mesh network name and password from the device's management page. If you have not visited the device's management page, the pairing process for multiple devices will not start normally.

**Proposed solution:**

Before you start connecting multiple DNA Mesh WiFi modems into a seamless mesh network, you must confirm or set the WiFi network name and password from the device's management page.

  * Install the first DNA Mesh modem [according to the instructions](https://www.dna.fi/dna-mesh-wifi-wa8021v5-modeemi#kayttoonotto). 
    * Once the first DNA Mesh WiFi modem is working, log in to the modem's management page in a web browser at dna.wifi/ or 192.168.101.1. When it opens, the management site will ask you to enter the default password 1234.
    * After logging in, you can choose the wireless WiFi network name (SSID) and password you want for your mesh network. You can also continue using the default passwords of the first DNA Mesh WiFi modem, which you can find on the sticker on the bottom of the device, by selecting 'Skip'.

After this, you can start connecting multiple modems to each other. You can use two or more DNA Mesh WiFi modems to form a comprehensive Mesh WiFi network:

  1. Install the first DNA Mesh modem [according to the instructions](https://www.dna.fi/dna-mesh-wifi-wa8021v5-modeemi#kayttoonotto).
  2. Place the second DNA Mesh WiFi device (i.e., the device used as a mesh access point) close to, no more than 2 meters from, the device used as a router (i.e., the first DNA Mesh WiFi modem) and connect the power cord of the device acting as a mesh access point to a power outlet.
  3. Wait about a minute after connecting power to the device used as a mesh access point
  4. Check the indicator light on the device acting as a router. If the indicator light is flashing slowly, the router has recognized the mesh access point
  5. Press the pairing button on the device acting as a router once. The indicator lights on both DNA Mesh WiFi devices will flash quickly. Wait for the indicator light on the mesh access point to start to glow steadily white. This is a sign that the pairing was successful.
  6. Disconnect the device used as a mesh access point from the power outlet and move it to the location where you want the wireless connection to reach. Connect the device to power. When the indicator light glows steadily white, the device is able to establish an internet connection. What steps are not needed.
  7. You can add more DNA Mesh WiFi devices to the wireless mesh network by repeating the steps described above.
