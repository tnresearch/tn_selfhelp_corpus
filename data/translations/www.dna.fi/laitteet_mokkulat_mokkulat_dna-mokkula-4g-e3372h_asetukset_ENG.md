## Settings

Tips for speeding up your modem connection

Modems work most efficiently on 4G or 3G networks. If the connection is slow or intermittent, try the following:

  * Indoors, the connection is best near windows.
  * Connect the modem to your computer with the USB cable included in the sales package.
  * Place the modem in an upright position, for example at the top corner of your computer screen, using the USB cable.
  * Try an external antenna, for more information contact DNA Customer Service at 044 144 044.

NOTE! The modem automatically uses only the 4G or 3G network, depending on
coverage. You can view coverage areas at dna.fi/kuuluvuus.
If you enter a 2G network area, you must change the network used in the modem settings.  
  
If the modem is used on the border between a 4G and 3G network or a 3G and 2G network,
the modem may switch between these networks. Switching between networks
causes the connection to drop and slows down the modem. If you wish, you can lock
the modem to any network technology as follows:

  1. Open a web browser and type http://dna.mokkula in the address bar.
  2. Select **Settings – Mobile Network Settings – Network**
    * 4G only: Locks the modem to the 4G network
    * 3G only: Locks the modem to the 3G network
    * 2G only: Locks the modem to the 2G network
    * 4G & 3G: Locks the modem to the 4G or 3G network
    * AUTO: First selects 4G, then 3G, and finally 2G network

To improve the user experience, the modem is forced to be on a 4G or
3G network by default. If you are in an area where there is only a 2G network, the modem will not find
the network at all. In this case, the modem should be set to automatic
network selection according to the instructions above.

Using an external antenna

If the modem connection speed is slow, you should try an external antenna.
An external antenna improves signal strength and thus data transfer speed.
For more information about the external antenna, contact DNA Customer Service at 044 144 044.  
  
The external antenna is connected to the connector on the side of the modem, which is numbered 1.
If you use two antennas at the same time, connect the other antenna to connector 2.
The external antenna connector is a so-called miniature connector, which is not designed to withstand
frequent disconnections and connections, so connecting and disconnecting
should be done carefully and only when necessary. The connector is a consumable part, and the warranty
does not cover wear and tear damage to the connector.

Changing the SIM card PIN code

By default, the modem enters the PIN code 1234 for the SIM card, which is the default PIN code used by DNA. You can change the PIN code as follows:

  1. Open a web browser and type http://dna.mokkula in the address bar.
  2. Select **Settings – Security – PIN Code Management**
  3. Select **Change** from the drop-down menu
  4. Enter the currently used PIN code in the **PIN Code** field
  5. Enter the new desired PIN code in the **New PIN** and **Confirm PIN** fields
  6. Press **Apply**
