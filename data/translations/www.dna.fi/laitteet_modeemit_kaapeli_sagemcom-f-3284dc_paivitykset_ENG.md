## Updates

The device's software is no longer actively updated. We recommend replacing it with a new device to ensure that security and performance are up to date.

Updates for cable modems come automatically from the network. Updates are run on the modems at night, causing the least amount of problems. In some rare cases, the modem may need to be reset and restarted in the morning after an update, so that the device functions optimally.

If you want to run the updates to the device immediately, it is worth trying to disconnect all cables from the device for a few minutes and then reconnect them. This will cause the modem to come back online and request updates at the same time.

**Latest version released 2.183.0, released on 20.1.2020**

  * Cable Hunt fix
  * Security updates

  
**Version release 87.11.2018**

  * Improved compatibility with DNA Hub
  * Improved port forwarding and usage with medium and high firewall settings
  * Minor user interface changes

The new version number is 2.150.0

**NOTE!** The new update (11/15) for the Sagemcom F-3284DC modem includes new features and changes to the default settings. The changes include a new setting page for the LED light, disabling IP-flood detection, and enabling firewalls. DNA recommends that the user disable firewalls (ipv4 and ipv6) if they do not feel they need them.
