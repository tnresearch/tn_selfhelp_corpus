# Get Started and Change Password

Before you start using your new ZTE router, it is important to change the
password. Just follow this guide and you'll be done in a few minutes.

Start by finding the WiFi connection for your router. The WiFi name is on the
router's display.

  1. Open your web browser and enter http://192.168.10.1 in the address bar. Log in with "admin" as the password.
  2. Change the password for the mobile broadband. You do this under "Settings" > "Device Settings" > "Account Management"
  3. Change the password for your WiFi. You do this under "Settings" > "WiFi Settings" > "WLAN". Tip! Here you can also change the WiFi name/network name (SSID) if you want.
  4. If an upgrade is available, it is important to download and install it. If so, an information box will appear when you log in.

If for any reason you have reset the device by pressing the reset
button, it is important to repeat points 1 and 2 again.
