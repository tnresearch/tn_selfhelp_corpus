## Updates

The Home Modem H122 is updated by logging into the settings pages and selecting the "Updates" tab from behind the "Advanced Settings" menu and following the instructions on the site.

**H122 has received an update starting May 25, 2023:**

  * new carrier aggregation frequency combinations that improve the device's performance, especially in the area of the Finnish Joint Network
  * New software version: 11.0.2.20(H329SP2C182) 
  * New web interface software version: 11.0.2.1(W2SP9C182)

#### Older updates:

**October 11, 2021**

  * the update includes fixes that improve the general functionality of the device from the device manufacturer
  * New software version: 11.0.2.11(H329SP3C182) 
  * New web interface version: 11.0.2.1(W2SP3C182)
