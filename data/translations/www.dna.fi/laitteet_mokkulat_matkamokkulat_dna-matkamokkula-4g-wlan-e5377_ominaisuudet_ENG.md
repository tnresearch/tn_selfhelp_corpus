## Features

### DNA Prepaid Travel Modem 4G WLAN E5377

Product name: Huawei E5377  

A top-of-the-line travel modem that allows you to connect multiple devices to the internet at home, at the cottage, or while traveling.  
The device supports 4G connectivity and older network technologies, such as 3G.  
The modem has the ability to use 2.4 Ghz and 5 Ghz WLAN networks simultaneously.  
A large battery makes it easy to move around, and the modem's clear display makes it easy to use.

  * 4G LTE maximum speed from the network 150 Mbit/s
  * 4G DC maximum speed 42 Mbit/s 
  * HSPA+ maximum speed 21.1 Mbit/s
  * WLAN b/g/n
  * WLAN 2.4 Ghz and WLAN 5 Ghz
  * 14 WLAN devices, adjustable WLAN network range
  * 3560 mAh battery and large LCD screen
  * TS9 connector for external antenna
  * Mini-SIM card, i.e. a normal-sized SIM card
  * Automatic wireless network WPS setup, updates from the internet
  * Support for IPv6

### Sales package contents:

DNA Modem 4G WLAN E5377 with DNA settings, AC power adapter, charging cable (Micro-USC), Finnish-language quick start guide.

### Hardware requirements / Supported operating systems:

  * Supported operating systems: Windows® 10, Windows® 8 / 8.1, Windows® 7, Vista, XP SP2/SP3, Mac OS X® 10.7
  * WLAN: 802.11b/g/n
  * USB slot 1/2/3
  * Internet browser via USB connection or WLAN connection: Microsoft Internet Explorer 6.0 or later, Firefox 2.0 or later, Safari 4.0 or later, Opera 10.0 or later, Chrome 5.0 or later
