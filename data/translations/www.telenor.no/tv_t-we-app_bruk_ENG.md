# T-We App

Here you will find information about logging in, how to add more family members to the T-We App, and which devices support the T-We App.

[Login](/kundeservice/tv/t-we-app/bruk/#innlogging)[Add family members](/kundeservice/tv/t-we-app/bruk/#familiemedlemmer)[Devices](/kundeservice/tv/t-we-app/bruk/#enheter)

You need the following to use the T-We app or web TV on t-we.no

  * An active TV subscription and one T-We Box or card reader from Telenor

  * The mobile number of the subscription owner must be registered in our systems

  * Internet connection via mobile network or WiFi

  *  **Only for T-We app:** If you want access to content that is locked to the home, you must also have a T-We Box connected to the same network. This will not be available on t-we.no.

## Login

 **Here's how to log in as the subscription owner:**

To log in, you must use your mobile number. The mobile number of the person who is the owner of the subscription must be registered in our systems for you to access the app/web TV and be able to give family members access. If we have not registered your mobile number, you must create a user on [My Pages](https://www.telenor.no/minesider) on telenor.no.

Need help creating a user on My Pages:

[Read more about Telenor ID and get help with login.](/telenor-id/)

 **Note:** The TV subscription owner must log in to the app/on t-we.no before access can be granted to more family members.

## Add more family members

Use a profile with admin rights to add new mobile numbers and grant access to up to 5 family members. Once the mobile number is added, the person can log in to the app or on twe.no.  

  1. Select **☰ More**

  2. Press **Access and profiles**

  3. Select **Add mobile number**

  4. Enter the PIN code (this is the same as the administrator profile on the T-We box. 1-2-3-4 as default if it has not been changed.)

  5. Enter the mobile number of the person who should have access to the app or web TV.

In addition to granting access to the app/web TV, you can create user profiles tailored to each family member. You can [create these directly in the app](/kundeservice/tv/t-we-app/profiler/index.page), and they work across all devices.

## Which devices can I use?

The app can be downloaded on mobile phones and tablets with iOS or Android and is available as a separate app on Apple TV 4 or newer, Chromecast with Google TV and for devices that have the Android TV operating system.  
  
The app supports up to four simultaneous users, so multiple family members can watch different content at the same time.

 **twe.no** is available for Windows and Mac, and currently supports all browsers except Microsoft Edge.

A total of up to 10 devices can be connected simultaneously.

In the app, you can also send the content to your T-We box. If you want more T-We boxes, you can [order a T-We Box II here.](/privat/tv/t-we/dekoder/)
