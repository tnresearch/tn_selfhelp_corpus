# Troubleshooting E-mail Issues

Here you will find solutions to known problems related to sending and receiving
e-mail.

## What problem are you experiencing?

  * #### Cannot send e-mail

    1. Check if you are experiencing the same problem in the webmail at <https://www.online.no/>

      * If the same problem occurs in webmail, go to [Webmail is not working](https://www.telenor.no/kundeservice/e-post/problemer/#webmail)

      * If it works normally there, proceed to the next step

    2. If you can receive e-mail, but not send, the cause is usually _problems with outgoing settings_.

    3. Check that you have entered the correct server and port as described under [general setup](/kundeservice/e-post/oppsett/). Note that authentication of username and password is required for the outgoing server.

[Open Online E-mail](https://www.online.no/)

  * #### Cannot receive e-mail

    1. Check if you are experiencing the same problem in the webmail at <https://www.online.no/>

      * If the same problem occurs in webmail, go to [Webmail is not working](https://www.telenor.no/kundeservice/e-post/problemer/#webmail)

      * If it works normally there, proceed to the next step

    2. Is it possible to send e-mail, but not receive? If the problem applies to all incoming e-mail, it is likely that the settings for the incoming server need to be changed. Follow [setup for Online e-mail](/kundeservice/e-post/oppsett/) for correct settings.

In some cases, the problem may also be due to a full inbox. The maximum
limit for the inbox is 25,000 e-mails. Try deleting a few messages from
**webmail** if you suspect this may be the case. You will normally
be notified when you are approaching the limit.

[Open Online E-mail](https://www.online.no/)

  * #### Problem not solved - Add account again

If you cannot solve the problem, the solution may be to add the e-mail account
again.

Delete the account from the e-mail program ( **NOTE:** _If you have set up an e-mail account with
POP on Mac, iPad or iPhone, all e-mail will be deleted. You should back up or save all the content first)_

Add the account again with IMAP setup.

[Go to Setup](/kundeservice/e-post/oppsett/)

  * #### Forgot password

    1. Open [Telenor My Pages](https://www.telenor.no/mine-sider/)

    2. Log in or create a TelenorID (You do not need to be a Telenor customer)

    3. Select **Go to e-mail** under services

    4. Select **Change password** for the desired account and follow the instructions

[Forgot password](/kundeservice/e-post/glemt-passord/)

## Problems with webmail on online.no

If you are experiencing problems with your Online e-mail, this is the first thing you should
check. If the mail does not work here, it is likely that the problem is due to something with _the account itself_.

This can be anything from an incorrect password if you cannot log in, to the
e-mail account being deactivated or deleted. **Deactivation** happens automatically
if you have not logged in for the last 6 months. You will find
help with these issues below.

If you cannot solve the problem, [contact us at customer service](/kundeservice/kontakt-oss/) so we can help you.

  * #### My e-mail is deactivated

It is currently not possible to reopen e-mail accounts on My Pages. If you want to
reopen your e-mail, [contact us at Customer Service](/kundeservice/kontakt-oss/) for further assistance.

  * #### Receiving a lot of spam and unwanted e-mail

The most important thing to avoid a lot of spam is how you use - and where you leave
your e-mail address on the internet. You can learn more about this here: [Avoid spam and
junk mail](https://www.telenor.no/privat/artikler/sikkerhet/unnga-soppel-epost/).

You can also do this: **

Report spam and unwanted e-mail:**

The most important thing you can do is report spam and unwanted e-mail in Online
e-mail.

This flags senders and content so that you and other users will not receive
unwanted e-mail from these senders.

**Here's how:**

    1. Log in to [Online e-mail](https://www.online.no/) on PC or Mac

    2. Click on an e-mail. Check the box to the left of the e-mail(s) in question.

    3. Click on the stop sign.

    4. Now the e-mail(s) are moved to the spam folder and the sender is reported.

**Change Spam Filter Strength:**

* ***** _All users of Online e-mail have now had the spam filter adjusted to "Strong". If you experience that important e-mail ends up in the spam box, you can adjust the filter back to "Standard" again._

    1. Log in to [online.no](https://www.online.no/) from PC or Mac

    2. Click on the **settings wheel ⚙** on the left side of the screen

    3. Select **Spam**

    4. Set Filter Strength to **Strong** / **Standard**

    5. To move Spam to a separate folder, we recommend that **Filter Effect** is set to **Quarantine**

    6. Make sure that **authentication for incoming e-mail** is enabled (Important)

    7. Click **Save**

[Open Online e-mail](https://www.online.no/)

  * #### Cannot adjust my storage amount

Unfortunately, we have some technical challenges that make it impossible to
adjust the storage amount you have on Online e-mail.

We sincerely apologize for this and are working on solutions to the problem!

**Short-term solution:**
If you have run out of storage space, we recommend deleting e-mails such as
Newsletters, Spam and e-mails with large attachments. Remember to empty the trash
afterwards.

  * #### Set default folders

**Here's how:**

    1. Log in to your e-mail at [Online.no](https://www.online.no/)

    2. Click on the **settings wheel** ⚙ on the left side

    3. Click **Advanced**

    4. Find **Folder Structure** and select the option that is relevant to you is _(AppleMail for iPhone and Outlook are widely used)_ in the drop-down menu

    5. After you have done this, you may need to set up your e-mail account again in your e-mail reader, so that everything is updated. Here you get [help setting up the account](/kundeservice/e-post/oppsett/index.page).

  * #### Received notification about Telenor's Sender Policy Framework (SPF)?

Sender Policy Framework (SPF) prevents spoofing and abuse of your
e-mail address. This is done by the recipient system verifying that the e-mail
is sent from one of Telenor's approved servers. If this cannot
be verified, the message will be rejected.

To ensure that your messages are accepted, you must use Telenor's own SMTP
servers: **smtp.online.no**

[See how to set up e-mail with the correct server and
settings](/kundeservice/e-post/oppsett/).

  * #### Error message: "554 5.7.1 Your email sending is blocked. ..."

For security reasons, it will not be possible to send e-mail with
Telenor e-mail (@online.no) without being logged in with a password. This
means that [your e-mail program must be set up with the correct settings, username and password to work](/kundeservice/e-post/oppsett/).

For a transition period, it will be possible to send e-mail without a password
on the outgoing server, but the number of e-mails you can send each day will be limited. If you send more e-mails, you will receive an error message that says: _"554 5.7.1 Your email
sending is blocked. Configure your client with username and password to send
more mails."_

Have you forgotten your password?

    1. Open [Telenor My Pages](https://www.telenor.no/mine-sider/)

    2. Log in or create a TelenorID (You do not need to be a Telenor customer)

    3. Select **Go to e-mail** under **Services**

    4. Select **Change password** for the desired account and the instructions

  * #### Windows Live Mail has stopped working?

This is because the security certificate of the old e-mail program is no longer
updated. To be able to send e-mail, you must therefore switch e-mail program
_(outlook, thunderbird, windows live etc.)_ or use [online webmail](https://www.online.no/).
