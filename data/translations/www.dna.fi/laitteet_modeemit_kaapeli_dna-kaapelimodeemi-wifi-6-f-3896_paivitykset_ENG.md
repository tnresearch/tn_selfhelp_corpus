## Updates

#### Release date of new version FAST3896_DNA_sw18.83.15.17e-14 is 4.3.2024

(Note: the modem will only update to the new software when the device is restarted)

  * Security fixes
  * DHCPv6 server and IPv6 disabling have been made possible
  * Increase of maximum WiFi client count from 32->64
  * Other general improvements

#### Older updates:

**FAST3896_DNA_sw18.83.15.17e-9 release date 3.7.2023**

(Note: the modem will only update to the new software when the device is restarted)

  * Fix for port forwarding
  * Other general improvements

**FAST3896_DNA_sw18.83.15.17e-8, release date 6.6.2023**

  * DHCPv6 settings
  * Change in bridging settings (can bridge the 2.5G port separately)
  * Guest-Wifi works via extender
  * Access to the management page in bridging mode
  * Language corrections
  * Other general improvements
