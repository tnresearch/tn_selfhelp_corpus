## Features

### DNA Travel Modem 4G WLAN MF910

Product name: ZTE MF910

High-quality WLAN Modem. Includes a WLAN network for ten users and 4G network support.  
The battery makes it easy to move around and the large screen makes usage unprecedentedly easy.

• 4G LTE maximum speed from the network 150 Mbit/s

• 4G DC maximum speed 42 Mbit/s

• HSPA+ maximum speed 21.1 Mbit/s

• WLAN b/g/n

• 10 WLAN devices, adjustable WLAN network range

• 1800 mAh battery and large 5-line LCD screen

• MicroSD memory card slot (up to 32 GB), also works over WLAN

• TS9 connector for external antenna

• Mini-SIM card, i.e. a normal-sized SIM card

• Automatic wireless network WPS setup, updates from the internet

• Support for IPv6.

### Hardware requirements / Supported operating systems:

  * USB connection: Windows® 10, Windows® 8 / 8.1, Windows® 7, Vista, XP SP2/SP3, Mac OS X® 10.7
  * WLAN: 802.11b/g/n/ac
  * USB Slot 1.1 or 2.0
  * Internet browser via USB connection or WLAN: Microsoft Internet Explorer 6.0 or later, Firefox 2.0 or later, Safari 4.0 or later, Opera 10.0 or later, Chrome 5.0 or later
