## Getting Started

Getting the Home Modem up and running

  1. Make sure you are using the correct type of SIM card.
  2. Open the cover of the nano-SIM card slot on the bottom of the modem.
  3. Carefully insert the nano-SIM card into the designated slot in the orientation shown in the picture, so that it clicks into place. Then close the nano-SIM card slot cover.
  4. Connect the power cord to the power outlet and the modem.

The following indicator lights will illuminate when the modem has connected to the network.

**NETWORK indicator light**

  * Solid blue light: the device is connected to a 3G/4G network.
  * Solid white light: the device is connected to a 5G network.

**Note:** If the NETWORK indicator light is red, there is no network connection.

  * The Home Modem uses a NANO-SIM card size
  * Remove the nano-SIM card by gently pressing it inwards until it clicks. The card will automatically pop out.
  * Do not insert or remove the nano-SIM card while the modem is running, as this may affect performance or damage the nano-SIM card.

Wireless network connection information for the Home Modem

DNA Home Modem supports 2.4 GHz and 5 GHz wireless WiFi networks.
By default, the modem is in a mode where it primarily connects to the 5
GHz WiFi network. When this mode is active, the 2.4 GHz and 5 GHz networks share
the same wireless network name and the wireless connection is primarily established
to the 5 GHz WiFi network if the devices connecting to the network support that
frequency band. If you want to make sure that your device is definitely connected to the 5
GHz WiFi network, you can disable the mode by following the instructions here.

## Connecting the Home Modem to a Wireless Network with Different Devices

Windows 10

On a Windows 10 computer, click the WiFi network signal bars in the bottom right corner of Windows.

NOTE. The WiFi network name of the modem is in the format DNA-WIFI-XXXX, unlike the images.

Then select the network whose name is on the label on the bottom of the modem (SSID). Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. The password is on the label on the bottom of the modem (Password). Enter the password exactly as it is on the label and press **Next**. Now you can start using the internet.

Windows Vista or Windows 7

On Windows Vista and Windows 7 computers, click the WiFi network signal bars in the bottom right corner of Windows.

NOTE. The WiFi network name of the modem is in the format DNA-WIFI-XXXX, unlike the images.

Then select the network whose name is on the label on the back (SSID). Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. The password is on the label on the bottom of the modem (Password). Enter the password exactly as it is on the label and press OK. Now you can start using the internet.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select the gear icon (settings). Next, select the signal bars.

NOTE. The WiFi network name of the modem is in the format DNA-WIFI-XXXX, unlike the images.

Then select the network whose name is on the label on the back (SSID). Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. The password is on the label on the bottom of the modem (Password). Enter the password exactly as it is on the label and press Next.

If you want to share files between devices, select the lower option. If you do not want to share files between devices, select the upper option.

MAC

Click the WiFi network icon at the top of the screen with the mouse. Then select the network whose name is on the label on the bottom of the modem (SSID).

NOTE. The WiFi network name of the modem is in the format DNA-WIFI-XXXX, unlike the images.

Next, the computer will ask for the wireless network (Password). The password is on the label on the bottom of the modem. Enter the password exactly as it is on the label on the bottom of the modem. Click **Remember this network** and press **Join**.

Apple iPad

  1. Select Settings from the desktop.
  2. Select Wi-Fi from Settings (on older iPad devices, the item is marked WLAN).
  3. Wait a moment for the iPad to search for networks. Then select the network whose name is on the label on the bottom of the Home Modem (SSID).
  4. Next, the iPad will ask for the wireless network password. Then select the one whose name is on the label on the bottom of the Home Modem (Password).
  5. Press **Join**. Now you can start using the internet.

Android Tablet

  1. Go to the view where you see all the apps.
  2. Select **Settings**.
  3. Select Wi-Fi (Wireless & networks on older Android tablets)
  4. Wait a moment for the tablet to search for networks. Then select the network whose name is on the label on the bottom of the Home Modem (SSID).
  5. Next, the tablet will ask for the wireless network password. Then select the one whose name is on the label on the bottom of the Home Modem (Password).
  6. Press **Connect**. Now you can start using the internet
