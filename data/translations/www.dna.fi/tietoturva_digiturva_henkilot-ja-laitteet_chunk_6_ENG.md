## Removing DNA Digiturva

Releasing the License

1. Open DNA Digiturva and select the **People and Devices** section.

2. Select your profile from the list. If you do not have child profiles,
only your profile will be listed.

3. You will see all your protected devices, select the device whose license you want
to release.

  * On a mobile device, you may need to scroll the list sideways if you have multiple devices. You can see all devices by scrolling to the end and pressing **All**.

4. Press **Release Access**.

5. Confirm that you want to remove access from the device and
press **Release Access**.

6. Access has been removed from the device and it is free
to be used with another device.

Removing from an Android Device

1. Open DNA Digiturva.

2. Select **your profile** from the top right corner.

3. Press **Settings**.

4. Scroll down and press **Uninstall**.

5. Press **OK**.

6. The DNA Digiturva application has now been removed. DNA Digiturva no longer protects
the device. Note that this does not deactivate the license.

Removing from an iPhone or iPad

1. Open DNA Digiturva.

2. Select **your profile** from the top right corner.

3. Press **Settings**.

4. Scroll down and press **Uninstall**.

5. Press **OK**.

6. The DNA Digiturva application has now been removed. DNA Digiturva no longer protects
the device. Note that this does not deactivate the license.

Removing from a Windows Computer

1. Search for DNA Digiturva using the search function in the taskbar.

2. DNA Digiturva information and functions will open on the right side, select
**Uninstall** from there.

3. This will open the Installed Apps view. Search for DNA Digiturva again
from the apps.

4. Press the **three dots** on the right side of DNA Digiturva and select
**Uninstall**.

5. The computer will confirm that you want to remove the application. Press **Uninstall**.

6. Allow the application to make changes by pressing **Yes**.

7. DNA Digiturva will confirm if you want to remove the application, press **Uninstall**.

8. The computer will uninstall.

9. The DNA Digiturva application has now been removed. DNA Digiturva no longer protects
the device. Note that this does not deactivate the license.

Removing from a Mac Computer

1. Open the folder where you installed the product. The product is by default
in the Applications folder.

2. Double-click the product's **Uninstall icon**. The uninstaller
program will start.

3. Select **Uninstall**. Removing the product requires
an administrator password.

4. Enter the administrator username and password and select **OK**.

5. The DNA Digiturva application has now been removed. DNA Digiturva no longer protects
the device. Note that this does not deactivate the license.

Cancelling DNA Digiturva

DNA Digiturva can be cancelled through customer service or by logging in to
dna.fi.

**Cancelling Digiturva on dna.fi**

1. Press **Log in** on the dna.fi page.

2. Log in by authenticating.

3. Press your profile picture and select **Subscriptions and Services**.

4. Select **DNA Security Services**.

5. Select **cancel the agreement**.

6. Select the reason for cancellation and press **Cancel the agreement**.
