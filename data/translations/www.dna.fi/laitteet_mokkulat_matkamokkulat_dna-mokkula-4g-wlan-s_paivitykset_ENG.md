## Updates

The device's software is no longer actively updated. We recommend replacing it with a new device to ensure that security and performance are up to date.

### Critical Fix Update

A bug was discovered on 23.3 that prevents internet operation. The bug is identified by the fact that the device automatically restarts itself around the 1.5-minute mark.

  
DNA strongly recommends purchasing a new modem. The AC762S device is over five years old and therefore clearly outdated technology.

The user experience will improve significantly with a new modem.

  1. 4G speed increases significantly, in many cases even doubling, as new modems have Carrier Aggregation feature.
  2. The wireless network (WLAN / WiFi) covers a wider area and is significantly faster.

**The update below fixes the problem. The update is done as follows:**

  1. Download the update package to a Windows computer [here](/documents/753910/853450/AC762S_kriittinen_paivitys.exe/f61befbc-b5ca-e7c6-1918-2a428f9de2f7)
  2. Remove the SIM card from the AC762S modem
  3. Connect the modem to a Windows computer with a USB cable
  4. The modem will install connection drivers on the computer. If the installation does not happen automatically, open "My Computer" and double-click "Tru-install"
  5. Once the installation is complete, double-click the update package you downloaded in step one
  6. The computer screen will display the text "Insert device and click Start to begin configuration". Click Start.
  7. The screen will show "Configurating device" and a progress bar. The update will take a few seconds.
  8. The device is now updated. The screen will read "Configuration successful. Insert another device to configure Or Exit to quite program". Now press Exit.
  9. Re-insert the SIM card into the modem.

Now the AC762S will work normally.

NOTE: If the update program cannot update the modem and a separate firewall and/or antivirus program is installed on the computer, try disabling it during the update. If you have to temporarily remove the antivirus program, make sure the SIM card is removed from the modem. This way, the computer cannot connect to the internet.
