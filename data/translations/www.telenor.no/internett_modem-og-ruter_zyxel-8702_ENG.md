# Help with Zyxel P8702N

Here you will find information about the router and guides for connection and
settings.

## About Zyxel P8702N

Zyxel P8702N is a wireless router modem with built-in antennas. WiFi signals
are sent on both 2.4 Ghz and 5 Ghz, which provides both good range
and speed on WiFi. The router works in combination with all our
broadband technologies. The router also supports all speeds and
broadband telephony. By default, the router uses a secure encryption of
the password, called WPA2.

Did you know that Telenor offers a brand new router and WiFi extender? Read more about
[our new equipment](/privat/internett/alltid-wifi/).

  * #### What do the lights on the Zyxel P8702 mean?

 **POWER:**

    * Blue = Connected to power

    * Blinking blue = Modem testing in progress

    * Red = Error detected after test

 **DSL:**

    * Green = Connected to VDSL

    * Yellow = Connected to ADSL

 **WAN:**

    * Green = Connection with fiber box

    * Dark = No connection with fiber box

 **INTERNET:**

    * Green = Connected to internet

    * Red = Not connected to internet

 **ETHERNET 1-4:**

    * Yellow = Lights up when there is a 100Mbit/s connection

    * Green = Lights up when there is a 1000Mbit/s connection

 **WIRELESS:**

    * Blue = WiFi is active

 **PHONE 1:**

    * Solid green = Broadband telephony is connected

    * Blinking green = Handset is off or phone is in use

  * #### Forgotten password for the wireless network?

The wireless network is pre-configured from Telenor. On a label on the underside
of the router you will find the network name (SSID) and network password (WPA2).  
  
If you have changed or want to change the network name or password, you can
easily do so from My WiFi: [wifi.telenor.no](https://wifi.telenor.no)

  * #### Turn WiFi on or off?

Button to activate lights/WiFi (click once to activate the lights and then
once to turn WiFi on or off).  
NB: After about 30 minutes, all lights except POWER will be turned off. WIRELESS
will also continue to light up if you have wireless on.

  * #### Internet from another broadband provider?

Zyxel P8702N is intended to be used with broadband provided by Telenor. When using
broadband provided by other providers, the functionality of the router may therefore
be limited. Such limitation will be related to access
to manage settings as well as the router not receiving software and
security updates. Telenor's customer support assumes that the router is
connected to broadband from Telenor.

  * #### Details about the router

 **Dimensions:**  
200 x 150 x 100 mm

 **WiFi standard:**  
802.11b/g/n on 2.4 Ghz and 802.11a/n/ac on 5 Ghz

 **Standard encryption:  
** WPA2 PSK (Can be changed to WPA, WPA+WPA2)

## Manage your router in My WiFi

Do you want to change the settings on your router, such as changing the network name
or password? You can do this by logging in to My WiFi, at
<https://wifi.telenor.no/>

To log in, you must be connected to your home network, and you log in
with the admin password that you find on the sticker under your router.
