## Ominaisuudet

**Tuotenimi: Huawei E5186**  
  
DNA Kotimokkula 4G+ WLAN E5186 on tehokas 4G-mokkula, joka jakaa verkon
langattomasti tai Ethernet-kaapelilla. Kotimokkulassa on 4 kpl Ethernet-
portteja.

  * 4G LTE enimmäisnopeus verkosta 300 Mbit/s
  * 3G DC enimmäisnopeus 42 Mbit/s 
  * HSPA+ enimmäisnopeus 21,1 Mbit/s
  * WLAN b/g/n/ac
  * 4 kpl RJ-45 Ethernet-liitäntää, max. nopeus 1000 Mbit/s.
  * USB
  * 32 WLAN-laitetta 
  * Kaksi liitäntää ulkoisille antenneille, liitäntätyyppi SMA
  * Mikro-SIM-kortti

### Myyntipaketin sisältö:

DNA Kotimokkula 4G+ WLAN E5186, virtalähde, pikaopas, Ethernet-kaapeli, 2
lisäantennia.

### Laitteistovaatimukset / Tuetut käyttöjärjestelmät:

  * WLAN: 802.11b/g/n/ac
  * RJ45 liitäntä Ethernet-kaapelilla
  * Tuetut käyttöjärjestelmät: Windows XP SP2/SP3, Vista SP1/SP1, Windows 7, Windows 8 / 8.1, Windows 10, MAC 10.5
  * Internetselain hallintaa varten: Microsoft Internet Explorer 6.0 tai uudempi, Firefox 2.0 tai uudempi, Safari 4.0 tai uudempi, Opera 10.0 tai uudempi, Chrome 5.0 tai uudempi
