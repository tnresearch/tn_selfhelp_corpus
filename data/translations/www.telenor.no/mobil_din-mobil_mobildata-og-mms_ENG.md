# Troubleshooting Mobile Data or MMS Issues

We can help you find a solution if the internet or MMS isn't working when you're connected to the mobile network.

[Manual MMS Settings](/kundeservice/mobil/din-mobil/mobildata-og-
mms/#manuell)

## Causes of Problems

When you want to use the internet over the mobile network, coverage isn't the only thing that matters. The internet works with all types of coverage, but weak signals or fluctuating coverage can make the network feel unstable or slow.

If you're unsure about the coverage in your area, you can [look up the address in the coverage map](https://www.telenor.no/dekning/#dekningskart) and check if any errors have been reported there.

If the coverage appears to be good, the next step is to check your mobile's settings and your mobile subscription.

## 1. Check that Mobile Data is Activated

MMS depends on mobile data being activated on your mobile, and cannot be sent over WiFi. If an MMS message doesn't load on your mobile (e.g., the mobile is turned off or out of coverage), we will attempt to deliver it for 24 hours. After 24 hours, the MMS will not be delivered.

Mobile data must also be activated for the internet to work when you are not connected to WiFi.

**Don't forget roaming!** If you are outside of Norway, or the EU/EEA, you should check that **Data Roaming** is activated. This setting allows you to use mobile data when you are traveling. In the EU/EEA, you can use your mobile just like at home.

[Read more about prices abroad](https://www.telenor.no/privat/mobil/utlandet/)

  * #### Activate Mobile Data on iPhone

    1. Go to **Settings**

    2. Select **Cellular**

    3. Activate **Cellular Data** using the switch on the side

Data Roaming is activated under **Cellular Data Options.**

  * #### Activate Mobile Data on Android

    1. Go to **Settings**

    2. Select **Connections**

    3. Select **Data Usage**

    4. Activate **Mobile Data** using the switch on the side

Data Roaming is activated under **Mobile Networks** after Connections.

## 2. Check Usage and Restrictions

If mobile data is activated and everything looks fine, it may be wise to check that you haven't used up the mobile data available on your subscription. You can easily see this in the [My Telenor app](https://www.telenor.no/privat/mobil/app/mitt-telenor/) or on My Pages. If you have used up your mobile data, you can upgrade to a subscription with more data or order a data package that applies to the current month. [See an overview of all our subscriptions](/mobilabonnement/)[.](https://www.telenor.no/privat/mobil/mobilabonnement/)

Your mobile subscription may also be blocked from data usage with a blocking service. Look for _Blocking of all data traffic_ on My Pages or the _Safe Child_ service.

  1. [Log in to My Pages](https://www.telenor.no/minesider)

  2. Select **Mobile and Subscription**

  3. Select the subscription you want to check

  4. Select **Settings**

  5. Select **Restrictions**

  6. Add or remove restrictions as desired

If you have Safe Child activated and want access to mobile data, you can replace it with Safe Use. Safe Use contains the same restrictions as Safe Child with the exception of blocking the use of the internet on your mobile.

[Read more about Safe Use and Safe Child](https://www.telenor.no/privat/mobil/mobiltjenester/sikkerhet/)

## 3. Check Settings and Configuration

For MMS and mobile data to work, the correct configuration must be set up on your mobile. The configuration is retrieved automatically on most mobiles.

In some cases, however, the configuration may fall out or stop working. This can happen, for example, if you have recently been traveling, or if you have moved your mobile subscription to Telenor from another operator. In such cases, the configuration can be entered manually or retrieved automatically by resetting the network settings on your mobile.

Manual Settings

  * APN/Access Point Name: telenor.smart

  * MMS proxy: mms-proxy.telenor.no

  * MMS port: 8080

  * MMSC: http://mmsc

  * MCC: 242

  * MNC: 01

  * Authentication type: PAP

  * APN protocol: IPv4/IPv6

The settings you need to fill in depend on the type of mobile. Some mobiles also require that the MMS proxy and port are combined in this way: mms-proxy.telenor.no:8080

## How to Retrieve Configuration Automatically

  * #### Reset Network Settings on iPhone

    1. Go to **Settings**

    2. Select **Cellular**

    3. Select **Cellular Data Network**

    4. Scroll down and select **Reset Settings**

    5. Select **Reset**

Resetting network settings is not the same as resetting the entire mobile. You will therefore not lose any content on your mobile, but WiFi and Bluetooth must be reconnected. Configuration for mobile data and MMS is automatically retrieved with the correct settings from the operator.

  * #### Reset Network Settings on Android

    1. Go to **Settings**

    2. Select **Connections**

    3. Select **Mobile Networks**

    4. Select **Access Point Names**

    5. Select **Reset to default**

    6. Select **Reset**

Note that the procedure may vary slightly from mobile to mobile. Check the user manual if you cannot find the options. Configuration for mobile data and MMS is automatically retrieved with the correct settings from the operator.
