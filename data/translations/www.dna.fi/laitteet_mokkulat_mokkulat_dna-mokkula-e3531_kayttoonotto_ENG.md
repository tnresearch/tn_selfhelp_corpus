## Getting Started

## Installing the Modem

The modem uses a standard Mini-SIM card, which is the largest card size. The SIM card comes off without much force when you press it from the back of the SIM card. If you remove a SIM card of the wrong size, visit a DNA Store to exchange it for a new SIM card.

The SIM card is installed under the cover on the front of the modem. Lift the back cover from the front of the modem and install the SIM card into the modem with the metal part facing down, and finally close the cover. Note! Lifting the cover may require a considerable amount of force.

Registering to the DNA network takes a few minutes. If the connection fails to open, call DNA's [customer service](https://www.dna.fi/yhteystiedot#asiakaspalvelu).

The internet connection is available when the power light and network status indicator light are on in the modem.

## Enabling Wireless Network or Wi-Fi

Windows 10

DNA Modem E3131 supports the Windows 10 operating system, but installation must be done manually. Connect the modem to the computer's USB port and follow the instructions in the attached appendix.

[See the instructions](/documents/753910/853450/K%C3%A4ytt%C3%B6opas+Huawei+E3131.pdf/77895678-f186-eafa-04b1-8cc236b5ad1d).

Windows XP, Vista, Windows 7 and MAC computers

1\. Connect the modem to the computer.

2\. Installation starts automatically. Note! If the installation does not start automatically, open **My Computer** and the CD drive named **DNA Net**. Click the file named **DNA Net.**

3\. Installation begins. Accept the license agreement by pressing **I Accept.**

4\. DNA Net installs itself and the internet connection is established automatically.

5\. The default PIN code for the DNA Net application is 1234. If your PIN code is something else, enter the PIN code.

Now you can use the internet.

Windows 8

1\. Connect the modem to the computer.

2\. Open network connections from the bottom right corner of Windows by clicking on the signal strength bars icon.

3\. Select Mobile Broadband / Wireless Broadband. Click the Connect button.

4\. Enter the PIN code, the default is 1234. Press Next.

5\. Now the connection works. In the future, the PIN code must be entered from this point.

## Tips if Installation Fails

  * Try a different USB port.
  * Remove the old USB modem connection program through the Add/Remove application in the computer's control panel. Then restart the computer and then connect the modem to the computer.
