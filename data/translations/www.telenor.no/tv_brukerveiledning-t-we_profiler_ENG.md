# How to Use Profiles with T-We

Profiles allow you to customize content for everyone in the family. Here, we'll help you create, change, set age restrictions, or switch between profiles in the TV menu.

Profiles: This is what it looks like when you have selected the profile icon from the TV menu.

## Create a New Profile

  1. Press the button labeled MENU or T-We on the remote control, depending on which remote you have.

  2. Select the profile icon at the top left.

  3. Select **New Profile** and press **OK**.

  4. Give the profile a name and select the profile type.

  5. Press **Create**.

Settings such as language, color, age restriction, and permissions can be set before you press "Create", or you can go back and change the settings later.

 **NOTE!** If you want to prevent access to the profile, the **PIN-protected** option must be set to **Yes**. You will then also be required to enter a PIN code when logging into the profile.

## Switching Between Profiles

The active profile is always visible at the top right of the screen. To switch profiles, select the profile icon from the menu and select the profile you want under "Select Profile".

 **Profile Selector at Startup:**

When you start up the TV box, you will be prompted to select the desired profile. Here you can uncheck the box to prevent this selection from appearing every time you start up the TV box. If you do this, the TV box will select the profile you used last upon next startup.  
You can also remove this pop-up like this:

  1. Go to settings

  2. Select Profiles

  3. Change from “Yes” to “No” on "Show profile selector at startup".

## Profile Types in T-We

The first time you set up your T-We box, you have access to two profiles: Owner and Kids. Owner is an administrator profile, while Kids is tailored for children.

All profiles except Kids have access to use a PIN code. You will be prompted to enter this when you want to change certain settings, rent a movie, or unlock content that is restricted for other reasons.

The profile type and age restriction you have chosen determine what access you have.

PIN Code

Most changes require you to be logged in as Owner or have access to the PIN code set on the Owner profile from a standard profile.

You can find more [information about the PIN code for
T-We](/kundeservice/tv/brukerveiledning-t-we/pin-kode/).

## Owner

Has access to all content with a PIN code. The profile cannot be changed or deleted.

## Kids

Does not have access to content that requires a PIN code, except for movie rentals. If you have questions about the PIN, you must switch to Owner or a standard profile.

## Standard

Has access to all content with a PIN code except for settings in the Owner profile.

## Age Restriction on Profiles

You can change the age restriction on any profile, but Kids is locked to either 6, 9, or 12 years. By default, the age restriction for Kids is set to 6 years, which means that content with a higher age restriction will be unavailable to the user.

 **How to change the age restriction:**

  1. Press the MENU button or T-We on the remote control, depending on which remote you have.

  2. Select the profile icon at the top left.

  3. Press the pencil icon under the profile you want to change.

  4. Select **Change Profile**.

    * Enter the PIN code for the profile if it has its own PIN protection.

  5. Select **Age Restriction** and change to the desired limit.

 **  
**If you set the age restriction on the profile to 18+ you will not be prompted to enter a [PIN code](/kundeservice/tv/brukerveiledning-t-we/pin-kode/) for age-rated content.

 **NOTE: Age restriction on profiles does not apply to streaming services.** These have their own profile settings, and you must set your own limits in the various services.

## Delete a Profile

  1. Press the MENU button or T-We on the remote control, depending on which remote you have.

  2. Select the profile icon at the top left.

  3. Select the pencil icon on the profile you want to delete.

  4. Enter the PIN code for the profile if it has its own PIN protection.

  5. Select **Delete Profile**.
