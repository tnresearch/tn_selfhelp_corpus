## APN Settings for Modems and Terminal Devices

### Public IP and NAT Address Change

DNA has changed its APN settings on the consumer side in December 2016. All
new subscriptions and therefore Modems are delivered with APN default settings
with NAT address change from the network side. However, if the user feels
they need a public IP from the network side, this can be easily done
by changing the terminal device's APN settings. A public IP may be needed
for example with a home server, game server or security cameras.

By default, since December 2016, the APN address with NAT address change
enabled is:  
  
**internet**  
  
To obtain a public IP, the user must change the following APN address in their
network device (Modem, mobile router,  
SIM card camera, router etc.):  
  
**julkinen.dna.fi**  
  
If the subscription was acquired before December 2016, it may have the APN
address below, which  
still produces a public IP:  
  
**data.dna.fi**  
  
**NOTE!** **data.dna.fi** is always recommended APN when the modem has a
corporate subscription. And for consumer subscriptions,  
when the subscription was acquired before December 2016.  
  
**NOTE! The change does not apply to corporate subscriptions.**
