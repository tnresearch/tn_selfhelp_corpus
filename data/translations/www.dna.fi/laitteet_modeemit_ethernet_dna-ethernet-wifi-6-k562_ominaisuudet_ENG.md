## Features

The modem can be used as the main home modem for an ethernet connection. The modem acts as the first mesh point and can be expanded with one or more DNA Ethernet and Mesh WiFi 6 K562 modems. To ensure a high-quality WiFi network, it is not recommended to connect more than four devices.

The DNA Ethernet and Mesh WiFi 6 K562 modem is compatible with the DNA Kotimokkula 5G WiFi H158, in which case the H158 acts as the first mesh point. Additionally, the K562 is compatible with the DNA Mesh WiFi WA8021V5, in which case it is recommended to use the K562 as the first mesh point and the WA8021V5 as an extender. With other modems or hotspots, you will need at least two K562 modems to create a separate Mesh WiFi network for extension.
