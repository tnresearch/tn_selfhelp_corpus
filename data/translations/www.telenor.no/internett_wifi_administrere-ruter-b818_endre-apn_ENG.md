# Change APN

APN stands for Access Point Name and is a setting that determines how
the router connects to the mobile network.

## Log in to the router

  1. Open a browser (e.g. Google Chrome) on the device connected to the router.

  2. Enter 192.168.1.1 in the address field and search

  3. Enter the password. 

The password is the same as your original wireless password. You can find it
on the sticker on the back of the router after **WIFI**.  
**Note:** If you have changed the password to the menu yourself, enter the one you
have chosen.

## When you are logged in

  1. Select **Network Settings**

  2. Select **Mobile Network**

  3. Select **Internet Connection**

  4. A list of APNs will appear. Press the + icon and enter a new APN  
Note: Telenor uses _telenor.smart_ as the APN. If you need to open ports, you should
use _telenor.fwa_.

  5. If you need to open ports, enter telenor.fwa in "Profile Name" and "APN"

  6. Press **Save**

  7. Turn the router off and on using the power switch on the back
