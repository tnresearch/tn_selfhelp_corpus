## Getting Started

## Installing the Modem

Install the SIM card into the modem's SIM card slot by first removing the back cover and the battery. After installing the SIM card, put them back in place.

If the modem does not start with the power button, its battery may be empty. Connect the included power cord to the device and the other end of the power adapter to the wall socket.

Place the modem as close to the window as possible. This way, the connection speed will be the best possible.

On your computer, tablet, or mobile phone, select the WiFi network and password. You can find them on the modem's display.

If necessary, change the settings in these instructions, and find the best location for the modem, considering the locations of both 4G base stations and the devices you are using.

Registration with DNA's internet takes a few minutes. If the connection fails to open, call DNA customer service.

The internet connection is available when the power light and network status indicator light are on in the modem (in a color other than red). If the modem has a display, you will see an icon indicating the signal on the display.

You can change the device settings either directly on the device's display or in the management page using the browser on your device. Link to "Locking the Travel Modem to a 4G or 3G network."

## Enabling Wireless Network (WiFi)

DNA modems are encrypted in terms of wireless network. You can find the network name and password on the modem's display or on the sticker under the battery.  
  
SSID (network name)  
Example. DNA-Mokkula-2G-XXXXX and DNA-Mokkula-5G-XXXXX  
  
Password  
Example. 12345678901

DNA Travel Modem supports 2.4 GHz and 5 GHz wireless WiFi networks. 2.4 GHz is enabled by default. These are distinguished from each other by the 2G and 5G terms in the WiFi name (SSID).  
  
You can enable the 5 GHz WLAN frequency either on the modem's display or in the management pages. More information on enabling the 5 GHz frequency can be found here and here. Link to "Connecting to WiFi" and "Changing the WiFi network name and password"

Windows 10

On a Windows 10 computer, click the WLAN network availability bars in the bottom right corner of Windows.  
  
Then select the network whose name you see on the modem's display (SSID). Check the box next to **Connect automatically** and press **Connect**.  
  
Next, the computer will ask for the wireless network password. You can find the password on the modem's display. Enter the password exactly as it appears on the display and press **Next**. Now you can start using the internet.  

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select **Settings** (gear icon). Next, select the availability bars.  
  
Then select the network whose name is on the sticker on the bottom of the modem.  
  
Check the box next to **Connect automatically** and press **Connect**.  
  
Next, the computer will ask for the wireless network password. You can find the password on the sticker on the bottom of the modem. Enter the password exactly as it is and press **Next**.

Windows 7 / Vista

On a Windows 7 and Vista computer, click the WLAN network availability bars in the bottom right corner of Windows. Then select the network whose name is on the sticker on the bottom of the modem.  
  
Check the box next to **Connect automatically** and press **Connect**.  
  
Next, the computer will ask for the wireless network password. You can find the password on the sticker on the bottom of the modem. Enter the password exactly as it is and press **OK**.  
  
You can start using the internet.

Windows XP

On a Windows XP computer, click the computer icon in the lower left corner, which contains the symbols of the wireless network, as on a Windows 7 computer.  
  
Then select the network whose name is on the sticker on the bottom of the modem.  
  
Press **Connect**.  
  
Next, the computer will ask for the wireless network password. You can find the password on the sticker on the bottom of the modem. Enter the security key exactly as it is on the sticker and confirm the password again in the field below. Select **Connect**.

Mac OSX

Click the WLAN network icon at the top of the screen with the mouse. Then select the network whose name you find on the sticker on the bottom of the modem.  
  
Next, the computer will ask for the wireless network password. You can find the password on the sticker on the bottom of the modem. Enter the password exactly as it is. Select "Remember this network" and press **Join**.  
  
You can start using the internet.

Apple iPad

Select Settings from the iPad home screen. From settings, select Wi-Fi (WLAN in older models).  
  
Wait a moment while the iPad searches for networks. Then select the network whose name is on the sticker on the bottom of the modem.  
  
Next, the iPad will ask for the wireless network password. Enter the password exactly as it is on the sticker on the bottom of the modem. Press **Join**. You can start using the internet.

Android Tablet

Go to the view where you see all the apps.  
  
Select **Settings** and from the menu select **Wi-Fi** (Wireless & networks in older versions). Wait a moment while the tablet searches for networks. Then select the network whose name is on the sticker on the bottom of the modem.  
  
Next, the tablet will ask for the wireless network password. Then select the password whose name is on the sticker on the bottom of the modem.

## PIN Code

If the SIM card uses a PIN code other than 1234, the PIN code must be entered in the modem settings.

  1. Open a web browser when you are connected to the modem's WiFi network. 
  2. Type http://dna.mokkula or http://192.168.1.1 in the address bar. 
  3. The default username is **admin** and the default password is **1234**.
  4. Select **Settings** at the top and PIN code management from the menu below.
  5. Select **Security** on the left.
  6. Enter your desired PIN code in the **Enter PIN** field and press **Apply**.
