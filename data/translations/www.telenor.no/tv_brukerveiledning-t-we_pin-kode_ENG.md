# PIN Code for T-We

Your PIN code is linked to the Owner profile on T-We, but can also be set for
other profiles. Here we show you how to find, change, or
reset the PIN code.

## What is the T-We PIN Code?

 **The T-We PIN code is, by default, set to 1-2-3-4.**

If the code is not 1-2-3-4, this means you have changed the code to something you
have chosen yourself, or that a different code has been set for a new profile.

You need the PIN code, among other things, when you change [settings on the T-We
box](/kundeservice/tv/brukerveiledning-t-we/innstillinger/), [rent
movies](/kundeservice/tv/brukerveiledning-t-we/filmleie/) or [change and
delete profiles](/kundeservice/tv/brukerveiledning-t-we/profiler/).

## How to Change the PIN Code

  1. Press the button labeled MENU or T-We on the remote control depending on which remote control you have

  2. Select the profile icon at the top left

  3. Press the pencil icon under the profile you want to change

    * The pencil will first become visible when you navigate to the profile

  4. Select **Edit Profile**

  5. Select **Change PIN Code** and press **OK** on the remote control

  6. Enter the old PIN code

  7. Enter the new PIN code twice to confirm the change

Change PIN Code: Select the profile you want to change the PIN code for.

## Reset the PIN Code

Have you forgotten the PIN code for the Owner profile? You can reset it on My
Pages.

  1. [Log in to My Pages](https://www.telenor.no/mitt-telenor/tv-internett/twe/tilbakestill-twe-pin/)

  2. Select the TV subscription that applies

  3. Press **Reset T-We pin**

  4. The code is now reset to 1-2-3-4

 **Note!** If the code does not update, you can restart the T-We box by unplugging
the power. Wait 5 seconds before plugging the power back in.
