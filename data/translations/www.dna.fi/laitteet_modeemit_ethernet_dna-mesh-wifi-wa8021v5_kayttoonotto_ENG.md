## Getting Started

You can use the DNA Mesh WiFi modem in two different ways:

  * As the main modem for your home, or
  * In addition to the main modem for your home to create a wider wireless Mesh WiFi network

### Connecting the First DNA Mesh WiFi Modem:

If you have a connection cabinet in your apartment (often in the apartment's electrical cabinet), you can specify which of the apartment's network sockets your home internet connection comes from.

  1. Connect an ethernet cable from the ethernet socket in the room (internet input socket) or from a free LAN port of your main modem to a free LAN port of the DNA Mesh WiFi device.
  2. Connect the power cord to a power outlet and connect the other end to the DNA Mesh WiFi modem.
  3. The modem will start up automatically after connecting the power cord. Wait about a minute while the device starts up. The installation is correct when the status indicator light glows a steady white. The modem and internet connection installation is now complete.

### Connecting Multiple DNA Mesh WiFi Modems to a Seamless Mesh Network

You can use two or more DNA Mesh WiFi modems to create a comprehensive Mesh WiFi network:

  1. Install the first DNA Mesh modem according to the previous instructions.
  2. Once the first DNA Mesh WiFi modem is working, log in to the modem's management page in a web browser at dna.wifi/ or 192.168.101.1. When it opens, the management site will ask you to enter the default password 1234. 

After logging in, you can choose the wireless WiFi network name (SSID) and password you want for your mesh network. You can also continue using the default passwords of the first DNA Mesh WiFi modem, which you can find on the sticker on the bottom of the device, by selecting 'Skip'.

After this, you can start connecting more modems to each other.

  3. Place the second DNA Mesh WiFi device (i.e., the device used as a mesh access point) close to, no more than 2 meters from, the device used as a router (i.e., the first DNA Mesh WiFi modem) and connect the power cord of the device acting as a mesh access point to a power outlet.
  4. Wait about a minute after connecting power to the device used as a mesh access point.
  5. Check the indicator light on the device acting as a router. If the indicator light is flashing slowly, the router has recognized the mesh access point.
  6. Press the pairing button on the device acting as a router once. The indicator lights on both DNA Mesh WiFi devices will flash quickly. Wait for the indicator light on the mesh access point to start glowing a steady white. This is a sign that the pairing was successful.
  7. Unplug the device used as a mesh access point from the power outlet and move it to the location where you want the wireless connection to reach. Plug the device into the power. When the indicator light glows a steady white, the device is able to establish an internet connection. No further action is required.
  8. You can add more DNA Mesh WiFi devices to the wireless mesh network by repeating the steps described above.

## WiFi Network Name and Password

DNA Mesh WiFi modems are encrypted for WiFi network security. You can find the network name and password on the sticker on the bottom of the device and on the settings pages.

SSID (network name): E.g. **DNA-WIFI-XXXX** and **DNA-WIFI-5Ghz-XXX**  
Wireless network password: E.g. **25694177898**

The DNA Mesh WiFi modem supports 2.4 GHz and 5 GHz wireless WiFi networks. By default, the device has the 5Ghz network enabled, as well as a 2.4 Ghz and 5 Ghz combination network, so your device will choose which frequency to use. Choose 5 Ghz if you see this on your device for a better connection.

## Device Connections

  1. Ethernet ports. Connect an ethernet cable from the ethernet socket or another modem to any of the device's ethernet ports. Remember, you can connect, for example, a television or computer to the device from the ethernet ports.
  2. The reset button on the back of the device restores the modem to its factory settings. If you have forgotten the changes you made to the modem settings, for example, the password, press a sharp-pointed object (e.g., a straightened paper clip) lightly for over 2 seconds into the hole of the reset button on the back panel of the modem. Resetting the modem restores all original factory settings.
  3. Power connection to the device's own power adapter. 
  4. Pairing button.
