### Settings

Logging in to the Settings Page

When a computer or other terminal device is connected to the modem via a wired or wireless connection, all of its settings can be managed using a web browser. We recommend using Google Chrome and Safari browsers.

  1. Open a web browser and type 192.168.101.1 or dna.wifi/ into the address bar and press **Enter**.
  2. User Name is **admin** and password is **1234**
  3. Press **Login** and the modem settings pages will open.

You are now logged in to the modem settings pages. You can change the password from the **More** -> **System Management** -> **Account Management** menu.
From the settings pages, you can also change WiFi settings, network name, or even security settings, as well as update the device to the latest software version.

Changing the Password and Forgotten Password

All of DNA's wireless modems have the same default password, 1234. The password is required to change the device's settings. The password should be changed for security reasons so that outsiders cannot manage the modem. Once you are logged in to the settings pages, you can change the password as follows:

  1. Select **More** from the home page.
  2. Select **Account Management** from the **System Management** menu.   

  3. Enter your current password in the **Old Password** field. Then, enter your desired new password in the **New Password** field and again in the **Confirm Password** field. Finally, press **Apply**.

Turning off Bandsteering / Combination Network

Log in to the device settings page and select **My Wi-Fi**.

On the My Wi-Fi tab, you can choose whether the combination network (2.4 GHz & 5 GHz) is enabled. If you want to disable the combination network, select **OFF** in the **Dual-band Combination** option. Press **Apply** to save the changes.

After making the selection, you will have separate 2.4GHz and 5GHz networks, the settings of which you can change independently.

DynDNS

Log in to the device settings page and select **More**. Go to the Network Configuration -> DDNS Function tab.

Select **New**. Select **Enable DDNS** and fill in the required information in the fields. Finally, save the changes by pressing **Apply** at the bottom of the page.

Using the DynDNS service requires the user to have already created an account with a DynDNS service provider.

Port Forwarding

Log in to the device settings page and select **More**. Go to the **IPv4 Port Mapping / IPv6 Port Mapping** tab via the **Security Configuration** tab.

The modem has the UnPn tool enabled by default for port forwarding. For example, when playing games or using download programs, the user can also open ports manually.

**Making manual forwarding:**

Select **New** and fill in the IP address information. Then press **Add** and add the necessary port information. You can open more ports for the device by pressing the **Add** button. Finally, press **Apply** to accept the changes.

Viewing the Network Topology

When you have two or more DNA Mesh WiFi modems in use, you can view the topology view to see that the modems are optimally connected to each other. You can also check which modem your devices are connected to.

Log in to the device settings page and select **Terminal**. You will see a device list on the Terminal page. By default, devices that are online (Online devices) are selected. By selecting **Offline devices** from the drop-down menu, you can see devices that were previously online.

Press the **Currently in list mode, click to switch to Topo chart mode** icon to switch to the topology view. Press the same icon again to return to the device list.

Collecting Error Logs from the Device

Log in to the device settings page and select **More**. Go to the **Fault Info Collect** tab via the **Maintenance Diagnosis** tab.

Press **Start** to start collecting the logs. Once the logs have been collected, press the **Download** button, and the logs will be downloaded to your device as a collectFaultFinish.txt file.

Setting Parental Controls

Log in to the device settings page and select **More**. Go to the **Security Configuration** tab and then the **Parental Control Configuration** tab.

  * First, select the Template tab and create a rule for parental control

  1. Select **New** and define a name and time period for the Template. Press **Next**.
  2. Specify whether the parental control is valid all day or part of the day and the days of the week when it is valid. Press **Apply** to accept the settings. Press **Next**.
  3. In the next section, you can specify certain network addresses to which the blocking applies. Press **New** and enter the address. Press **Apply** to accept the changes. Press **Finish**.

  * Next, select the devices that you want to be subject to parental control.

  1. Go to the Overview tab and select **New**.
  2. Select the device, enter a description for the device, and select the Template to use. Press **Apply** to accept the changes.

## Changing WiFi Settings

You can easily change the wireless network settings on the modem settings page. These include the name, password, and security settings of the wireless network, or WiFi network.

The DNA Mesh WiFi modem supports 2.4 GHz and 5 GHz wireless WiFi networks. By default, the device has a 5 GHz network (DNA-WIFI-5Ghz-XXXX) and a 2.4 GHz and 5 GHz combination network (DNA-WIFI-XXXX) available, where your device chooses which frequency to use. We recommend using the combination network.

The settings for the 5 GHz and combination networks are changed in different menus on the settings page.

[ Watch the instructional video on how to change the WiFi network name and password ](https://youtu.be/Yae3bjIxf2k?si=xfPPzZpaNxd7ncMW)

Changing the Combination Network Settings

  1. Log in to the device settings page and select **My Wi-Fi** from the home page.
  2. A new window will open where you can change the WiFi network name (SSID) and password of the combination network.
  3. To change the WiFi network name, type it in the **Wi-Fi Name** field. To change the password, type it in the **Wi-Fi Password** field. Finally, press **Apply**.

Changing the 5 GHz Network Settings

  1. You can access the 5 GHz network settings through the combination network settings menu. Press **Click here for more 5G SSID configurations.** in the **My Wi-Fi** menu.
  2. A new window will open. Select **DNA-WIFI-5Ghz** in the SSID Index.
  3. To change the WiFi network name, type it in the **SSID Name** field. To change the password, type it in the **WPA PreSharedKey** field. Finally, press **Apply**.

## Device Information

Checking the Serial Number

Log in to the device settings page and select **More**. Go to the **System Info** tab and then the **Device Information** tab. The serial number is displayed under **SN**. You can also find the serial number on a sticker attached to the device.

Checking the Device Version

Log in to the device settings page and select More. Go to the System Info tab and then the Device Information tab. The device version is displayed under Software Version.

Checking the WAN MAC Address

Log in to the device settings page and select More. Go to the System Info tab and then the Device Information tab. The WAN MAC address is displayed under MAC.

Checking the Public IP Address

Log in to the device settings page and select Homepage. The IP address is displayed at the bottom of the page under Local IP Address.
