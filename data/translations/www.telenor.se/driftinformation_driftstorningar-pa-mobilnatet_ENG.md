# Mobile Network Disruptions

## Current Major Disruptions

Currently, we have no

major disruptions.

Do you have a disruption and need to call 112?

Remove the SIM card. If you have an e-SIM, temporarily disable it.

To disable e-SIM on iPhone, go to: Settings > Cellular  
To disable e-SIM on Android, go to: Settings > Network &
internet

Don't forget to turn your e-SIM back on when you are finished with your 112 call.

  
Call via broadband using Wi-Fi calling. Works if you are connected via a
broadband connection. This is a feature you can always have enabled.  
[More information is available here:](/support/mobiltelefoni/abonnemang/fler-
tjanster/wifi-samtal/)

Call via the 112 app. You need a mobile network or Wi-Fi to do so. If the mobile network is not working, you can call via the 112 app if you are connected
via a broadband connection. [You can download the 112 app here.
](https://www.sosalarm.se/112-och-andra-viktiga-nummer/112-appen/)

If you have home phone via broadband and there is a disruption on your
broadband, call via your mobile phone instead.

Tip!
