## Switching from an Old Device to a New Device

Installation on a new device

If you are using a password vault, see the instructions for synchronizing the password vault
before releasing and removing DNA Digiturva from your old device.

#### Available Free Licenses

  1. Install DNA Digiturva on the new device.
  2. Release your old device by following the instructions in the **Removing a License from an Old Device** section.
  3. Remember to also uninstall DNA Digiturva from your old device.

#### No Free Licenses Available

1\. Log in to the DNA Digiturva settings management via your browser [from this
link](https://safeavenue.f-secure.com/iframe/-sso/dna_fbb/).

  * Log in with a one-time password by pressing **Log in**.
  * Enter the email address used for your subscription and press **Request Password**.
  * You will receive a one-time password to the email address you entered. Type the code from the message into the One-Time Password field and press **Log in**.

2\. Press the device from which you want to release the license.

3\. Press **Release License**.

4\. Press **Release License** again.

5\. Remember to also uninstall DNA Digiturva from your old device.

Removing a License from an Old Device

1\. Open DNA Digiturva and select the **People and Devices** section.

2\. Select **your profile** from the list. If you do not have
child profiles, the list will only contain your profile.

3\. You will see all your protected devices, select the device whose license you want
to release.

  * On a mobile device, you may need to scroll the list sideways if you have multiple devices. You can see all devices by scrolling to the end and pressing **All**.

4\. Press **Release Access**.

5\. Confirm that you want to remove access from that device and
press **Release Access**.

6\. Access has been removed from that device and it is free
to be used with another device.

Password Vault Synchronization When Switching Devices

You must synchronize the password vault to your new device before removing DNA
Digiturva from your old device. Synchronize your passwords to the new device
from your old one using the following instructions:

  1. Install DNA Digiturva and log in.
  2. Press the **Password Vault** section.
  3. Select **I am already a user**.
  4. Open DNA Digiturva on the device that already has the password vault in use and log in to your password vault with your master password.
  5. If you are on a phone or tablet, select the gear icon in the upper right corner and press **Connect Devices**. On a computer, select **Connect Devices**.
  6. Select **Create Synchronization Code** if you are using a phone or tablet. On a computer, you will immediately see the generated synchronization code. If the code expires on the computer, press **Generate New Code Now**.
  7. Enter the code now into the new device and press **Connect**. 
  8. Then enter the same master password that you use on the other device and press **Confirm**.
  9. Your passwords are now available on the new device as well. You can enable auto-fill.

If you do not have free licenses available and the password vault is in use
on only one mobile device, you need to synchronize the password vault
to another device in use. If the password vault is only in use on the device being removed, you will no longer be able to access your passwords.

Password Vault Synchronization When All Licenses Are in Use

If you are in a situation where the password vault is in use on only one
device and your licenses are all used, you are at risk of losing
your saved passwords. **We recommend that the password vault is always
synchronized to two different devices.**

#### Password Vault in Use Only on a Computer

  * You can download your password vault's saved data through the password vault settings: Open the password vault's **Settings**, select **Export Passwords**, enter your master password and press **Confirm**, choose the folder where you want to save the file and press **Save**.
  * Send the file to yourself and set up the password vault as a new user on the new computer. You can access your passwords on the new computer by importing the old passwords through the password vault settings. Open the password vault settings, select **Import Passwords**, select **This Product** and select the file with the passwords you sent to yourself.

#### Password Vault in Use Only on One Phone or Tablet

**One device in your own use and another device with a child's profile**

  1. Synchronize the passwords to the child's device, remove the license from the old phone, download DNA Digiturva to the new phone, synchronize the passwords to the new device using the child's password vault.
  2. Once you have synchronized the passwords to the new device, you can leave the password vault on your child's device. However, make sure that biometric identification is not used to open the password vault if biometric identification is otherwise used on your child's phone. If you want to completely remove the password vault from your child's phone, you must uninstall and reinstall DNA Digiturva. 

**Two mobile devices in use with different password vaults**

  * You cannot download the data stored in the password vault as a separate file from mobile devices.
  * If the password vault has not been synchronized to another device, you will no longer be able to access it when you remove it from the device.
  * If your licenses are all used and you want to switch to another device, you must purchase additional licenses. We strongly recommend that the same password vault be used on at least two different devices so that you do not lose your data if the device breaks or is lost. 

Switching a Child's Device

  1. Release the license from your child's old device.
  2. Install DNA Digiturva on the new device and select your child's profile during installation.
  3. The new device is ready for use.
  4. Remove DNA Digiturva from the old device. See more detailed instructions on removing the application below.
