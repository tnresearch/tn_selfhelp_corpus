## Family Rules

Installation and setup on a child's computer

1\. **Install** and log in to the DNA Digiturva application.

2\. Select **My child's device** during the protection configuration phase and press Continue.

3\. If you are creating a new profile, press **New child profile**.

  * If you have already created a profile and are installing DNA Digiturva on a child's new device, you can select an existing profile. In this case, the restrictions you have set will be directly in effect on the new device.

4\. Define family rules on a Windows computer:

  * Set daily time limits. You can set different times for weekdays and weekends. Press **Continue**.
  * Set bedtime. You can set different times for school nights and weekend nights. Press **Continue**.
  * Set content filtering restrictions. Press **Continue**.

4\. Define family rules on a Mac computer:

  * Set bedtime. You can set different times for school nights and weekend nights. Press **Next**.
  * Set content filtering restrictions. Press **Next**.

Installation and setup on a child's Android device

1\. Install and log in to the DNA Digiturva application.

2\. Select **Are you installing on behalf of the child?** during the protection configuration phase.

3\. If you are creating a new profile, press **Create a new child profile**.

  * If you have already created a profile and are installing DNA Digiturva on a child's new device, you can select an existing profile. In this case, the restrictions you have set will be directly in effect on the new device.

4\. Enter the child's name and select age. Press Next and define family rules.

5\. Set **bedtime**: You can set your own restrictions for school days and weekend nights separately. Press **Next**.

6\. Enable **Content filtering** and select the content categories you want to block. Press **Next**.

16\. Allow DNA Digiturva to add VPN settings by pressing **Allow**.

17\. Allow DNA Digiturva to send notifications. Press **Allow**.

18\. The child's device is now protected.

Installation and setup on a child's iPhone or iPad

1\. Install and log in to the DNA Digiturva application.

2\. Select **Are you installing on behalf of the child?** during the protection configuration phase.

3\. If you are creating a new profile, press **Create a new child profile**.

  * If you have already created a profile and are installing DNA Digiturva on a child's new device, you can select an existing profile. In this case, the restrictions you have set will be directly in effect on the new device.

4\. Enter the child's name and select age. Press **Continue**.

Deleting a child's profile

You can easily delete a child's profile through your own DNA Digiturva application.

  1. Open DNA Digiturva and select the **People and devices** section.
  2. Select the child's profile you want to delete.
  3. Open **Profile settings**.
  4. Select **Delete child** profile.
  5. DNA Digiturva will confirm that you want to delete the profile. Press **Delete**.
  6. The profile has been deleted. If the profile was in use on any device, DNA Digiturva will automatically log out of the profile.

Removing DNA Digiturva from a child's Android device

When a child profile is in use, you cannot remove DNA Digiturva. You must switch users and log in with your own profile to uninstall.

1\. Open DNA Digiturva and select your **profile** from the top right corner.

2\. Press **Switch user**.

3\. **Log in** with a one-time password.

4\. Select **My device** in the device definition and press Continue.

5\. Select your **profile** from the top right corner.

6\. Open **Settings**.

7\. Scroll down and select **Uninstall**.

8\. DNA Digiturva will confirm that you want to uninstall, press **OK**.

9\. DNA Digiturva has been removed.

Modifying family rules

You can modify family rules per child profile.

1\. Open DNA Digiturva and select **People and devices**.

2\. Select the **Child profile** whose settings you want to modify.

3\. Select the rule you want to modify.

4\. You can completely turn off the rule by making the selection button inactive, or you can modify the settings as you wish and finally press **Save**.

5\. You can change the child's name and age group or delete the child's profile by pressing **Settings**.

Please note that the settings of a child's profile are affected by the device on which the child's profile was created. Child profiles created on iOS devices have fewer settings. If you switch your child's profile to an Android or Windows device, you can set more restrictions on these devices.

Family rules on Android and Windows devices

You can set the following family rules:

  * Daily time limits for app usage
  * Bedtimes for weekdays and weekend nights
  * Content filters
  * App management: you can set time-limited usage, unlimited usage, or block the app on a per-app basis

Family rules on iPhone, iPad and Mac devices

You can set the following family rules:

  * Bedtimes for weekdays and weekend nights
  * Content filters
