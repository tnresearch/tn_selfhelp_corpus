## Features

  * Supports all device types, in an Ethernet-connected home it works directly from the power outlet, in other connection technologies (cable, DSL and FTTH) you need a modem.
  * Installation and use with iOS or Android application (application in Finnish, Swedish and English)
  * Two 1 Gbit/s ethernet ports, each of which can function as a WAN or LAN connection
  * 802.11 a/b/g/n/ac 
  * MU-MIMO technology 2.4 GHz (2 x 2) & 5 GHz (2 x 2)
  * Ethernet and WiFi Backhaul
  * Quality of Service, Parental Control and versatile status information
  * The sales package includes one base station, you can purchase base stations separately and add them with the application to work together
