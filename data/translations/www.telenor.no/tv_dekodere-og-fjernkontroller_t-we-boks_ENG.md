# Help with T-We Box

Do you need a user guide, help with connecting or installing the T-We Box? You'll find everything gathered in one place here.

## T-We

With the T-We Box, you have access to several useful features such as favorite lists and weekly archive. For help with the various functions in the TV menu, you can browse the user manual on this page, or take a look at our [user guides for T-We](/kundeservice/tv/brukerveiledning-t-we/)[.](https://www.telenor.no/privat/kundeservice/tvhjelp/bruk-twe/)

  * #### Technical Specifications

    * Optimized for streaming to iPad

    * 500 GB Hard Drive

    * 8 tuners

    * HD resolution

    * Electronic Program Guide (EPG)

    * Built-in modem

    * Dolby Digital Plus

    * HDMI

    * RCA Stereo output

    * Optical audio output (toslink S/PDIF)

    * Digital radio channels

    * Parental control

    * Size (WxDxH): 330x340x70 mm

    * Supports up to 60Hz 1080P

  * #### Reset T-We Box

Here you will find[ ](/privat/kundeservice/nullstill-dekoder/)[information on how to reset the T-We Box](/kundeservice/delt/nullstill-dekoder/) via the menu or physically on the set-top box.

  * #### T-We PIN Code

The PIN code is by default set to 1-2-3-4.

Do you want to change the PIN code, or have you forgotten what you have changed it to?[ Read more about PIN codes here.](/kundeservice/tv/brukerveiledning-t-we/pin-kode/)
