## Troubleshooting

What should I do if my modem's battery is swollen?

If your modem's battery is swollen even slightly, stop using it immediately.
Take the modem to a DNA Store. Swelling can be noticed directly by the
battery bulging or, for example, the back cover moving. With current battery
technology, a similar risk of swelling exists for every battery-powered
device. The risk increases if the use is very intensive, the modem is in a
place where its temperature rises critically, or changes have been made to it
that are not mentioned in the manual.

I cannot establish a connection between the modem and the computer via USB cable

Install the modem software on the computer and run the setup program in the My
Computer window. If the modem driver appears abnormal, reinstall the software.
Install the software first.

I cannot establish a WiFi connection between the modem and the client device

Make sure that the WiFi function is enabled. Update the network list and select
the correct network name (SSID). Check the IP address and make sure that the
client device can obtain an IP address automatically. Also, make sure that
the 2.4 GHz WiFi radio frequency is enabled in the modem.

Enter the correct network key (WiFi password) when connecting the client
device to this device.

The internet connection of a device connected to the modem does not work

First, check that the SIM card is inside the modem. Bring the modem closer to
the device or move the modem as close to the window as possible.

Check that you have selected the correct WiFi network. You can see the WiFi
network name on the modem's display.

The connection is slow

Bring the modem closer to the device or move the modem as close to the window
as possible.

If the modem fluctuates between different network technologies (such as 3G and
4G), try locking the modem to one network (see Speeding up WiFi network).

The computer reports "Limited connectivity from the computer"

The modem is not connected to the internet. Check your internet connection and
restart the modem if necessary.

I cannot access the modem's management pages

Check that you have selected the correct WiFi network or that the USB cable is
connected to the device. You can see the WiFi network name on the modem's
display.

Enter the correct address. The default address of the configuration page is
http://192.168.0.1 or http://dna.mokkula.

Turn off other internet connections on the computer and disconnect the
Ethernet cable. Restart the modem by holding down the power button for 5
seconds.

Reset the modem to factory settings.
