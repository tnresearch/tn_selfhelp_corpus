## Features

**Product Name: ZTE MF286, ZTE MF286A**

A home modem that creates a fast and reliable internet connection for your home or cottage, on a 3G or 4G network, at speeds of up to 300 Mbit/s. The stylish Modem provides WiFi coverage throughout the apartment and for all devices. Advanced settings, a super-easy user interface and the latest technology guarantee that this Modem works excellently as the only internet connection in your home.

  * 4G LTE (Cat 6) maximum speed from the network 300 Mbit/s
  * 4G LTE maximum speed towards the network 50 Mbit/s
  * 3G DC maximum speed 42 Mbit/s
  * HSPA+ maximum speed 21.1 Mbit/s
  * WLAN 802.11b/g/n/ac (AC 2x2, N 3x3)
  * USB 2.0 for sharing USB memory on the local network (FTP)
  * 4 Ethernet ports, max. 1000Mbit/s (LAN1 WAN)
  * 32 devices can be connected to the wireless network
  * Two connections for external antennas, connection type SMA (Note! MIMO is formed between diversity and the external antenna)
  * Standard size Mini-SIM card
  * DNA's customized operating system

### Package contents:

DNA Home Modem MF286(A), power supply, DNA quick guide, Ethernet cable.

### Hardware requirements / Supported operating systems:

  * WiFi: 802.11b/g/n/ac
  * RJ45 connection with Ethernet cable
  * Supported operating systems: Windows XP SP2/SP3, Vista SP1/SP1, Windows 7, Windows 8 / 8.1, Windows 10, MAC 10.5 or later
  * Internet browser for management: Microsoft Internet Explorer 6.0 or later, Firefox 2.0 or later, Safari 4.0 or later, Opera 10.0 or later, Chrome 5.0 or later
