## Settings

When a computer or other terminal device is connected to the modem either via a USB cable or wirelessly via WiFi, all of the modem's settings can be managed with a web browser. We recommend Internet Explorer, Firefox, Google Chrome, and Safari browsers.

Open your web browser, type **http://dna.mokkula** or **http://192.168.1.1** into the address bar, and press **Enter**.

Enter admin in the Username field and **1234** as the password.

Press **OK** and the modem settings pages will open.

From the settings pages, you can also change the WiFi channels, network name, or even security settings.

Locking the modem to a 4G or 3G network

Modems work most efficiently on 4G or 3G networks. If the connection is slow or drops, it is worth trying the following:

  * Indoors, the connection is best near windows
  * You can view coverage areas at [dna.fi/kuuluvuus](https://www.dna.fi/kuuluvuus-ja-peittoalueet).

If you are using the modem on the border between 4G and 3G networks or 3G and 2G networks, the modem may switch between these networks. Switching between networks causes the connection to drop and slows down the modem. If you wish, you can lock the modem to any network technology as follows:

**With a web browser:**

  1. Open a web browser when you are connected to the modem's WiFi network or have connected the device with a USB cable.
  2. Type **http://dna.mokkula or http://192.168.1.1** into the address bar.
    * The default username is **admin**.
    * The default password is **1234**.
  3. Select **My Router and Settings** from the main page.
  4. From the menu that opens, select **network selection**.
    * Automatic – Selects 4G first, then 3G, and finally 2G.
    * 4G/3G only – Selects 4G first, then 3G.
    * 4G only – Locks the modem to the 4G LTE network.
    * 3G only – Locks the modem to the Dual Carrier or 3G network.
    * 2G only – Locks the modem to the 2G network.

Playing online games

Many online games work better if the modem has UPnP (Universal Plug and Play) enabled. You can check this as follows:

**With a web browser:**

  1. Open a web browser when you are connected to the modem's WiFi network or have connected the device with a USB cable.
  2. Type **http://dna.mokkula or http://192.168.1.1** into the address bar.
    * The default username is **admin** and the default password is **1234**.
  3. Select **advanced settings** from the main page and then **Firewall** from the top menu that opens.
  4. Select **UPnP**.
  5. Check the box next to **Enabled**.
  6. Press **Apply**.

Note! You can also open ports manually from the same firewall settings section, port forwarding and DMZ mode. If necessary, you can also find bridge mode, with which you can open all ports from the 4G settings.

Locking the modem to a specific 4G frequency band

In addition to network selection, locking the modem to a specific 4G frequency band can help with connection speed and possible interruptions. For example, a modem located at the junction of many base stations may switch or choose a poorer frequency band for the location.

**With a web browser:**

Changing the frequency band is done by selecting **My Router** and **settings** from the main page, and then **lock frequency** from here.

Changing the WiFi network channel and bandwidth

DNA Travel Modem 4G+ WiFi MF917V automatically searches for the best WiFi channel and channel width.

**With a web browser:**

  1. Open a web browser when you are connected to the modem's WiFi network or have connected the device with a USB cable.
  2. Type **http://dna.mokkula or http://192.168.1.1** into the address bar.
    * The default username is **admin** and the default password is **1234**.
  3. Select **Wi-Fi** from the main menu.
  4. At the top of the view that opens, there is a section called **advanced settings**.
  5. Select the frequency in advanced settings and choose the freest possible **WiFi channel** from the drop-down menu.
  6. Using the drop-down menu, you can change the **network mode and channel bandwidth**. Choose the option that best suits your environment.
  7. Press **Apply**.

Updating the modem

The modem receives updates from time to time, which should be done. In a normal situation, the modem will notify you via the browser that an update is available. You can check for updates on the settings pages, under **advanced settings** (on the main page) – **update** – **check**.

Changing the modem's administration password

You can change the modem's administration password if you wish. If you forget the changed administration password, you can reset the modem to factory settings.

**With a web browser:**

  1. Open a web browser when you are connected to the modem's WiFi network or have connected the device with a USB cable.
  2. Type http://dna.mokkula or http://192.168.1.1 into the address bar
    * The default username is admin and the default password is 1234
  3. Select the **change login password** from the upper right corner of the settings pages home page.
    * Current password is 1234.
    * New password – Enter the password you want.
    * Confirm password – Confirm the password you want.
  4. Press Apply.

Resetting the travel modem to factory settings

You can restore the default settings of the DNA Travel Modem 4G+ WiFi MF917V by holding down the reset button for about 15 seconds.

You can find the reset button under the same flap that protects the SIM card.
