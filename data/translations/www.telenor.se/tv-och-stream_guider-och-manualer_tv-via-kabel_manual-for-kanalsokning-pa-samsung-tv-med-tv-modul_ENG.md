# Manual for channel search on Samsung TV with TV module

Follow the instructions below to perform a channel search on a Samsung TV with a TV
module:

  * ### Get the remote control

Then press the menu button and select **System**.

  * ### Select Setting

Then enter the pin code **0000** using the remote control. Or check
what pin code it is in the manual for your TV.  
  
  
  
  
  

  * ### Select start language

In the list of languages, select **Swedish**.  
  
  
  
If you have a smart TV from Samsung, Network settings will then appear. Select
your network or skip this step by pressing the right arrow and
then Skip.

  * ### Select country and channel source

Here you should select **Finland**. Note that this does not affect the language in
the menus.  
  
Then select channel source **Antenna** and then the right arrow **.**  
  
  
  
  

  * ### Select Cable and Digital and Analog

Then select **Search**.  
  
When the search is complete, you will see it on the TV screen. Then select the right arrow.  
  
  
  

  * ### Select Time Zone Auto

Then press **OK** to complete.  
  
Then everything is ready. Just flip through the channels and find your
favorites!
