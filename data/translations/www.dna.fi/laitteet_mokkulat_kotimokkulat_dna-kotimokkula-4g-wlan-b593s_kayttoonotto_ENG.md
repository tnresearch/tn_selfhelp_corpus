## Getting Started

## Installing the Modem

The DNA Home Modem 4G WLAN B593S uses a standard Mini-SIM card.
Insert the SIM card into the right side of the modem. To remove the SIM card
from the modem, press the card in gently first and then pull the SIM card out.

If the SIM card has a PIN code of 1234, the modem will automatically connect
to the internet. If you have a different PIN code, you need to enter the PIN
code through the modem's management page. You can find more instructions [here](/dna-
kotimokkula-4g-wlan-b593s#asetukset).

Registering to the DNA network takes a few minutes. If the connection fails,
call DNA's [customer service](https://www.dna.fi/yhteystiedot#asiakaspalvelu).

The internet connection is available when the power light and network status
indicator (in a color other than red) are lit on the modem. If the modem has
a display, you will see an icon indicating the signal strength on the display.

## Enabling the Wireless Network (WiFi)

DNA modems are encrypted for wireless network security. You can find the
network name and password on the sticker on the bottom of the home modem.

WiFi network name: WLAN-Name (SSID)

WiFi network password: WLAN-Key (WPA/WPA2)

Windows 10

Click the WLAN network availability bars in the bottom right corner of Windows
10.

Then select the network with the name on the sticker on the back (SSID). Check
the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password, or security key.
You can find it on the sticker on the back (WLAN-Key). Enter the password
exactly as it is on the sticker and press **Next**. Now you can start using
the internet.

Windows 8

Move the mouse cursor to the top right corner of the computer screen. Then
select **Settings** (gear icon). Next, select the availability bars.

Then select the network with the name on the sticker on the back of the modem
(SSID). Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password, or security key.
You can find it on the sticker on the back of the modem (WLAN-Key). Enter the
password exactly as it is and press **Next**.

If you want to share files between devices, select the lower option
("Yes, turn on sharing"). If you do not want to share files between devices,
select the upper option ("No, do not turn on sharing").

Windows 7 / Vista

Click the WLAN network availability bars in the bottom right corner of Windows
7 and Vista. Then select the network with the name on the sticker on the back
(SSID).

Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find the
password, or security key, on the sticker on the back (WLAN-Key). Enter the
password exactly as it is and press **OK**.

You can start using the internet.

Mac OSX

Click the WLAN network icon at the top of the screen with the mouse. Then
select the network with the name on the sticker on the back of the modem
(SSID).

Next, the computer will ask for the wireless network password. The password,
or security key, can be found on the sticker on the back (WLAN-Key). Enter
the password exactly as it is on the sticker on the back. Click **"Remember
this network"** and press **Join**.

You can start using the internet.

Apple iPad

Select Settings from the iPad home screen. Select Wi-Fi from settings (WLAN in
older models).

Wait a moment while the iPad searches for networks. Then select the network
with the name on the sticker on the back of the home modem (SSID). Next, the
iPad will ask for the wireless network password. You can also find the
password, or security key (WLAN-Key), on the sticker on the back of the
modem.

Press **Join**. You can start using the internet.

Android Tablet

Go to the view where you see all the apps.

Select **Settings** and select **Wi-Fi** from the menu (Wireless & networks in
older versions). Wait a moment while the tablet searches for networks. Then
select the network with the name on the sticker on the back of the home modem
(SSID). Next, the tablet will ask for the wireless network password. Then
select the password, or security key (WLAN-Key), which is on the sticker on
the back of the home modem.

Press **Connect** and you can start using the internet.
