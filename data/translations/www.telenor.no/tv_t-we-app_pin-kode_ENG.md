# PIN Code in the T-We App

Your PIN code is linked to the Owner profile in the app, but can also be set for other profiles. Here we show you how to find, change, or reset the PIN code.

## What is the PIN Code in the T-We App?

**The default PIN code on T-We is set to 1-2-3-4. This is the same in both the app and on your T-We Box.**

If the code is not 1-2-3-4, this means you have changed the PIN code to something you have chosen, or that a different code has been set for a new profile.

You need the PIN code, for example, when you change [settings in the T-We App](/kundeservice/tv/t-we-app/innstillinger/), [rent a movie](/kundeservice/tv/brukerveiledning-t-we/filmleie/), or [change and delete profiles](/kundeservice/tv/t-we-app/profiler/).

## How to Change the PIN Code

  1. Select ☰ More.

  2. Tap on **Access and profiles.**

  3. Tap on the pencil in the upper right corner of the desired profile.

  4. Select **Edit profile.**

    * Enter the PIN code for the profile if it has its own PIN protection.

  5. Tap **Next.**

  6. Tap **Next.**

  7. Select **Change PIN code**

  8. Enter **new** PIN code

  9. Repeat new PIN code

  10. New PIN code has been created

## Reset the T-We PIN Code

Have you forgotten the PIN code for the Owner profile? You can reset it on My Pages.

  1. [Log in to My Pages](https://www.telenor.no/minesider/)

  2. Select Reset T-We PIN code at the bottom left on the first page you arrive at

  3. Tap Reset PIN code

  4. The code is now reset to 1-2-3-4

**Note!** If the code does not update, you can restart the T-We box by unplugging it. Wait 5 seconds before plugging it back in.
