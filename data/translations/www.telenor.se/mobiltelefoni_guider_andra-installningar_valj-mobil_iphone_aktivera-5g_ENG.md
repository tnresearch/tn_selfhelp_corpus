# Activate 5G

Virtually all mobile phones released today are ready for 5G. If you have a 5G mobile
with a subscription from us, it is likely already pre-configured to use 5G. So it
is just to start surfing faster than ever!

If you still want to be sure that your mobile is set to use 5G, you can
follow this guide. Also, keep in mind that there may not be 5G coverage
where you are located.

  
[Read more about 5G and see the coverage map here](/5g/)

This guide shows you how to do it in the **latest operating system (iOS)** from
Apple. So feel free to start by making sure it is installed on your mobile –
not least so that it works as well and securely as possible.  
  
[Here's how to update
the operating system](/support/mobiltelefoni/guider/sakerhet/valj-
mobil/iphone/uppdatera-operativsystemet/)  
  
Now you have the latest iOS installed, right? Then let's go!

  * ### Go to the home screen

  * ### Select "Settings​"

  * ### Select "Mobile network​"

  * ### Select "Mobile data options​"

  * ### Select "Voice & Data​"

  * ### Select "5G Auto" or "5G On" depending on what suits you best
