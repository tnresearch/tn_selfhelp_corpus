**Features**

  * FTTH fiber converter with SFP connector
  * Wireless connection: Wi-Fi 802.11b/g 2.4GHz
  * 4 LAN ports (e.g. for a set-top box or computer)
  * IPv6 support
  * Firewall and NAT
  * DNA's customized settings
  * Default in bridge mode, DNA recommends router mode

**Bridging the Modem**

Default is bridging, here are instructions for changing to router mode.

  1. Change the network card settings to an IP address of 192.168.1.0 /24 e.g. 192.168.1.100 / 255.255.255.0
  2. Open a browser and enter 192.168.1.1 in the address bar and press “Enter”. Log in with username admin/admin
  3. Go to Advanced setup -> WAN service
  4. Check the box next to eth4.2 and press “Remove”
  5. Select the "Edit" checkbox next to the remaining connection
  6. Clicking the "Edit" button will take you to the Network Address Translation settings menu: Check the box "Enable NAT" (this enables routing) Fulcone NAT does not need to be enabled. The firewall can be turned on with "Enable Firewall". Press the "Next" button.
  7. The summary page shows a summary of the settings. Press "Apply/Save".
  8. Go to the "LAN" menu and select "Enable DHCP server" and press "Apply/Save"

If you want to change the LAN addresses to something other than 192.168.1.0/255.255.255.0,
you can do so in the same menu.
