# Setting up Icotera i4882-70

What the diodes (lights) on the router mean

The router has two lights: the one on top shows whether WiFi is connected, and the one below shows whether there is a connection.

  * If the bottom light (WAN) is red, there is no physical connection to the internet.  
 **What you can do:** Check the cables to see if they are fully plugged in.

  * If the bottom light is blinking, there is a physical connection, but no IP address.  
 **What you can do:** Try resetting the router by inserting a pin or similar object into the reset hole on the bottom of the router. This should be done while the router is turned on, and the reset button should be held down for 10 seconds. If the reset is performed correctly, the lights will start to blink after the reset button is released.

  * If the bottom light is solid green, the router is receiving an IP address and is online.  
 **What you can do:** Therefore, check if your devices are connected to the correct WiFi, and if cables are fully plugged in.

  * When the top light (WiFi) is green, WiFi is turned on; if the light is off, WiFi is turned off. If the light is blinking, WPS is enabled.

## More settings

How to log in to the router (e.g. to change WiFi name and password)

  * To log in to the router, you must be connected to the router from the device used for login
  * In a browser, type **http://10.0.0.1:80** and press **Enter** to open the login page  
 **Username:** admin  
**Password:** is on the underside of the router, and is called "Router Code". If there is no Router Code, use your WiFi password.

How to change WiFi name and password

  * Log in to your router by following the guide 'How to log in to the router'. Once logged in, select the menu item **Settings** and then **WiFi 2.4 GHz** or **WiFi 5 GHz** , depending on which network you want to change the name of  
 **Note:** if you do not want 2 different networks, it is recommended that you name them with the same name and password. This way, the router can move your device to the network that is best in terms of signal strength and speed.

  * Once you have entered the new information, select **Apply** , at the top of the page.  
 **Note:** If you have been connected via WiFi, your device will be logged off the network, and you will need to log in with the new information.

How to set up Port Forwarding

Port Forwarding is a way to give internet access to different devices - it could be a surveillance camera or a PlayStation, for example. If you are having trouble connecting the device, you get the code **Strict Nat** , and then you do the following:

  * Log in to your router by following the guide 'How to log in to the router'. Once logged in to the router in a browser window, select the menu item **Port Forward**
  * Check the box **Enable** next to the first available line on the right side of the window
  * Enter the port information to be forwarded, as well as the IP address to be forwarded to   
**Note:** A separate line must be created for each rule that is set up

  * Once you have entered the new information, select **Apply** at the top of the page

How to read the signal strength of your WiFi

  * Log in to your router by following the guide 'How to log in to the router'. Once logged in, under the menu item **Status** select either **Wi-Fi 2.4 GHz** or **Wi-Fi 5 GHz**
  * In the overview of connected devices, **Associated Clients** , find the device you are experiencing is slow or has dropouts
  * In the **RSSI** column, read the signal strength. If the value is in the range **-20 to -50** , it indicates that the device is receiving a good signal. From **-50 to -70** the signal will be acceptable, but you may experience that the received speed is lower. Signal strength From **-70 to -100** indicates that there is a low signal between the router and the device you are measuring on. This can be experienced in the form of WiFi dropouts or very low speed. If you experience slower WiFi than expected, a good tip is to move the device and router closer together.

How to connect devices to the router via WPS

If you have a device (printer, smart device, WiFi extender or similar) that needs to be connected via WPS, it is done as follows:

  * Place the device you want to WPS-pair in immediate proximity to the turned on router
  * On the front of the router there is a button called **WPS**. Press once and briefly on this. If WPS pairing is enabled, the bottom diode on the router will blink. You now have two minutes to complete the following steps:

  1. Press the **WPS** button on your device, and wait up to two minutes
  2. WPS pairing is now complete

Router specifications

**Ports:**

  * 1x 2.5Gbit WAN port - used when connecting to a fiber modem
  * 1x 2.5Gbit LAN port
  * 2x 1Gbit LAN ports
  * 1x USB 3.0 port

**WiFi connection:**

  * IEEE 802.11b/g/n 2.4 GHz
  * IEEE 802.11ax 2.4 GHz
  * IEEE 802.11ac 5 GHz
  * IEEE 802.11ax 5 GHz

**Known limitations:**

  * Setting up Fast LAN IP (static lease) is not possible
  * The i4882-70 router cannot be set to Bridge Mode. For alternative solutions, please feel free to contact Telenor
  * There may be problems accessing the router's GUI - this can be resolved by restarting the router
