## Settings

Modem management page and changing settings

The modem's settings are changed using web browsers. Changing the setting requires that the device using the browser is connected to the WiFi network created by the modem or the device is connected to the modem with an Ethernet cable.

From the settings you can change, for example, the WiFi network name and password or lock the modem to use, for example, a 4G or 3G network.

Open your web browser and type http://192.168.8.1 into the address bar and press **Enter**.
Enter **admin** in the Username field and **admin** in the Password field.
Press OK, and the modem settings pages will open.

Entering the PIN code

If the SIM card has a PIN code other than 1234, the PIN code must be entered in the modem settings.

  1. Open a web browser when you are connected to the modem's WiFi network
  2. Type http://192.168.1.1 into the address bar
  3. The default username is **admin** and the default password is **admin**.
  4. Select **Internet** from the top
  5. Select **PIN Code Management** from the left
  6. Enter the desired PIN code in the **Enter PIN** field and press **Submit**

Playing online games

Many online games work better if UPnP is enabled on the modem. You can check this as follows:

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://192.168.1.1 into the address bar
    * The default username is **admin**.
    * The default password is **admin**.
  3. Select **Security** from the top.
  4. Select **UPnP** from the left.
  5. Check the box next to **Enable**.
  6. Press **Submit**.

Locking the modem to a 4G or 3G network

Modems work most efficiently on a 4G or 3G network. If the connection is slow or intermittent, you should try the following:

  * Indoors, the connection is best near windows.
  * Attach the additional antennas included with the modem to the modem's antenna connectors.

More information about coverage areas: [dna.fi/kuuluvuus-ja-peittoalueet](/kuuluvuus-ja-peittoalueet)

If the modem is used on the border of a 4G or 3G network or a 3G or 2G network, the modem may switch between these networks. Switching between networks causes the connection to drop and slows down the modem. You can optionally lock the modem to any network technology as follows:

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://192.168.1.1 into the address bar
    * The default username is **admin**.
    * The default password is **admin**.
  3. Select **Internet** from the top.
  4. Select **Network Connection** from the left.
  5. Select from **Network Mode**.
    * Automatic – Selects 4G first, then 3G and finally 2G network.
    * 4G – Locks the modem to the 4G LTE network.
    * 3G – Locks the modem to the Dual Carrier or 3G network.
    * 2G – Locks the modem to the 2G network.

Changing the WiFi network name and password

You can change the WiFi network name and password as you wish. If you do this, devices that were already connected to the WiFi network must be reconnected to the renamed WiFi network.

If you forget the changed WiFi network password, you can reset the modem to factory settings, which will restore the WiFi network password to the same as on the sticker on the back of the modem.

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://192.168.1.1 into the address bar
    * The default username is **admin**.
    * The default password is **admin**.
  3. Select **WLAN** from the top.
  4. Type a new WLAN network name in the **SSID** field.
  5. Type a new password in the **WPA-PSK** field. If you want to see the typed characters, select **Enable** from above.
  6. Press **Submit**.

Changing the modem management password

You can optionally change the modem management password. If you forget the changed management password, you can reset the modem to factory settings.

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://192.168.1.1 into the address bar
    * The default username is **admin**.
    * The default password is **admin**.
  3. Select **System** from the top.
  4. Select **Change Password** from the left.
    * The current password is **admin**.
    * **New Password** – Enter the password you want.
    * **Confirm Password** – Confirm the password you want.
  5. Press **Submit**.

Reset to factory settings

You can restore the modem to its default settings by holding down the Reset button on the left side of the device for about 2 seconds.

Updating the modem

A notification will normally be automatically displayed on the web user interface and the home modem screen when a new update is available for download.
