## Features

### DNA Travel Modem 4G WiFi MF971RS2

**Product Name: ZTE MF971RS2**

The DNA Travel Modem 4G WiFi MF971RS2 is a battery-powered modem that operates via a wireless WiFi network or USB connection, allowing you to connect multiple devices that need internet access. DNA's customizations make it very easy to use.

  * 4G LTE maximum speed from the network 300 Mbit/s
  * 3G DC maximum speed 42 Mbit/s 
  * WiFi b/g/n/ac Dual-Band
  * Micro-USB connector
  * 16 WiFi devices 
  * 1.4” TFT screen
  * 2000 mAh battery
  * Micro-SIM card

**Sales package contents**

  * DNA Travel Modem 4G WiFi MF971RS2
  * power supply
  * USB cable
  * user manual
  * quick start guide
