# Anslut till wifi via Windows 10

  * ### Klicka på pilen längst ner på skrivbordets högra hörn

Välj sedan wifi-symbolen för att se alla nätverk i din närhet.

  * ### Välj ditt nätverk

Du hittar nätverkets namn, SSID, på undersidan av din router. Om du använder
vårt nätverk börjar det på TN. Välj om du vill använda 5 GHz eller 2,4 GHz.

Tips: 5 GHz = bättre hastighet och 2,4 GHz = bättre räckvidd.

  * ### Klicka på anslut

Fyll i lösenordet, Wireless Key, som du hittar på routerns baksida. Klicka på
Nästa.

  * ### Klart!

Efter några sekunder kommer du att vara ansluten till ditt wifi-nätverk och
kan börja surfa.
