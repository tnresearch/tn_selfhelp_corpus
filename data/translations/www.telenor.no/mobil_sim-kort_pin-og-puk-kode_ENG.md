Prerequisites for Retrieving PUK Code

  * Only the **subscriber** can retrieve the PUK code.

  * Parents/guardians can request a PUK code if the user is under 15 years old. (A separate profile must be created for users under 15 years old if the PUK code is to be retrieved via self-service solutions.)

  * PUK code can be retrieved free of charge on My Pages, in [My Telenor](/privat/mobil/app/mitt-telenor/), and via the Telmi chatbot.

  * Customer service can provide the PUK code over the phone for NOK 50.

Self-service solutions require that [you log in with Telenor ID](/telenor-id/)

## Retrieve PUK Code on My Pages

  1. Log in to My Pages

  2. Select **Mobile and Subscription**

  3. Select the subscription in question

  4. Select the device or SIM card in question under **Devices and SIM**

  5. Click the **Show** button under PUK1 or PUK2.  
The **Show** button **is only visible if you are a registered user of the subscription.**

[Log in to My Pages](/mitt-telenor/)

## Problems Logging in to My Pages?

If your mobile phone is locked and you cannot receive SMS, try choosing email as the recipient of the one-time password. You do this by **logging in to your Telenor ID with your email address** instead of your mobile number.  

**Note:** This only works if you are connected to a network you have previously logged in to with Telenor ID. For example, if you are abroad, you will not be able to log in this way.

If you cannot receive email or SMS, you must contact customer service to get the PUK code over the phone.

## Find PUK Code in My Telenor

  1. Scroll down to Devices

  2. Select the number/device in question

  3. The PUK code is at the top, along with info about SIM number, IMEI, and options to order/activate or block the SIM card.

  4. If the PUK code is not at the top, it is because you are not registered as a user of the subscription.

Locked out of your mobile phone because you cannot get past the PIN code?

If you have previously logged in to the My Telenor app with your mobile phone and have access to WiFi, you can find your PUK code by following these steps:

  1. Turn off your mobile phone

  2. Remove the SIM card from your mobile phone

  3. Turn on your mobile phone without the SIM card

  4. Enter any regular lock code for your mobile phone, and open the My Telenor App

## Change or Create New PIN Code

When you turn on your mobile phone, you can create a new PIN code by entering the PUK code. If you do not have the PUK code available, you can retrieve it in the My Telenor app, on My Pages, or via the Telmi chatbot. You can find more info about this on this page if you scroll up a bit.  

**Here's how to change the PIN:**

  1. Enter the PIN code incorrectly three times

  2. Enter the 8-digit PUK code

  3. Enter a new PIN code (you choose this yourself)

  4. Repeat the new PIN code

Next time you are asked to enter a PIN code, you can enter the new one you have created. It is also possible to change the PIN code under Settings on your mobile phone, but the procedure may vary depending on the type of mobile phone.

## Do I Need PIN, PUK, or Screen Lock?

When the mobile phone is locked, it will ask for a code. Normally, the screen will indicate which code it is asking for, but it can sometimes be a little confusing to distinguish between them.

These are the most common codes:

  *  **Screen Lock Code**

A 4- or 6-digit code, or possibly a pattern you use to open the screen on your mobile phone.

  *  **PIN Code**

A 4-digit code that belongs to the SIM card. This code is personal and can be changed.

  *  **PUK Code**

An 8-digit code that belongs to the SIM card. This code cannot be changed.

You need the PIN code to get coverage if the mobile phone has been turned off. If you have forgotten this, you can unlock the mobile phone with the PUK code for the SIM card.

**Note**: If the mobile phone does not specifically ask for a PIN or PUK code, it is generally a screen lock code that needs to be entered.

### Problems with PUK Code?

  * #### Entered Incorrect PUK Code

You have 10 attempts to enter the correct PUK code. If you enter the incorrect PUK code more than 10 times, the SIM card will be blocked and you will need a new card.
