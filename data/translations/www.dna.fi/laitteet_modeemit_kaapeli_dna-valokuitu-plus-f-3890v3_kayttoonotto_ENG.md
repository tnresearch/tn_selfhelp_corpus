## Getting Started

### Modem Installation

  1. Connect one end of the antenna cable to the data socket of the antenna socket in the room, and the other end to the RF interface of the modem. If the socket does not have a data socket or you want to use a set-top box and modem at the same time, attach the antenna cable to the TV port using a socket splitter. Make sure all ends are securely connected.
  2. Connect the yellow end of the power cable to the Power interface of the modem, and the plug to the power outlet in the room. 

  3. Registering the modem to the DNA cable network usually takes about 10 minutes - but no more than 2 hours. If the connection fails to open, call DNA customer service. The internet is available when the status indicator light on the modem lights up continuously. You can connect your devices, such as a computer or phone, to the modem either wirelessly or using an Ethernet cable.

### Meaning of Modem Lights and Buttons

1\. WiFi Light

On | WiFi is on  
---|---  
Blinking | WPS or EasyMesh functionality is activated or WiFi has been
disabled  
Off | All WiFi radios are off  
  
2\. Status Light

On | Modem is on and working  
---|---  
Slow Blinking | Modem is starting up (duration approx. 30 seconds)  
Normal Blinking | Modem is not connected to the internet  
Fast Blinking | Modem is not connected to the internet  
Off | Power is not connected  
  
3\. WiFi Button

Press and hold for three seconds to turn off WiFi.

4\. WPS Button

Press and hold for three seconds to activate WPS or EasyMesh functionality.
By pressing the corresponding button on the device to be connected within two
minutes, the devices will connect to each other over WiFi.

5\. Reset Button

If you want to restore the modem to its original factory settings, press the Reset
button with a pointed object (e.g. a hairpin) for 30 seconds. The modem must
be on for the factory reset to work.

### Setting up a Wireless WiFi Network

DNA broadband modems are encrypted in terms of wireless networks. You can find
the network name and password on the sticker on the bottom of the modem.

  * SSID (wireless network name):   
E.g. DNA-WiFi-5Ghz-XXXX and DNA-WiFi-XXXX

  * Wireless network password:  
E.g. 11345778206

The DNA 3890v3 modem supports 2.4 Ghz and 5 Ghz WiFi networks.
The modem has a combined network and a separate 5 Ghz network enabled by
default. The combined network allows the connecting device to choose which
network is better.  
DNA recommends choosing the 5 Ghz network so that faster WiFi is always
available on devices that support it. You can find instructions for logging
into the settings page on the [Settings page](https://www.dna.fi/dna-valokuitu-plus-
modeemi-f-3890v3#asetukset).

The modem's serial number (S/N) and MAC number can be found on the same sticker.

You can find more extensive broadband guides [here](http://dna.fi/tuki-laajakaista).  
You can find more information about WiFi network settings [here](http://dna.fi/tuki-wifi).  
Also, familiarize yourself with safe internet use and protecting your
information [here](http://dna.fi/tietoturvaopas).  

### Connecting to WiFi

Note! The DNA 3890v3 modem searches for WiFi networks on both 2.4 Ghz and 5
Ghz frequencies by default. Always choose the option with "5 Ghz" if one is
found. This ensures you always have the fastest internet.

Windows 10

Here's how to enable a wireless network connection (WiFi) in Windows 10:

  1. Press the WiFi icon in the lower right corner of the Windows desktop, near the clock. 

  2. Then select the network whose name is on the sticker on the back of the modem (SSID). Check the box "Connect automatically" and press Connect. 

  3. Enter the network password. You can find the password on the sticker on the back of the modem. Enter the password exactly as it is on the sticker and press OK. Now you can start using the internet.

Windows 8

  1. Move the mouse cursor to the upper right corner of the computer screen. Then select the gear icon (**settings**). Next, select **connectivity**.
  2. Then select the network whose name is on the sticker on the back of the modem (SSID). Check the box "**Connect automatically**" and press **Connect**. 

  3. Enter the network password. You can find the password on the sticker on the back of the modem. Enter the password exactly as it is on the sticker and press **OK**. Now you can start using the internet. 

  4. If you want to share files between devices, select the lower option. If you do not want to share files between devices, select the upper option. 

Windows Vista / Windows 7

  1. Click the WiFi icon in the lower right corner of the Windows desktop, near the clock. 

  2. Then select the network whose name is on the sticker on the back of the modem (SSID). Check the box "**Connect automatically**" and press **Connect**. 

  3. The computer will then ask for the wireless network password. You can find the password on the sticker on the back of the modem (Password). Enter the password exactly as it is on the sticker and press **OK**. You can start using the internet. 

**Note**

  * To get the most out of fast AC-WiFi (WiFi 5), the devices connecting to the internet, such as computers and phones, must also be compatible with it.
  * Physical obstacles weaken the WiFi range. The signal passes through doors, windows and lighter wall structures, but each obstacle weakens it. Metal, concrete, brick and stone disrupt the signal flow most significantly. Even difficult obstacles can be overcome with separate antennas or base stations.
  * It is also advisable to avoid placing other electronics right next to the modem to ensure the best possible WiFi.
  * The modem should be placed in as central a location as possible in the room where the network is used. The modem should also be higher than normal table height.
  * Wireless WiFi currently cannot reach the peak speeds of the modem. To ensure the fastest possible internet, we recommend connecting the computer directly to the modem with an Ethernet cable.
  * WiFi is also affected by the number of other wireless networks nearby and the transmission channels in use. If your WiFi is intermittent or slows down, the solution may be to search for another WiFi channel or change the frequency manually.
