#### Reset T-We Box Mini

**Via Remote Control**

  1. Press **MENU** on the remote control

  2. Select **Settings** and press OK

  3. Select **Installation** and enter the PIN code

  4. Select **Factory Settings** and press OK

  5. You will be asked if you want to reset all decoder settings and delete all recordings

    * Select **Yes** to delete all recordings

    * Select **No** to keep recordings

  6. Select **Continue** to confirm the reset

**Alternative Procedure via Remote Control**

  1. Turn on the decoder, and wait for it to finish loading

  2. Within 5 seconds: Press **MENU** on the remote control, and then 3-7-5-3-3-7

  3. The decoder will turn off within 5-10 seconds and restart

  4. Try again if there is no response

**Via Decoder**

  1. Unplug the power cable on the back of your decoder

  2. Hold down the power button on the front of the decoder while plugging in the power cable

  3. Continue holding down the power button for 5-10 seconds while the box starts up

#### How do I get the correct regional broadcast on the TV?

If your T-We Box Mini needs to be reset to factory settings, you will
need to specify your region manually. [See an overview of all regions with associated
district and local broadcasts to set the correct
value.](https://www.telenor.no/privat/tv/t-we/regionid/) If you do not specify a region
your decoder will automatically be set to region 1.

Manual region change is done by going to settings:

  1. An automatic channel search appears and you fill in the region.

  2. You can also change it by going to **Menu**, select **Installation** -> enter **Pin** -> select **Channel Search**.

#### Multiroom

This feature allows one T-We Box (ADB 5743) and one ADB 2840 (T-We Box Mini)
to communicate on the home network and gives you more enjoyment of your TV offer.
It is more flexible both where, when and how you want to watch both live TV and
recordings.  
  
TV in multiple rooms also gives you the opportunity to place the T-We Box Mini in a room
without an antenna outlet and still be able to watch regular TV broadcasts retrieved from the T-We
Box via the home network. Recordings can be programmed and played on both
boxes and stored centrally on the T-We Box (5743). If you start watching a
recording in one room, you can continue watching the recording in another room with a couple
of button presses on the remote control

Multiroom cannot be used with T-We Box II (ADB 3770).
