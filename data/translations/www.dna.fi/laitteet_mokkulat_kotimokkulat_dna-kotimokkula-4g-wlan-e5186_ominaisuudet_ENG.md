## Features

**Product Name: Huawei E5186**  

DNA Home Modem 4G+ WLAN E5186 is a powerful 4G modem that shares the network
wirelessly or via Ethernet cable. The Home Modem has 4 Ethernet ports.

  * 4G LTE maximum speed from the network 300 Mbit/s
  * 3G DC maximum speed 42 Mbit/s 
  * HSPA+ maximum speed 21.1 Mbit/s
  * WLAN b/g/n/ac
  * 4 RJ-45 Ethernet ports, max. speed 1000 Mbit/s.
  * USB
  * 32 WLAN devices 
  * Two connections for external antennas, connector type SMA
  * Micro-SIM card

### Package contents:

DNA Home Modem 4G+ WLAN E5186, power supply, quick guide, Ethernet cable, 2
additional antennas.

### Hardware requirements / Supported operating systems:

  * WLAN: 802.11b/g/n/ac
  * RJ45 connection with Ethernet cable
  * Supported operating systems: Windows XP SP2/SP3, Vista SP1/SP1, Windows 7, Windows 8 / 8.1, Windows 10, MAC 10.5
  * Internet browser for management: Microsoft Internet Explorer 6.0 or later, Firefox 2.0 or later, Safari 4.0 or later, Opera 10.0 or later, Chrome 5.0 or later
