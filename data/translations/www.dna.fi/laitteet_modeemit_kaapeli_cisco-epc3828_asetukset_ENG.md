## Settings

Logging in to the Settings Page

All of the device's settings are managed using a web browser. The settings pages stored in the device are similar to using regular web pages, so changing the settings is easy. DNA recommends Internet Explorer, Firefox, Google Chrome, and Safari browsers.

Open a web browser (at this stage, you may receive an error message in your browser, but do not pay attention to it). Type http://192.168.0.1 into the address bar. Pressing Enter will take you to the login page.

  1. Log in to the settings page by leaving both fields blank (Username and Password).
  2. Press Log In.
  3. The settings pages will open.  

  
Now you are logged in to the modem's settings pages. From the settings pages, you can also change WiFi channels, network name, or security settings. First, you will be prompted to change the device's password on the Administration Management page.  

Changing the Password and Forgotten Password

All of DNA's wireless modems have the same password by default. To prevent security risks and unauthorized access to the modem, the password must be changed.

  1. Select **Administration** from the navigation menu at the top of the settings pages.
  2. Select **Management** from the upper navigation menu below. You can change the device's username and password from this page. The password is required to change the device's settings.
  3. Type the new username into **Change Current User Name to** and the password into **Change Password to** and again into **Re-Enter New Password**.
  4. Press **Save Settings.**

Changing the WiFi Frequency

The 2.4 GHz and 5 GHz WiFi networks of the Cisco 3828 modem have the same name by default. This means that the choice of using 5 GHz or 2.4 GHz happens completely automatically according to the settings of the end device.

The WiFi frequency is changed in **Wireless** -> **Radio Settings** -> from **Radio Band**.

By selecting 2.4 GHz or 5 GHz from the drop-down menu, you change the WiFi network name and other settings for that frequency. If you know you only want to use one frequency (2.4 GHz or 5 GHz), it is recommended to change the frequencies' names (SSID) to be different.

For example, by selecting the 2.4 GHz frequency from the Radio Band and changing the network name (SSID) of this network to "My Network Name 2G" and doing the same for 5 GHz to "My Network Name 5G", it is easier to find the correct frequency.

Changing the WiFi Password

Go to **Wireless** -> **Wireless Security** -> **Passphrase** to find the password, which is by default located on the sticker on the bottom of the device ( **Pre-shared-key** ).

Selecting and Changing the Transmission Channel

The password can be changed in the menu tree **Setup** -> **Quick Setup**. Here you can also configure the settings of the WiFi radios by setting **Wireless Interface enable/disable**. The frequencies of the radios are 2.4 GHz and 5 GHz. You can also set the SSID and encryption method / cryptography.

Select **Wireless** from the navigation menu at the top of the settings pages and **Basic Settings** from the navigation menu on the left.

  1. Select a channel between 1-13 from the **Standard Channel** drop-down menu.
  2. Press **Save Settings.**

Managing 802.11n Mode

If the hardware supports the 802.11n specification, you can use the 40MHz-Wide Channel function. This improves the connection speed of the WiFi network.

  1. Select **Wide 40 MHz Channel** from the **Channel Width** drop-down menu.
  2. Press **Save Settings.**

Encrypting Wireless Connection and Modem Traffic

Special attention should be paid to protecting the wireless local area network connection. Because the wireless local network also works through walls, it is practically impossible to limit the network coverage to operate only in the desired area. Encrypting the connection is an effective way to prevent unauthorized use or takeover of the broadband connection by outsiders. Encryption applies only to wireless traffic between the cable modem and the computer.

However, protection between the cable modem and the computer does not prevent threats from the internet, such as network attacks, viruses, and data breaches, to which an unprotected computer is always vulnerable when connected to the internet. Therefore, DNA recommends purchasing DNA Nettiturva. It is an easy and effortless way to take care of your computer's security. We recommend using the so-called WPA2 (Wi-Fi Protected Access) encryption in wireless local networks. It is currently the most secure of the available options. By default, the modem supports WPA2- PSK, TKIP and WPA-PSK encryption methods.

Setting the Modem to Bridge Mode

Select **Administration** from the navigation menu at the top of the settings pages and **Management** -> **Gateway Setup (WAN)** from the navigation menu on the left.

  1. Select **Bridged Only** from the **Working Mode** drop-down menu.
  2. Press **Save Settings**

Note! The management address is 192.168.100.1 when bridged.

IP Flood Detection and Firewall

If your internet connection drops, for example, when surfing, playing console games, making IP calls, or downloading files, you should try turning off the IP Flood detection setting (IP Flood detection = detection of IP packet attacks coming from the internet).

Connect the computer to the modem either wirelessly or via Ethernet.

Type http://192.168.0.1 or 192.168.0.1 into the browser, depending on whether the modem is in router or bridge mode. Log in with the credentials (the username and password are left blank by default).

  1. Select **Security** -> **Firewall** -> **Filters** from the top.
  2. Uncheck **IP Flood Detection.**
  3. Press **Save settings.**

**Note.** It is recommended to change wireless network settings only from a computer that is connected to the device with a network cable (Ethernet cable).
