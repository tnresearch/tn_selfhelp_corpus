## Setting Modems to Bridge Mode

NAT (routed) and BRIDGE (bridged) settings

Devices or modems are by default either in NAT or Bridge mode. In NAT mode,
the device shares IP addresses for the home network with devices, and internet
traffic occurs using a single public IP address.

In NAT mode, multiple devices can be connected to the connection
simultaneously. In Bridge mode (bridged), IP addresses for the home network
are shared directly from DNA, and each device connected to the modem (max. 5
devices) uses its own public IP address to access the internet. For example,
with 100/350/1000 Mbit/s connections, better connection speeds are achieved
when bridged.

Bridged mode can achieve higher peak speeds than routed mode, as the modem
does not filter traffic. Modems can be switched to bridged mode as needed,
allowing you to connect 5 network devices to the broadband connection.
Switching to bridged mode means that your modem no longer has DHCP and NAT
features enabled, and you will not be able to share files or printers on the
local network. The security of connected devices may also be reduced. Your
network device will receive an IP address directly from DNA.

Generally about the IP Flood setting

IP Flood Detection is a method for detecting IP packet attacks coming from
the internet. If your internet connection is intermittent while surfing,
Skyping, downloading files, etc., you should disable the IP Flood detection
setting. The setting is turned on and off on a per-modem basis.

## Traffic Restrictions

For fixed broadband connections, IP traffic directed to the connection from
the public network is restricted. The restrictions correspond to, for
example, the regulations of the Communications Regulatory Authority. The
restrictions do not remove the need for security services, such as firewalls
and antivirus software. Traffic is restricted as follows:

Blocked ports (IPv4 and IPv6)

  * 25 UL (TCP) 
  * 53 DL (UDP) 
  * 7547 UL/DL (TCP)
  * 1900 DL (UDP)

Above, UL means traffic from the device to the Internet, and DL means traffic
from the Internet to the device.

Outgoing email traffic (SMTP) from the connection to port 25 is only allowed
to DNA's own SMTP servers, in accordance with the Communications Regulatory
Authority's regulations.

Service Addresses

  * DNA's SMTP email server address is smtp.dnainternet.fi
  * DNA's NTP time server address is ntp.dnainternet.fi
  * DNA's DNS name server IPv4 addresses: 62.241.198.245 and 62.241.198.246
  * DNA's DNS name server IPv6 addresses: 2001:14b8:1000::1 and 2001:14b8:1000::2

### Slow Internet?

A speed test helps you determine the broadband speed in under a minute.

[Take a speed test](https://www.dna.fi/liittymat-ja-palvelut/netti/nopeustesti)

Please note that the performance and compatibility of devices using your home
internet (e.g., computer, television, phone) as well as the modem or [Mesh
Wifi](https://www.dna.fi/laitteet/modeemit-ja-mokkulat/mesh) system affect
your internet speed.

It is a good idea to take an internet speed test by connecting your computer
directly to the modem with an Ethernet cable. The speed measured over a
wireless WiFi connection may be up to half lower.
