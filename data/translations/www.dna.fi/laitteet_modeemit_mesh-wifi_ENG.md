### Features

  * Shares wireless WiFi network from the home's Ethernet port or modem's LAN port
  * Creates a comprehensive WiFi network and optimizes the network for all devices
  * Tri-band Mesh – three simultaneously operating transfer bands guarantee a fast connection and low speed loss
  * Up to 400 Mbit/s speed on the 2.4 GHz frequency, 867 + 867 Mbit/s speed on the 5.0 GHz frequency
  * 802.11 a/b/g/n/ac MU-MIMO technology 4 GHz 2 x 2, 5 GHz 2 x 2, 5 GHz 2 x 2 
  * Asus AiProtection, Quality of Service, IPv6 support, Parental Control
  * Connections: WAN x 1/10/100/1000, LAN x 1 RJ-45 10/100/1000
  * System management via web browser or Asus Lyra app (Android and iOS)

## What is a Mesh Network?

One internet endpoint, such as a modem or Mokkula, is not always sufficient to create a network that covers the entire home. In this case, the internal network can be expanded
by linking one or more Mesh routers to the modem. A Mesh network is therefore
a whole formed by multiple Mesh WiFi devices that creates a unified
wireless internal network in the home without dead zones.

[ Read more ](https://www.dna.fi/laitteet/modeemit-ja-mokkulat/mesh)
