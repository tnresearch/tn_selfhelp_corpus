#### Version V5R020C10S312 released on October 1, 2024.

The update will cause a brief interruption, during which the device will restart.

  * Mesh compatibility with DNA Kotimokkula 5G WiFi H158
    * Note: See instructions below if you have previously used Kotimokkula H158 and have one or more K562 mesh extenders connected to it.
  * WPA3 encryption optimization
  * Other general improvements

**DNA Kotimokkula 5G WiFi H158 in router mode + one or more
Ethernet and Mesh Modem WiFi 6 K562**

If your Kotimokkula H158 is in router mode (default setting)
and a K562 mesh device is connected to it, the H158 will become the main device after the K562 software update, and you will use the WiFi network (SSID and password) defined in the H158.

  1. If the K562s are connected to the network with Ethernet cables: No action required
  2. If the K562s are connected to the network wirelessly: Re-establish the Mesh WiFi network connection for them. or See instructions [Using as a WiFi Extender](https://www.dna.fi/tuki/laitteet/modeemit/ethernet/dna-ethernet-wifi-6-k562/kayttoonotto#wifi-laajentimena) or <https://www.youtube.com/watch?v=2lJf5OI8jds>

**DNA Kotimokkula 5G WiFi H158 in bridge mode + one or more DNA
Ethernet and Mesh Modem WiFi 6 K562**

If your Kotimokkula H158 has been switched to bridge mode and a K562 mesh device is connected to it, the WiFi network will continue to function as before.

  * You can enable the H158 as the main device of your WiFi network by switching it back to router mode from the device's settings page. See [instructions](https://www.dna.fi/tuki/laitteet/mokkulat/kotimokkulat/dna-kotimokkula-5g-wifi-h158/asetukset) for removing bridge mode or resetting the device by gently pressing the reset button on the bottom with a sharp object for 5 seconds. After that, you can add your existing K562s as WiFi extenders by re-establishing the Mesh WiFi network connection for them. See instructions [Using as a WiFi Extender](https://www.dna.fi/tuki/laitteet/modeemit/ethernet/dna-ethernet-wifi-6-k562/kayttoonotto#wifi-laajentimena) or <https://www.youtube.com/watch?v=2lJf5OI8jds>
  * After the change, you will use the WiFi network (SSID and password) defined in the H158.
