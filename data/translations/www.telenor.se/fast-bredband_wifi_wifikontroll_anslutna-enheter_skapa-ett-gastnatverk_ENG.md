# Create a Guest Network

Here's how to create a guest network using the Wifi Control app:

  * ### Select Home in the menu

  * ### Swipe right until you see Guest Network

Make sure the guest network is turned on and then click share.

  * ### Share Network

Now you can either provide the person who needs access to the network with
the password, or you can ask them to scan the QR code. Clicking share allows
you to forward the QR code via SMS, Whatsapp, email, etc.

If you want to change the name and password, click edit.
