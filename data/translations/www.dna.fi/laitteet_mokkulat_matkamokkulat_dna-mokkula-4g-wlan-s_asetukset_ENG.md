## Settings

You can access the modem's software management page by entering the following in the address bar of your web browser: http://dna.mokkula or alternatively http://192.168.1.1.  Connection requires you to be connected to the modem's WiFi network or a USB cable is connected to the computer. The default password for the management page is 12345.

From the management page you can do things like:

• Change the WiFi network name, password and encryption type.

• Select a connection method

• Change GPS settings and use GPS coordinates and a map for location

• View and change all other modem settings

### Using the modem management page on a smartphone

If you have an Android or Apple phone, you can download the modem management application to your phone. Download the Netgear Aircard app from the app store. With the app you can e.g. change the WiFi network range or lock the modem to a 4G or 3G network.

The application requires you to use the phone on the modem's WiFi network. The application will ask for the modem password and it is 12345 by default.

Locking the modem to a 4G or 3G network

The modem defaults to selecting either a 4G or 3G network. If you want to change this, follow these steps.

1\. Type http://dna.mokkula into the address bar of your web browser.

2\. Enter **12345** as the password.

3\. Click on the image with **antennas and signal bars**.

4\. Change the item labeled **network technology**:

\- Automatic: The modem selects the fastest available network. If a 4G or 3G network is not available, the modem selects a 2G network.

\- 4 G or 3G: The modem selects a 4G or 3G network by default.

\- Only 4G LTE: Locks the modem to the 4G network.

\- Only 3G: Locks the modem to the 3G network.

Enabling GPS

1\. Go to the modem management page http://dna.mokkula

2\. Log in. The default password is **12345.**

3\. Click on the **GPS icon.**

4\. Select **Search for GPS signal** (one-time location) or **start GPS location** (continuous).

5\. Press **On Map** when you want to see your location.

Using WPS (WiFi)

Some devices can be connected to the modem's WiFi network without a keyboard. This requires that the devices support the WPS feature. These devices include certain cameras, printers and smartphones.

1\. Press the WPS button on the modem. You can find the WPS button on the edge of the modem.

2\. Within two minutes, press the WPS button on the wireless device you want to connect to the modem.

3\. An automatic connection is created between the device and the modem, after which the internet connection works.

Changing the modem management password

You can change the modem management password if you wish. If you forget the changed management password, you can reset the modem to factory settings.

1\. Open a web browser when you are connected to the modem's WiFi network

2\. Type http://dna.mokkula in the address bar

3\. The management page password is **12345**

4\. Click on the lock icon on the management page

5\. Change the new password in the first field

Reset to factory settings

  1. Insert the battery into the modem and close the back cover. Turn on the modem by pressing the power button.  

  2. Wait for the modem to start up. Then press and hold the power button and WPS button (on the edge of the modem) simultaneously for 5 seconds.  

  3. Press the power button before the bar on the screen has time to run out. After this, the text "Restarting" will appear on the screen.   

  4. Wait for the modem to restart. Then accept Finnish as the language by pressing the power button. 

Entering the PIN code

By default, the modem's PIN code is 1234. If the PIN code is something else, the code must be entered the first time the modem is used in the modem settings. This happens as follows:

1\. Open a web browser and type http://dna.mokkula in the browser's address bar

2\. Select **Settings** from the top

3\. Enter **12345** as the password

4\. The modem now asks for the PIN code. Enter the SIM card PIN code and press **OK.**
