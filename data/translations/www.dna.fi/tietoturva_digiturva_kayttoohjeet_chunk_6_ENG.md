## Password Vault

Getting Started with the Password Vault

**Especially Important When Setting Up the Password Vault**

  * Choosing a Master Password
  * Creating and Saving a Recovery Code

When you use the Password Vault for the first time, you must choose a master password. The master password is extremely important because it is required to use the application and also ensures the security of your password information. Choose a master password or passphrase that is difficult to guess and that you remember, as a forgotten **master password cannot be recovered.** During setup, you can create a recovery code that you should save in a secure location. If you forget your master password, you will no longer be able to access your saved passwords without the recovery code.

#### Using the Password Vault for the First Time

1\. Open DNA Digiturva and select **Password Vault**.

2\. Select **Start**.

3\. Select **I am a new user**.

4\. Enter your chosen master password and press **Continue**.

5\. Re-enter your chosen master password and press **Continue**.

6\. Create and save the QR recovery code. Press **Save as image**.

7\. If your device uses fingerprint or facial recognition, you can now grant the application permission to use it to unlock the password vault. If you want to use this feature, press **Save** and confirm your fingerprint or facial recognition.

8\. Now you can create new passwords.

Using the Password Vault on Multiple Devices

1\. Open DNA Digiturva on the device to which you want to import passwords from another device.

2\. Press the **Password Vault** section.

3\. Select **I already have an account**.

4\. Open DNA Digiturva on the device where you already have the password vault enabled and log in to your password vault with your master password.

5\. If you are on a phone or tablet, select the **gear icon** in the upper right corner and press **Connect Devices**. On a computer, select **Connect Devices**.

6\. Select **Create Sync Code** if you are using a phone or tablet. On a computer, you will immediately see the generated sync code. If the code expires on the computer, press **Generate New Code Now**.

7\. Enter the code into the new device now and press **Connect**.

8\. Then enter the same **master password** that you use on your other device and press **Confirm**.

9\. Your passwords are now available on the new device. You can enable automatic filling.

**Note!** If you only use the application on one mobile device and have to perform a factory reset on that device, all the data in your Password Vault will be deleted from the device during the factory reset. This deleted data cannot be recovered in any way.

Saving a New Password or Card Information

1\. **Open** DNA Digiturva.

2\. Select the **Password Vault** section.

3\. Enter your master password.

4\. Press **\+ Add** if you are using a mobile device or **\+ Add New** if you are using a computer.

5\. Choose whether you want to add a **password** or a **payment card**. On a computer, you can select the type of information to be saved from the dropdown menu next to **Name**.

  * Password: Add **Name**, **Username**, **Password** (or use the password generation feature), Website address, and any notes.
  * Payment Card: **Name**, **Cardholder**, **Card Number**, **PIN Code**, **Expiration Date**, **Verification Code**, and any website addresses and notes.

6\. Once you have filled in all the selected information, press the **check mark** in the upper right corner if you are using a mobile device or **Save** if you are using a computer. You will then see a summary of the information you just added.

Creating a Strong Password in the Password Vault

You can create passwords yourself or use DNA Digiturva's password generator to help you.

1\. DNA Digiturva tells you how strong your password is when you are creating a new item and typing the password into the designated field.

2\. Or you can use DNA Digiturva's create password feature, which generates a strong password.

  * You can choose whether the password should include uppercase and lowercase letters, special characters, or numbers. You can also choose how many characters your password should have.
  * To use the generation feature, press the dice image next to the password field.

**Using the Create Password Feature**

1\. Create a new password or edit an existing saved password.

2\. Press the dice next to the password field.

3\. You can optionally modify the suggested password and its content or enable the password by pressing the **check mark** in the upper right corner if you are using a phone or tablet, or **Use** if you are creating the password on a computer.

It is also recommended to enable automatic password filling on your device.

Enabling Automatic Password Filling on Phone or Tablet

1\. **Open** DNA Digiturva from your device's screen.

2\. Press the **Password Vault** section.

3\. Press the **gear icon** in the upper right corner.

4\. Press **Automatic Filling**.

**On Android devices:**

  1. Press the **selection button** next to Automatic Filling so that it becomes active.
  2. In your phone's settings, select **DNA Digiturva** as the primary automatic filling service.
  3. The phone will verify that you trust this application. Press **OK**.

**On iPhone or iPad:**

  1. Press **Go to Settings**.
  2. Press **Passwords**.
  3. If you use fingerprint recognition, unlock the saved passwords with it.
  4. Press **Fill Passwords Automatically**.
  5. Enable automatic password filling by pressing the selection button to activate it.
  6. Select DNA Digiturva by pressing the **selection button** next to it.

When you return to the DNA Digiturva application, you will see that automatic filling is enabled when the selection button has become active.

Please note that automatic filling only works if you have saved the service's username, password, and website address.

Enabling Automatic Password Filling on Computer

1\. Open DNA Digiturva.

2\. Click the **Password Vault** section.

3\. Enter your master password.

4\. Select **automatic filling**.

5\. Automatic filling requires installing a browser extension, select the browser you want to install the extension on and click **Install Extension**.

6\. Press **Add to Chrome/Firefox/Edge/Safari** and **Add Extension**.

5\. Return to the DNA Digiturva application. You will need the code displayed on the page after installing the extension. Copy the code by pressing **Copy Code**.

7\. Return to the desired browser. Press the **extension icon** next to the address bar and select **Password Manager by F-secure**.

8\. Enter the copied code into the field that appears and press **Authorize**. You can close the Password Manager window by pressing **Close**.

Recovering a Forgotten Master Password

If you have forgotten your master password, but you have the QR recovery code saved, you can recover your master password. If you cannot find the QR recovery code, you will no longer be able to access your saved passwords.

#### Recovery on Phone or Tablet

1\. Open the DNA Digiturva application and select **Password Vault**.

2\. Press **Forgot Master Password?**

3\. If the QR code is saved on the device you are using to recover the password, press **Import Image**. If you have the QR code saved on another device or as a printout, press **Scan Recovery Code**.

4\. After you provide the QR code, the application will show you your master password.

#### Recovery on Computer

1\. Open the DNA Digiturva application and click the **Password Vault** section.

2\. Click **Have you forgotten your master password?**

3\. The QR recovery code must be saved on the device you are using to recover the master password. Press **Import**.

4\. After you provide the QR code, the application will show you your master password.
