# Help with ZTE MF60

Here you will find information and guidance on how to set up and use the
ZTE MF60 Mobile Broadband Router.

Upgrade your router

## Simple steps to get online

1

#### Insert the SIM card (do not break out Micro or Nano-SIM)

Open the lid and insert the SIM card

2

#### Turn on the router

Hold down the On/Off button for a few seconds.

3

#### Connect a computer to the wireless network

Windows:

  1. Left-click on the icon for the wireless network at the bottom by the clock and date
  2. Find the network that matches the network name on the inside of the lid and press 'connect'
  3. Enter the network password that is on the inside of the lid, press 'connect'

Mac:  

  1. Press Airport, the icon for the wireless network  

  2. Press your network  

  3. Enter the network password that is on the inside of the lid, press 'connect'

  

You can also find the network name and password inside the router's menu
under info.

4

#### Open a browser and follow the wizard

Enter a web address, such as www.online.no.

You will find the PIN code in the letter that came with the SIM card.

If you cannot find the PIN code, you need the PUK code to create a new PIN.

**You can find the PUK code like this:**

  * [Log in to My Pages](https://www.telenor.no/privat/minesider/abonnement/abonnement.cms)

  * Select the subscription in question

  * Click **Get PUK code** under **My SIM cards** at the bottom of the page

## Questions and Answers

#### How do I access the router's menu?

The router has its own menu, where you can, among other things, change the wireless network name
and network key.

**Here's how to access the router's menu:**

  * Open a new browser, such as Internet Explorer, on a computer that is connected to the router. Type **192.168.1.1** in the address field, press **Enter**.

  * Enter **Password**: admin

Note, if you have changed the password yourself, enter that one.

?

#### How do I restore factory settings?

If you are experiencing problems connecting to the Internet, it may help to reset
the router.

The network name (**SSID**) and network key (**PWD/WIFI KEY**)
can be found inside the lid of the router. You can also find the sticker on
the inside of the cover.

**Here's how to reset the router manually:**

  1. Open the lid on the router.

  2. Hold down the On/Off and WPS buttons simultaneously for 5 seconds, or until the router turns off.

  3. The router turns off and on, and you can connect to the wireless network again.

**Note**, after you have reset the router, the network name and
network password will be reset.

**Here's how to restore factory settings via the menu:**

  1. Open a new browser, such as Internet Explorer, on a computer that is connected to the router. Type **192.168.1.1** in the address field, press **Enter**.

  2. **The password** is admin

  3. Click **Settings**

  4. Select **Advanced** then **Restore.**

  5. Press **Restore** again to confirm.

The router will automatically turn on again, and you can connect again. Note,
after you have reset the router, the network name and network password will be
reset. If you have changed the login password for the router, this will also
be reset.

?

#### How do I change the wireless channel?

If you have a weak signal strength or problems finding the wireless network,
it may help to change the wireless channel.

To change the wireless channel, you must access the router's menu. The computer must
be wirelessly connected to the router to access the menu.

  1. Open a new browser, such as Internet Explorer, on a computer that is connected to the router. Type **192.168.1.1** in the address field, press **Enter**.

  2. Enter password: **admin**

  3. Select **Settings**

  4. Click **Wi-Fi settings.**

  5. Select a channel from the drop-down menu under **Frequency (Channel)**. It is recommended to choose **1**, **6** or **11**. Channel 11 may work better than channel 1 at your home, so try it out.

  6. Press **Apply**. The settings are now saved.

If you still experience the same problem, repeat from step 4 and try a
different channel that may work better on your computer.

?

#### How do I lock the network to 4G, 3G or 2G?

If the network is unstable, it may help to lock the network to either 4G, 3G or 2G.

**Here's how to do it:**

  1. Open a new browser, such as Internet Explorer, on a computer that is connected to the router. Type **192.168.1.1** in the address field, press **Enter**.

  2. Enter **Password:** admin

  3. Select **WAN connection**

  4. Check **Manual**, select **Disconnect from Internet** in the drop-down menu.

  5. Press **Apply**.

  6. Select **Settings**.

  7. Press **Select Network.**

  8. Select **Only 3G** or **Only 2G**. Press **Apply**.

  9. You must now reconnect to the Internet. Select **WAN connection**.

  10. Check **Manual**, select **Connect to Internet** in the drop-down menu.

#### Error message - Device not found

  1. Turn on the router

  2. Connect the USB cable between the router and the PC

  3. **Windows:** Select Computer -> Telenor icon -> TelenorMiniruter_MF91D to start installation

  4. **MAC:** Click Finder -> Devices -> Telenor -> TelenorMiniruter_MF91D to start installation

?

#### Change Access Point Name (APN)

  1. Open a browser, such as Internet Explorer, on a computer that is connected to the router

  2. Type 192.168.1.1 in the address field, press Enter.

  3. Enter admin in the password field, press Login. The default password is “admin” or a custom password that was chosen during the first-time setup of the router

  4. Select Settings and press APN

  5. Press Add

  6. Enter the desired profile name. (this is just a description of the new profile)

  7. Enter the desired APN in the APN name field

  8. Press Save

  9. Check that your new profile is selected as active under Profile selection at the top of the page

  10. Restart your router.
