# Change Network Name or Password

Do you want to change the network name or password for your wireless network?
Here we show you how to do it in My WiFi!

## How to do it

  1. Log in to My WiFi by going to: wifi.telenor.no

  2. Press **Manage Wireless Networks**

  3. Find the network you want to change

  4. Enter a new network name and/or password and press **Save**

    *  **Tip:** The password must consist of at least 8 characters (we recommend using at least 12 characters), feel free to use a combination of numbers, lowercase and uppercase letters to make your network as secure as possible.

  5. You can now connect your devices to My WiFi

Forgot admin password?

If you have changed your admin password, this will still apply after a
router reset or if you get a new router. If you have forgotten what it is,
it is still possible to change it.

  1. Open a browser and go to the address wifi.telenor.no

  2. Select Forgot password

  3. Enter mobile number or email address

  4. Select Send reset link

  5. You will now receive an SMS or email with further information

If you no longer have the email address or mobile number that was
registered during creation, you must [contact Customer
Service](/kundeservice/kontakt-oss/).
