# Activate discovery+ Entertainment

Add the streaming service discovery+ as part of your TV package. On this
page you will find help with registration and activation of username and password.

[discovery+ on T-We Box](/kundeservice/tv/velge-kanaler/aktiver-
discoveryplus/#boks)[Already have a discovery+ account](/kundeservice/tv/velge-
kanaler/aktiver-discoveryplus/#konto)[Questions and
Answers](/kundeservice/tv/velge-kanaler/aktiver-discoveryplus/#sos)

## How to Access discovery+ Entertainment

  1. Add discovery+ Entertainment on [My Pages](https://www.telenor.no/minesider/)

  2. Follow the link to create a user account for discovery+ and activate it against T-We

  3. Log in with username and password the first time you use the service

**Need help adding or removing content on My Pages?** [Here
we show you how to choose channels and streaming services into your T-We
channel package.](/kundeservice/tv/velge-kanaler/)

### Already chosen discovery+, but haven't started using it?

If you have chosen discovery+ on My Pages, you must create a discovery+ account and
log in to start streaming.

Create account or log in

### Where can I use discovery+?

The service is available on T-We Box, but you can also use it on PC, mobile
or tablet via the discovery+ app or
[discoveryplus.no](https://www.discoveryplus.no/). It is possible to watch
discovery+ on up to 3 different devices simultaneously.

It is not possible to watch discovery+ Entertainment via [T-We
app](/privat/tv/t-we/tv-hvor-du-vil/).

Create a user account with Discovery: After choosing the streaming service into the TV
package on My Pages, you will be taken to registration with Discovery. Fill
in email address, create a password, check that you approve the terms and
press "Accept and continue".

## Already have discovery+? Use the same login.

If you have a user account with Discovery, you can use the same login with
us. Choose "I already have a discovery+ account" when you are taken to
activation after adding discovery+ Entertainment on My Pages.

You will then see this image. Then enter username and password and press on
**Log in**.  
_Do not use "Log in with partner"_.

If you have an active subscription with Discovery, you must remember to cancel this
afterwards so that you do not pay for the subscription in addition to using points.

Log in with an existing discovery+ user: When you press "I already have a discovery+ account" you will see this image. Enter username
and password and press Log in.

## Questions and Answers

  * #### Are you getting an error message: "You do not have access to this content."?

This error message may appear if you try to open content that
is not available in discovery+ Entertainment. It is not possible to use
the same discovery+ account that you have via Telenor to order other content from
discovery+. The error message will then appear instead of you getting the opportunity to
order or upgrade the content.

If you want to order other content in discovery+, you must register with
Discovery with a different user account.

  * #### Why am I asked to log in with Telenor ID?

This is to verify that discovery+ Entertainment is active as part of
your channel package.

If you are not [logged in with Telenor ID](/telenor-id/) on this device from
before, you will be asked to log in before registering a user on discovery+.

  * #### Can I watch discovery+ Live?

It is not possible to upgrade from discovery+ Entertainment to discovery+
Live, but it is possible to watch TV channels directly via T-We as part of
the standard package or the optional channels.

  * #### Can I use the discovery+ app on the T-We box with a user account from Discovery?

Yes, you can use any discovery+ user account. If you
subscribe to discovery+ Sport with Discovery, you can, for example, log in with this
instead of activating discovery+ Entertainment in the TV package.
