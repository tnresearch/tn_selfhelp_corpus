## Getting Started

  * Place the Travel Modem's battery in place under the back cover.

  * Open the SIM card slot located on the top of the Travel Modem using the tool included in the package and insert the SIM card.

  * If the Travel Modem does not start with the power button, its battery may be empty. Connect the included power cord to the modem and the other end of the power adapter to the wall outlet.

  * Place the modem as close to the window as possible, so that the connection speed is the best possible.

  * On your computer, tablet or mobile phone, select the WiFi network and password, you can find them behind the touch screen WiFi menu of the Travel Modem as well as on the sticker under the battery.

  * If necessary, change the settings according to these instructions, and find the best location for the Travel Modem, taking into account both the locations of the 4G/5G network base stations and the placement of devices using the modem's wireless WiFi network.

  * You can change the device settings on the management page in a web browser. You can also edit some settings on the modem's display screen.

#### The Travel Modem uses a Nano-SIM card size.

The SIM card comes off its tray without using much force when you press it from the back of the SIM card. If you remove a SIM card of the wrong size, visit a DNA Store to exchange it for a new SIM card.

## Connecting to WiFi

Windows 10

On a Windows 10 computer, click the WiFi network signal bars in the bottom right corner of Windows.  
Then select the network whose name is on the back of the modem (SSID). Check the box next to "**Connect automatically**" and press **Connect**.

Next, the computer will ask for the wireless network password. The password can be found on the sticker on the back of the modem. Enter the password exactly as it is on the sticker and press **Next**. Now you can start using the internet.

Windows Vista or Windows 7

On Windows Vista and Windows 7 computers, click the WiFi network signal bars in the bottom right corner of Windows.  
Then select the network whose name is on the back of the modem (SSID). Check the box next to "**Connect automatically**" and press **Connect**.

Next, the computer will ask for the wireless network password. The password can be found on the sticker on the back of the modem. Enter the password exactly as it is on the sticker and press **OK**. Now you can start using the internet.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select the gear icon (**settings**).  
Next, select the signal bars.  
Then select the network whose name is on the back of the modem (SSID). Check the box next to "**Connect automatically**" and press **Connect**.

Next, the computer will ask for the wireless network password. The password can be found on the sticker on the back of the modem. Enter the password exactly as it is on the sticker and press **Next**.

If you want to share files between devices, select the lower option. If you do not want to share files between devices, select the upper option.

MAC

Click the WiFi network icon at the top of the screen with the mouse. Then select the network whose name is on the back of the modem.

Next, the computer will ask for the wireless network password. The password can be found on the sticker on the back of the modem.  
Enter the password exactly as it is on the sticker. Click "**Remember this network**" and press **Join**.

Apple iPad

  1. Select **settings** from the desktop.
  2. Select the **Wi-Fi** section in settings. (On older iPad devices, the section is marked WLAN).
  3. Wait a while for the iPad to search for networks. Then select the network whose name is on the sticker on the back of the modem.
  4. Next, the iPad will ask for the wireless network password. The password can be found on the sticker on the back of the modem. Enter the password exactly as it is on the sticker.
  5. Press **Join**. Now you can start using the internet.

Android tablet

  1. Go to the view where you can see all applications.
  2. Select **Settings**.
  3. Select Wi-Fi (Wireless & networks on older Android tablets).
  4. Wait a while for the tablet to search for networks. Then select the network whose name is on the sticker on the back of the modem.
  5. Next, the tablet will ask for the wireless network password. Enter the password exactly as it is on the sticker.
  6. Press **Connect**. Now you can start using the internet.

## Connecting to a network wirelessly with the Modem

DNA modems are encrypted in terms of wireless networks. You can find the network name and password on the sticker under the modem's battery or on the management page and on the modem's display screen under the "**Device info**" menu.

  * SSID (network name):  
E.g. DNA-Modem-2GHz-XXXXX  
DNA-Modem-5GHz-XXXXX

  * Password:  
E.g. 12345678901

The DNA Travel Modem supports 2.4 GHz and 5 GHz wireless WiFi networks. More detailed instructions for different modem models and operating systems can be found at [dna.fi/tuki-mokkulat](http://dna.fi/tuki-mokkulat)

Also, familiarize yourself with safe internet use and protecting your data at [dna.fi/tietoturvaopas](http://dna.fi/tietoturvaopas).

## Mobile and WiFi connection and modem placement

WiFi is a flexible and easy way to build your own local network.  
However, please note the following:

  * Obstacles weaken the range of WiFi devices. The signal travels through doors, windows and lighter wall structures, but each obstacle weakens it. The materials that most block the signal are metal, concrete, brick and stone. Even in difficult cases, a solution is usually found by using additional antennas or base stations, and the location of the base station or antenna is also very important. Do not place other electronics right next to the WiFi device.
  * Pay attention to the placement of devices. The modem should be placed as centrally as possible in relation to the area where the network is desired to function. The modem should also be higher than the average table level.
  * Wireless WiFi networks currently cannot achieve the peak speeds of the modem. When using our fastest speeds, we recommend connecting the computer directly to the modem with a USB cable.
  * The speed and functionality of the WiFi network are also affected by the number of nearby wireless networks and the transmission channels in use. If your WiFi connection is intermittent or slow, you can try to fix the connection by searching for a better WiFi channel or manually changing the frequency. See instructions here.
  * In addition to WiFi, the location must also take into account the coverage of the 4G/5G network when considering the mobile connection. The best place for the modem at home is near a window facing the direction of the base station. The approximate locations of base stations can be checked with DNA customer service.
