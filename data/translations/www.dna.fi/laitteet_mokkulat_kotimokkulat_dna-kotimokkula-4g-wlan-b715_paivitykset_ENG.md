## Updates

The DNA Home Modem B715 is updated by logging into the settings pages,
selecting "updates" and following the instructions on the site. You can also
set the modem to update itself automatically from the "system" section.  
  
**B715 receives an update starting 12.8.2019:**

  * Improvements and fixes to the setup wizard (including ‘reboot schedule’)
  * Improvements to bridged mode operation
  * Security updates

New software version: 11.198.01.00.182  
  
New web interface version: 21.100.50.00.03  

**B715 receives an update starting 7.11.2018:**

  * Frequency information to system information
  * Full IPv6 support
  * Fixes to bridged mode with third-party routers
  * Time zone fix
  * WiFi country code to FI format
  * Improvement to redirection in setup and updates 

New software version: 11.197.01.00.182

New web interface version: 21.100.45.00.03

DNA recommends updating to the new version as soon as possible. However,
the update happens gradually, meaning not everyone can update to the latest
version at the same time. After the update, it is a good idea to restore the
device to factory settings and clear the browser cache (cookies, offline
files).

**B715 receives an update starting 8.5.2018:**

  * User interface is renewed in every area
  * Bridged mode added
  * 4G frequency lock (first select "4G only" mode)
  * Signal info added
  * IPv6 fixes
  * Much more

New software version: 11.195.03.00.182

New web interface version: 21.100.39.00.03
