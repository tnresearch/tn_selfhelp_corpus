# Problems with SMS?

If you can't send or receive SMS with your Samsung, you can often solve the
problem yourself. Here we have collected a list of the most common
troubleshooting steps.

  * Restart your mobile and check if there are any updates available.
  * Can you not make calls either? Then there may be problems with access to the network. Check our [service information](/support/driftinformation/driftstorningar-pa-mobilnatet/) to see if there is any temporary service disruption.
  * Test if you can send an SMS to another recipient. Did it work? Then it may be a problem with the recipient.

Normally, you should not need to set the number for the message center, but it
is done automatically when you insert the SIM card. Follow the steps below to
ensure that the number is still correct.

  1. Press "Messages.."
  2. Press "MORE".
  3. Press "Settings".
  4. Press "More settings".
  5. Press "SMS".
  6. Press "Message center".
  7. Enter +46708000708 and press "SELECT".
