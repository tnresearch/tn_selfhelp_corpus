## Updates

Inteno/Genexis devices are updated from their settings pages or a possible update button.

You can access the settings pages by connecting a user device to the modem via WiFi or cable and the internet, typing the following into the address bar of a mobile device or computer browser: 192.168.1.1 and logging in with the username admin and the password 1234.

If an update is available for the device, a notification will appear on the settings page homepage after logging in ("New software available"). Clicking the notification button will present different options for updating the device.

**Yes:** Updates the software and retains user-made settings.  
**No:** Updates the software and restores default settings.  
**Cancel** : Does not update the latest software. The notification button remains visible to remind you of the update. The selection is made by clicking the desired button.  

Once you have pressed the selection, the device will start downloading the software from the server, updating the software and restarting.

### New version 4.3.6.100 released on 29.6.2021

  * Changed WiFi Mesh Repeater/Extender mode detection - the device switches back to routing mode if it receives a public IP address
  * UBUS-X backend enabled for communication between devices (WLAN Mesh)
  * HTTPS Web management added
  * EasyQoS feature (as a widget on the WebGUI homepage)
  * Other minor fixes and security improvements

### **New version 3.16.9 released in February 2020**

  * Driver updates, security updates and bug fixes, such as e.g. EX400 malfunction as a repeater/mesh*.
  * New feature where the DG200AC, DG301AC, EG300 EXT light flashes if an update is available. Pressing the light starts the update.

*With the new version, you can use the new EX400 router as an additional access point for other Inteno/Genexis devices.[ See more information](https://www.dna.fi/dna-valokuitu-plus-modeemi-ex400-ethernet-talouksiin#asetukset).

### **New version 3.16.7 released in June 2019**

  * Minor fixes in all areas
  * Latest security updates 

### **New version 3.15.4 released on 25.9.2018**

  * IPv6 fixes
  * 2.4GHz 40MHz fixed
  * Internet status check changed from DNS ping to GW address
  * Interval time increased to 30s (IPv4) and 300s (IPv6)
  * [Vulnerability](https://www.kyberturvallisuuskeskus.fi/fi/haavoittuvuudet) patched

### **New version 3.15.0 released on 26.6.2018**

  * Numerous security and performance improvements
  * Fix for connecting to 2.4Ghz WiFi
  * Fix for IPv6
  * User interface improvements
  * Extender feature improvement
  * DYNDNS/DDNS fixed
