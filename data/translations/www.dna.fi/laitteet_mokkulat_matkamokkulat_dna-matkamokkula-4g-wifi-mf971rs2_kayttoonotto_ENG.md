## Installing the Modem

Place the SIM card into the SIM card slot on the bottom of the modem by first opening the protective flap.

If the modem does not start with the power button, its battery may be empty. Connect the included power cord to the device and the other end of the power adapter to the wall socket.

Place the modem as close to the window as possible. This way, the connection speed will be the best possible. Check the signal strength from the upper left corner of the modem's display screen.

On your computer, tablet, or mobile phone, select the WiFi network and password. You can find them on the sticker on the back of the modem and on the modem's display screen under the "Device Info" menu.

If necessary, change the settings in these instructions and find the best location for the modem, considering the locations of both 4G base stations and the devices you are using.

Registering to the DNA network takes a few minutes. If the connection fails to open, call DNA's [customer service](https://www.dna.fi/yhteystiedot#asiakaspalvelu).

You can see an icon indicating the signal strength on the modem's display.

You can change the device settings either directly on the device's display or through the management page in your device's browser.

## Enabling Wireless Network (WiFi)

DNA modems are encrypted in terms of wireless network. You can find the network name and password on the sticker on the back of the modem, on the modem's management page, and on the modem's display screen under the "Device Info" menu.

SSID (network name)  
E.g. DNA-Modem-2GHz-XXXXX and DNA-Modem-5GHz-XXXXX

Password  
E.g. 12345678901

  
DNA Travel Modem supports 2.4 GHz and 5 GHz wireless WiFi networks.

Note! The 2.4 GHz and 5 GHz networks share the same antenna system. Using the networks simultaneously will affect the WiFi transfer speed of both networks.

Windows 10

On a Windows 10 computer, click the WiFi network availability bars in the bottom right corner of Windows.

Then select the network whose name you see on the modem's display (SSID). Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find the password on the sticker on the back of the modem. Enter the password exactly as it is on the sticker and press **Next**. Now you can start using the internet.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select Settings (gear icon). Next, select the availability bars.

Then select the network whose name is on the sticker on the bottom of the modem.

Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find the password on the sticker on the back of the modem. Enter the password exactly as it is and press **Next**.

Windows 7 / Vista

On a Windows 7 and Vista computer, click the WiFi network availability bars in the bottom right corner of Windows. Then select the network whose name is on the sticker on the back of the modem (SSID).

Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find the password on the sticker on the back of the modem. Enter the password exactly as it is and press **OK**.

You can start using the internet.

Mac OSX

Click the WiFi network icon at the top of the screen with the mouse. Then select the network whose name you can find on the sticker on the back of the modem.

Next, the computer will ask for the wireless network password. You can find the password on the sticker on the back of the modem. Enter the password exactly as it is. Select “Remember this network” and press **Join**.

You can start using the internet.

Apple iPad

From the iPad home screen, select Settings. From settings, select Wi-Fi (WLAN in older models).

Wait a moment while the iPad searches for networks. Then select the network whose name is on the sticker on the back of the modem.

Next, the iPad will ask for the wireless network password. Enter the password exactly as it is on the sticker on the back of the modem. Press **Join**. You can start using the internet.

Android Tablet

Go to the view where you see all the apps.

Select **Settings** and from the menu select **Wi-Fi** (Wireless & networks in older versions). Wait a moment while the tablet searches for networks. Then select the network whose name is on the sticker on the back of the modem.

Next, the tablet will ask for the wireless network password. Then select the password whose name is on the sticker on the back of the modem.

## Changing the Modem Settings

**Entering the PIN code**

If the SIM card has a PIN code other than 1234, the PIN code must be entered on the modem's display or through the settings pages.

**From the modem's display:**

  1. Turn on the display by pressing the modem's power button
  2. Enter the PIN code using the power button and the Func button.
  3. Finally, press OK with the power button

**Through the web browser:**

  1. Open a web browser when you have used the modem's WiFi network.
  2. Type **http://dna.mokkula or http://192.168.1.1** in the address bar
    * The default username is **admin**.
    * The default password is **1234**.
  3. Select **advanced settings** from the main pages and **Other** from the top menu that opens.
  4. Select **PIN code management** from the left. 
  5. Enter the PIN code in the **Current PIN** field and press **Apply**.
