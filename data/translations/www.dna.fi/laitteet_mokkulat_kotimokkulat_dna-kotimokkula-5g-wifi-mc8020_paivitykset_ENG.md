# Updates

#### MC8020 has received an update starting from week 19/2024

**Update content:**

  * The default network selection setting changes to 5G NSA
  * IPv6 settings have been optimized
  * Security fixes from the device manufacturer
  * Other minor bug fixes
  * New software version: CR_FIDNAMC8020V1.0.0B15

#### Previous updates:

#### MC8020 has received an update starting from 9.12.2022

The software version includes several minor fixes and improvements to the
device's operation. The naming of the device's wifi networks will change
slightly with the update. Even if a 2.4 GHz & 5 GHz (band steering) network
is active on the modem, a separate 5 GHz network will be visible alongside
it, to which you can alternatively connect if you want to ensure that your
device remains connected to the 5 GHz wifi network.

With band steering active, the following network names (SSIDs) will be
displayed in the future:

  * DNA-WIFI-XXXX (combined 2.4 GHz and 5 GHz network)
  * DNA-WIFI-5Ghz-XXXX (separate 5 GHz network)

With band steering deactivated, the following network names will be displayed
in the future:

  * DNA-WIFI-2Ghz-XXXX (2.4 GHz network)
  * DNA-WIFI-5Ghz-XXXX (5 GHz network)

New software version: CR_FIDNAMC8020V1.0.0B08
