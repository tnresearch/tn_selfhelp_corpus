## Updates

The device's software is no longer actively updated. We recommend replacing it with a new device to ensure that security and performance are up to date.

You can perform the modem update from the management page. A notification will appear on the settings page if new updates are available.

You can check for updates manually at **Settings > Device settings > Update management.**

## Troubleshooting

What should I do if my modem's battery is swollen?

If your modem's battery is swollen even slightly, stop using it immediately. Take the modem to a DNA Store. Swelling can be noticed directly by the bulge of the battery or, for example, the movement of the back cover. With current battery technology, a similar risk of swelling exists for every battery-powered device. The risk increases if usage is truly intensive, the modem is in a place where its temperature rises critically, or if changes have been made to it that are not mentioned in the manual.

I cannot establish a connection between the modem and the computer via USB cable

Install the modem software on the computer and run the setup program in the My Computer window. If the modem driver appears abnormal, reinstall the software. Install the software first.

I cannot establish a WiFi connection between the modem and the client device

Make sure that the WiFi function is enabled. Update the network list and select the correct network name (SSID). Check the IP address and make sure that the client device can obtain an IP address automatically.

Enter the correct network key (WiFi password) when connecting the client device to this device.

I cannot access the internet with a client device connected to the modem

Make sure that the modem has a working mini-SIM card. Change your location if necessary and look for a place where the modem signal is good.

Check the external connection settings (WAN). Contact your service provider and verify the APN settings.

I cannot use the internet in Internet access point mode

Make sure that the WiFi device is connected to the Internet. Make sure that the modem and WiFi device are on different subnets.

I cannot access the modem configuration page

Enter the correct address. The default address of the configuration page is http://192.168.0.1 or http://dna.mokkula.

Use only one network adapter on your computer. Do not use any proxy server.
