## Troubleshooting

I am using the modem with a SIM card that asks for a PIN code.

You can enter the PIN code through the modem's management page. See the instructions at [Entering the PIN code](/dna-kotimokkula-4g-wlan-b593s#asetukset).

The modem connection is intermittent or slow.

If the connection is slow or intermittent, it is worth moving the modem closer to the window and enabling the additional antennas included with the modem. If these measures do not help, you can call DNA Customer Service and ask which direction the nearest base station is located and move to that window.

The computer reports "Limited connectivity."

The modem is not connected to the internet. Check the connection, connections, and SIM card PIN code. Restart the modem if necessary.

The modem reports that it is connected to the internet, but the connection does not work on the computer.

Make sure you have connected your computer to the WiFi network created by the modem. You can find the WiFi network name (SSID) on the sticker on the back of the modem.
