## Updates

#### MC889A has received an update starting from week 51/2024:

**Update content:**

  * Information on the hidden speed of the ethernet port has been added to the management pages
  * References to 3G have been removed from the user interface
  * Other minor bug fixes
  * New software version: MC889A_DNA1_B15

#### Previous updates

#### MC889A has received an update starting from week 27/2024:

**Update content:**

  * The operation of the antenna selection mode for the 3.5GHz frequency has been optimized
  * Device stability has been improved in situations where multiple frequencies below 1GHz are used simultaneously
  * New software version: MC889A_DNA1_B13

#### MC889A has received an update starting from week 17/2024:

**Update content:**

  * The default network selection setting changes to 5G NSA
  * Security fixes from the device manufacturer
  * Other minor bug fixes
  * IPv6 settings have been optimized
  * New software version: MC889A_DNA1_B12
