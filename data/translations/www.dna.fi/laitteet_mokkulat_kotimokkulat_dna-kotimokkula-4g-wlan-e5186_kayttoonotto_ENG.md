## Getting Started

## Installing the Modem

Install the micro-SIM card on the back of the Home Modem. You can easily check the correct positioning of the SIM card by comparing one cut corner of the card with the pattern on the slot.

The Home Modem connects to the internet automatically if the SIM card has the PIN code 1234 enabled. If you have a different PIN code, enter the PIN code through the modem's management page.

Install additional antennas on the back of the modem by first removing the protective cover on the back and screwing the antennas into their designated connectors. Note! Remember to disconnect the modem's power source before connecting the antennas.

Plug the modem into a power outlet. If the modem does not start automatically, turn it on using the power button on top.

On your computer, tablet or phone, select the WiFi network and password. You can find them on the sticker on the back of the modem.

## Connect to the Internet

You can connect your computer or any other desired device to the internet with the Home Modem's Ethernet cable or wirelessly via WiFi. The internet connection for devices using an Ethernet cable works when the device is connected, the modem is on, and the SIM card is installed.

Registering to the DNA internet takes a few minutes. If the connection fails to open, call DNA's [customer service.](https://www.dna.fi/yhteystiedot#asiakaspalvelu)

The internet connection is available when the power light and network status indicator (in a color other than red) are lit on the modem.

Place the modem as close as possible to a window. If your apartment is new, we recommend an external antenna installed outside the window. You can find more information about antennas from DNA Store or DNA Customer Service.

## Enabling Wireless Network (WLAN)

The easiest way to connect devices to the WiFi network is using the WPS function. Press the WPS button on the modem for 1-5 seconds and then the WPS function on the device to be connected, and the devices will automatically connect to each other on the 2.4 Ghz WLAN network. If you want to connect to the 5 Ghz network, press the WPS button on the modem for more than 5 seconds.

The default WiFi network name and password (security key in some devices) of the Home Modem can be found on the sticker on the bottom of the modem. You can use the WiFi network to connect any device that supports the WiFi feature.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select **Settings** (gear icon). Next, select the signal bars.

Then select the network whose name is on the sticker on the bottom of the Home Modem.

Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find the password on the sticker on the bottom of the Home Modem. Enter the password exactly as it is and press **Next**.

Windows 7 / Vista

Click the WiFi network signal bars in the lower right corner of the Windows 7 and Vista computer. Then select the network whose name is on the sticker on the bottom of the modem.

Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find the password on the sticker on the bottom of the Home Modem. Enter the password exactly as it is and press **OK**.

You can start using the internet.

Windows XP

On a Windows XP computer, click the computer icon in the lower left corner, which contains the wireless network symbols, as on a Windows 7 computer.

Then select the network whose name is on the sticker on the bottom of the Home Modem.

Press **Connect**.

Next, the computer will ask for the wireless network password. You can find the password on the sticker on the bottom of the Home Modem. Enter the security key exactly as it is on the sticker and confirm the password again in the field below. Select **Connect**.

Mac OSX

Click the WiFi network icon at the top of the screen with the mouse. Then select the network whose name you find on the sticker on the bottom of the Home Modem.

Next, the computer will ask for the wireless network password. You can find the password on the sticker on the bottom of the Home Modem. Enter the password exactly as it is. Select "Remember this network" and press **Join**.

You can start using the internet.

Apple iPad

Select Settings from the iPad home screen. Select WiFi (WLAN in older models) from settings.

Wait a moment while the iPad searches for networks. Then select the network whose name is on the sticker on the bottom of the Home Modem.

Next, the iPad will ask for the wireless network password. Enter the password exactly as it is on the sticker on the bottom of the Home Modem. Press **Join**. You can start using the internet.

Android Tablet

Go to the view where you see all the apps.

Select **Settings** and select **WiFi** (Wireless & networks in older versions) from the menu. Wait a moment while the tablet searches for networks. Then select the network whose name is on the sticker on the bottom of the Home Modem.

Next, the tablet will ask for the wireless network password. Then select the password whose name is on the sticker on the bottom of the Home Modem.

## PIN Code

If the SIM card has a PIN code other than 1234 enabled, the PIN code must be entered in the modem settings.

  1. Open a web browser when you are connected to the Home Modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.8.1 in the address bar.
  3. The default username is **admin** and the default password is **1234**.
  4. Select Internet from the top.
  5. Select **PIN Code Management** from the left.
  6. Enter the desired PIN code in the **Enter PIN** field and press **Submit**.
