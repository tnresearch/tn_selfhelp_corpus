## Updates

The device's software is no longer actively updated. We recommend replacing
it with a new device to ensure that security and performance are up to date.

### Software Updates

In cable modems, updates come automatically from the network. Updates are
run on the modems at night, causing the least amount of problems. In some
rare cases, the modem may need to be reset and restarted in the morning
after an update, so that the device functions optimally.

If you want to run the updates to the device immediately, it is worth trying
to disconnect all cables from the device for a few minutes and then reconnect
them. This will bring the modem back online and request updates at the same
time.
