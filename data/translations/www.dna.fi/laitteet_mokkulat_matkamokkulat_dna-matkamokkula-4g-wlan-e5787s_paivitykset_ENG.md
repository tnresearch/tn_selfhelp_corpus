## Updates

The device's software is no longer actively updated. We recommend replacing it with a new device to ensure that security and performance are up to date.

Updating is done by accepting it from the touchscreen or by going to the settings pages and searching for new updates from the "updates" -> "check for updates" path.

**E5787s received an update on 24.4.2018, changes:**

  * Ipv4 and dual stack switch
  * Finnish as the default language on the touchscreen
  * Added: 3G: CELL_ID, RSSI, RSCP, ECIO 4G: PCI, CELL_ID, RSRQ, RSRP, RSSI, SINR, LTE Frequency Band
  * SSID and password visible on the touchscreen

The version number is V200R001B317D62SP00C182
