## Getting Started

## Installing the Modem

The modem uses a standard Mini-SIM card, which is the largest card size. The SIM card comes off without much force when you press it from the back of the SIM card. If you remove a SIM card of the wrong size, visit a DNA Store to exchange it for a new SIM card.

The SIM card is installed under the cover on the front of the modem. Push the cover away from the USB port. Install the SIM card into the modem with the metal part facing down and finally close the cover.

Registering to the DNA network takes a few minutes. If the connection fails to open, call DNA's [customer service](https://www.dna.fi/yhteystiedot#asiakaspalvelu).

The internet connection is available when the power light and network status indicator light are on in the modem.

## Enabling Wireless Network (Wi-Fi)

Windows XP, Vista and Windows 7

  1. Connect the modem to your computer.
  2. Installation starts automatically. Note! If the installation does not start automatically, open **My Computer** and the CD drive named **HiLink**. Click the file named **AutoRun.exe**.
  3. If the Windows firewall is on, confirm the installation by pressing **Yes**.
  4. Installation begins. When the installation is complete, the computer opens a web browser and the modem's own management page in the browser. Now you can use the internet.

Windows 8

You can run the installation in the same way as in Windows 7, but the following installation method also works in Windows 8.

  1. Connect the modem to your computer.
  2. A window with the title **”CD drive (E:) HiLink”** appears in the upper right corner of the computer. Click the window.
  3. The next window opens and select **Run AutoRun.exe** from it.
  4. If the Windows firewall is on, confirm the installation by pressing **Yes**.
  5. Installation begins. When the installation is complete, the computer opens a web browser and the modem's own management page in the browser. Now you can use the internet.

Mac OSX

  1. Connect the modem to your computer.
  2. A CD image with the name HiLink appears on the computer's desktop. Click it. If you do not see the image, disconnect and reconnect the modem to the computer.
  3. Installation begins. When the installation is complete, the computer opens a web browser and the modem's own management page in the browser. Now you can use the internet.

### Tips if installation fails

  * Try a different USB port.
  * Remove the old USB modem connection program through the Add/Remove application in the computer's control panel. Then restart the computer and then connect the modem to the computer.
