D-Link DWR-923 - Router for Mobile Broadband

## Simple steps to get online

1

#### Insert the SIM card (do not break out to Micro or Nano-SIM)

2

#### Screw on the antennas and connect the power adapter

3

#### Connect to a computer on the wireless network

Windows:

  1. Left-click on the icon for the wireless network at the bottom by the clock and date
  2. Find the network that matches the network name on the back of the router and press 'connect'
  3. Enter the network password that is on the back of the router, press 'connect'

Mac:  

  1. Press on Airport, the icon for wireless network  

  2. Press on your network  

  3. Enter the network password that is on the back of the router, press 'connect'

4

#### Enter PIN code, then your own settings

**PIN code**

In the wizard, you will be prompted to enter a PIN code. This can be found in
the letter you received with the SIM card for the router.

If you cannot find the PIN code, you can [retrieve the PUK code on My
Pages](https://www.telenor.no/privat/minesider/web/mobil/). Once you have entered
the PUK code, you will be prompted to create a new PIN code.

**How to retrieve the PUK code**

  1. [Log in to My Pages](https://www.telenor.no/privat/minesider/web/mobil/)

  2. Select the subscription that applies

  3. Under **Devices and SIM** , select the SIM card that applies

  4. Press **Show PUK code**.

#### How do I change the network name and network password?

To change the network name (SSID) and network key (WIFI KEY):

  * Open a browser, such as Internet Explorer, on a computer that is connected to the router.
  * Type 192.168.1.1 in the address field, press Enter.
  * Type 'admin' in the username field. The password is the same as the network key. The network key (WIFI KEY) can be found on a sticker on the back of the modem.
  * Select **Wi-Fi** , then **Wifi Settings**
  * Mark the wireless network you want to change, press Edit
  * Enter  
\- Network name: Name of your wireless network (SSID). You choose the name
of the network yourself.  
\- Network password: Password for your wireless network. You create the network password
yourself and it must consist of at least 9 characters, as well as a lowercase and an uppercase letter
(not æøå)

  * Press **Apply**

#### How do I access the router's menu?

The router has its own menu, where you can, among other things, change the wireless network name
and network key.  
Here's how to access the router's menu:

  * Open a browser, such as Internet Explorer, on a computer that is connected to the router.
  * Type 192.168.1.1 in the address field, press Enter.
  * Type 'admin' in the username field. The password is the same as the network key. The network key (WIFI KEY) can be found on a sticker on the back of the modem.
  * Note, if you have changed the password yourself, enter this.

?

#### How can I restore factory settings?

If you are experiencing problems connecting to the Internet, it may help to reset
the router.  
Here's how to reset the router manually:  

  * Press a paperclip/needle into the reset hole, and hold for 10 seconds.
  * The router turns off and on, and you can connect to the wireless network again.
  * After you have reset the router, the network name and network password will be reset. You can find the name and password on a sticker on the back of the router.

?

#### How to lock the network on 4G, 3G or 2G?

If the network is unstable, it may help to lock the network to either 4G, 3G or 2G.  

Here's how to do it:  

  * Open a browser, such as Internet Explorer, on a computer that is connected to the router. Type 192.168.1.1 in the address field, press Enter.
  * Type 'admin' in the username field. The password is the same as the network key. The network key (encryption key) can be found on a sticker on the back of the modem.
  * Select Internet, then Radio Configuration.
  * Select Only 4G, 3G, 2G from the drop-down menu under Radio Mode.
  * Press Apply.

#### Software update

New software is important to maintain security and stability. When new
software is available, the router is upgraded automatically. Device and SIM
card information necessary to perform the software update. You can also
download the update on this page.

The technical parameters required to perform the automatic
software update are the device's serial number and the SIM card's IMSI number.
This identifies which device you are using and that you are using Telenor's
mobile network, so that your device receives the correct software adapted
to Telenor's mobile network.
