Is it malfunctioning?

If you have Telenor's wifi router, you may need to factory reset it for the Wifi Control app to work as it should. For example, use a pin and press it into the hole labeled "Reset" on the back of the router for 7-8 seconds.

## Questions and Answers

  * How do I find the Wifi Control app?

You can download the Telenor Wifi Control app from the [AppStore](https://apps.apple.com/se/app/wifikontroll/id1490238568?l=sv) if you have an iPhone and in [Google Play](https://play.google.com/store/apps/details?id=com.fon.wifikontroll.telenor) if you have an Android phone. Search for Wifi Control. Below you can see what the app's logo looks like.  
  
  
  

  * How do I log in to the Wifi Control app?

You log in with the same details as you log in to [My Telenor](/link/a4531ddbfeef48d3a256e369df95234d.aspx) with. If you do not have a My Telenor account, you must create one first.

  * Which devices can I use the app with?

You can use Wifi Control with all mobile phones and tablets that have iOS (version 9 or later) or Android (version 5 or later).

  * With which routers can I use Wifi Control?

You can use Wifi Control with Telenor's wifi router and Technicolor 799.

  * Which broadband service from Telenor do I need to have to be able to use Wifi Control?

You need to have broadband via fiber or telephone jack. Wifi Control does not work with mobile broadband.

  * Does it cost anything to use Wifi Control?

Using the Wifi Control app is free of charge.

  * Can I create multiple logins to Wifi Control?

No, that is not possible.
