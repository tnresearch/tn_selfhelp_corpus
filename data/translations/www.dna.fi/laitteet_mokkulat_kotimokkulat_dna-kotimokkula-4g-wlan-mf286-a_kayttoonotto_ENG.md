## Getting Started

## Installing the Modem

The DNA Home Modem 4G+ WLAN MF286(A) uses a standard-size, i.e., Mini-SIM
card. Install the SIM card into the SIM card slot of the modem as shown in
the picture on the side of the home modem.

Press the SIM card into the slot. Please note that the orientation of the
SIM card matters. The modem has markings that you can compare to the cut
corner of the SIM card and the installation location. You can best see the
installation side of the SIM card in the accompanying image.

Registration to the DNA network takes a few minutes. If the connection
fails to open, call DNA's
[customer service](https://www.dna.fi/yhteystiedot#asiakaspalvelu).

The internet connection is available when the power light and network status
indicator light (in a color other than red) are lit on the modem.

## Enabling Wireless Network (WiFi)

DNA modems are encrypted in terms of wireless networks. You can find the
network name and password on the sticker on the bottom of the home modem or
on the modem's management page.

SSID (network name)

E.g. DNA-Mokkula-2G-XXXXX and DNA-Mokkula-5G-XXXXX

Password

E.g. 12345678901

The DNA Travel Modem supports 2.4 GHz and 5 GHz wireless WiFi networks. 2.4
GHz is enabled by default. These are distinguished from each other by the
2G and 5G terms in the WiFi name (SSID).

Please note that not all devices support the 5 GHz frequency.

Windows 10

Click the WiFi network availability bars in the bottom right corner of
Windows 10.

Then select the network whose name is on the sticker on the back (SSID).
Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. The password
can be found on the sticker on the back (Password). Enter the password
exactly as it is on the sticker and press **Next**. Now you can start using
the internet.

**Note!** Select **DNA-Mokkula-5G-XXXXXX** as the wireless network to get a
faster internet connection. If there are many other networks in your
environment, the speed of the wireless internet will improve at 5 GHz, but
at the same time the network coverage may decrease compared to the 2.4 GHz
network. Please note that not all devices support the 5 GHz frequency.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then
select **Settings** (gear icon). Next, select the availability bars.

Then select the network whose name is on the sticker on the back (SSID).
Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find
it on the sticker on the back of the modem (Password). Enter the password
exactly as it is and press **Next**.

If you want to share files between devices, select the lower option ("Yes,
enable sharing"). If you do not want to share files between devices, select
the upper option ("No, do not enable sharing").

Windows 7 / Vista

Click the WiFi network availability bars in the bottom right corner of
Windows 7 and Vista. Then select the network whose name is on the sticker on
the back (SSID).

Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find
the password on the sticker on the back (Password). Enter the password
exactly as it is and press **OK**.

You can start using the internet.

Mac OSX

Click the WiFi network icon at the top of the screen with the mouse. Then
select the network whose name is on the sticker on the back of the modem
(SSID).

Next, the computer will ask for the wireless network password. The password
can be found on the sticker on the back. Enter the password exactly as it is
on the sticker on the back. Click **"Remember this network"** and press
**Join**.

You can start using the internet.

Apple iPad

Select Settings from the iPad home screen. Select the WiFi section (WLAN in
older models) from the settings.

Wait a moment while the iPad searches for networks. Then select the network
whose name is on the sticker on the back of the home modem (SSID). Next, the
iPad will ask for the wireless network password. You can also find the
password on the sticker on the back of the modem.

Press **Join**. You can start using the internet.

Android Tablet

Go to the view where you see all the apps.

Select **Settings** and select **WiFi** from the menu (Wireless & networks
in older versions). Wait a moment while the tablet searches for networks.
Then select the network whose name is on the sticker on the back of the home
modem (SSID). Next, the tablet will ask for the wireless network password.
Then select the password whose name is on the sticker on the back of the
home modem.

Press **Connect** and you can start using the internet.

## PIN Code

If the SIM card has a PIN code other than 1234, the PIN code must be entered
in the modem settings.

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.1.1 in the address bar.
  3. The default username is **admin** and the default password is **1234**.
  4. Select **Settings** at the top and PIN code management from the menu
    below.
  5. Select **Security** on the left.
  6. Enter your desired PIN code in the **Enter PIN** field and press
    **Apply**.
