## Settings

You can access the modem's software management page by entering http://dna.mokkula in the address bar of your web browser.  A connection requires you to be connected to the modem's WiFi network or a USB cable is connected to your computer. The default password for the management page is 1234.

Locking the modem to a 4G or 3G network

By default, the modem selects either a 4G or 3G network. If you want to change this, follow these steps.

  1. Open a web browser and type http://dna.mokkula in the browser's address bar.
  2. Select **Settings** at the top.
  3. Enter 1234 as the password.
  4. Select **Modem** on the left.
  5. Under Modem, select Mobile Network Settings and from next to this section's recommended mode: 
    * 4 G or 3G: The modem selects a 4G or 3G network by default.
    * Only 4G: if you want to force the modem to a 4G network.
    * Only 3G: if you want to force the modem to a 3G network.
    * AUTO: The modem automatically selects the fastest available network technology. If a 4G or 3G network is not available, the modem selects a 2G network. 

Changing the WiFi network name or password

  1. Open a web browser and type http://dna.mokkula in the browser's address bar.
  2. Select **Settings** at the top.
  3. Enter 1234 as the password.
  4. Select Settings from the top bar and then WiFi and then WiFi Basic Settings from the left.
  5. You change the WLAN network name in the SSID field and the network password in the WPA Pre-Shared Key field. Select Show Password if you want to see the password as letters.
  6. Finally, select Apply.

4G Mode

When a client device is connected to this modem, you can use the internet in Automatic or Manual mode. The default mode is Automatic.  

Mode | Function  
---|---  
Automatic | The device is automatically connected to the internet. You can use the internet through the client device.  
Manual |

1\. Log in to the modem's configuration page.

2\. Select **Settings > Network Settings > Connection > Connection Mode** >
**Manual** and then select **Apply**.

3\. Select Home and then select Connect or Disconnect.  
  
  
Note! You can change the device's parameters by logging in to the modem's configuration page.

Internet Access Point Mode

  1. Log in to the modem's configuration page.
  2. Select **Settings > Internet Access Point**.
  3. Set **Connection via an access point** to **Enable** and **Preferred Network** to **WiFi** and then select **Apply**.
  4. Select **Add** and then add the WiFi access point in two ways 
    * Select the WiFi access point mentioned in the table, enter the password in the Password field if necessary, and select **Apply**.
    * Enter the WiFi access point information in the Add Wi-Fi Hotspot section and then select **Apply**.
  5. Select the WiFi access point you added and then select Connect.

When a client device is connected to the WiFi access point, you can use the internet.

Setting up computer settings (Windows 7)

**The following are instructions for setting up the Internet Protocol for a WiFi connection in Windows 7:**

  1. Right-click on the Network item and select **Properties**
  2. Select **Change adapter settings**.
  3. Right-click on **Wireless Network Connection** and select **Properties**.
  4. Select **Internet Protocol Version 4 (TCP/IPv4)** and select **Properties**.
  5. Select **Obtain an IP address automatically, Obtain DNS server address automatically** and select **OK**.
