# How to Use Telenor Security Package and Extended Security Package

As a Telenor customer, you are never alone if you experience digital abuse. We offer two security packages: [Telenor Security Package (Formerly NetSikker)](/shop/telenor-tryghedspakke/) and [Extended Security Package (formerly NetSikker Plus)](/shop/udvidet-tryghedspakke/). Both security packages are offered in collaboration with HELP Insurance.

### Contact

Contact HELP Insurance via helpforsikring.dk, by phone at 39 90 09 00 [39 90 09 00](tel:%2039%2090%2009%2000) or by sending an email to [kontakt@helpforsikring.dk](mailto:kontakt@helpforsikring.dk).

### Advice

You can always call if you need help with a specific case, or if you have questions regarding digital abuse, e.g., cyberbullying, fake profiles, or unwanted sharing of private images.

### Legal Assistance

If necessary, a lawyer will take care of your case from start to finish and ensure contact with relevant authorities - e.g., Google, Facebook, etc.

## Frequently Asked Questions

Who does the Telenor Security Package and Extended Security Package cover?

**Telenor Security Package**
**Internet Subscription**
Telenor Security Package is included in your subscription if you have 5G internet for the home, internet via fiber or cable TV connection with Telenor. Telenor Security Package covers the entire household at the address. This applies to everyone with a registered civil registration address at the legal address - which also means that Telenor Security Package covers children who, for example, are at boarding school. Telenor Security Package is not included in subscriptions to internet via telephone connection and mobile internet.

**Mobile Subscription**
If you have a mobile subscription with Telenor, the user of the subscription is covered.

Do you want the whole family covered? Then remember that we offer [Bundle Discount](/shop/landingpage/samlerabat/), so you save 50,- for each extra mobile subscription you create.

**Extended Security Package**
Extended Security Package covers the entire household. The household covers up to two adults living together, and all children living at home at the address.

Who is HELP Insurance?

HELP Insurance has existed since 2000 and has approx. 140 employees distributed across offices in Denmark, Norway and Sweden. HELP Insurance specializes in professional legal assistance in a number of areas - including in connection with digital abuse and ID theft. HELP Insurance's lawyers have helped people in more than 100,000 cases throughout Scandinavia.

What can HELP Insurance advise on?

At HELP Insurance, you will be met by specialists who have extensive experience in advising on digital abuse, economic crime and ID theft. Included in both Telenor Security Package and Extended Security Package, you have access to advice if you have questions about digital security, or you need advice for your specific case. If legal assistance is necessary, HELP Insurance is also ready to take over the case from start to finish.

Can HELP Insurance remove unwanted content from the internet?

HELP Insurance's lawyers specialize in the process of getting illegal or offensive content removed from platforms such as Facebook, Youtube and Google. HELP Insurance can both advise you and contact the platform. However, there is never a guarantee that the material can be removed from the internet.
