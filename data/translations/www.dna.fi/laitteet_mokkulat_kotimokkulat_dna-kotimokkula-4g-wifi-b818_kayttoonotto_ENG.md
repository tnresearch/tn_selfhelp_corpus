## Getting Started

## Installing the Modem

The DNA Home Modem 4G WiFi B818 uses a Micro-SIM card. Carefully insert the SIM card into the designated slot in the position shown in the picture, so that it clicks into place. Then close the cover of the Micro-SIM card slot.

To remove the SIM card, gently press it inwards until it clicks. The card will automatically pop out. Do not insert or remove the SIM card while the router is running, as removing the card may affect performance or damage the SIM card.

Connect the power cord to the modem and the power outlet. If the modem does not start, press the power button on the back. An internet connection is available when the status indicator light and the signal indicator lights are lit on the modem. Note! If the status indicator light is red, there is no internet connection. See additional instructions on the Troubleshooting tab.

## Enabling Wireless Network (WiFi)

DNA modems are encrypted in terms of wireless network. You can find the network name and password on the sticker on the back of the Home Modem or on the modem's management page.

WiFi network names (SSID):  
E.g. DNA-Mokkula-XXXXX and DNA-Mokkula-XXXXX_5GHz

Password:  
E.g. 12345678901

The DNA Home Modem supports 2.4 GHz and 5 GHz wireless WiFi networks. By default, the modem is in a mode where it connects primarily to the 5 GHz WiFi network.

When in use, the 2.4 GHz and 5 GHz networks share the same wireless network name, and a wireless connection is established primarily to the 5 GHz WiFi network if the devices connecting to the network support that frequency band.

If you want to ensure that your device is definitely connected to the 5 GHz WiFi network, you can disable the mode by following the instructions on page 21. After this, two separate WiFi networks created by the modem will be visible. Connect to the network whose name contains the term 5 GHz.

Windows 10

On a Windows 10 computer, click the WLAN network availability bars in the bottom right corner of Windows.

Then select the network whose name is on the sticker on the back (SSID). Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. The password can be found on the sticker on the back (Password). Enter the password exactly as it is on the sticker and press **Next**. Now you can start using the internet.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select **Settings** (gear icon). Next, select the availability bars.

Then select the network whose name is on the sticker on the back (SSID). Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find it on the sticker on the back of the modem (Password). Enter the password exactly as it is and press **Next**.

If you want to share files between devices, select the lower option ("Yes, enable sharing"). If you do not want to share files between devices, select the upper option ("No, do not enable sharing").

MacOS

Click the WLAN network icon at the top of the screen with the mouse. Then select the network whose name is on the sticker on the bottom of the modem (SSID).

  
Next, the computer will ask for the wireless network password. The password can be found on the sticker on the back. Enter the password exactly as it is on the sticker on the back. Click **Remember this network** and press **Join**.  
  
You can start using the internet.

Apple iPad

From the iPad home screen, select Settings. From settings, select Wi-Fi (WLAN in older models).  
  
Wait a moment while the iPad searches for networks. Then select the network whose name is on the sticker on the back of the Home Modem (SSID). Next, the iPad will ask for the wireless network password. You can also find the password on the sticker on the back of the modem.  
  
Press **Join**. You can start using the internet.

Android Tablet

Go to the view where you see all the apps.  
  
Select **Settings** and select **Wi-Fi** from the menu (Wireless & networks in older versions). Wait a moment while the tablet searches for networks. Then select the network whose name is on the sticker on the back of the Home Modem (SSID). Next, the tablet will ask for the wireless network password. Then select the password whose name is on the sticker on the back of the Home Modem.  
  
Press **Connect** and you can start using the internet.

## Mobile and WiFi Connection and Positioning the Modem

WiFi is an adaptable and easy way to build your own local network.

To ensure the best user experience, please note the following:

#### Signal Obstruction

Obstacles weaken the range of mobile and WiFi devices. The signal passes through doors, windows and lighter wall structures, but each obstacle weakens it. The materials that most block the signal are metal, concrete, brick and stone. Even in difficult cases, a solution is usually found by using additional antennas or base stations, and the location of the base station or antenna is also very important. Do not place other electronics right next to the WiFi device.

#### Modem Location

Pay attention to the placement of devices in terms of the wireless WiFi network. The modem should be placed as centrally as possible in relation to the area where the network is desired to function. The base station should also be higher than the average table level.

#### Wireless Network Speed

Currently, the peak speeds of the modem cannot be achieved with a wireless WiFi network. When using our fastest speeds, we recommend connecting the computer directly to the modem with an Ethernet cable.

#### Other Wireless Networks

The number and channels used by nearby wireless networks also affect the speed and functionality of the WiFi network. If your WiFi connection is intermittent or slow, you can try to improve the connection by searching for a better WiFi channel or manually changing the frequency.  

#### 4G Network Coverage

In addition to WiFi, also consider the coverage of the mobile network, i.e. the 4G network. The best place for the modem at home is near a window facing the direction of the base station. The approximate locations of base stations can be checked at dna.fi/peittokartta or from customer service.
