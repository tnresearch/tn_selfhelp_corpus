## Updates

The device's software is no longer actively updated. We recommend upgrading to a new device to ensure that security and performance are up to date.

#### **B593 received a new update on 22.8.2018.**

Changes from the previous version:

  * Fix for the network MIB feature. Without the fix, the device may disconnect.

The version number is B593s-22TCPU-V200R001B270D25SP03C182  
  

#### **B593 received a new update on 25.8.2015.**

New fixes and features:

  * LTE frequency lock
  * Improved IPv6 support
  * SNR information
  * DNA's customized UI and settings
  * UPnP enabled by default
  * ipv4v6 dual-stack enabled by default

The new version number is:  
V200R001B270D25SP01C182  
  
**Note!** The update cannot be canceled or reverted to the previous version.

  
Instructions for performing the update:

  * While on the Modem's wireless network or connected to it with an Ethernet cable, log in to the settings page by going to **homerouter.cpe/ or 192.168.1.1/** in your browser.
  * Enter the following credentials: 
    * Username: **admin**
    * Password: **admin**
  * In some cases (latest updates, multiple resets, etc.) the values may have changed to: 
    * **dna.mokkula/ or 192.168.8.1**
    * Username: **admin**
    * Password: **1234**

A notification about the update should appear. Pressing the notification will allow you to accept the start of the update.  
  
If you do not see the update notification, do the following:

  * Log in and select **update** > **check for update** from the top menu.
  * The device will search for the update and accept it by pressing **OK**.

Normally, user settings are retained in the new version during an update. However, DNA cannot guarantee this.  
In certain cases, you may need the previous update.  
[B710C0UPDATE_V200R001B270D10SP03C182.bin](/documents/753910/853450/B710C0UPDATE_V200R001B270D10SP03C182.bin/a1d31a31-da35-da96-9c5d-4fd8214cf831)

  
Please note that the update can only be installed on devices sold by DNA. The update cannot be changed to an older one, nor can it be installed if the device already has the latest DNA update.
