# Anslut till wifi via macOS

  * ### Klicka på wifi-symbolen

Du hittar den uppe på skrivbordet högra hörn. Nu ser du alla trådlösa nätverk
i din närhet.

  * ### Välj ditt nätverk

Du ser namnet på ditt nätverk genom att vända på routern. Titta vad det står
efter SSID. Om du använder vårt nätverk börjar det på TN. Välj sedan om du
vill ha 5 GHz eller 2,4 GHz.

Tips: 5 GHz = bättre hastighet och 2,4 GHz = bättre räckvidd.

  * ### Klicka på anslut

Fyll i lösenordet som du hittar på routerns baksida, efter Wireless Key.

  * ### Klart!

Nu är du ansluten och kan surfa via ditt wifi-nätverk.
