## Features

The modem can be used as the main modem for an Ethernet home network. It functions as the first mesh
point and can be expanded with one or more [F-266 Mesh
Extenders](https://www.dna.fi/dna-mesh-f-266-modeemi).

## Dimensions and Weight

  * Height 255 mm
  * Width 90 mm
  * Depth 205 mm
  * Weight 670 g

**Installation methods:** on a table (upright)

**Power consumption:** 24 W

## Information

**Manufacturer** : Sagemcom

**Model** : F-5670

**Manufacturer's warranty** : 24 months

**Network connections:**

  * **ethernet** 1 x 2.5 Gbit/s WAN + 1 x 2.5 Gbit/s LAN + 3 x 1 Gbit/s LAN
  * **WiFi 6** (802.11ax), 5 GHz (4x4) and 2.4 GHz (3x3)
