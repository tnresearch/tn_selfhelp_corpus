## Spam

  1. Go to **Preferences** (the gear icon in the lower left)

  2. In the menu, select **Spam**

  3. Here you can choose between **Filter Strength** (Low, Standard, or High) and **Filter Action** (Delete, Tag and deliver, or Quarantine). You can also manually block email addresses/domains or add approved senders.

  4. Select the filtering you want and press **Save**

Read more and see guides on how to set up the spam filter according to
your needs and how to report incoming email as spam:

[Change settings on the spam filter](/kundeservice/e-post/problemer/spam/)

  * #### General preferences

Under General, you can update your name and add a profile picture. You
can also adjust the following settings:

    *  **Show mailbox as:** This option lets you switch between horizontal and vertical view

    *  **Write new messages:** This dropdown option is used to adjust how message composition is displayed

      *  **In current page:** This is the default setting. Emails are written in the same browser window

      *  **In a separate window:** If you choose this setting, it will always open in a new window when you are writing an email

    *  **Write new messages as:** The two available options are **Text** or **HTML**

    *  **Write replies and forwards as:** This option refers to the format of text or email messages you choose to reply to or forward. The available options are **Original** , **Text** or **HTML**. Original means to retain the format as it was when the message was received.

    *  **Default font:** Sets the default font

    *  **Default font size:** Sets the default font size

    *  **Default font color:** Sets the default font color

    *  **Indent text when replying and forwarding:** This function can be turned on or off by clicking in the checkbox

  * #### Change date, time or preferred language

    1. Select **Preferences** in the main menu on the left

    2. Select **General**

    3. Scroll down to **Date and Time**

    4. Here you can change the following:

      * Preferred language

      * Time format

      * Date format

      * Time zone

    5. Press Save when you have made the changes

  * #### Change theme/appearance

    1. Go to **Preferences**

    2. Under **General** scroll down to the bottom, under Date and Time

    3. Press **Change theme**

    4. The theme selection panel appears on the right side of the screen

    5. Here you can choose to upload an image, select a color, or select an image from the library

    6. Press **Save** when you have selected the desired theme

  * #### Set up automatic reply

Automatic reply is used when you are on vacation, for example, and want to inform
those who send you email that you are unavailable for a period of time.  

    1. Go to **Preferences** (press the gear icon in the menu on the left)

    2. Select **Automatic reply**

    3. Fill in the title. This is just for you to know what the auto-reply is about, it will not appear in the actual reply to the sender

    4. Fill in the desired period and the message you want to send to those who send you email during the period

    5. Press Save

  * #### Change language

    1. Go to Preferences (press the gear icon in the menu on the left)

    2. Select General

    3. Under Date and time, select the desired language from the dropdown menu

    4. Press Save in the upper right corner of the page

  * #### Message filters

Message filters can be used for several actions. For example, you can create
a filter that says that all emails from a sender should be sent directly to a
specific folder, or that all emails that have a specific word in the subject line
should be sent directly to the trash.

 **How to create a filter for messages:**

    1. Under **Preferences** click on **Message filters**

    2. On the **Message filters** screen, you must fill in the following:

      * Enter a name for the filter

      * Select **Any of** or **All of** from the dropdown menu **If**

      * Select **To** , **Subject line** , **From** , **Cc or Priority** , and enter data relevant to the field selection

      * To add an extra rule, select **Add condition**

      * Select action from the dropdown list **Perform the following actions**

    3. Click on **Add**

  * #### Change password

Change your password by entering the current password once and then
entering the new password twice – to confirm that you have entered the
new password correctly.

 **How to change the password:**

    1. To change the password, go to **Settings** and select **Password**

    2. Enter your current password in **Current password**

    3. Enter the new password under **New password**

    4. Enter the new password again in the **Confirm password** field

    5. Click on **Save**

  * #### Security question

An important step to secure the privacy of your email is to add a
security question. You should choose a question that is easy for you to remember, but
difficult for others to guess.

 **How to add and update the security question:**

    1. Under **Preferences** select **Security question**

    2. Choose a security question from the dropdown menu

    3. Enter the answer to your question

    4. Click on **Save**
