## Ominaisuudet

**Tuotenimi: ZTE MF286, ZTE MF286A**

Kotimokkula, jolla luot nopean ja varman netin kotiin tai mökille, 3G- tai
4G-verkkoon, jopa 300 Mbit/s nopeudella. Tyylikkäästä Mokkulasta riittää WiFi-
kantavuutta koko asunnolle ja kaikille laitteille. Edistyneet asetukset,
superhelppo käyttöliittymä ja uusin tekniikka takaavat, että tämä Mokkula
toimii erinomaisesti kodin ainoana nettiyhteytenä.

  * 4G LTE (Cat 6) enimmäisnopeus verkosta 300 Mbit/s
  * 4G LTE enimmäisnopeus kohti verkkoa 50 Mbit/s
  * 3G DC enimmäisnopeus 42 Mbit/s
  * HSPA+ enimmäisnopeus 21,1 Mbit/s
  * WLAN 802.11b/g/n/ac (AC 2x2, N 3x3)
  * USB 2.0 USB-muistin jakamiseen lähiverkkoon (FTP)
  * 4 kpl Ethernet-liitäntää, max. 1000Mbit/s (joista LAN1 WAN)
  * 32 laitetta yhdistettävissä langattomaan verkkoon
  * Kaksi liitäntää ulkoisille antenneille, liitäntätyyppi SMA (Huom! MIMO muodostuu diversity- ja ulkoantennin välille)
  * Normaalikokoinen Mini-SIM-kortti
  * DNA:n kustomoitu käyttöjärjestelmä

### Myyntipaketin sisältö:

DNA Kotimokkula MF286(A), virtalähde, DNA:n pikaopas, Ethernet-kaapeli.

### Laitteistovaatimukset / Tuetut käyttöjärjestelmät:

  * WiFi: 802.11b/g/n/ac
  * RJ45 liitäntä Ethernet-kaapelilla
  * Tuetut käyttöjärjestelmät: Windows XP SP2/SP3, Vista SP1/SP1, Windows 7, Windows 8 / 8.1, Windows 10, MAC 10.5 tai uudempi
  * Internetselain hallintaa varten: Microsoft Internet Explorer 6.0 tai uudempi, Firefox 2.0 tai uudempi, Safari 4.0 tai uudempi, Opera 10.0 tai uudempi, Chrome 5.0 tai uudempi
