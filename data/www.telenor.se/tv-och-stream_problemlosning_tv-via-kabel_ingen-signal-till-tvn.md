# Ingen signal till tv:n

  
Om det inte går någon signal från tv-boxen till tv:n så visar sig det oftast
genom ett felmeddelande på din tv-skärm. Det kan stå ”Ingen signal” eller
liknande.  
  
För att lösa problemet behöver du installera din tv-box.
