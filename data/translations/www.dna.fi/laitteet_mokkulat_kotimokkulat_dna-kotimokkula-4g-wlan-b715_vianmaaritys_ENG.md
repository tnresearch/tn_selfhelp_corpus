## Troubleshooting

How do I restore factory settings?

With the modem turned on, press the Reset/Restore button with a pointed
object for about 30 seconds, until the modem's indicator light starts to
flash. Restoring factory settings will reset the settings to their
defaults. You can reconfigure them after the router has been restored to
factory settings.

What do I do if I forget the WiFi password or username, as well as the
password for the web-based management page?

Restore the modem to factory settings and try again using the default WiFi
password, username, and login password found on the information label.

What do I do if the mobile network indicator light is red or I cannot connect
to the internet?

  1. Check that the micro-SIM card is in place. See "Getting Started" > "Modem Installation" for the SIM card size and correct installation method.
  2. If the problem persists, restore the modem to factory settings and try again.
  3. Check with DNA to see if the SIM card has been deactivated.

What do I do if my internet connection slows down?

Check the modem's signal indicator light. If the signal is weak, turn the
modem around or move it closer to the nearest window to the base station to
improve signal reception ([more information on improving speed](/tuki-
netti#liikkuva)).

  1. If the device is connected to a router via WiFi, try moving the device to get a better signal.
  2. Switch the WiFi connection to the 5 GHz band if your device supports it.
  3. Restart the modem and device and try again.

How do I connect the modem with WiFi Protected Setup (WPS)?

  1. Make sure WiFi is enabled on the device.
  2. Establish a 2.4 GHz WPS connection by holding down the modem's WPS button for 2-5 seconds, or establish a 5 GHz WPS connection by holding down the modem's WPS button for more than five seconds.

Why can't I use the modem's web-based management page?

  1. Make sure the computer is connected to the modem with an Ethernet cable or WiFi connection.
  2. Make sure the computer is set to obtain the IP address and DNA server address automatically.
  3. Restart the browser or try a different web browser.
  4. If the problem persists, restore the modem to factory settings.

If you are having problems with the modem:

  1. Restart the modem.
  2. Restore the modem to factory settings.
  3. See the help section of the web-based management page.
  4. Contact DNA.
