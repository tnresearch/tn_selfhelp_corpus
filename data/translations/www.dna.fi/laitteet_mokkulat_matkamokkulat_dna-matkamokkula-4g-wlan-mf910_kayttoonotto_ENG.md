## Getting Started

## Installing the Modem

Open the SIM card cover, insert the SIM card into the card slot, and close the SIM card
cover. The modem's battery is partially charged by default. Fully charge the battery using a USB-
cable by connecting the USB cable to a power outlet with the included adapter
(recommended method) or by connecting the USB cable to a computer's USB-
port.

Press the power button for 3 seconds to turn on the Modem. After starting up,
the Modem automatically connects to the internet. The LCD screen displays the WiFi network
name and password. The WiFi network name is above these and the password is below PWD
after the letters. You must select this WiFi network from the device connecting to the internet and enter the WiFi network password into the device. On some
devices, the word "encryption key" is used instead of the password.

Registration to DNA's network takes a few minutes. If the connection
fails to open, call DNA customer service.

The internet connection is available when the power light and network status
indicator light are on in the modem (in a color other than red). If the modem has a display,
you will see an icon indicating the signal on the display.

##  
Enabling Wireless Network or WiFi

We recommend using the modem via a WiFi connection. Using a WiFi connection does not
require connecting a USB connection to a computer. Press the modem's power button for 3
seconds to turn on the modem. After starting up, the modem automatically connects
to the internet.

The modem's LCD screen displays the WiFi network name (SSID) and password (PWD).

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select **Settings** (gear icon). Next, select the signal bars.

Then select the network named **modem xxxxxxx**. You can find the exact name of the network on the modem's display. If you do not see the WiFi network name, press the WPS button on the side of the modem.

The X letters are unique to each subscription. Check the box next to **Connect automatically** and press **Connect.**

Next, the computer will ask for the wireless network security key. See
the security key on the modem's LCD screen after the letters PWD. Enter
the security key exactly as it appears on the screen and press **Next**. If you don't see the security key, press the WPS button.

Windows 7 / Vista

Click on the WiFi network signal bars in the lower right corner of the Windows 7 and Vista computer. Then select the network named **modem xxxxxx**. You can find the exact name of the network on the modem's display. If you do not see the WiFi network name, press the WPS button on the side of the modem.

The X letters are unique to each subscription.

Check the box next to **Connect**.

Next, the computer will ask for the wireless network security key. See
the security key (PWD) on the modem's display. Enter the security key exactly as it is and press OK.

You can start using the internet.

Mac OSX

Click on the WiFi network icon at the top of the screen with the mouse. Then select the network named **modem xxxxxx**. You can find the exact name (SSID) of the network on the modem's display. The X letters are unique to each subscription. If you do not see the WiFi network name, press the WPS button on the side of the modem.

Next, the computer will ask for the wireless network security key. See
the security key on the travel modem's display. If you do not see the WiFi network password, press the WPS button.

You can start using the internet.

Apple iPad

Select Settings from the desktop. Select the WiFi section (WLAN in older models) from the settings.

Wait a moment while the iPad searches for networks. Then select the network named **modem xxxxxx.** You can find the exact name of the network on the modem's display. The X letters are unique to each subscription. If you do not see the WiFi network name, press the WPS button.

Next, the iPad will ask for the wireless network password. See the password on the modem's display. Enter the password exactly as it is and press **Join**. You can start using the internet.

Android Tablet

**Go to the view where you see all apps.**

Select **Settings** and select **WiFi** from the menu (Wireless & networks in older versions). Wait a moment while the tablet searches for networks. Then select the network named **modem xxxxxx**. You can find the network name on the modem's display. The X letters are unique to each subscription. If you do not see the WiFi network name, press the WPS button.

Next, the tablet will ask for the wireless network password. You can find the network name on the modem's display. The X letters are unique to each subscription.

USB cable

We recommend using the modem via a WiFi network. However, you can also use the modem via a USB connection.

Using the USB connection is done by connecting the USB cable to the computer and installing the connection software according to the instructions on the computer screen. Once the connection software is installed, the internet connection will work automatically. USB connection is supported in Windows XP and Mac 10.5 or newer operating systems.
