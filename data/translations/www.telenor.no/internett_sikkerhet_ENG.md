# Help with Security Services

Here you can get help setting up Net Security or Net Security+, so you can
surf the web a little more safely.

## Net Security and Net Security+

Net Security and Net Security+ are security filters from Telenor that allow you to surf
a little more safely. The security filters check if the websites you are trying to access
are safe. [Read more about Net Security and
Net Security+](https://www.telenor.no/nettvern/)

 **Disable or enable Net Security or Net Security+?**

  *  **Net Security** is automatically activated for all Telenor customers, but it is possible to disable it. We do not recommend that you disable the service, but if you still want to do so, we have guides for this below.

  *  **Net Security+** is an enhanced security filter included in all our broadband subscriptions and in selected mobile subscriptions, and **you choose whether to turn** on Net Security+ so you can surf safely.

[Activate or deactivate
Net Security](/kundeservice/internett/sikkerhet/nettvern/)

## Other Security Services

  * #### Filter against Child Abuse

Filter against child abuse prevents access to internet images showing
sexual abuse of children, without exercising any form of general monitoring.
The filter is centrally located in Telenor's network itself and applies to all Telenor
customers regardless of whether you surf the web via a computer, a tablet or
on your mobile.  
[Read more about the filter here...](/kundeservice/internett/sikkerhet/nettfilter/)
