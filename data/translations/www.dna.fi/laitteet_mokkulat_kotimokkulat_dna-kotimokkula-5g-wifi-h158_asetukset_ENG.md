## Settings

Logging in to the settings page

When a computer or other terminal device is connected to the modem via a wired or wireless connection, all of its settings can be managed using a web browser. We recommend using Google Chrome and Safari browsers.

  1. Open a web browser and type 192.168.1.1 or dna.wifi/ into the address bar and press **Enter**. 
  2. User Name is **admin** and password is **1234**
  3. Press **Log In** and the modem settings pages will open

Changing the password and forgotten password

All DNA wireless modems have the same default password, 1234. The password is required to change the device's settings. The password should be changed for security reasons so that outsiders cannot manage the modem. After logging into the settings pages, you can change the password as follows:

  1. Select **Advanced** from the home page
  2. Select **Modify Password** from the System menu

Enter your current password in the **Current Password** field. Then, enter your desired new password in the **New Password** field and again in the **Confirm Password** field. Finally, press **Confirm**.

If you have forgotten the password you set, you can restore the device to its factory settings by pressing the reset button on the bottom of the modem for a few seconds. The device will restart and the password will be reset to the default password **1234**.

Turning off Bandsteering / combined network

  1. Log in to the device settings page and select **Wi-Fi Settings**. 
  2. Uncheck the **5 GHz preferred** box. 

After turning off the combined network, the upper section of the **Wi-Fi Basic Settings** page view manages the 2.4 GHz WiFi network and the lower section manages the 5 GHz network.

Setting the modem indicator lights to dark mode

  1. Log in to the device settings page and select **Advanced**
  2. Select **System Settings** from the System menu
  3. Activate the **Indicator** item from the page
  4. Select the period during which you want the modem lights to be off. If you want to completely turn off the device lights, select a period of 00:00 – 23:59 
  5. Confirm the selection by finally selecting **Save**

Setting bridge mode

  1. Log in to the device settings page and select **Advanced**
  2. Select **Bridge Mode** from the **Router** menu
  3. Select **Enable bridge mode**
  4. Select **Confirm**

You can disable bridge mode by logging into the settings pages ( **note**. in bridge mode you can only access the settings pages using the IP address 192.168.1.1) and unchecking the **Enable bridge mode** box or by performing a factory reset by pressing the reset button on the bottom of the modem for a few seconds.

Setting up a guest network

  1. Log in to the device settings page and select **Wi-Fi Settings**
  2. Select **Guest Wi-Fi** from the **Guest Wi-Fi** menu
  3. Enter the information in the following fields 
    1. Set the validity period of the guest network in the Duration field 
    2. Set the name of the guest network in the Wi-Fi name field 
    3. Set the network security level (open/protected) in the Security field 
  4. Finally, select **Save** to confirm the settings 

DynDNS

  1. Log in to the device settings page and select **Advanced**
  2. Select **DDNS** from the **Router** menu
  3. Select the + sign on the right side of the DDNS List section 
  4. Fill in the required information in the fields in the Add DDNS pop-up window 
  5. Save the changes by pressing **Save**

Using the DynDNS service requires the user to have already created an account with a DynDNS service provider.

Port forwarding

Log in to the device settings page and select **Advanced**. Go to the **port forwading** tab via the **Security** menu.

The modem has a UPNP tool for port forwarding enabled by default. For example, when playing or using download programs, the user can also open ports manually.

Making manual forwarding:

Select the + sign on the right side of the Virtual Servers List section and add the required information. Finally, press **Confirm** to accept the changes.

Parental control

Log in to the device settings page and select Tools. Go to the Parental Control menu.

Select the + sign on the edge of the Internet Access Time Control section and create a rule for parental control

  1. Set the time period during which parental control is valid in the Time field 
  2. Set the days of the week on which parental control is valid in the Repeats field 
  3. Select the devices that you want to be under parental control from the Enable on selected devices box 
  4. Finally, select Confirm to confirm the settings

## Changing WiFi settings

You can easily change the wireless network settings on the modem's settings page. These include the name, password, and security settings of the wireless network, or WiFi network.

Log in to the device settings page and select **Wi-Fi Settings** from the home page.

[Watch the instructional video on changing the WiFi network name and password](https://youtu.be/9qHe1xDrTCs?si=bYQE-McLC_iiAqF6)

Changing combined network settings

From the **WiFi Basic Settings** menu, you can change the most common wireless network settings. The DNA Home Modem supports 2.4 GHz and 5 GHz wireless WiFi networks. By default, the device has the 5 GHz network and a 2.4 GHz and 5 GHz combined network enabled, so your device chooses which frequency to use. We recommend using the combined network (DNA-WIFI-XXXX).

Changing the WiFi network name

The combined network name is changed by typing the new desired WiFi network name in the **2.4/5 GHz Wi-Fi name** field and saving the change by selecting Save at the bottom of the page. Similarly, you can change the 5 GHz network name by typing the new desired network name in the **5 GHz Wi-Fi name** field and saving the change by selecting **Save**.

Changing the WiFi network password

The WiFi network password is changed by typing the desired WiFi network password in the **Wi-Fi Password** field and saving the change by selecting **Save** at the bottom of the page. You can set separate passwords for the combined network and the 5 GHz network by editing each network's **Wi-Fi Password** field and selecting **Save**.

## Device information

Checking the serial number

Log in to the device settings page and select **Advanced**. Go to the **Device Information** tab in the **System** menu. The serial number is displayed in the **Serial number** field. You can also find the serial number on a sticker attached to the device.

Checking the device software version

Log in to the device settings page and select **Advanced**. Go to the **Device Information** tab in the **System** menu. The device software version is displayed in the **Software version** field.

Flashes blue: | Searching for WPS pairing
