##  Settings

Modem management page and changing settings

The modem's settings are changed using web browsers. Changing the setting
requires that the device using the browser is connected to the WLAN network
created by the modem or the device is connected to the modem with an Ethernet
cable.

  * Open your web browser and type http://dna.mokkula or http://192.168.8.1
    into the address bar and press **Enter**.
  * Type **admin** in the Username field and **1234** in the Password field.
  * Press OK, and the modem's settings pages will open.
  * From the settings pages, you can also change the WLAN channels, network
    name, or security settings.

Entering the PIN code

If the SIM card uses a PIN code other than 1234, the PIN code must be
entered in the modem's settings.

  1. Open a web browser when you are connected to the modem's WLAN network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar
    * The default username is **admin**.
    * The default password is **1234**.
  3. Select **Internet** from the top.
  4. Select **PIN Code Management** from the left.
  5. Enter the PIN code in the **Enter PIN** field and press **Submit**.

Playing online games

Many online games work better if UPnP is enabled on the modem. You can check
this as follows:

  1. Open a web browser when you are connected to the modem's WLAN network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar
    * The default username is **admin**.
    * The default password is **1234**.
  3. Select **Security** from the top.
  4. Select **UPnP** from the left.
  5. Check the box next to **Enable**.
  6. Press **Submit**.

Locking the modem to a 4G or 3G network

Modems work most efficiently on a 4G or 3G network. If the connection is
slow or drops, it is worth trying the following:

  * Indoors, the connection is best near windows.
  * Attach additional antennas to the modem.

More information about coverage areas: [dna.fi/kuuluvuus-ja-peittoalueet](/kuuluvuus-
ja-peittoalueet)

If the modem is used on the border of a 4G or 3G network or a 3G or 2G
network, the modem may switch between these networks. Switching between
networks causes the connection to drop and slows down the modem. You can
optionally lock the modem to any network technology as follows:

  1. Open a web browser when you are connected to the modem's WLAN network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar
    * The default username is **admin**.
    * The default password is **1234**.
  3. Select **Settings -> Modem -> Mobile Network Settings** from the top.
  4. Select from the Network, recommended mode field:

    * Auto
    * Only 2G
    * Only 3G
    * Only 4G
    * 4G+3G Auto
    * Only LTE 800
    * Only LTE 1800
    * Only LTE 2600

The modem has gained a feature called **LTE frequency lock** (LTE
channel/band lock) with software updates. With the frequency lock, the modem
can be set to use only a specific 4G LTE frequency, i.e. the 800/1800 MHz
frequencies used by DNA. This feature only helps in certain situations or
for troubleshooting. If the user chooses the feature incorrectly, the modem
will no longer connect to the base station.

You can change the WLAN network channel, frequency, update the device, change
the administration password and SSID from the modem's management page, and
enter the PIN code if it is something other than 1234, if necessary.

Changing the WLAN network name and password

You can change the WLAN network name and password as you wish. If you do so,
devices that were already connected to the WLAN network must be reconnected
to the renamed WLAN network.

If you forget the changed WLAN network password, you can reset the modem to
factory settings, which will restore the WLAN network password to the same
one that is on the sticker on the back of the modem.

  1. Open a web browser when you are connected to the modem's WLAN network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar
    * The default username is **admin**.
    * The default password is **1234**.
  3. Select **WLAN** from the top.
  4. Type a new WLAN network name in the **SSID** field.
  5. Type a new password in the **WPA-PSK** field. If you want to see the
    typed letters, select **Enable** from above.
  6. Press **Submit**.

Changing the modem administration password

You can optionally change the modem administration password. If you forget the
changed administration password, you can reset the modem to factory settings.

  1. Open a web browser when you are connected to the modem's WLAN network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar
    * The default username is **admin**.
    * The default password is **1234**.
  3. Select **System** from the top.
  4. Select **Change Password** from the left.
    * The current password is **1234**.
    * **New password** – Enter the password you want.
    * **Confirm password** – Confirm the password you want.
  5. Press **Submit**.

Reset to factory settings

You can restore the modem to its default settings by holding down the Reset
button on the left side of the device for about 3 seconds.

Updating the modem

A notification will normally appear automatically on the web user interface
and on the home modem screen when a new update is available for download.
