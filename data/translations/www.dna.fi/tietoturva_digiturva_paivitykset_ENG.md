## Updates

### Changes in DNA Digital Security in week 7/2025 update:

The new Scam Protection feature replaces the Safe Browsing feature on Android
devices and brings increased security with new features:

  * Message Protection, which checks and filters fraudulent text messages
  * Reliability ratings for pages and online stores
  * WiFi protection

### Changes in DNA Digital Security in week 5/2025 update:

The new Scam Protection feature replaces the Safe Browsing feature on iPhone and
iPad devices and brings increased security with new functionalities:

  * Message Protection, which checks and filters fraudulent text messages
  * Reliability ratings for pages and online stores

### Changes in DNA Digital Security in week 39/2024 update:

  * New and improved look and feel for the user interface
  * The Viruses and Threats section was updated to Device Protection
    * New feature: App Permissions and Screen Lock Recommendation
  * Safe Browsing: Chrome protection for Android operating system
  * Safe Browsing: Safari browser extension update

A cookie is a small text file that is stored on your device when
you visit DNA's digital services or mobile apps. It is a
numerical, anonymous identifier that does not harm your device or
