## Troubleshooting

I am using the modem with a SIM card that asks for a PIN code.

You can enter the PIN code through the modem's management page. See the instructions at [Entering the PIN code](/dna-kotimokkula-4g-wlan-b315#asetukset).

The modem's connection is intermittent or slow.

If the connection is slow or intermittent, it is worth moving the modem closer to the window and enabling additional antennas (available for separate purchase from the DNA Store). If these steps do not help, you can call DNA Customer Service and ask which direction the nearest base station is located and move the modem to face that direction.

If the modem's LED signals show more than three bars and the connection is still slow, try connecting with an Ethernet cable.

The computer reports "Limited connectivity."

The modem is not connected to the internet. Check the connection, connections, and SIM card PIN code. If necessary, restart the modem.

The modem reports that it is connected to the internet, but the connection does not work on the computer.

Make sure you have connected the computer to the WLAN network created by the modem. You can find the WLAN network name (SSID) on the sticker on the back of the modem. You can also try connecting with an Ethernet cable. If this does not help, restart the modem.

I accidentally changed a setting that I shouldn't have, and now the modem no longer responds to commands.

You can restore the modem to its default settings by holding down the Reset button for 3 seconds. Or restart the modem. Turn it off with the power cord disconnected for 30 seconds. After this, all settings must be done again.
