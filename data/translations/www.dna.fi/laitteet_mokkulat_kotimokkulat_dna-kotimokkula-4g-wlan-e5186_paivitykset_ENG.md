## Updates

The device's software is no longer actively updated. We recommend upgrading to a new device to ensure that security and performance are up to date.

The update is done by accepting it from the settings pages (Web UI) either automatically via a future notification or manually by searching for the update from the path **Update -> Check for update**.  

**A new update for E5186 was released on 30.11.2017**

The update includes:

• Bridging mode • 2100 MHz lock

• Security updates

• 5 Ghz Wi-Fi intermittent problem fixed

• Other minor UI changes

**The update version number is: V200R001B316D01SP01C182**  

An update for E5186 was released on Wednesday, September 16, 2015.  
  
The update includes:

  * LTE frequency lock
  * WiFi bandwidth renaming from “auto” to ”20/40”. 
  * SNR information on the info page
  * IPv6 support
  * UPnP is enabled by default
  * Ipv4v6 dual stack is enabled by default

The update version number is 21.306.01.00.182
