# Settings in the T-We App

Choose the language for subtitles, or how good the playback quality should be. Here
you will find access to useful services and features in the T-We App.

## The Menu

When you select ☰ in the T-We App, you get an overview of:

  * Access and profiles

  * Settings

Access and profiles give you an overview of which profile you have selected and have,
as well as the ability to create a new profile.

Under Settings, you have the option to choose Menu Language, audio language,
subtitles, in addition to playback quality.

## Language and Text

When you select Settings, you will again get more choices in the app. Below
you will find guidance on how to proceed to make changes to the
various settings.

## Menu Language

In the T-We App, you can choose between Norwegian and English as the menu language.

  1. Select ☰

  2. Select Menu Language

  3. Select desired language

  4. The choice is saved automatically

## Subtitle Settings

Here you can choose whether subtitles should be on or off, subtitle language, and
subtitles for the hearing impaired.

 **Text Language**

  1. Select ☰

  2. Select **Primary Subtitle Language** or **Secondary Subtitle Language**

  3. Select desired language

  4. The choice is saved automatically

  
 **Subtitles for the Hearing Impaired**

  1. Select ☰

  2. Tap **Subtitles for the Hearing Impaired** so that it shows **Yes**

  3. The choice is saved automatically

## Video Quality

  1. Select ☰

  2. Tap **Settings for Bandwidth Usage**

  3. Select **Settings for WiFi Connection** or **Settings for 4G/5G Connection**  
** 4G/5G connection is automatically set to Good, while WiFi connection is set
to Best

  4. The choice is saved automatically
