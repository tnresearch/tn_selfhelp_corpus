## TW-3G Flash OFDM Dock

### User Guide

The user guide is available on Telewell's website at
[www.telewell.fi](https://www.telewell.fi/fi/tuote/tuotannosta-poistuneet-
tuotteet/3g-tuotteet/tw_3g_thumb/tw-3g-flash-ofdm-reititin)

### Manufacturer's Product Name

Telewell TW-3G Flash

### Product Description

The Telewell TW-3G Dock was the second dock sold by DNA. The product is no
longer manufactured and its support for various USB sticks is limited.
Practically, new sticks are not supported.

### Package Contents

  * Dock
  * Power Adapter
  * Ethernet Cable
  * Quick Start Guide

### Technical Specifications

  * Connections: 4 Ethernet cable connections (RJ45), power adapter and USB connection
  * WLAN encryption: WEP 64/128, WPA, WPA2
  * DHCP, NAT DNS
  * Finnish user interface
  * Supported wireless standards: 802.11b/802.11g
  * Check the modems supported by the dock on Telewell's website, https://www.telewell.fi/fi/tuote/tuotannosta-poistuneet-tuotteet/3g-tuotteet/tw_3g_thumb/tw-3g-flash-ofdm-reititin
  * Operating voltage 12V

### Update Instructions

[www.telewell.fi](https://www.telewell.fi/fi/tuote/tuotannosta-poistuneet-
tuotteet/3g-tuotteet/tw_3g_thumb/tw-3g-flash-ofdm-reititin)
