# Setting up the Kaon AP2400

This refers to the diodes (lights) on the router

The router has two lights: the top one shows if WiFi is connected, and the
bottom one shows if there is a connection. During startup, the bottom diode
(WAN) lights up briefly **white**.

  * If the bottom light (WAN) is **red**, there is no physical connection to the internet.
 **What you can do:** check if the cables are correctly connected and fully
inserted.

  * If the bottom light (WAN) is flashing **orange**, there is a physical connection, but no IP address.
 **What you can do:** Try resetting the router by inserting a pin or
similar object into the reset hole on the bottom of the router. This should be done
while the router is turned on, and the reset button should be held down for 12 seconds. If the reset
is performed correctly, the diodes will start flashing approximately 10-20 seconds after
the reset button is released.

  * If the bottom light is solid **green**, the router is receiving the IP address and is online.
 **What you can do:** Check if your devices are connected to the correct WiFi,
and if the cables are fully inserted.

  * When the top light is **green**, WiFi is turned on, and if the light is off, WiFi is turned off. It flashes if WPS is enabled.

## More Settings

How to log in to the router (e.g. to change WiFi name and password)

To log in to the router, you must be connected to the router from the device used for login.
In a browser, type **http://10.0.0.1:2033** and press **Enter** to
open the login page.

**Username:** admin
 **Password**: is on the underside of the router and is called "Router Code".

How to change WiFi name and password

  * Log in to your router by following the guide 'How to log in to the router'. Then go to the menu item **WiFi**
  * Under **WiFi Settings**, select **WiFi 2.4 GHz** or **WiFi 5 GHz** - depending on which network you want to change the name of.
Note: if you do not want two different networks, it is recommended that you
name them with the same name and password. This way, the router has the opportunity
to move your device to the network that is best in terms of
signal strength and speed.

  * After entering the new information, press **Save**.
 **Note:** If you have been connected via WiFi, your device will be logged
off the network, and you will need to log in with the new information.

Fixed LAN IP

Fixed LAN IP is used if it is important that your device has a specific IP
address. This could be a sound system or a computer that needs to be set up
port forwarding for.

1\. Log in to your router by opening your browser and typing:
**http://10.0.0.1:2033**

NOTE: A warning may appear on the page, ignore this and continue.

Username: admin

Password: Enter the password for your router. The code is on the underside of
the router and is called Router Code.

2\. Click on the **Advanced Parameters** menu and open **Network**

3\. Under the **Static DHCP leases** section, you can set up, delete
or edit the fixed IP addresses.

4\. Select the device that needs to use a fixed IP from the list.

5\. If the device needs a specific IP, it can be changed in the middle field.

6\. Press **Add** on the far right.

7\. To change an IP, the previous rule must be deleted, and a new one must be
created.

Rules can be deleted by pressing the trash can on the right side.

How to set up Port Forwarding

  * Log in to your router by following the guide 'How to log in to the router'. Then you must select the menu item **Network**
  * Then select the **Port Forwarding** tab.
  * Enter the port information to be forwarded, as well as the MAC address to be forwarded to. Note: IP addresses must NOT be entered here.
  * Select **Create**

How to read the signal strength of your WiFi

  * Log in to your router by following the guide 'How to log in to the router'. Then you must select the menu item **Connected Devices**
  * In the overview of connected devices, find the device you are experiencing is slow, or has dropouts, and click on the name.
  * Here you read the signal strength (**Signal Strength**). If the value is in the range **-20 to –50**, it indicates that the device is receiving a good signal. From **-50 to -70** the signal will be acceptable, but you may experience that the received speed is lower. A signal strength from **-70 to -100** indicates that there is a low signal between the router and the device you are measuring on. This can be experienced in the form of WiFi dropouts or very low speed.

You can get good advice on improving your WiFi coverage in your home
[here](/shop/landingpage/bedre-wifi/).

How to connect devices to the router via WPS

If you have a device (printer, smart device, WiFi extender, etc.) that needs to be
connected via WPS, it is done as follows:

  * Place the device you want to WPS-pair in immediate proximity to the turned on router.
  * On the side of the router there is a button called **WPS**. Press once and briefly on this. If WPS pairing is enabled, the bottom diode on the router will flash. You now have 2 minutes to complete the following steps:

  1. Press the **WPS** button on your own device and wait up to two minutes.
  2. WPS Pairing is now complete.

Router specifications

**Router Specs:**

  * 1x 1Gbit LAN/WAN port
  * 4x 1Gbit LAN ports
  * 1x USB 3.0 port

  
**WiFi connection:**

  * IEEE 802.11b/g/n/ac/ax/
