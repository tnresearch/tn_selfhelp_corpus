## Updates

### Software Updates

Updates for cable modems are delivered automatically over the network. Updates are run on the modems at night, causing the least amount of problems. In some rare cases, the modem may require a reset and restart in the morning after the update, so that the device functions optimally.

If you want to run the available update to the device immediately, it is worth trying to disconnect all cables from the device for a few minutes and then reconnect them. This will bring the modem back online and request updates at the same time. However, the update will not be run to the modem if it is not available.

Please note that updates are distributed in stages.
