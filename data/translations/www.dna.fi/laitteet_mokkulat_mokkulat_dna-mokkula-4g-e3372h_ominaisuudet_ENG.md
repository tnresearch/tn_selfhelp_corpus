## Features

### DNA Modem 4G E3372h

Product name: Huawei E3372h

The DNA Modem 4G E3372h is suitable for a user who wants a fast 4G connection
to one computer.  
The product automatically supports all older network technologies, such as 3G.

  * 4G LTE maximum speed from the network 150 Mbit/s
  * 4G DC maximum speed 42 Mbit/s
  * HSPA+ maximum speed 21.1 Mbit/s
  * Automatic installation
  * MicroSD memory card slot (up to 32 GB)
  * TS9 interface for external antenna
  * The modem is connected directly to the computer's USB port
  * Mini-SIM card, i.e. a normal-sized SIM card
  * Package contents: USB modem, Finnish-language quick start guide and USB extension cable

### Sales package contents:

DNA Modem 4G E3372h, quick start guide, USB extension cable.

### Hardware requirements / Supported operating systems:

  * USB port v. 1/2/3
  * Supported operating systems: Windows XP SP3 or later, Vista SP1 or later, Windows 7, Windows 8 / 8.1, Windows 10, MacOSX 10.7, 10.8, 10.09, 10.10, 10.11
  * Internet browser for using the management page: Microsoft Internet Explorer 6.0 or later, Firefox 2.0 or later, Safari 4.0 or later, Opera 10.0 or later, Chrome 5.0 or later
