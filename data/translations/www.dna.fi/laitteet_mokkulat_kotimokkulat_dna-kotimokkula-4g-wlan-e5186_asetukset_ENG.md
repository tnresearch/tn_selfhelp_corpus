## Settings

The modem's settings are changed using a web browser. Changing the settings requires that the device using the browser is connected to the WiFi network created by the modem, or the device is connected to the modem with an Ethernet cable.

From the settings, you can change, for example, the WiFi network name and password, or lock the modem to use, for example, a 4G or 3G network.

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar. The default username is **admin** and the default password is **1234**. 

By default, the modem starts an automatic installation. Follow the instructions and install your modem quickly and easily.

Locking the modem to a 4G or 3G network

Modems work most efficiently on 4G or 3G networks. If the connection is slow or intermittent, it is worth trying the following:

  * Indoors, the connection is best near windows.
  * Attach additional antennas to the modem's antenna connectors. 

You can view coverage areas at [dna.fi/kuuluvuus-ja-peittoalueet](/kuuluvuus-ja-peittoalueet).  

If you are using the modem on the border between 4G and 3G networks or 3G and 2G networks, the modem may switch between these networks. Switching between networks causes the connection to drop and slows down the modem. If you wish, you can lock the modem to any network technology as follows:

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar. 
    * The default username is **admin** and the default password is **admin**.
  3. Select **Settings -> Modem -> Mobile Network Settings** from the top.
    * Automatic: First selects 4G, then 3G, and finally 2G network.
    * 4G: Locks the modem to the 4G LTE network.
    * 3G: Locks the modem to the Dual Carrier or 3G network.
    * 2G: Locks the modem to the 2G network.

The modem also has an LTE frequency lock (LTE channel/band lock). With the frequency lock, you set the modem to use only one specific 4G LTE frequency, i.e. the frequencies used by DNA 800/1800 Mhz. The frequency lock only solves problems in certain situations. If you use the functionality incorrectly, the modem will no longer be able to connect to the base station.

Playing online games

Many online games work better if UPnP (Universal Plug and Play) is enabled on the home modem. You can check this as follows:

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar. 
    * The default username is **admin** and the default password is **admin**.
  3. Select **Security** from the top. 
  4. Select **UPnP** from the left.
  5. Check the box next to **Enable**.
  6. Press **Submit**.

Changing the WiFi network name and password

You can change the WiFi network name or password if you wish. If you do this, devices that were already connected to the WiFi network must be reconnected to the renamed WiFi network.  

If you forget the WiFi network password you changed, you can reset the modem to factory settings. In this case, the WiFi network password will return to the same as on the sticker on the back of the modem.

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar. 
    * The default username is **admin** and the default password is **admin**.
  3. Select **WLAN** from the top.
  4. Type a new WLAN network name in the **SSID** field.
  5. Type a new password in the **WPA-PSK** field. If you want to see the typed characters, select **Enable** from above.
  6. Press **Submit**.

Changing the WiFi network frequency

The DNA Home Modem 4G WLAN E5186 uses both WiFi network frequencies, i.e. Dual Band, by default. You can change the WiFi network frequency used by the modem as follows:

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar. 
    * The default username is **admin** and the default password is **admin**.
  3. Select **WLAN** from the top. 
    * Select the network frequency you want.

Changing the modem's administration password

You can change the modem's administration password if you wish. If you forget the changed administration password, you can reset the modem to factory settings.

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the address bar. 
    * The default username is **admin** and the default password is **admin**.
  3. Select **System** from the top.
  4. Select **Change password** from the left. 
    * The current password is **admin**.
    * **New password** : Type the password you want.
    * **Confirm password** : Confirm the password you want.
  5. Press **Submit**.

Reset to factory settings

You can restore the modem's default settings by holding down the reset button on the left side of the device for over 3 seconds.

Entering the PIN code

If the SIM card uses a PIN code other than 1234, the PIN code must be entered in the modem settings.

  1. Open a web browser when you are connected to the modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.8.1 into the browser's address bar. 
    * The default username is **admin** and the default password is **admin**.
  3. Select **Internet** from the top.
  4. Select **PIN code management** from the left.
  5. Enter the PIN code in the **Enter PIN** field and press **Submit**.
