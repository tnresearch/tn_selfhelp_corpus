## Updates

#### MF791RS has received an update since August 16, 2023

  * The update includes security fixes related to the device from the device manufacturer.
  * New software version: BD_DNAMF971RSV1.0.1B02 

#### **Older updates:**

**December 14, 2022**

  * The update includes security fixes related to the device from the device manufacturer.
  * New software version: DNA_FI_MF971RS4V1.0.2B01

**February 28, 2022**

  * The update includes fixes that improve the general functionality of the device from the device manufacturer.
  * New software version: BD_DNAMF971RSV1.0.0B07

**August 10, 2021**

  * The update fixes a bug where the 5GHz WiFi network password of the modem did not match the password on the device's information label. After installing the update, the modem still needs to be reset to factory settings by pressing the reset button for 10-15 seconds. After this, the 5GHz WiFi network password will also match the password on the label. 
  * New software version: BD_DNAMF971RSV1.0.0B06
