## Getting Started

### Modem Installation

1\. Connect the modem as shown in the picture. The white antenna cable goes to the antenna socket. A splitter is used if the antenna socket does not have its own data port and you want to use cable television or a set-top box at the same time. Finally, connect the power cord to the modem and the wall, and turn on the power from the modem's main power switch. A computer or other device can be connected to the modem wirelessly or with an Ethernet cable.

  

2\. Reset the modem by pressing and holding the Reset button on the back of the modem for 30 seconds. During this time, all the lights on the modem will flash simultaneously.  

  

3\. Registration with DNA's cable network usually takes about 10 minutes, up to 2 hours. If the connection fails to open, call DNA customer service. The connection is available when the 6. Power, 5. DS/US and 4. Internet (@) lights on the modem are lit continuously. Now you can start using the internet.

### Enabling Wireless Network (WiFi)

DNA broadband modems are pre-encrypted in terms of wireless WiFi network. You can find the name and password of the wireless network on the bottom or back of the device, or in some cases on the device's packaging. If the modem is reset, these original settings will be restored.

Find the wireless WiFi network according to the instructions using the wireless network search function of your computer or other device. If the network is not found, make sure that the computer's wireless connection is turned on. Enter the WiFi network password into the device (you can find the correct password on the bottom, back or packaging).

The WiFi network is now ready to use.

### WiFi Network Name and Password

DNA broadband modems are encrypted in terms of wireless network. You can find the network name and password on the sticker on the right side of the modem.

  * **SSID (network name)** : E.g. DNA-WLAN-2G-XXXX and DNA-WLAN-5G-XXXX
  * **Wireless network password** : E.g. 12345678901

Windows 10

**How to enable a wireless network connection (WiFi) in Windows 10:**

  1. Press the WiFi icon in the lower right corner of the Windows desktop, near the clock.  
  

  2. Then select the network whose name is on the sticker on the back of the modem (SSID). Check the box "Connect automatically" and press Connect.  
  
  

  3. Enter the WiFi password (security key, SSID) in the open field. You can find the WiFi password on the sticker on the modem. Accept the connection by pressing next.  
  
  
If you want to share files between devices, select Yes. If you do not want to share files between devices, select No.  

  4. The computer searches for a connection to the network and the wireless connection is now ready to use.

Windows 8

**How to enable a wireless network connection (WiFi) in Windows 8:**

  1. Move the mouse cursor to the upper right corner of the computer screen. Then select the gear icon (settings).  

  2. Next, select the signal bars.  

  3. Then select the network whose name is on the sticker on the back of the modem (SSID). Check the box "Connect automatically" and press Connect.  

  4. Enter the WiFi password (security key, SSID) in the open field. You can find the WiFi password on the sticker on the modem. Accept the connection by pressing next.  
  
  
If you want to share files between devices, select the lower option. If you do not want to share files between devices, select the upper option.  

  5. The computer searches for a connection to the network and the wireless connection is now ready to use.

Windows 7 / Vista

**How to enable a wireless network connection (WiFi) in Windows 7 / Vista:**

  1. Press the WiFi icon in the lower right corner of the Windows desktop, near the clock.  
  

  2. Then select the network whose name is on the sticker on the back of the modem (SSID). Check the box **"Connect automatically"** and press **Connect.**  

  3.   

  4. Enter the WiFi password (security key, SSID) in the open field. You can find the WiFi password on the sticker on the modem. Accept the connection by pressing **OK.**  
  

  5. The computer searches for a connection to the network and the wireless connection is now ready to use.

Mac OS X

  1. Press the WiFi icon in the upper corner.  
  
  

  2. Select your own network (SSID).  
  
  

  3. Enter the WiFi password (security key, SSID) in the open field. You can find the WiFi password on the sticker on the modem. Select "Remember this network" and press OK.  
  

Android Tablet

**Enabling a wireless network connection (WiFi) on an Android tablet:**

  1. Go to the view where you see all the apps.  

  2. Select Settings.  

  3. Select WiFi (in older Android tablets Wireless & networks).  

  4. Wait a moment for the tablet to search for networks. Then select the network whose name is on the sticker on the back of the modem (SSID).  

  5. Next, your tablet will ask for the wireless network password. Enter the password that is on the sticker on the back of the modem (security key, SSID) in the open field.
  6. Press Connect. Now the internet connection works.

Apple iPad

  1. Select settings from the desktop.  

  2. Select WiFi (in older iPad devices the item is marked WLAN) from the settings.  

  3. Wait a moment for the iPad to search for networks. Then select the network whose name is on the sticker on the back of the modem (SSID).  

  4. Next, the iPad will ask for the wireless network password. Enter the password that is on the sticker on the back of the modem (security key, SSID) in the open field.
  5. Press Join. Now the internet connection works.

**Forgot the password?** You can restore the factory settings by pressing and holding the RESET button on the back of the device for over 30 seconds.

Restoring the factory settings will erase all changes made to the device's settings. After this, you can start modifying the modem's factory settings from scratch again via an Ethernet connection or by connecting to the wireless network with the default name and password found on the modem's stickers.
