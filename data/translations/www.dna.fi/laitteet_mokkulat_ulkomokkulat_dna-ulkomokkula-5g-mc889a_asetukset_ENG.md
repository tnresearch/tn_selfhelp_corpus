##  Settings

PIN Code

If the SIM card uses a PIN code other than 1234, the PIN code must be entered through the settings pages.
Open a web browser when you have connected the user device to the external modem's power supply via an ethernet cable to the **RJ45-1** port.

  1. Type http://192.168.8.1 into the browser's address bar. The default password is 1234.
  2. Select **Advanced Settings** at the bottom and **Other** tab from the menu that opens on the right.
  3. Select PIN code management from the left-hand additional menu.
  4. From here, you can enter the current PIN code and turn the SIM card PIN code query on or off. Remember to press **Apply** at the end.

  
Note! You can only change the setting when the **Mobile Data Connection** setting in the **My Router** section on the front page of the settings pages is in the **Off** position.

Password Change and Forgotten Password

All DNA modems have the same default password, 1234.
A password is required to change the device's settings. The password should be changed for security reasons so that outsiders cannot manage the modem.
Once you have logged into the settings pages, you can change the password as follows:

  1. Select **Change Login Password** from the top of the home page.
  2. Enter your current password in the **Current Password** field. Then, enter your desired new password in the **New Password** field and again in the **Confirm Password** field. Finally, press **Apply**.

If you have forgotten the password you set, you can restore the device to its factory settings by pressing the reset button on the bottom of the modem for a few seconds. The device will restart and the password will be reset to the default password **1234**. You can also restore the factory settings through the device's settings pages, see instructions in the section "**Restoring the External Modem to Factory Settings**".

Turning on UPnP for Online Gaming

Note! You can only change the setting when the External Modem is in router mode.
When using bridge mode, UPnP settings must be made on the settings pages of the Wi-Fi router used with the external modem.

  
Many online games work better if UPnP is enabled. After logging into the external modem's settings pages, you can make the setting as follows:

  1. Select **Advanced Settings** at the bottom and the **Firewall** tab from the menu that opens in the middle.
  2. Select **UPnP** from the additional menu that opens on the left.
  3. Turn UPnP on by selecting **Enabled** and pressing **Apply**.

Note! Opening ports manually from the modem may be necessary for online gaming or even maintaining your own server. Familiarize yourself with port forwarding in the settings menu and consult the game developer. Remember to also change the APN setting to public.

Port Forwarding

Note! You can only change the setting when the external modem is in router mode.
When using bridge mode, port forwarding settings must be made on the settings pages of the Wi-Fi router used with the external modem.

Log in to the device's settings page and select **Advanced Settings** from the bottom of the home page. Go to the **Port Forwarding** tab via the **Firewall** menu.

Select **Virtual Server Settings** to **Enabled** and confirm the selection by pressing **Apply**. Fill in the required information in the fields that appear. Finally, press **Apply** to accept the changes.

  

Changing APN Settings

Note! You can only change the setting when the **Mobile Data Connection** setting in the **My Router** section on the front page of the settings pages is in the **Off** position.
The external modem contains various APN profiles pre-configured in the settings pages.
The default is Internet, which provides an address-changing (NAT) IP address. If the user needs a public IP, this can be conveniently changed from the following path:

  1. After logging into the device's settings pages, select **Settings** from the **My Router/Mobile Data Connection** section on the home page and select **Connection Point** from the left-hand menu that opens.
  2. Click on the status setting to **Manual** which will change the public IP profile to be visible.
  3. Click **Set as Default** from the bottom right.
  4. The APN setting may require a modem restart to take effect.

Setting the External Modem Indicator Lights to Dark Mode

  1. Log in to the device's settings page and select **Advanced Settings** from the bottom of the home page.
  2. Select the **Power Saving** menu.
  3. Select **Disabled** for the **Device Indicator Lights** section.
  4. Confirm the selection by finally selecting **Apply**.

Note! In dark mode, the device's indicator lights will turn off after 15 minutes of normal operation. If a problem is detected in the network connection, the modem's indicator lights will automatically turn on.

  

Checking the External Modem Software Version

Log in to the device's settings page and select **Detailed Information** from the bottom right of the home page. The device's current software version is displayed under **Software Version**.

  

Updating the External Modem Software Version

The external modem receives updates from time to time, which should be done. You can manually check for updates in the settings pages by selecting **Update** tab from the bottom and selecting the **Check for New Version** button from the menu that opens on the right.

A good rule of thumb is to check for updates every three months. The external modem has automatic update checking enabled by default.

  

Restoring the External Modem to Factory Settings

You can restore the external modem to its default settings by pressing the reset button on the bottom of the device with a pin, for example, for about 15 seconds, until the indicator lights turn off and the device restarts. You can also restore the default settings through the device's management pages as follows:

Log in to the device's settings pages and select **Advanced Settings** from the bottom and the **Other** tab from the menu that opens on the right. Select the **Restore** section from the left-hand menu and click **Restore**. Confirm the selection by pressing **Yes** in the pop-up window.

Restoring the factory settings will restore the modem's settings to their default values.
