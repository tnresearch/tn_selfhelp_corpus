# Har du kopplat din tv-box via en hemmabioanläggning?

  
Om du har kopplat din tv-box via en hemmabioanläggning eller ett externt
högtalarsystem (en så kallad soundbar) så kan felet finnas där.  
  
Prova att koppla tv-boxen direkt till tv:n och se om ljudet funkar då. Om
felet beror på din hemmabioanläggning så kan du behöva se över
ljudinställningarna i den.
