# Router Settings

Here you will find information on how to change settings on your Huawei
B818 router.

[Forgot password](/kundeservice/internett/wifi/administrere-
ruter-b818/#passord)[Advanced
settings](/kundeservice/internett/wifi/administrere-ruter-b818/#avansert)

## Login

  1. Check that you are connected to your home network

  2. Open a browser and enter http://192.168.1.1 in the address field, and press enter.

  3. Enter your password

  4. The password is the same as your original wireless password. You can find it on the sticker on the back of the router after **WIFI**.   
**Note:** If you have changed the password to the menu yourself, enter the one you have chosen.

## Change network name or password

  1. Open a browser and enter http://192.168.1.1 in the address field, and press enter.

  2. Enter your password

 **In the menu**

  1. Select **WiFi security settings**

  2. At WiFi name (SSID), enter the desired network name

  3. If you want to change the password, enter it at WiFI password

    * The password cannot contain the letters æ, ø, or å.

  4. Press Save
