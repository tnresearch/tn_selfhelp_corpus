# Extra Networks and Guest Network

Here you will find information on how to set up extra wireless networks and a
guest network on your wireless router.

[Smart Devices ➜](/kundeservice/internett/wifi/administrere-
ruter/gjestenett/#smart)

## Extra Wireless Networks

On WiFi Router II and WiFi Router, it is possible to activate up to 3 extra
wireless networks, and these networks can be either regular networks, or
so-called **_guest networks._** You can also set up your own rules for an entire
network, so that everyone who uses it will follow the rules that are set. This
is often called [Parental Control](/kundeservice/internett/wifi/administrere-
ruter/foreldrekontroll/), and you can read more about how this is activated on
the link.

Users connected to the guest network do not have access to the regular
internal network, but they can use the internet. In practice, this means that those
connected to the guest network cannot reach different services or devices
running on your home local network.

  
For example, you may have a wireless speaker connected to your
regular wireless network. The speaker can stream music from Spotify, and you can
control it from your mobile phone, because it is also connected to the regular
wireless network. If you are connected to a guest network, you will not be able
to control the speaker, but you can use the internet as usual.

## Here's how to do it:

  1. Log in to <https://wifi.telenor.no>

    * You must be connected to the router's network to access the link above

  2. Press _Manage Wireless Networks_

  3. Scroll down to _Extra Networks_

  4. Press the switch at _Activated_ next to the network you want to activate

  5. Press the switch at _Guest Network_, on the same network you activated

  6. Come up with a suitable name and enter it in the Network Name field, or leave the default name as is

  7. Come up with a network password. This must be at least 8 characters long, but we recommend that you use at least 12 characters. Write it in the Network Password field

  8. Click _Save_

## Setting up a separate network for smart devices

Today, there is a steadily increasing amount of equipment that requires connection to
the internet - smart devices such as panel heaters, vacuum cleaners, cameras
and refrigerators. Some of these devices operate on a wireless 2.4 GHz frequency,
which makes it necessary to create a separate network specifically for them.

Therefore, we have created a simple guide that shows you how to set up
such a wireless network.

 **Here's how to do it:**

  1. Log in to the router here: <https://wifi.telenor.no>

    * You must be connected to the router's network to access the link above

  2. Press _Manage Wireless Networks_

  3. Scroll down to _Extra Networks_

  4. Press the switch at _Activated_ next to the network you want to activate

  5. Change the field where it says _Band_ to be only 2.4 GHZ

  6. In some cases, you must change Encryption to _WPA2_, but as a rule you can leave it on WPA2+WPA3.

    * If you experience problems with the connection, you can test changing the encryption to WPA2 later.

  7. Come up with a suitable name and enter it in the Network Name field, or leave the default name as is

  8. Come up with a network password. This must be at least 8 characters long. Write it in the Network Password field

  9. Click _Save_
