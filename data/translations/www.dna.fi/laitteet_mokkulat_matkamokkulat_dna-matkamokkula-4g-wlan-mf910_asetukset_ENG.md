## Settings

Locking the modem to a 4G or 3G network

By default, the modem selects either a 4G or 3G network. If you want to change
this, follow these steps.

1\. Open a web browser and type http://dna.mokkula into the browser's address bar.  
2\. Enter 1234 as the password and press **Login**.  
3\. Disconnect by pressing **Disconnect**.  
4\. Select Settings > Network Settings > Network:  
\- Only 4G: if you want to force the modem to use the 4G network.  
\- Only 3G: if you want to force the modem to use the 3G network.  
5\. Press **Apply**, return to the beginning by pressing **Home**, and then select
**Connect**.

Changing the WiFi network name and password

1\. Open a web browser and type http://dna.mokkula into the browser's address bar.  
2\. Enter 1234 as the password and press Login.  
3\. Type the desired WiFi network name in the WLAN Name field.  
4\. Type the desired WiFi network password in the Password field.

Changing the WiFi network frequency

Changing the WiFi network frequency allows you to use the less congested 5 GHz
frequency band. Before making the change, check that your device supports the 5 GHz network.
If your device does not support this network, you will not be able to use the WiFi network at all
after the change. In this case, reset the modem to factory settings.

1\. Open an internet browser and type http://dna.mokkula into the address bar  
2\. The password is 1234, press **Login.**  
3\. If all your devices use the 5 GHz wireless WiFi network, select
5 GHz in the WLAN 1 settings  
4\. Press **Apply.**  
5\. Now you need to reconnect the device to the WiFi network. If the WiFi network
disappeared completely, your device does not support the 5 GHz WiFi network. In this case,
reset the modem to factory settings.  

Simultaneous use of two WiFi networks

If you wish, you can enable both 2.4 GHz and 5 GHz WiFi networks at the same time.
In this case, the maximum speed of the WiFi network may decrease slightly.

1\. Open an internet browser and type http://dna.mokkula into the address bar  
2\. The password is 1234, press **Login.**  
3\. Select **On** in WLAN 2 and set the frequency to **5 GHz**
from WLAN 1 settings 5 Ghz  
4\. Press **Apply.**  
5\. Now you have a WiFi network available on the 2.4 GHz and 5 GHz frequencies.

Changing the WiFi network range

If the WiFi network does not reach far enough from the modem, you can try to
increase the WiFi network range as follows:

1\. Open an internet browser and type http://dna.mokkula into the address bar  
2\. The password is 1234, press **Login**.  
3\. Select **Settings > Device Settings > Battery Saving** and change
WLAN performance to **Long Range WiFi.**  
4\. Press **Apply.**

Changing the WiFi network channel width

The WLAN network channel width may speed up the WiFi network. If you are using
an older device with the modem, it is also possible that the WiFi network will not
work at all. In this case, reset the modem to factory settings and
use only the 20Mhz channel width.  
You can enable the 40Mhz channel width as follows:

1\. Open an internet browser and type http://dna.mokkula into the address bar  
2\. The password is 1234, press **Login.**  
3\. Select **Settings, WiFi settings, Advanced settings** and select
**20/40** from the band channel width.  
4\. Press **Apply.**

Resetting the modem to factory settings

If you can no longer log in to the modem's WiFi network or the modem is not responding
in any way, you can try resetting the modem to factory settings. Resetting
is done by pressing the Reset button under the SIM card cover. Hold the button
down until a light appears on the screen and it turns off completely. Only then
release the Reset button.
