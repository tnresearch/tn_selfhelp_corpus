# Manual for channel search on Sony TV with TV module

Follow the instructions below to perform a channel search on a Sony TV with a TV
module:

  * ### Get the remote control

Press the Home button. Then select **Settings** (the symbol that looks like
a bag).  
  

  * ### Select Digital setting

  * ### Select Digital auto. channel setting

  * ### Start the automatic channel setting

You do this by selecting **Yes**.

  * ### Select Cable TV

  * ### Select operator

Select **other** from the list.

  * ### Select Start

NOTE! Do not change any settings. Only select **Start**.  
  
Then the channel search will start. It takes a few minutes and you can calmly
wait during that time.  
  
  
  
  

  * ### Here's how to complete

When everything is finished, it will say **Automatic channel search completed** on your TV screen.  
  
Complete by pressing the Home button twice.  
  
There you go, now you can watch TV.
