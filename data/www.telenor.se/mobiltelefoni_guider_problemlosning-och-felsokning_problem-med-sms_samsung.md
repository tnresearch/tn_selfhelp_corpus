#  Problem med sms?

Kan du inte skicka eller ta emot sms med din Samsung kan du ofta själv lösa
problemet. Här har vi samlat en lista på de vanligaste problemlösarna.

  * Starta om mobilen och kolla om det finns några uppdateringar att hämta.
  * Kan du inte ringa heller? Då kan det vara problem med åtkomsten till nätet. Kolla vår [driftinformation ](/support/driftinformation/driftstorningar-pa-mobilnatet/)för att se om det är någon tillfällig driftstörning.
  * Testa om du kan skicka ett sms till någon annan mottagare. Funkade det? Då kan det vara ett problem hos mottagaren.

Normalt ska du inte behöva ställa in numret till meddelandecentralen, utan det
görs automatiskt när du stoppar in sim-kortet. Följ stegen nedan för att
säkerställa att numret ändå är korrekt.

  1. Tryck på "Meddelan.."
  2. Tryck på "MER".
  3. Tryck på "Inställningar".
  4. Tryck på "Fler inställningar".
  5. Tryck på "SMS".
  6. Tryck på "Meddelandecentral".
  7. Skriv +46708000708 och tryck på "VÄLJ".
