# Hur gör jag för att skaffa autogiro/e-faktura om jag inte har BankID?

Du kan enkelt ansöka om autogiro eller e-faktura via din internetbank genom
att använda din bankdosa. De uppgifter som behövs för att ansöka hittar du på
din pappersfaktura från Telenor.

Samma uppgifter kan du få från kundservice, men då behöver du identifiera dig.
Om du inte har BankID kan du att identifiera dig med hjälp av en personlig kod
som du beställer genom att [kontakta](/support/old-kontakta-oss/) vår
kundservice. Koden skickas till din folkbokföringsadress.
