## Settings

Logging in to the Settings Page

All of the device's settings are managed with a computer's web browser. The settings pages stored in the device's memory are similar to using regular web pages, so changing the settings is easy. DNA recommends using Internet Explorer, Firefox, Google Chrome and Safari (Apple) browsers. Connect your device (computer or tablet) to the modem wirelessly or with an Ethernet cable.

Open a web browser. Type the address dna.wlan/ or http://192.168.1.1 into the address bar. Pressing Enter will take you to the login page.

  1. Press the link that says **Please click here to login**
  2. The username is **admin** and the password is **1234**
  3. Press Ok and the modem's settings pages will open

Now you are logged in to the modem's settings pages. You will first be prompted to change the device's password.  

  

If you forget the password, you can restore the modem to its factory settings by pressing and holding the Reset button on the back of the device for 30 seconds. Restoring the factory settings will erase all changes made to the device's settings. After that, you can start modifying the factory settings of the modem with the default name and password found on the modem's labels, or by connecting the modem to a computer with an Ethernet cable.  

  

You will find all the information related to the network connection status on the first page that opens.

Changing the Advanced Settings of the Modem's WiFi Network

The DNA Cable Modem UBC1303 has radios for the 2.4 GHz and 5 GHz frequency bands. Both are enabled by default and have recognizable names, so the desired frequency can be selected on the device by simply selecting the appropriate network name (DNA-WLAN-2G-XXXX or DNA-WLAN-5G-XXXX).

After logging in to the settings pages, select **Gateway** at the top and **WLAN** from the menu that appears on the left. From here you can change the WiFi settings.

Changing the Wireless Network Name

SSID refers to the name of the wireless network. You can change the factory-set name to whatever you want. Naming it makes it easier to identify your own network, especially if there are other wireless connections nearby. The network name according to the factory settings can be found on the label on the bottom of the device.

For security reasons, it is not advisable to name the network in a way that can be associated with a user, username, or password. The name can consist of letters, numbers, and punctuation marks (the maximum length of the name is 32 characters).

For example, you can change the network settings for the 2.4 GHz frequency (left side of the page) by changing the SSID name of this network to "My Network Name 2G" and doing the same for 5 GHz to "My Network Name 5G", it will be easier to find the correct frequency on the user device.

Selecting Your Own Transmission Channel

Select **Gateway** from the menu at the top of the settings page and **WiFi** from the menu that appears on the left, which will take you to the WiFi settings page. By default, the modem uses the currently available transmission channel (Channel) on both frequencies/radios (auto).

There may be several wireless access points within range of your WiFi network card, which may by default use the same channel within their range, causing interference between the access points and causing the connection to slow down and drop.

If the connection speed does not match the default speed of the DNA broadband connection or the connection drops, you can also try manually locking the channel and channel width. Please note that when using DFS channels, scanning the channels may take 10–30 minutes.  

  

You can search for the most available channel with third-party software or with the UBC1303's built-in scanner, which you can find under **Diagnostics** in the left menu.  

  
Note! You can access advanced WiFi settings by selecting **Media** from the left menu.

Changing the Transmission Channel

  
Select **Gateway** from the top of the settings page and **WLAN** from the left to get to the WiFi home page.

  1. Select the channel from **1-13** from the **2.4 GHz Channel** drop-down menu or leave **auto** on. You can select more options from the 5 GHz menu.
  2. Press **Apply.**  

Securing the Wireless Network

Special attention should be paid to securing the wireless local area network connection. Because the wireless local network also works through walls, it is practically impossible to limit the network coverage to operate only in the desired area. Encrypting the connection is an effective way to prevent unauthorized use or takeover of the broadband connection by outsiders. Encryption applies only to wireless traffic between the cable modem and the computer.

However, the protection between the cable modem and the computer does not prevent threats from the internet, such as network attacks, viruses, and data breaches, to which an unprotected computer is always vulnerable when connected to the internet. Therefore, DNA recommends purchasing DNA Net Security. It is an easy and effortless way to take care of your computer's security. We recommend using the so-called WPA2 (Wi-Fi Protected Access) encryption in a wireless local network. It is currently the most secure of the available options. By default, the modem supports WPA2- PSK, TKIP and WPA-PSK encryption methods.

Changing the Wireless Traffic Encryption of the UBC1303 Modem

Select **Gateway** from the menu at the top of the settings page and **WLAN** and **Security** from the left to get to the WLAN security settings pages.

  * The default on the settings pages is WPA-PSK/TKIP/WPA2-PSK encryption.
  * The settings pages have defined values that have been found to be good for the required settings.
  * Change the WPA Key password (8-63 ASCII characters) if necessary.
  * Save the changes by clicking Apply.

Setting the Modem to Bridge Mode

The Ethernet ports of the UBC1303 modem are routed by default, so computers and other network devices connected to them receive local IP settings from the modem's own DHCP server.

You can change the ports and WiFi mode to bridged from the **Gateway** in the top menu, selecting **WAN** from the side menu and **operation mode**. Finally, select **Apply.**

After the selection, the selected ports will be bridged and IP settings will come to the devices connected to them from DNA's DHCP server (max. 5 pcs).

In this case, it is good to be aware that the modem's firewall does not protect the devices in those ports anymore.

Modem Firewall Settings

The UBC1303 modem has basic IPv4 and IPv6 firewalls enabled by default. This helps protect against certain attacks coming from the internet. However, DNA also recommends using security software (e.g. DNA Net Security) on end devices.

You can access the modem's firewall settings by selecting **Firewall** from the top menu. The IP-Flood setting is disabled by default in the UBC1303 modem.  

Opening Modem Ports

The UBC1303 modem has the UnPn port forwarding tool enabled by default. The user can also open ports manually to achieve the best possible speeds (e.g. when gaming or using download programs).

You can find the UnPn port forwarding tool by selecting **Gateway** at the top and then **Advanced settings** and **Port Forwarding** from the side menu. Clicking the **Create entry** button opens the setting where the user can specify an open port or port range by target IP.
