## Features

### DNA Modem 4G WLAN MF920V(A)

**Product Name: ZTE MF920V**

The DNA Modem 4G WLAN MF920V(A) is a basic modem that also allows you to connect wirelessly. Outside of 4G network coverage, the modem automatically uses the 3G network.

  * 4G LTE (CAT4) maximum speed 150 Mbit/s
  * 3G DC maximum speed 42 Mbit/s
  * HSPA+ maximum speed 21.1 Mbit/s
  * WLAN b/g/n, up to 32 users
  * 2000 mAh battery standby time up to 8 hours
  * Micro-SIM card

### Sales package contents:

DNA Modem 4G WLAN MF920V, power supply, MicroUSB cable, built-in battery, quick guide.

### Supported operating systems (via USB):

  * Windows 10, 8, (not RT), 7, XP, SP3, Vista (compatibility checked Q2/2017)
  * Mac OS X 10.11 (compatibility checked Q2/2017)
