# Humax CDIG-1000C TV Box

Great to be watching TV! Here you will find everything you need to get started with your TV box.

###

Connect the devices

  1. Connect the antenna cable. It should be between the RF in port on the TV box and the antenna socket in your home.
  2. Connect the box to your TV with the HDMI cable.
  3. Insert the program card into the card reader. The chip on the card should be facing downwards.
  4. Connect the power cable between the wall socket and the TV box.
  5. Turn on the TV box (Power button). If the box starts in standby mode, a red light will illuminate on the front. Then press the red Power button on the remote control.
  6. If this is the first time you are using the TV box, the installation guide will start automatically. It will help you make all the basic settings. Once all steps are complete, you can start using your box. You can always change your selections later under Settings.

**First time the TV box is started**  
First check that you have the correct source set on your TV. You do this by selecting the button on your remote control that says Source, Input or AV.
The button may also be marked with an arrow.

Then select the HDMI input to which the box is connected. To find the correct input, follow the HDMI cable from the TV box to the TV. For example, if the cable is connected to port 1, you should select HDMI1 on your TV.

**The guide starts as soon as you have selected the correct source on the TV:**

  1. Language: Select language.
  2. Screen: Select the settings that best suit your TV.
  3. Search for channels: The channel search starts automatically. Save found channels when the search is complete.
  4. Result: The result for the installation guide is displayed. Close the guide by selecting finish.

If you terminate the channel search prematurely, you may not be able to see all channels. Go to Menu – Settings – Installation and search for more channels.

The default password is 0000.

**Not working?**  
Go through the following steps:

  1. Check that the cables are in the correct sockets and are securely plugged in.
  2. Also check that you have selected the correct HDMI source (source) with the remote control.
  3. Try restarting the TV box.

If you still can't get it to work, go in and read more on our troubleshooting pages.

Perform a factory reset

Sometimes, during troubleshooting, a factory reset of the TV box may be needed.
Here is a step-by-step guide.

  1. Select Menu and go to Settings – Installation - Factory Reset
  2. A pop-up appears with the text "Do you want to perform a factory reset?" Select Yes.
  3. Enter password (the default password is 0000)
  4. The box will now restart and you will now have to go through the new installation steps again.
  5. Language: Select language.
  6. Screen: Select the picture settings that best suit your TV
  7. Search for channels: The channel search starts automatically.
  8. Save the channels when the search is complete.
  9. The result for the installation guide is displayed. Close the guide by selecting Finish. When you have completed the factory settings, the Installation Guide will appear automatically.

Edit channels

**Adding a channel to the list**

  1. Go to Menu – Settings – Edit channels.
  2. Enter password. The default is 0000.
  3. Select favorite channel with up/down arrow and press ok.
  4. Press the red button and the selected channel will be in the right column.
  5. Click on Menu when your list is ready.

**Removing a channel from the list**

  1. Select channel with up/down arrow. Click ok.
  2. Click on the red button.
  3. Press Menu when your list is ready.

**Edit the list**  
If you want to place channels in a list in the left column, press the green button and select the list you want to edit.

**Move a favorite channel**

  1. First select channel with up/down arrow and press ok.
  2. Click on the green button.
  3. Move selected channel with up/down arrow. Press ok.

**Change list**  
Do you want to see channels in another list? Press the yellow button and select the correct list.

Change and reset pin code

**Change pin code**

  1. Click on Menu on the remote control.
  2. Select Settings – System – Encryption system.
  3. Select Change CA-Pin.
  4. Enter your new pin code and confirm it.

**Reset forgotten pin code**

  1. Click on Menu.
  2. Select Settings – System – System information.
  3. Press the following buttons: red – green – yellow – blue – green – yellow – blue.
  4. Now you can enter your new pin code.
