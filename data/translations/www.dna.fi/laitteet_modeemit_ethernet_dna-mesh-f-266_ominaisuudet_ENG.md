## Features

The modem can be used as the main modem for an Ethernet home network. The modem acts as the first
mesh point and can be expanded with one or more DNA Ethernet and
Mesh WiFi 6 F-266 modems.

In addition, the following modems also function as the first mesh
connection point with the DNA Ethernet and Mesh WiFi 6 F-266 modem: DNA Cable Modems F-3890v3 and F-3896, and
DNA Ethernet Modem WiFi 6 Plus F-5670. You can connect a maximum of
four devices to each other.

#### Dimensions and weight

  * Height 142 mm
  * Width 110 mm
  * Depth 57 mm
  * Weight 285 g

**Installation methods:** on a table (upright)

**Power consumption:** 18 W

#### Information

**Manufacturer** : Sagemcom

**Model** : F-266

**Manufacturer's warranty** : 24 months

**Network connections:**

  * **ethernet** 1 x 1 Gbit/s WAN + 1 x 1 Gbit/s LAN
  * **WiFi 6** (802.11ax), 5 GHz (4x4) and 2.4 GHz (2x2)
