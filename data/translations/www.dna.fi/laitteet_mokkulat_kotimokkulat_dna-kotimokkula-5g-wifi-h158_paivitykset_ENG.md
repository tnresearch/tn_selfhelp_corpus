## Updates

#### H158 has received an update starting from week 36/2024:

Update content:

  * The default mode of the 2.5G WAN/LAN port has been changed from WAN/LAN-auto mode to LAN mode.
  * Other general fixes made by the device manufacturer
  * Mesh compatibility with DNA Ethernet and Mesh modem WiFi 6 K562  
Note. See instructions below if you have previously used a Home Modem
H158 and have one or more K562 mesh extenders connected to it.

  * New software version: 3.0.0.1(H3563SP5C182)

**DNA Home Modem 5G WiFi H158 in router mode + one or more
Ethernet and Mesh modem WiFi 6 K562**

If your Home Modem H158 is in router mode (default setting)
and a K562 mesh device is connected to it, the H158 will become the main device after the K562 software update and you will have the WiFi network defined in the H158 (SSID and password) in use.

  * If the K562s are connected to the network with ethernet cables: No action required
  * If the K562s are connected to the network wirelessly: Re-do the Mesh WiFi network setup for them. See instructions [Using as a WiFi extender](https://www.dna.fi/tuki/laitteet/modeemit/ethernet/dna-ethernet-wifi-6-k562/kayttoonotto#wifi-laajentimena) or <https://www.youtube.com/watch?v=2lJf5OI8jds>

**DNA Home Modem 5G WiFi H158 in bridge mode + one or more DNA
Ethernet and Mesh modem WiFi 6 K562**

If your Home Modem H158 has been switched to bridge mode and a K562 mesh device is connected to it, the WiFi network will continue to function as before.

  * You can put the H158 into operation as the main device of your WiFi network by switching it back to router mode from the device's settings page to disable bridge mode [Instructions](https://www.dna.fi/tuki/laitteet/mokkulat/kotimokkulat/dna-kotimokkula-5g-wifi-h158/asetukset\)) or by resetting the device by gently pressing the reset button on the bottom with a sharp object for 5 seconds. After this, you can add the K562s you have in use as extenders to your WiFi network by re-doing the Mesh WiFi network setup. See instructions [Using as a WiFi extender](https://www.dna.fi/tuki/laitteet/modeemit/ethernet/dna-ethernet-wifi-6-k562/kayttoonotto#wifi-laajentimena) or <https://www.youtube.com/watch?v=2lJf5OI8jds>
  * After the change, you will have the WiFi network defined in the H158 (SSID and password) in use.
