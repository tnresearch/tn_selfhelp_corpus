## Updates

The device's software is no longer actively updated. We recommend replacing it with a new device to ensure that security and performance are up to date.

### Software Updates

Updates to cable modems are delivered automatically over the network. Updates are run on the modems at night, causing the least amount of problems. In some rare cases, the modem may require a reset and restart in the morning after the update, so that the device functions optimally.

If you want to run the available update to the device immediately, it is worth trying to disconnect all cables from the device for a few minutes and then reconnect them. This will bring the modem back online and request updates at the same time. However, the update will not be run on the modem if it is not available.

Please note that updates are distributed in stages.

**Update 1.4.3214.S15.DNA was released in July 2020**

  * Flash memory corruption fix

**Update 1.4.3213.S15.DNA was released in June 2019**

  * Fix for rare flash memory corruption, the symptom of which is connection drops or a boot loop.

Known and under investigation issues:

  * WiFi disappears in some cases from the available networks (fix now: new modem)
  * Ipv6 does not work on all CMTS areas (fix now: force ipv4 only mode)

**Update 1.4.3212.S15.DNA was released in February 2019**

  * US power level corrected
  * ToD Filter - incorrect error message
  * Diplexer setting added
  * WiFi can be kept on in bridge mode
  * DNA TV Hub port configurations ready
  * Fix for restart issue

**Update 1.4.3210.S15.DNA was released in May 2018**

  * Band Steering as default setting
  * Fixes to error reporting
  * Fixes to port forwarding

**Update 1.4.3208.S15.DNA was released in January 2018**

  * DFS channel channel notification added
  * dna.wlan/ - address corrected
  * WLAN security setting malfunction corrected
