## Updates

#### **MF791V has received an update since August 3, 2021**

  * The update fixes a bug identified by the device manufacturer, which may have caused customers to have difficulty connecting the travel modem's WiFi network to the latest MacBooks (with the M1 chip series).
  * New software version: BD_DNAFIMF971VV1.0.0B08

#### Previous updates

**October 22, 2020**

  * The update includes a fix for issues encountered with WhatsApp calls and certain phone models from specific manufacturers.
  * New software version: BD_DNAFIMF971VV1.0.0B07
