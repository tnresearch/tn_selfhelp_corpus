## Troubleshooting

Computer cannot find the modem

Disconnect the modem and restart the computer. Connect the modem to the same
port as before. If the modem is still not found, try a different USB-
port.  

Disconnect the modem from the computer and remove the connection programs from the computer (Windows
add/remove function). Restart the computer. Connect the modem and reinstall
the connection program.

I cannot establish an internet connection with the modem

Make sure you are within coverage area. If you are using a fixed broadband
connection with a wireless router, close the wireless network when you want to use
mobile broadband.

Connection fluctuates between 4G and 3G networks

On the modem's management page (http://192.168.0.1) you can lock your modem to
a specific network (you can only do this when the modem is not connected to
the computer):  

Select **Settings** and then **Modem Settings**. You will have the following
options: **4G LTE Only** and **3G Only**. After selecting one of these,
click the **Apply** button.

If the broadband speed does not seem to be at its best

You can improve the internet connection by placing the modem as close as
possible to the window (use a USB extension cable if necessary) or by using an
external TS9 antenna. Explore additional antennas for modems
[here](https://kauppa4.dna.fi/Lis%C3%A4laitteet-ja-tarvikkeet/c/muut-
laitteet?q=%3Arelevance%3AaccessoryType%3ALis%C3%A4antennit).  

See [on our website](/kuuluvuus-ja-peittoalueet) where the coverage is
best and what speeds you can expect.
