## DNA Dock Telewell 802.11AP

### User Manual

User manuals can be downloaded from the manufacturer's website
[www.telewell.fi](https://www.telewell.fi/fi/tuote/tuotannosta-poistuneet-
tuotteet/wlan-tuotteet/tw-3g-router/tw-3g-reititin-802-11n)

### Manufacturer's Product Name

Telewell TW-3G Router 80211 AP

### Product Description

The Dock is an excellent choice for a user who wants to share an existing
USB Modem connection among multiple users.

### Package Contents

  * Dock
  * Power Adapter
  * Ethernet Cable
  * Quick Guide

### Technical Specifications

  * Connections: 4 Ethernet cable connections (RJ45), power adapter and USB connection
  * Built-in antenna
  * WLAN encryption: WEP 64/128, WPA, WPA2
  * DHCP, NAT DNS
  * Finnish user interface
  * Supported wireless standards: 802.11b/g/n
  * Supported Modems list: https://www.telewell.fi/files/mokkulat.pdf
  * Operating voltage 12V
