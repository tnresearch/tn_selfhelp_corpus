## Settings

Managing the modem's web page and changing settings

When a computer or other terminal device is connected to the modem via cable or wirelessly, all of its settings can be managed with a web browser. We recommend Internet Explorer, Firefox, Google Chrome, and Safari browsers.

• Open your web browser and type http://192.168.1.1 into the address bar and press
**Enter**.

• Type **admin** in the Username field and **1234** in the Password field.

• Press OK, and the modem's settings pages will open.

From the settings pages, you can also change WiFi channels, network name, or even security settings.

Entering the PIN code

If the SIM card uses a PIN code other than 1234, the PIN code must be entered on the modem's display or through the settings pages.

1\. Open a web browser when you are connected to the modem's WiFi network

2\. Type http://dna.mokkula or http://192.168.1.1 into the address bar

• The default username is **admin.**

• The default password is **1234.**

3\. Select **advanced settings** from the main page and **Other** from the top menu that opens.

4\. Select **PIN code management** from the left.

5\. Enter the PIN code in the **Current PIN** field and press **Apply.**

Playing online games

Many online games work better if UPnP is enabled on the modem. You can check this as follows:

1\. Open a web browser when you are connected to the modem's WiFi network.

2\. Type http://dna.mokkula or http://192.168.1.1 into the address bar

• The default username is **admin.**

• The default password is **1234.**

3\. Select **advanced settings** from the main page and **Firewall** from the top menu that opens.

4\. Select **UPnP** from the left.

5\. Check the box next to **Enabled.**

6\. Press **Apply**.

Note! You can also open ports manually from the same, **port forwarding** and **DMZ mode** sections. From **4G settings** you can find **bridge mode**, which opens all ports.

Locking the modem to a 4G or 3G network

Modems work most efficiently on 4G or 3G networks. If the connection is slow or drops, it is worth placing the modem near windows where the connection is at its best. More information about coverage areas:
[dna.fi/coverage.](https://www.dna.fi/kuuluvuus-ja-peittoalueet)

If the modem is used on the border of a 4G or 3G network or a 3G or 2G network, the modem may switch between these networks. Switching between networks causes the connection to drop and slows down the modem. If you wish, you can lock the modem to any network technology as follows:

1\. Open a web browser when you are connected to the modem's WiFi network.

2\. Type http://dna.mokkula or http://192.168.1.1 into the address bar

• The default username is **admin.**

• The default password is **1234.**

3\. Select **My Router** from the main page and **settings.**

4\. Select **network selection** from the menu that opens.

• 4G/3G – First selects 4G, then 3G, and finally 2G network.

• 4G – Locks the modem to the 4G LTE network.

• 3G – Locks the modem to the Dual Carrier or 3G network.

• 2G – Locks the modem to the 2G network.

Locking the modem to a specific 4G frequency band

In addition to network selection, locking the modem to a specific 4G frequency band can help with connection speed and possible interruptions. For example, a modem located at the junction of many base stations may switch and choose a poorer frequency band for the location.

You can select the frequency band by selecting **My Router** and **settings** from the main page, and then **lock frequency** from there.

Changing the WiFi network name and password

You can change the WiFi network name and password as you wish. If you do this, devices that were already connected to the WiFi network must be reconnected to the renamed WiFi network.

If you forget the changed WiFi network password, you can reset the modem to factory settings, which will restore the WiFi network password to the same one that is on the sticker on the back of the modem.

1\. Open a web browser when you are connected to the modem's WiFi network.

2\. Type http://dna.mokkula or http://192.168.1.1 into the address bar.

• The default username is **admin.**

• The default password is **1234.**

3\. Select **WiFi** from the settings in the main menu.

4\. At the top of the view that opens, there is a section for **2.4 GHz frequency** and its settings.

5\. Select **2.4 GHz** and retype the name in the **network name** field.

6\. Press **Apply.**

Changing the WiFi network channel and bandwidth

DNA Modem 4G WLAN MF920V automatically searches for the best WiFi channel and channel width.

1\. Open a web browser when you are connected to the modem's WiFi network.

2\. Type http://dna.mokkula or http://192.168.1.1 into the address bar.

a. The default username is **admin**.

b. The default username is **1234.**

3\. Select **WiFi** from the settings in the main menu.

4\. At the top of the view that opens, there is a section for **advanced settings**.

5\. Select the frequency in the advanced settings and select the freest possible **WiFi channel** from the drop-down menu.

6\. The drop-down menu for **channel bandwidth code** brings up options, depending on the frequency range, **20,40** or **20/40 (auto)**. Choose the best one for your environment.

7\. Press **Apply.**

Changing the modem's management password

You can change the modem's management password if you wish. If you forget the changed management password, you can reset the modem to factory settings.

1\. Open a web browser when you are connected to the modem's WiFi network.

2\. Type http://dna.mokkula or http://192.168.1.1 into the address bar.

• The default username is **admin**.

• The default password is **1234.**

3\. Select **Edit login password** from the upper right corner of the settings pages home page.

• The current password is **1234.**

• **New password** – Enter the password you want.

• **Confirm password** – Confirm the password you want.

4\. Press **Apply.**

Reset to factory settings

You can restore the modem to its default settings by holding down the Reset button for about 15 seconds. The Reset button is located under the same flap that protects the SIM card.
