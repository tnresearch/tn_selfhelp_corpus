## Updates

The device's software is no longer actively updated. We recommend upgrading to a new device to ensure that security and performance are up to date.

The modem receives updates occasionally, which should be performed.

### Instructions for updating:

  1. Open a web browser when you are connected to the DNA Home Modem's WiFi network or have connected the device with an Ethernet cable.
  2. Type http://dna.mokkula or http://192.168.1.1 in the address bar.
    * The default username is admin
    * The default password is 1234.
  3. Select advanced settings from the home page.
  4. Select update from the top menu.
  5. Select check.
  6. Follow the instructions in the user interface. Do not turn off or disconnect the power cord from the device during the update. The update may take 5-30 minutes.

If the update is not found or is interrupted unexpectedly, try resetting the device and clearing the browser cache and try again.

**An update has been released for the device on 15.8.2018**

Changes from the previous version:

  * GDPR notification
  * Improvements to battery security

The new version is: **ZTE_DNA_MF920V_B08** (MF920V) and **ZTE_DNA_MF920V_B06**
(MF920VA)**

The update is rolled out gradually, meaning not everyone will receive the update at the same time. Clearing the browser cache helps if the new features are not visible after the update.

**An update has been released for the device on 23.8.2017**

**Changes from the previous version:**

  * Mobile version DNA look and feel has been added
  * Improvement to update notifications and so-called forced update
  * 700 MHz lock
  * Possibility to schedule automatic update checks
  * Incoming text messages do not interfere with internet use
  * Other fixes related to performance, security and usability.

  
The new version is: **ZTE_DNA_MF920V_B05**

**An update has been released for the device on 7.12.2016.**

Changes from the previous version:

  * Information about the connected base station (Cell ID) has been added to the additional information view
  * DNA APNs have been added to the menu and the default APN has been changed to the future productization format
  * Translation corrections
  * Fixes to bridging mode, including improved support when the device is connected to an external router via USB
  * Wi-Fi is disabled when bridging mode is enabled. This is a limitation of the chipset.

  
The new version is: **ZTE_DNA_MF920V_B03**
