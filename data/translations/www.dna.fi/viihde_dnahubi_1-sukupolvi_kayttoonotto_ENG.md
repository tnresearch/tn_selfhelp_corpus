## DNA Entertainment Box Installation and Getting Started

If you have a DNA Entertainment Box (Hubi 1.0), proceed in this order:

If you also ordered DNA Net, install the internet connection first.

Install the internet first. We recommend a minimum speed of 10 Mbps for using
the entertainment box. The entertainment box will not work without an
internet connection. If you purchased an internet connection at the same
time, it was delivered in a separate package. Install the broadband first
according to the separate instructions included with it and make sure the
internet connection works.

Gather all the accessories from the sales package

  * Check that you have all the contents of the sales package at hand (entertainment box, power cord, remote control with batteries, HDMI cable, ethernet cable, antenna cable, quick guide)
  * A working internet connection (if you ordered DNA Net together with the entertainment box, install DNA Net first)
  * If using a wireless internet connection, you will need the wireless network password
  * If using a fixed connection, you will need a free ethernet port
  * A television with at least HD-ready resolution
  * You may also need an antenna splitter, for example, when using a cable modem

Connect the entertainment box to the TV with an HDMI cable

Connect the entertainment box to the TV with an **HDMI cable** ➀. You can
choose any available HDMI port, which is usually located on the back or side
of the TV and is labeled **HDMI IN**. Make sure you insert the cable into the
connectors the right way around.

Connect the device to the internet with a network cable

Connect the device to the internet with a **network cable** ➁. Connect your
DNA Hubi modem to the internet port or the wall socket of the local network.
Many modems have local network ports marked with **LAN**. You can use any LAN
port on the modem.

If you want to connect the entertainment box to the internet with a wireless
WiFi network, its credentials will be entered later after the device starts
up. This will be instructed in later steps of this guide.

Connect the antenna cable to the TV antenna socket

Connect the **antenna cable to the TV antenna socket** ➂ unless you are only
watching channels over the internet. If you have a cable modem connection,
use a separately purchased antenna splitter if necessary. Place the splitter
in the antenna socket and connect the antenna cables from the splitter to
the DNA Hubi device and the cable modem.

Make sure the antenna cable is connected correctly.  

**Note. You can skip connecting the antenna cable if you are only watching
channels over the internet. Channels can also be viewed on the entertainment
box in IPTV quality over the internet. We recommend a minimum speed of 10
Mbps.**

#### Connection using an antenna splitter

Connect the power cord last

Connect the **power cord to the device** ➄ **and to the power outlet**. The
device will start up automatically.

## Using the Entertainment Box After Startup

Check that the **Source or input** of your TV is set to the HDMI port to
which you connected the entertainment box HDMI cable. You can change the input
source using the Source button on your TV remote control. When the input
source is correct, you will see a welcome start screen on the TV screen.

#### The device checks for available updates during startup

The entertainment box is constantly updated, and its features and included
applications are updated at the same time. During startup, the device checks
for available updates and installs them if necessary. The device may then
restart automatically. Allow the entertainment box to install the updates so
that your device is up-to-date in terms of features and functionality.

Select the system language

Start by selecting your desired system language. Use the arrow keys on the
remote control to move between language options. Accept the selection by
pressing the **OK button** on the remote control.

Google Accounts and Their Use

**Using Google accounts gives you access to all the features of the
entertainment box**

  * By entering Google credentials and allowing apps to use your location, you can download YLE Areena, Ruutu or mtv apps, and play games.
  * You can use existing Google accounts or create new ones if needed. You can use any Google service username and password as Google credentials, e.g. a Gmail email address and password.
  * **If you wish, you can skip this step by selecting "Skip" during startup. You can then watch TV channels and recordings normally on the entertainment box once the startup is otherwise completed.** You can enter Google credentials later.

  
**Do you have an Android phone or tablet?**

**Yes**

Select **Yes** and continue the installation according to the instructions
on the TV screen.

  1. Find the Google app on your phone.
  2. Type **Set up my device** or in Finnish **Määritä laitteeni** in the app's search field, or alternatively say **OK Google, set up my device** or in Finnish **OK Google, määritä laitteeni**. Select **Next**.
  3. Select your entertainment box from the list. The name appears on your TV screen. Select **Next**.
  4. A code appears on the TV and phone screen. Confirm that the codes match. Select **Next**.
  5. Continue according to the instructions on the TV screen.
  6. Location, select **Yes** or **No**. Apps need the device's location information to display local weather and other location-specific information. Make your desired selection with the arrow keys and press **OK.**
  7. Help improve Android TV. Select **Yes** or **No.**

  
**No**  

Select **No** and continue the installation according to the instructions
on the TV screen.

  1. Log in to Google and use a phone or computer.
  2. Use your password.
  3. Skip. You can optionally skip this step and enter Google credentials
    later.

Apps need the device's location information to display local weather and
other location-specific information. Make your desired selection with the
arrow keys and press **OK**.

Select Wireless Network (if you are not using a network cable)

Select the wireless network you are using and press the **OK button** on the
remote control. Then enter the password for the wireless network. If you
connected the entertainment box with a network cable, this step will not be
displayed.

Tune Channels

#### An automatic channel search lasting a few minutes will start:

If you do not see the entertainment box startup screen, read this

After you have connected the entertainment box power supply to the power
outlet at the end of the installation, the entertainment box will start up.
Many TVs will start up at the same time, automatically setting the correct
input source.

If the TV did not start up, turn it on. Check that the Source or input of
your TV is set to the HDMI port to which you connected the entertainment box
HDMI cable. You can change the input source using the **Source button** on
your TV remote control. See the TV's user manual for more detailed
instructions on changing the input source.

Now the entertainment box setup is complete and it will automatically tune
to YLE TV1 channel. Enjoy watching!

You can start watching TV programs by pressing the pink DNA TV button in the
upper left corner of the remote control.
