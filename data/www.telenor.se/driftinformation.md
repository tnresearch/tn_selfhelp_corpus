# Driftinformation

## Kan du inte ringa eller surfa på mobilen? Eller är det bredbandet eller
tv:n som krånglar? Det kan bero på en driftstörning. Välj den tjänst du har
problem med.

[ Tv eller bredband ](/support/driftinformation/driftstorningar-pa-tv--och-
bredbandsnatet/)

[ Mobiltelefoni ](/support/driftinformation/driftstorningar-pa-mobilnatet/)

##

  * Jag har problem med att ringa till 112. Vad ska jag göra?

**Börja med att starta om mobilen.** Fungerar inte det, ta då ut simkortet ur
telefonen och ring 112 utan något simkort installerat.

**Har du e-sim? Stäng tillfälligt av det.**

För att stänga av e-sim i iPhone, gå till: Inställningar > Mobilnät  
För att stänga av e-sim i Android, gå till: Inställningar > Nätverk och
internet

Glöm inte att slå på ditt e-sim när du är klar med ditt 112-samtal.  
  
 **Ring via bredbandet med wifi-samtal**.  
  
Du kan ringa wifi-samtal om du är uppkopplad via ett bredband. Detta är en
funktion som du alltid kan ha påslagen. [Mer information finns
här.](/link/bc2556b175044d2a980f1376de2c6a66.aspx)

**Ring via 112 appen.**  
  
Du behöver ha mobilnätverk eller wifi för att kunna göra det. Fungerar inte
mobilnätet kan du ringa via 112-appen om du är uppkopplad via ett bredband.
[Du kan ladda ner 112-appen här.](https://www.sosalarm.se/112-och-andra-
viktiga-nummer/112-appen/)

**Har du hemtelefoni via bredbandet** och det är en driftstörning på ditt
bredband. Ring via mobiltelefonen istället.
