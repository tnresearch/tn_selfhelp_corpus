## Getting Started

## Installing the Modem

The Home Modem 5G WiFi H112 uses a Nano-SIM card. Carefully insert the Nano-SIM card into the designated slot in the position shown in the picture so that it clicks into place. Then close the SIM card slot cover.  

  
Note! Remove the SIM card by pressing it gently inwards until it clicks. The card will automatically pop out.  
Do not insert or remove the SIM card while the router is running, as removing the card may affect performance or damage the SIM card.  

  

Connect the power adapter to the router and press the power button. Connecting to the internet will take a few minutes. If the connection fails, check the instructions under point 3 below to see if the SIM card is locked and unlock it. If this does not help, call [DNA Customer Service](https://www.dna.fi/yhteystiedot#asiakaspalvelu).  
  
The 5G and 4G signal indicators will light up when the modem has connected to the network:  
  
Green: strong  
Yellow: moderate  
Red: weak

## Enabling Wireless Network (WiFi)

  

Once a connection to the 5G or 4G network has been established, you can connect your home computers, mobile phones and other network-enabled devices to the modem's WiFi network to access the internet. See the WiFi network's default name (Wi-Fi Name) and password (Wi-Fi Password) on the sticker on the bottom of the router.

## Removing SIM Card Lock

If the modem cannot find a mobile network:

If the PIN code request is active on the modem's SIM card, the device will not be able to access the network until you enter the PIN code via the management pages. In this connection, it is also recommended to deactivate the PIN code request. You can find the address of the device's management page on the sticker on the bottom of the modem, as well as the management page password.

In a situation where the SIM card PIN request is on, you will be redirected to enter the PIN code on the page shown in the following image. You can change the language of the user interface if necessary from the Language/Kieli menu in the upper right corner. PIN code confirmation is disabled by default, so the code does not need to be re-entered after each restart.  

  

## Logging into the Modem Management Pages

The login view of the modem's management pages is as follows. Enter the login password found on the bottom of the device in the field that says "enter password".  

  

When you log into the modem's management pages, you will be automatically prompted to activate automatic updates on your first login. DNA recommends enabling automatic updates so that the device remains automatically up to date with the latest software updates.  

  

Next, you can modify the name and password of the device's WiFi network, as well as whether the device shows a single combined 2.4 GHz and 5 GHz WiFi network (in which case 5 GHz network preference, i.e. band steering, is enabled) or separate 2.4 GHz and 5 GHz networks.  

  

Next, you will be prompted to change the password used to log into the modem's management pages. By default, you are given the option to change the password to the same as the Wi-Fi network password set in the previous section. Both the WiFi network and the management page login password can be reset to factory settings (the passwords shown on the sticker on the bottom of the modem) by pressing the reset button on the bottom of the device next to the SIM card slot for 10 seconds.  

  

After this, you will be able to access the actual management pages where you can check and, if desired, modify the device's settings. When using the modem in a 5G coverage area, the 5G signal strength will be displayed in the start view of the management page above the 4G signal strength on the left side of the screen.
