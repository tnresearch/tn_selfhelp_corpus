# How to Set Up Your Modem

See the guide below for setting up your modem. If you have already tried to
install the modem without success, we recommend that you start by uninstalling
it.

  * ## Open Your Mobile Broadband Software

If the program **does not appear** automatically, you can find it in
**file management** along with your C drive. The icon looks like this:

  * ## Select Language

Once you have selected your language, press "**ok**"

  * ## Press "Next"

  * ## Press "I Accept"

  * ## Choose Where to Install the Program

Then select "**Next**"

  * ## Choose a Name for the Shortcut in the Start Menu

Then press "**Install**"

  * ## The Program is Now Being Installed

  * ## Installation is Now Complete

  * ## Enter PIN Code and Choose Personal PIN

The first time you start the program, you must enter the included
**PIN code** - and then choose a **personal PIN**.

  * ## To Get Online, Press "Connect"
