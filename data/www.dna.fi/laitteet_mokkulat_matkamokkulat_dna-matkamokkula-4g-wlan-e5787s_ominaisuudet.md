## Ominaisuudet

### DNA Matkamokkula 4G+ WLAN E5787s

Tuotenimi: Huawei E5787  
  
DNA Matkamokkula 4G+ WLAN E5787s on tehokas 4G-mokkula,  
jolla luot nopean nettiyhteyden juuri siellä missä olet.  
Pienikokoisella matkamokkulalla luot langattoman verkon joko 4G- tai
3G-nopeudella  
usealle laitteelle.

  * 4G LTE enimmäisnopeus verkosta 300 Mbit/s
  * 3G DC enimmäisnopeus 42 Mbit/s 
  * HSPA+ enimmäisnopeus 21,1 Mbit/s
  * WLAN b/g/n/ac Dual-Band
  * USB
  * 16 WLAN-laitetta 
  * Kaksi liitäntää ulkoisille antenneille, liitäntätyyppi TS9
  * Mikro-SIM-kortti

### Myyntipaketin sisältö:

DNA Matkamokkula 4G+ WLAN E5787, virtalähde, pikaopas, UBS-kaapeli, akku.

### Laitteistovaatimukset / Tuetut käyttöjärjestelmät:

  * WLAN: 802.11b/g/n/ac
  * USB2/3-portti
  * Tuetut käyttöjärjestelmät: Windows XP SP2/SP3, Vista SP1/SP1, Windows 7, Windows 8 / 8.1, Windows 10, MAC 10.5-10.11
  * Internetselain hallintaa varten: Microsoft Internet Explorer 6.0 tai uudempi, Firefox 2.0 tai uudempi, Safari 4.0 tai uudempi, Opera 10.0 tai uudempi, Chrome 5.0 tai uudempi
