# Update Software

Here you will find information on how to update the software on your Huawei
B818 router.

New software is important for maintaining security and stability. The update
happens automatically each time new software is available - as long as the SIM card
and router are registered and connected.

If you need to update the software manually, you can download it
from the logged-in menu for the router.

## Log in to the Router

  1. Check that you are connected to your home network

  2. Open a browser and enter http://192.168.1.1 in the address field, and press enter.

  3. Enter your password

  4. The password is the same as your original wireless password. You can find it on the sticker on the back of the router after **WIFI**.   
**Note:** If you have changed the password to the menu yourself, enter the one
you have chosen.

## Update Software

  1. Select **Advanced**

  2. Select **Updates**  
** Here you can see which version of the software you have.

  3. Select **Check for Updates** and then follow the instructions
