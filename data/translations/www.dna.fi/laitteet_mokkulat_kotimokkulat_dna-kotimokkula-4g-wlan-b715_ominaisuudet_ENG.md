## Features

  
**Product Name: Huawei B715-32c**  
  
A true high-end modem that meets the needs of even the most demanding user. The modem supports LTE Cat 9 level network connection, so the peak speed of 4G internet is promised to be up to 450 Mbit/s. Advanced features and DNA's customizations make use unprecedentedly easy and smooth.  

  * 4G LTE (Cat 9) maximum speed from the network 450 Mbit/s
  * 4G LTE maximum speed towards the network 50 Mbit/s
  * 3G DC maximum speed 42 Mbit/s 
  * HSPA+ maximum speed 21.1 Mbit/s
  * WLAN 802.11b/g/n/ac, 3x3, Dual-Band
  * USB 2.0 port for sharing USB memory on the local network 
  * 4 Ethernet ports, max. 1000 Mbit/s (LAN1 WAN)
  * 32 devices can be connected to the wireless network 
  * Two connections for external antennas, connection type SMA 
  * Micro-SIM card
  * DNA's customized operating system
