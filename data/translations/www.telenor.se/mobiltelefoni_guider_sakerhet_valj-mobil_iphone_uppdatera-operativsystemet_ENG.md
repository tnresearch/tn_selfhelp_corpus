# Update operating system (iOS)

Here's how to install the latest version of the operating system
(also called a software update) on your iPhone. This will ensure that
your mobile works as well, and most importantly as securely, as possible.

  * ### Go to the home screen

  * ### Select "Settings​"

  * ### Select "General​"

  * ### Select "Software Update​"

  * ### Now your iPhone searches for the latest update

If you already have the latest version, it will be displayed on the screen. ​

  * ### Automatic updates

For your phone to work as well and securely as possible, it is important
to always have the latest operating system installed. Therefore, we recommend
that you take the opportunity to turn on the "Update Automatically" function.
