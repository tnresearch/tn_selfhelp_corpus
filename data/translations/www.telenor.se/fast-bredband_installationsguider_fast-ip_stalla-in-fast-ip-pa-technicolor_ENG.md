# Setting a static IP on Technicolor 784, 789 and 799

  * ### Open your web browser

Connect to the router by entering the address 192.168.10.1 in the address bar
of a web browser.

  * ### Log in

Log in with username Admin. You can find the password on the back of your
router (Gateway Password).

  * ### Gear icon

Once you are in the logged-in mode, you can look for the Internet access
menu and click on the gear icon in the upper right corner.

  * ### Advanced settings

Click on Show advanced in the upper right corner.

  * ### Static IP

Check Fixed IP mode and then click the Switch connection mode button.

  * ### Configuration

Now you can configure the router with the IP address details you received from Telenor
and connect any equipment (router, firewall, computer).
