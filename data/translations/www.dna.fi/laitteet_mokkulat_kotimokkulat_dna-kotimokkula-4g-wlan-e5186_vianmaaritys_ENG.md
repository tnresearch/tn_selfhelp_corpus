## Troubleshooting

I am using the modem with a SIM card that asks for a PIN code

You can enter the PIN code through the modem's management page (http://dna.mokkula).
See the instructions [Entering the PIN code](/dna-
kotimokkula-4g-wlan-e5186#asetukset).

The modem connection is intermittent or slow

If your connection is slow or intermittent, it is worth moving the modem closer
to the window and enabling additional antennas. You can find additional antennas
at the DNA Online Store. If these do not help, check the coverage and
coverage map on the DNA website or contact DNA Customer Service. Customer
service will advise you from which direction the base station transmits and
to which window you should move.

If the modem's LED signals show more than three bars and the connection is
still slow, try connecting with an Ethernet cable.

If possible, switch to using only one WiFi frequency. See more information
in the section Changing WiFi network frequency [link to section: **Settings – WLAN network frequency change** ].

The computer reports "Limited connectivity from the computer"

The modem is not connected to the internet. Check your internet connection,
connections and SIM card PIN code. Restart the modem if necessary.

The modem reports that it is connected to the internet, but the connection does
not work on the computer

Make sure you have connected the computer to the WiFi network created by the
modem. You can find the WiFi network name on the sticker on the back of the
modem. You can also try connecting with an Ethernet cable. If this does not
help, restart the modem.

I accidentally changed a setting that I shouldn't have and now the home modem
no longer responds to commands

You can restore the device to factory settings (press and hold the reset button
for 3 seconds) or restart the modem (with the power cord disconnected for
about 30 seconds). After this, however, all settings must be done again.
