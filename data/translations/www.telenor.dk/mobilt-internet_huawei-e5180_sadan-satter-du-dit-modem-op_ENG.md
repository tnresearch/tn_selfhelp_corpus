# How to Set Up Your Modem

Follow the guide below if you need to set up your new modem.

If you have already tried to install the modem without success, we recommend that you
start by uninstalling it.

  * ## Find Your Router on the List of Wireless Networks

Press "**Connect**"

  * ## Enter the Included Network Key

Then click "**Next**"

  * ## Choose Whether You Want to Automatically Connect to This Network in the Future

  * ## Choose a Personal Code

The first time you start the program, you must enter the included
**PUK code**, and choose a **personal 4-digit PIN code**.
