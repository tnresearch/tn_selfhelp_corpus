# Kan ej spola eller pausa i tidigare sända program

Så här tittar du på ett program som redan sänts.

Gäller det program som går på 4an, 7an eller 12 är det i dagsläget tyvärr ej
möjligt att spola/pausa.

  * ### 

Klicka på TV-ikonen på fjärrkontrollen och välj ett valfri kanal.

  * ### 

När du tittar på en kanal, klicka på **OK** och sedan " **Tablå** " som finns
längst ner i högra hörnet på Tv-skärmen.

  * ### 

Sen kommer du få upp en meny på vänstra sidan där du först väljer datum, efter
det väljer du vilket program du vill se och klicka **OK** på programmet.
