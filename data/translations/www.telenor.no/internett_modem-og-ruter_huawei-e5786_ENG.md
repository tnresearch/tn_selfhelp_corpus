# Help with Huawei E5786 / E5785

Here you will find information and guidance on how to set up and use
the Huawei E5786 and E5785 Mobile Broadband Routers.

Upgrade to newer router

Has it been more than 5 years since you replaced your equipment? We recommend switching to
newer equipment to achieve better quality. Technology is constantly evolving, and
equipment older than 5 years is no longer [within the
warranty period.](https://www.telenor.no/privat/vilkar/)

[Read more about our latest equipment for Mobile
Broadband.](https://nettbutikk.telenor.no/mobilt-bredbaand/)

## Simple steps to get online

  * #### Open the lid and insert the SIM card

  * #### Turn on the mini router and plug in the charger

  * #### Connect to the wireless network

  
 **Windows**

    1. Left-click on the wireless network icon at the bottom next to the clock and date

    2. Find the network that matches the network name on the underside of the router and click **Connect**

    3. Enter the network password that is on the underside of the router and click **Connect**

 **Mac**

    1. Press the Airport icon for wireless network

    2. Find the network that matches the network name on the underside of the router and click **Connect**

    3. Enter the network password that is on the underside of the router and click **Connect**

 **Samsung/Android:**

    1. Go to settings on your phone

    2. Select Connections

    3. Select Wi-Fi

    4. Find the network that matches the network name on the underside of the router and tap on it

    5. Enter the network password that is on the underside of the router and click **Connect**

 **iPhone/iPad:**

    1. Go to settings

    2. Select Wi-Fi

    3. Find the network that matches the network name on the underside of the router and tap on it

    4. Enter the network password that is on the underside of the router and click **Connect**

  * #### Open a browser and follow the wizard

Enter a web address, such as https://www.telenor.no

 **PIN code**

In the wizard, you will be asked to enter a PIN code. This can be found in
the letter you received with the SIM card for the router.

If you cannot find the PIN code, you can [retrieve the PUK code on My
Pages](https://www.telenor.no/privat/minesider/web/mobil/). Once you have entered
the PUK code, you will be asked to create a new PIN code.

**How to retrieve the PUK code**

    1. [Log in to My Pages](https://www.telenor.no/privat/minesider/web/mobil/)

    2. Select the subscription in question

    3. Under **Devices and SIM** , select the SIM card in question

    4. Click **Show PUK code**. 

## Questions and answers

  * #### How do I update the router?

The router's software is updated automatically. If you are having trouble getting
online, we recommend restoring the factory settings.

New software is important to ensure security and stability. When new
software is available, you will be prompted to update on the mini router's
screen. Device and SIM card information is required to perform
the software update. The technical parameters required are
the device's IMEI number and parts of the SIM card's IMSI number. This identifies
which device you are using and that you are using Telenor's mobile network, so that your
device receives the correct software tailored to Telenor's mobile network.

If you see the text 'Warning update' in the display on the router, you can press
the power button to start the update.

  * #### How do I access the router's menu?

The router has its own menu, where you can, among other things, change the wireless network name
and network key.

 **How to access the router's menu:**

Open a new browser, such as Google Chrome on a PC or mobile that
is connected to the wireless network on the router. Type **192.168.1.1** in
the address field, press **Enter**.

The username is admin and the password is the network key you received (PWD/WIFI
KEY)

 **Note** , if you have previously changed the password yourself, enter that one.

  * #### How do I know if 4G+ is available?

The router will display a "+" sign after 4G if you are in an area with 4G+ coverage
and using data.

  * #### How do I reset the Huawei E5786 or E5785?

If you are experiencing problems connecting to the Internet, it may help to reset
the router.

Note, the network name ( **SSID** ) and network key ( **PWD/WIFI
KEY** ) can be found on the inside of the lid on the router.

 **How to reset the router manually** :

    1. Open the lid on the router

    2. Press a paperclip/pin into the reset hole, and hold for 10 seconds

    3. The router turns off and on, and you can connect to the wireless network again

 **Note** , after you have reset the router, the network name and
network password will be reset.

 **How to reset via the menu** :

    1. Open a new browser, such as Internet Explorer, on a computer that is connected to the router. Type **192.168.1.1** in the address field, press **Enter**.

    2.  **Username** is admin and **password** is the network key you received (PWD/WIFI KEY)

    3. Click **Settings**

    4. Select **System security** then **Factory settings**

    5. Press **Restore**

    6. Press **Restore** again to confirm.

The router turns on automatically again, and you can connect again. Note,
after you have reset the router, the network name and network password will be
reset. If you have changed the login password for the router, this will also be
reset.

  * #### How do I change the wireless channel?

If you have a weak signal strength or problems finding the wireless network,
it may help to change the wireless channel.

To change the wireless channel, you must access the router's menu. The computer must
be wirelessly connected to the router to access the menu.

    1. Open a new browser, such as Google Chrome, on a computer that is connected to the router. Type **192.168.1.1** in the address field, press **Enter**.

      *  **Username** is admin and **password** is the network key you received ( **PWD/WIFI KEY** )

    2. Select **Settings**

    3. Click **Wi-Fi** , then **Advanced**

    4. Select a channel from the drop-down menu under **Frequency (Channel)**.

      * It is recommended to choose **1** , **6** or **11**. Channel 11 may work better than channel 1 at your home, so try it out. Avoid channels 12 or 13 as some network cards cannot connect to these.

    5. Press **Apply**. The settings are now saved.

    6. If you still experience the same problem, repeat from step 4 and try a different channel that may work better on your computer.

    7. If you cannot find your wireless network, you should restart your PC and router.

  * #### How do I change the Access Point Name (APN)?

    1. Open a browser, such as Internet Explorer, on a computer that is connected to the router

    2. Type 192.168.1.1 in the address field, press Enter

    3. Select Settings

    4. Type 'admin' in the username field. The password is the same as the network key or a custom password that was chosen during the first-time setup of the router. The network key (WIFI KEY) can be found on a sticker on the back of the modem

    5. Select Profile Management

    6. Press New profile and enter the desired profile name. (this is just a description of the new profile)

    7. Enter the desired APN in the APN(access point name) field

    8. Press Save

    9. Restart your router.
