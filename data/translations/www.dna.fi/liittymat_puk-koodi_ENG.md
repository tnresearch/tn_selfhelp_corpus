# PUK Code

If you have entered the PIN code incorrectly three times, you will need the PUK code to unlock it.

## How to find your PUK code

### By logging in to dna.fi

You can check the PUK code for your mobile subscription or mobile broadband free of charge by logging in to the DNA website. You can find the PUK code in your subscription details. Do this: log in and select **Subscriptions and Services**. Select the subscription in question, and select **SIM card** and **PUK codes**.

[ Go to login ](https://minunpalveluni.dna.fi/kirjautuminen)

### From the My DNA app

You can also check your mobile subscription's PUK code in the My DNA app from the details of the subscription in question. You can easily download the app for your use from your app store.

[ Download the app ](https://www.dna.fi/oma-dna-sovellus)

### Let DNA Assistant help

Lost your PUK code?

As a logged-in user, you can get the PUK code 24/7 via chatbot.

You can also get the PUK code from DNA customer service. There is a charge for finding out the PUK code through customer service, according to the call pricing.

[ See contact details ](https://www.dna.fi/yhteystiedot)

## Frequently Asked Questions

What is a PUK code?

The PUK code (Personal Unblocking Key) is 8 digits long and is needed to unlock a locked PIN code. If the PUK code is entered incorrectly ten times, the SIM card will no longer work and must be replaced with a new one.

Where can I find my subscription's PUK code?

You can find the PUK code for your mobile subscription in the subscription details by logging in to dna.fi, in the My DNA app, or by contacting customer service. You can also get the PUK code in the chat when you have logged in with online banking credentials or a mobile certificate.

  * The PUK code for DNA Multi-SIM is available in the My DNA app and through customer service
  * You can find the PUK code for DNA Prepaid and DNA Dataprepaid subscriptions in the frame of the subscription card. 
    * If you have registered your DNA Prepaid subscription in the DNA Store, you can also find out the PUK code through customer service

I need a PUK code. Where can I get it quickly?

You can conveniently get the PUK code directly from the chatbot. You can open the chat from the bottom right corner of the page.

What is the phone's PIN code?

The PIN code for DNA subscriptions is 1234 by default. You are prompted to change the PIN code as soon as a new subscription is activated. In most phone models, you can change the PIN code in the phone settings.

If the PIN code is entered incorrectly three times, it locks and the PUK code is needed to unlock it.

PIN code inquiry has been turned off for Prepaid subscriptions to make activation easier. You can enable PIN code inquiry at any time if you wish. You can find the PIN code for a Prepaid subscription in the frame of the SIM card.

I entered the PUK code incorrectly too many times, what should I do?

If the PUK code is entered incorrectly ten times, the SIM card will no longer work and must be replaced with a new one. You can replace the card through [customer service](https://www.dna.fi/yhteystiedot) or at the [DNA Store](https://www.dna.fi/dnakaupat).

Will my phone's services work without a PUK code?

A locked SIM card prevents the use of the mobile network (calls and data) and SMS messages. The PUK code is needed to unlock these services.

You can also use the phone and more functions with Wi-Fi. If you can access the Wi-Fi network with your phone, you can request the PUK code through it.
