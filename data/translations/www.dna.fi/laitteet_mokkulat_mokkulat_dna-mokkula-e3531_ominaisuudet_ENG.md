## Features

### DNA Modem E3531

**Product Name: Huawei E3531**

The DNA Modem E3531 is a handy modem for those who appreciate a small size.
Supports 2G and 3G connections.

  * HSPA+ maximum speed 21.1 Mbit/s
  * HSDPA maximum speed 14.4 Mbit/s
  * Automatic installation
  * MicroSD memory card slot (up to 32 GB)
  * CRC9 connector for external antenna
  * Modem is connected directly to the computer's USB port
  * Mini-SIM card, i.e. a normal-sized SIM card

### Package contents:

DNA Modem E3531, USB extension cable, quick start guide.

### System requirements / Supported operating systems:

  * Supported operating systems Windows XP SP2/SP3, Vista SP1/SP2, Windows 7, Windows 8 / 8.1, MAC 10.5
