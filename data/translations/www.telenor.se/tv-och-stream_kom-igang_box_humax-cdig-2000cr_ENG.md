#  Humax CDIG-2000C/R – recordable TV box

Great with TV! Here you will find everything you need to get started with your
recordable TV box.

###

Connect the devices

  1. Connect the antenna cable. It should be in the outlet on the TV box labeled RF in.
  2. Connect the box to your TV with the HDMI cable.
  3. Insert the program card into the card reader. The chip on the card should be facing downwards.
  4. Turn on the TV.
  5. Connect the power cable between the wall outlet and the TV box.
  6. Turn on the Power button on the TV box. If the box starts in standby mode, a light will illuminate in red on the front. Then press the red button on the remote control labeled Power.
  7. If it is the first time you are using the TV box, the installation guide will start automatically. It will help you make all the basic settings. When all steps are complete, you can start using your box. You can always change your choices later under Settings.

**First time the TV box starts**  
First check that you have the correct source set on your TV. You do this by
selecting the button on your remote control labeled Source, Input or AV.
The button may also be marked with an arrow. Then select the HDMI input to which the box
is connected. To find the correct input, you can follow the HDMI cable from the TV-
box to the TV. If the cable is, for example, connected to outlet 1, you should select
HDMI 1 on your TV.

**The guide starts as soon as you have selected the correct source on the TV:**

  1. Language: Select language.
  2. Screen: Select the settings that best suit your TV.
  3. Search for channels: The channel search starts automatically. Save found channels when the search is complete by pressing Ok.
  4. Select start mode: Select On if you want standby mode. Use the right arrow to switch between On and Off.
  5. Result: Now the result is displayed. Close the guide by selecting Finish.

If you terminate the channel search prematurely, you may not be able to see all
channels. Go to Menu – Settings – Installation and search for more
channels.

The default password is 0000.

**Not working?  
** Go through the following steps:

  1. Check that the cables are in the correct outlets and that they are firmly plugged in.
  2. Also check that you have selected the correct HDMI source (source) with the remote control.
  3. Try restarting the TV box.
  4. If you still can't get it to work, read more on our troubleshooting pages.

About factory reset

You can choose to do a factory reset of your TV box. Choose between factory resetting your user configuration or emptying the entire hard drive. When you are finished, the installation guide will appear automatically.

Remember: A factory reset will lose all saved data. Including
any recordings and media that you have saved on the hard drive.

Edit channels

Do you want to set up your favorite channels? Start by going to
Channel Settings:

  1. Press the Home button on the remote control.
  2. Select Settings, and then Channel Settings.
  3. Enter the TV box's PIN code to open the menu. The default PIN code is 0000.

Now you can add and remove channels and create your own favorites list.

Change PIN code

You change the TV box's PIN code/password by first pressing the Home button on
the remote control. Go to Settings and then General Settings.

Note: Your default password is 0000. If you have changed your password, and then
forgotten it, [contact us](/link/0c492f5608894771aeabe6efb2d6d096.aspx).

Record movies and TV programs

If you have a Humax CDIG-2000C/R, you can record movies and series and save
them on the TV box.

**Record directly**  
Press Record to record the program you are watching. Press Stop when
you want to finish.

**Extend recording time**

  1. Press the Record button while the channel is being recorded.
  2. Now you can set the recording time manually. Or you can choose to have the box automatically record until the end of the movie or program. 

Note: If the program ends within ten minutes, the next program will also be
recorded. If program information is missing, the recording will continue for two hours.

**Schedule recording via TV guide  
** Press the Home button and select TV guide. Select an upcoming program and
press the Record button.

**Schedule recording via program information**

  1. Record via Quick Guide. You get it up when you press Ok while watching a program. Then press the arrow button to the right to browse upcoming programs.
  2. Select a program in the list on the left and press Ok.
  3. Select a recording option.

**Schedule via recordings**

You can schedule recordings or reminders manually. Here's how:

  1. Press Home. Select Recordings – Scheduling – New scheduling.
  2. Set a new schedule manually. Press Ok.

**Change schedule**

  1. Press the Home button. Select Recordings – Scheduling.
  2. Select program and press the Plus button.
  3. Now you can choose either Delete or Change.

Tip: If you want to be sure not to miss the end of the movie or
program – set a time buffer. Go to Home – Settings – PVR-
Settings – Recording Options – Extend playtime.
