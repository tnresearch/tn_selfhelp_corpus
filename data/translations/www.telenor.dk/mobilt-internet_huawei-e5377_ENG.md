# How to Set Up Your Modem

See the guide below for setting up your modem. If you have already tried to
install the modem without success, we recommend that you start by uninstalling
it.

  * ## Find Your Router on the List of Wireless Networks

  * ## Enter the Provided Network Key

Find the network key in your welcome letter from us.

  * ## Automatic Connection

Now you need to choose whether you want to automatically connect to the
network in the future.

  * ## Enter PIN Code and Choose New PIN

The first time you start the program, you must enter your PIN code. Afterwards
you must choose a personal 4-digit PIN.
