# Skapa surfschema

För att skapa ditt första schema ska du klicka på profiler i menyn och sedan
klicka in på scheman.

Klicka på skapa schema.

Namnge schemat och bestäm mellan vilka tider och dagar som det ska gälla.
Klicka sedan på bocken upp i högra hörnet för att bekräfta dina val.

Ett exempel: Här är ett schema för läxläsning och det gäller mellan
18:00-19:00 på måndagar och onsdagar.

Ett schema är aktivt när det ser ut som på bilden nedan. Vill du skapa mer än
ett schema för en profil ska du klicka på plusteckent upp i högra hörnet.
