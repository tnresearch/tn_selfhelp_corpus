## Getting Started

## Installing the Modem

The DNA Home Modem 4G WLAN B315 uses a standard Mini-SIM card.
Insert the SIM card into the back of the modem. To remove the SIM card from
inside the modem, first slide off the protective cover and then carefully pull
the SIM card out.

  
  
If the SIM card has a PIN code of 1234, the modem will automatically connect
to the internet. If you have a different PIN code, you will need to enter it
through the modem's management page. You can find more instructions [here](/dna-
kotimokkula-4g-wlan-b315#asetukset).

Registering to the DNA network takes a few minutes. If the connection fails,
call DNA's
[customer service](https://www.dna.fi/yhteystiedot#asiakaspalvelu).

The internet connection is available when the power light and network status
indicator (in a color other than red) are lit on the modem. If the modem has
a display, you will see an icon indicating the signal strength on the display.  

## Enabling Wireless Network (WiFi)

DNA modems are encrypted for wireless network security. You can find the
network name and password on the sticker on the bottom of the home modem or
on the modem's management page.  
  
WiFi network name: SSID  
  
WiFi network password: WPA/WPA2

  

Windows 10

On a Windows 10 computer, click the WLAN network availability bars in the
bottom right corner of Windows.  
Then select the network with the name on the sticker (SSID). Check the box
"Connect automatically" and press "Connect".

Next, the computer will ask for the wireless network password. The password
can be found on the sticker (Password). Enter the password exactly as it
appears on the sticker and press Next. Now you can start using the internet.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then
select Settings (gear icon). Next, select the availability bars.

Then select the network with the name on the sticker (SSID). Check the box
"Connect automatically" and press "Connect".  
Next, the computer will ask for the wireless network password. You can find it
on the sticker on the back of the modem (Password). Enter the password
exactly as it is and press Next.

If you want to share files between devices, select the lower option
("Yes, enable sharing"). If you do not want to share files between devices,
select the upper option ("No, do not enable sharing").  
  

Windows 7 / Vista

On a Windows 7 and Vista computer, click the WLAN network availability bars in
the bottom right corner of Windows. Then select the network with the name on
the sticker (SSID).  
  

Check the box "Connect automatically" and press "Connect".  
Next, the computer will ask for the wireless network password. You can find
the password on the sticker on the back (Password). Enter the password
exactly as it is and press OK.  

You can start using the internet.

Mac OSX

Click the WLAN network icon at the top of the screen with the mouse. Then
select the network with the name on the sticker on the back of the modem
(SSID).

Next, the computer will ask for the wireless network password. The password
can be found on the sticker. Enter the password exactly as it is on the
sticker on the back. Click **"Remember this network"** and press **Join**.  
  
You can start using the internet.

Apple iPad

From the iPad home screen, select Settings. From settings, select Wi-Fi
(WLAN in older models).  
  
Wait a moment while the iPad searches for networks. Then select the network
with the name on the sticker on the back of the home modem (SSID). Next, the
iPad will ask for the wireless network password. You can also find the
password on the sticker on the back of the modem.  
  
Press **Join**. You can start using the internet.

Android Tablet

Go to the view where you see all the apps.  
  
Select **Settings** and from the menu select **Wi-Fi** (Wireless and networks
in older versions). Wait a moment while the tablet searches for networks.
Then select the network with the name on the sticker on the back of the home
modem (SSID). Next, the tablet will ask for the wireless network password.
Then select the password with the name on the sticker on the back of the
home modem.  
  
Press **Connect** and you can start using the internet.

## PIN Code

If the SIM card has a PIN code other than 1234, you must enter the PIN code
in the modem settings.

  1. Open a web browser when you are connected to the modem's WLAN network. 
  2. Type http://dna.mokkula or http://192.168.1.1 in the address bar. 
  3. The default username is **admin** and the default password is **1234**.
  4. Select **Settings** at the top and PIN code management from the menu
    below.
  5. Select **Security** on the left.
  6. Enter the desired PIN code in the **Enter PIN** field and press
    **Apply**.
