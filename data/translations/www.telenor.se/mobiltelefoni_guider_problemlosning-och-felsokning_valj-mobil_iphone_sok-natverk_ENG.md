# Search network

The network is selected automatically. But if you are experiencing problems, you can try connecting manually instead.

This guide shows you how to do it in the **latest operating system (iOS)** from Apple. So please start by making sure it is installed on your mobile – not least so that it works as well and securely as possible.

[How to update the operating system](/support/mobiltelefoni/guider/sakerhet/valj-mobil/iphone/uppdatera-operativsystemet/)

Now you have the latest iOS installed, right? Then let's go!

  * ### Go to the home screen

  * ### Select "Settings"

  * ### Select "Mobile network"

  * ### Select "Network selection"

  * ### Turn off "Automatic"

  * ### Select "Telenor SE" from the list that appears
