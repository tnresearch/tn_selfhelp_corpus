# Cannot Surf Wirelessly

Can't reach your wifi network? Read through the tips below.

  * ### Turn off the router

Start by turning off the router and computer for about 30 seconds. Also turn
off the fiber converter if you have one.

  * ### Restart all equipment

Check that the lights on the router are lit as they should be. If you have a Technicolor
799 Xtream, the eco light should glow green. If you have a Telenor wifi-
router i4882, the bottom and top lights should glow green.

More information about which lights should be lit can be found in your router's
instructions.

[Installation guides for routers](/support/fast-bredband/installationsguider/)

Are you using a wifi extender? Restart that too. [Read about the different colors
on the wifi extender's light](/support/vanliga-fragor/wifi/vad-betyder-
fargerna-pa-wifi-forstarkarens-lampa/)

  * ### Check the signal strength

If you are having connection problems, the signal strength may be too
weak.

[More on how to optimize your wifi](/support/fast-
bredband/wifi/felsokning/problem-med-hastigheten/)

  * ### Have you chosen the right network?

On the underside of the router you will find the name of the wireless network, SSID,
and which security key, Wireless Key or WPA, you should use. If you
have a Telenor Router i4882, only the name of the wireless network and
the password are displayed.

Do you have the Technicolor 799 router and have performed a factory reset?  
  
[Here's how to reconnect to your wifi](/support/fast-
bredband/wifi/felsokning/problem-att-ansluta-till-wifi-via-routern-
technicolor-799/)

  * ### Network settings

Check that wireless network is enabled in the settings on your computer,
tablet or mobile.

[Connect to wifi via macOS](/support/fast-bredband/wifi/kom-igang/anslut-
till-wifi-via-macos/)  
[Connect to wifi via Windows 10](/support/fast-bredband/wifi/kom-
igang/anslut-till-wifi-via-windows-10/)  
[Connect to wifi via iOS](/support/fast-bredband/wifi/kom-igang/anslut-till-
wifi-via-iphone-och-ipad/)  
[Connect to wifi via Android](/support/fast-bredband/wifi/kom-igang/anslut-
till-wifi-via-android/)

  * ### Update the drivers

Make sure you have the latest drivers for the network card in your
computer.  
  
The computer's operating system often has a function that helps you search for
new drivers.  
  
You can also get help from the manufacturer of your network card or your computer.

  * ### Disconnect the router

If possible, you can test connecting the network cable directly to the computer,
bypassing the router. This is to rule out that the problem is with the router.

  * ### Test with another device

Try surfing with another computer, mobile or tablet. Then you will know if the error
only applies to your computer or not.
