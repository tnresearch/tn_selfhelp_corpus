## Updates

#### MC7010 has received an update starting from week 17/2024

**Update content:**

  * the default setting for network selection changes to 5G NSA
  * security fixes from the device manufacturer
  * other minor bug fixes
  * new software version: MC7010_DNA5_B16

#### Older updates

#### MC7010 has received an update starting from 19.6.2023

  * The update includes several fixes improving the device's functionality from the device manufacturer.
  * New software version: MC7010_DNA5_B14

#### **22.11.2022**

  * The update includes several fixes improving the device's functionality from the device manufacturer.
  * New software version: MC7010_DNA4_B12

**21.3.2022**

  * the update includes security and bug fixes from the device manufacturer
  * after the update, frequency locking is possible in the 5G NSA network from the web interface, either on the 700 MHz (n28) or 3500 MHz (n78) frequency band
  * New software version: MC7010_DNA3_B09

**4.9.2021**

  * The update includes fixes to improve usability and functionality, as well as to the device's management pages and functionality.
  * NOTE: The APN profile will be reset to the default setting during the update, so if you have changed the APN settings on the device's management pages, you must make the changes again.
  * New software version: DNA_FI_MC7010V1.0.0B07
