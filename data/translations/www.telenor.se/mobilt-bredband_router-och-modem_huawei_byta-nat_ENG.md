# Switch Network

Often, it can be faster if you switch networks. Try it!

  * ### Log in to the router's interface

You do this by entering the address 192.168.8.1 in a web browser and then
filling in your wifi password.

  * ### Follow the quick setup or go to Network Settings

If you have never logged in to the router's interface before, you should follow
the quick setup. Otherwise, go directly to Network Settings.

  * ### Select Mobile Network Search

  * ### Find the network you want to switch to under Preferred Mode

  * ### Click Save
