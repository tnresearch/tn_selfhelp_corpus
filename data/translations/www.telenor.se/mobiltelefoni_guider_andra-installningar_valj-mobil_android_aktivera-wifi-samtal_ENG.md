# Enable Wi-Fi calling

## Samsung, Sony and Xiaomi

  
By enabling Wi-Fi calling, you can make calls over the Wi-Fi network.

[More about Wi-Fi calling](/support/mobiltelefoni/abonnemang/fler-tjanster/wifi-
samtal/)

This guide shows you how to do it in the **latest version of the Android
operating system.** So, please start by making sure it is installed on your
mobile – not least to ensure it works as well and securely as possible.  
  
[How to update the
operating system](/support/mobiltelefoni/guider/sakerhet/valj-
mobil/android/uppdatera-operativsystem/)  
  
Now you have the latest version installed, right? Then let's go!

  * ### Go to the home screen and swipe up to open the menu

  * ### Select "Settings"

  * ### Search for and select "Wi-Fi calling"

  * ### Choose to enable Wi-Fi calling
