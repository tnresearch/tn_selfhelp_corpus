## Getting started

## Installing the modem

Open the back cover, remove the battery and place the SIM card under the battery. Put the battery
back in place and close the cover.

Place the Travel Modem as close to the window as possible. The closer the Travel Modem is to the window,
the better the connection speed the Travel Modem usually gets. If the
apartment is new, we recommend an external antenna installed outside the window. For more information about antennas, please contact DNA Store or DNA Customer Service.

Registering to the DNA network takes a few minutes. If the connection
fails to open, call DNA's
[customer service](https://www.dna.fi/yhteystiedot#asiakaspalvelu).

The internet connection is available when the power light and the network status
indicator light (in a color other than red) are on in the modem. If the modem has a display,
you will see an icon indicating the signal on the display.

## Enabling the wireless network, i.e. Wi-Fi

DNA modems are encrypted in terms of wireless network. You can find the network name and
password on the modem's display.

SSID (network name)

PWD (password)

Windows 10

Click the WLAN network availability bars in the lower right corner of Windows 10. Then select the network named **DNA-Modem-
XXXXXX**. You can find the exact network name (SSID) on the modem's label. The X letters
are unique to each subscription.  
  
Check the box next to **Connect / Connect**.  
  
Next, the computer will ask for the security key for the wireless network. See
the security key on the sticker under the back cover of the modem.  
  
Enter the security key exactly as it is on the label and press **OK**.  
  
You can start using the internet.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select
**Settings** (gear icon). Next, select the availability bars.  
  
Then select the network named **modem_xxxxxxx_2.4Ghz**. You can find
the exact network name (SSID) on the modem's display. The X letters are unique
to each subscription.  
Check the box next to **Connect automatically / Connect automatically** and
press **Connect / Connect**.  
  
Next, the computer will ask for the security key for the wireless network. See
the security key on the sticker under the back cover of the modem.  
  
Enter the security key exactly as it is on the label and press **Next**.  
  
Note! The speed of the wireless network improves at 5 Ghz frequency if there is
a lot of other networks in the environment. In this case, select modem_xxxxxx_5G to achieve a faster connection. However,
the network coverage may decrease compared to the 2.4 Ghz network.

Windows 7 / Vista

Click the WLAN network availability bars in the lower right corner of Windows 7 and Vista. Then select the network named
**modem_xxxxxx_2.4Ghz**. You can find the exact network name (SSID) on the modem's
display. The X letters are unique to each subscription.  
  
Check the box next to **Connect / Connect**.  
  
Next, the computer will ask for the security key for the wireless network. See
the security key (PWD) on the modem's display. Enter the security key exactly the same way and press **OK**.  
  
You can start using the internet.

Mac OSX

Click the WLAN network icon at the top of the screen with the mouse. Then select the network named **modem_xxxxxx_2.4Ghz**. You can find the exact network name
(SSID) on the modem's display. The X letters are unique to each
subscription.  
  
Next, the computer will ask for the security key for the wireless network. See
the security key on the travel modem's display. Enter the security key exactly the same way and press **OK**.  
  
You can start using the internet.

Apple iPad

Select Settings from the iPad home screen. Select Wi-Fi (WLAN in older models) from settings.  
  
Wait a moment while the iPad searches for networks. Then select the network named **modem_xxxxxx_2.4Ghz**. You can find the exact network name (SSID) on the modem's
display. The X letters are unique to each subscription.  
  
Next, the iPad will ask for the wireless network password. See the password on the modem's
display. Enter the password exactly the same way and press **Join**.
You can start using the internet.

Android Tablet

**Go to the view where you see all the apps.**  
  
Select **Settings** and select **Wi-Fi** (Wireless & networks in older versions) from the menu. Wait a moment while the tablet searches for networks. Then select the network named **modem_xxxxxx_2.4Ghz**. You can find the exact network name
(SSID) on the modem's display. The X letters are unique to each
subscription.  
  
Next, the tablet will ask for the wireless network password. You can find the exact
network name (SSID) on the modem's display. The X letters are unique to each
subscription.

Using a USB cable

  1. Connect the modem to the computer with a USB cable.
  2. Turn on the modem. The computer's operating system will detect and recognize a new device and install the software automatically.   
Note! If the system does not recognize the device and start the installation
automatically, install the software by double-clicking the installation icon on the **My Computer** window.

  3. Wait until the computer is connected to the modem.

#### USB cable

We recommend using the modem over a WLAN network. However, you can also use the modem via a USB connection. You can use both the WLAN connection and the USB cable
at the same time.  
  
Using the USB connection is done by connecting the USB cable to the computer and
installing the connection software according to the instructions on the computer screen.
Once the connection software is installed, the internet connection will work automatically.  
  
USB connection is supported in Windows XP and Mac 10.5 or newer
operating systems. Make sure you have the latest version of these
operating systems on your computer.
