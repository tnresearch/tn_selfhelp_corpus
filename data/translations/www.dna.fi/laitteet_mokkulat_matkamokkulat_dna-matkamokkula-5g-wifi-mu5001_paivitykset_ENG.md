### Updates

#### MU5001 has received an update starting from week 13/2024

**Update content:**

  * The default network selection setting changes to 5G NSA
  * Security fixes from the device manufacturer
  * New software version: DNAFI_MU5001V1.0.0B07

#### Previous updates

#### MU5001 has received an update starting from 1.12.2022

  * With the update, the default language of the device's touchscreen changes to Finnish, instead of the current English. The update also includes bug fixes made by the device manufacturer.
  * New software version: DNA_FIMU5001V1.0.0B05
