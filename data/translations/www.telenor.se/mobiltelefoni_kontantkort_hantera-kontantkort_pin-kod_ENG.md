# PIN and PUK Code

Do you want to change your PIN or are you looking for your PUK code? Here we will guide you in the right direction.

## PIN Code

The PIN code is the code that protects the SIM card itself from other people accessing your mobile phone and using your subscription or prepaid card. If you move the SIM card to another phone, the same PIN code applies.

###

Find the PIN code

You can find the PIN code in the same letter that the SIM card was sent in.

Forgotten PIN code

Follow these steps if you have forgotten your PIN code:

  1. Find your eight-digit PUK code. (Read below on where to find it).
  2. Enter the wrong PIN code three times.
  3. Enter your PUK code.
  4. Create a new PIN code.

If you cannot unlock the SIM card using the PIN code or PUK code, or you see a warning message saying "PUK expired", you need to [order a new SIM card](/link/b3aaf0096b26492daf6e45809589e191.aspx).

Change PIN code

**Directly via the keypad on the phone**  
**04*old PIN code*new PIN code*new PIN code#**  
**

**Android phone**  
To change the SIM card PIN on an Android mobile, go to the following on your phone: Settings > Lock screen and Security > Set SIM card lock.  

 **iPhone**  
If you have a phone with iOS as the operating system (iPhone), go to the following: Settings > Phone > SIM PIN > Change PIN.

##  
PUK Code

The PUK code is an eight-digit code that you use when you have entered an incorrect PIN code three times. You with a mobile subscription can find it by logging in to My Telenor – either [on the web](/mitt-telenor/) or in [our app](/archive/2019/mitt-telenor-old/). Do you have a prepaid card? [Contact us](/support/old-kontakta-oss/) and we will help you.
