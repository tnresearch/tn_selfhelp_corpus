# Operator Lock

If your mobile phone is operator locked, it will not be possible to use SIM cards
from another operator until it is unlocked. Most mobile phones are not
operator locked.

### Is my mobile phone operator locked?

 **Mobile phones sold by Telenor after January 2015 do not have an operator lock and therefore do not need
an operator unlock code.**

If you have an older mobile phone that is locked to Telenor, you will receive an error message when you
insert a SIM card from another operator.

The error message you receive depends on the type of mobile phone you have.

Error messages with an operator locked mobile phone

  * Enter restriction code

  * Insert correct SIM card

  * Invalid SIM

  * Enter network code

  * Enter special code

## Retrieve the Operator Unlock Code

To retrieve an operator unlock code, you need the IMEI number of the mobile phone or
mobile device that is locked.

The IMEI number may be included with the packaging or documentation from when you
purchased the mobile phone, but it can also be retrieved directly from the mobile phone as follows:

  1. Open the keypad on the mobile phone as if you are going to dial a number

  2. Enter *#06#  

Then contact us at Customer Service, and we will help you further.

[Go to Contact Us](/kundeservice/kontakt-oss/)

SIM cards from Telenor until you have unlocked the mobile phone.

You get the operator unlock code by contacting the operator you purchased the
mobile phone from. This is important to do in advance if you move
your subscription to Telenor, or want to create a new subscription without
