#  Skaffa nytt simkort

Vill du skaffa ett nytt simkort till ditt kontantkortsnummer? Så här gör du.

Du kan skaffa ett nytt simkort till ditt kontantkortsnummer genom att
[kontakta vår kundservice](/archive/2020/kontakta-oss-old-old/).

Du måste först ha registrerat ditt kontantkort för att kunna få ett nytt
simkort till ditt nummer.

Kontantkort köpta via Telenor.se är automatiskt registrerade.

[Här kan du registrera ditt
kontantkort](/support/mobiltelefoni/kontantkort/hantera-
kontantkort/registrera-kontantkort/)
