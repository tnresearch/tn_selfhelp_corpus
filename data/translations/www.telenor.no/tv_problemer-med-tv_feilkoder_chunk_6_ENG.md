#### E0313 Duplicate Recording

This error code appears if you have already recorded the same program.
Select Menu/MENU with the remote control, and go to My Recordings to check that
the program you recorded is available.

?

#### E0314 - E0317 Low Disk Space Warning

This error code warns that you have limited storage space available on the hard drive.
If you receive the message when trying to start or during a recording, it means
there is insufficient storage space to start or complete the recording.

The solution is to delete recordings to free up space:

  1. Select Menu/MENU on the remote control
  2. Select My Recordings
  3. Find the recording you want to delete, and press OK
  4. Select Delete Recording

?

#### E031A, E0342 Hard Drive Not Available

This error code is caused by the fact that you do not have a hard drive connected to the set-top box. The T-We Box II
is available both with and without a hard drive. You can order [a set-top box with
a hard drive on My Pages](https://www.telenor.no/minesider/) or by
contacting customer service.

It is not possible to use a hard drive other than the one integrated into
the set-top box.

?

#### E031B Recording Limit

You have saved 1000 recordings on your set-top box, and cannot record any more programs.
To resolve the problem, you can delete recordings you no longer need.

  1. Select Menu/MENU on the remote control
  2. Select My Recordings
  3. Find the recording you want to delete, and press OK
  4. Select Delete Recording

?

#### E0320 Pause Mode

This error code appears if you have a T-We Box II without a recorder. It is not
possible to pause the program for more than 15 minutes without a hard drive.

You can order [a set-top box with a hard drive on My
Pages](https://www.telenor.no/minesider/) or by contacting customer service.

?

#### E0360 Recording in Progress

You cannot start recording this program because a recording is already in progress
on the same channel and program.

?

#### E0361 Conflict Resolution

You cannot record multiple programs simultaneously until you have stopped another one.

On the T-We Box and T-We Box II, the limit on the number of simultaneous recordings is 3.

#### E2305, E2306, E2307, E2308 Failed to Start/Remove Recording

With this error code, the set-top box must be restarted.

Unplug the power to the equipment, and wait 10 seconds before plugging it back in.

Also, check that all cables are properly connected.

If the error persists, note down as much information as possible about what you
were doing when the error occurred. Examples of information you can note are: title,
time, date, episode, channel, etc.

Contact Customer Service with the information. This makes it easier to find a
solution to the problem. [See opening hours and
contact information.](/kundeservice/kontakt-oss/)

#### E2312 Loading Content...

With this error code, the T-We Box, modem/fiber box and router must be restarted.

 **How to restart the equipment**

  1. Unplug the power cord, or use the ON/OFF switch.

  2. Leave the power off for about 10 seconds

  3. Plug in the power

It may take a couple of minutes for the internet and TV to work again after a
restart.

Also, check that all cables are connected correctly and are secure. If you
need help with cabling, you can find it here [Connect to
T-We](/kundeservice/tv/dekodere-og-fjernkontroller/t-we-boks-ii/koble-til/)

The error may also be due to problems with your cable or misconfigured equipment
(e.g. using a router not supplied by Telenor).  
Go to **[Problems with Cables or 3rd Party Equipment](/kundeservice/tv/kabler-
og-nettverksutstyr/)** for further troubleshooting.
