## Features

### DNA Travel Modem 4G+ WLAN E5787s

Product name: Huawei E5787  

DNA Travel Modem 4G+ WLAN E5787s is a powerful 4G modem,  
with which you can create a fast internet connection wherever you are.  
With the compact travel modem, you can create a wireless network using either 4G or
3G speed  
for multiple devices.

  * 4G LTE maximum speed from the network 300 Mbit/s
  * 3G DC maximum speed 42 Mbit/s 
  * HSPA+ maximum speed 21.1 Mbit/s
  * WLAN b/g/n/ac Dual-Band
  * USB
  * 16 WLAN devices 
  * Two connections for external antennas, connection type TS9
  * Micro-SIM card

### Package contents:

DNA Travel Modem 4G+ WLAN E5787, power supply, quick guide, UBS cable, battery.

### Hardware requirements / Supported operating systems:

  * WLAN: 802.11b/g/n/ac
  * USB2/3 port
  * Supported operating systems: Windows XP SP2/SP3, Vista SP1/SP2, Windows 7, Windows 8 / 8.1, Windows 10, MAC 10.5-10.11
  * Internet browser for management: Microsoft Internet Explorer 6.0 or later, Firefox 2.0 or later, Safari 4.0 or later, Opera 10.0 or later, Chrome 5.0 or later
