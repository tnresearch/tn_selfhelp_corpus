## Troubleshooting

What should I do if my modem's battery is swollen?

If your modem's battery is swollen even slightly, stop using it immediately.
Take the modem to a DNA Store. Swelling can be noticed directly by the
battery bulging or, for example, the back cover moving. With current battery
technology, a similar risk of swelling exists for every battery-powered
device. The risk increases if the use is truly intensive, the modem is in a
place where its temperature rises critically, or changes have been made to it
that are not mentioned in the manual.

I am using the modem with a SIM card that asks for a PIN code

You can enter the PIN code through the modem's management page (http://dna.mokkula),
using the default password 12345 and entering the PIN code. The default PIN
code for DNA SIM cards is 1234.

The modem's connection is intermittent or slow

Modems work most efficiently on a wireless 3G network. If your connection is
slow or intermittent, it is worth moving the modem closer to the window. If this
doesn't help, check the [coverage and coverage map](https://www.dna.fi/kuuluvuus-
ja-peittoalueet) on the DNA website or contact DNA Customer Service.
Customer service will advise you from which direction the base station transmits
and to which window you should move. In particularly difficult situations, we
recommend purchasing an additional antenna.

The computer reports "Limited connectivity from the computer"

The modem is not connected to the internet. Check your internet connection and
restart the modem if necessary.

If you are using Windows 8, connect the modem to the computer with a USB cable
and install the USB driver. The driver installation usually starts
automatically. After this, you can use the modem with a USB cable.

Then download all updates to Windows. If the problem still does not resolve,
download all WiFi device updates from the computer manufacturer's website.

The modem reports that it is connected to the internet, but the connection does
not work on the computer

Make sure you have connected the computer to the WiFi network created by the
DNA Modem 4G LTE Sierra. You can see the name of the WiFi network on the
modem's display.
