## Software Updates

  
Updates for cable modems are delivered automatically over the network. Updates
are run on the modems at night, causing the least amount of disruption. In
some rare cases, the modem may require a reset and restart in the morning
after an update, to ensure optimal device performance.

Please note that updates are rolled out gradually.

#### New version FAST3890V3_DNA_sw18.76.15.17e-16 released on 3.9.2024.

Security updates (port 8082 is closed)

#### Older updates:

**FAST3890V3_DNA_sw18.76.15.17e-14 released on 4.3.2024**

  * Security fixes
  * DHCPv6 server and IPv6 disabling enabled
  * Maximum number of WiFi clients increased from 32->64
  * Other general improvements

**FAST3890V3_DNA_sw18.76.15.17e-10 released on 27.9.2023**

  * Security improvements
  * Other general improvements

**FAST3890V3_DNA_sw18.76.15.17e-9 released on 4.7.2023**

  * Fix for port forwarding
  * Other general improvements

**FAST3890V3_DNA_sw18.76.15.17e-8, released on 6.6.2023**

  * Management page timeout changed from 5min -> 8h
  * Access to the management page in bridge mode
  * Language corrections
  * Other general improvements

**FAST3890V3_DNA_sw18.76.10.15j-14 released on 16.8.2022**

  * UPnP fix
  * Other general improvements

**FAST3890V3_DNA_sw18.76.10.15j-11 released on 5.4.2022**

  * Compatibility with the upcoming mesh extender F-266
  * DNA Mesh WiFi menus on the management page
  * Improvements to band steering features
  * Other general improvements

**DNA sw05.76.9.8u released on 21.1.2021**

  * Netpulse updates and activation
