## Adding New Devices

Setting up for yourself on multiple devices

You can install DNA Digiturva on as many devices as you have available licenses. You can install DNA Digiturva on a mobile device by downloading it directly from the app store or by sending a download link via DNA Digiturva.

#### Installing DNA Digiturva on another device via the DNA Digiturva app

1. Open DNA Digiturva and select the **People and Devices** section.

2. Press **Add Device**.

3. Select **My Device** and press **Continue**.

4. Choose whether to send the download link via email or text message. Enter the email address/number to which you want to send the installation link and press **Send Link**.

5. Open the sent message on the device where you want to install DNA Digiturva and press **Install DNA Digiturva app**.

6. Press **Install from here**.

  * On a mobile device, select the app store you want to use to install DNA Digiturva: Google Play Store/App Store.

7. Press **Install**, and when the installation is complete, press **Open**.

8. Log in with a one-time password by pressing **Log In**.

9. Enter the email address you used during the subscription and press **Request Password**.

10. You will receive a one-time password to the email address you entered. Enter the code from the message in the **One-Time Password** field and press **Log In**.

11. DNA Digiturva will request permission to allow notifications, press **Allow**. Your device may verify whether to allow DNA Digiturva to send notifications. Also, select **Allow** in this section.

12. The installation is complete. Next, you need to complete the configuration so that DNA Digiturva can protect the new device as comprehensively as possible.

Sharing DNA Digiturva with another person's device

You can protect the devices of the whole family with DNA Digiturva. You can find instructions for creating a child profile and installing the app in the following section.

You can protect another adult's device in the same way as your own. However, please note that the other adult will then see the same things as you do and be able to modify them, such as:

  * Monitored items and data breach monitoring under personal data monitoring
  * Protected devices and available licenses, as well as your own profile information
  * Child profiles and their settings

You can create separate password vaults for different users, but please note that we recommend that the same password vault be synchronized on at least two different devices.

Therefore, install DNA Digiturva only on the device of another adult you trust. Installing DNA Digiturva on another trusted adult works the same way as adding a new device for yourself. See detailed instructions in the **Setting up for yourself on multiple devices** section.

Creating a child profile and installing the app

You can create a new child profile while installing the app on the child's device and set family rules during installation. See below for instructions on installing DNA Digiturva on a child's device based on the device's operating system.

Purchasing new licenses

DNA Digiturva is available in three different packages.

  * up to **2** devices
  * up to **10** devices
  * up to **25** devices

The smallest license package is sufficient for the needs of one person if a phone and a computer are used. However, if there are multiple people or devices in the household, it is worth switching to a larger DNA Digiturva license package. One license corresponds to one device. For example, if you have a phone, tablet, and computer, and you also want to protect your spouse's phone, you will need 4 licenses. Therefore, the up to 10 devices license is suitable.

If you want to upgrade to a larger license package, please contact our [customer service](https://www.dna.fi/tuki/yhteystiedot/asiakaspalvelu).
