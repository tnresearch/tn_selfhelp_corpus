# Guest Network

Here you will find information on how to set up a guest network on the Huawei B818 router
for Wireless Broadband or Mobile Broadband.

## Log in to the Router

  1. Check that you are connected to your home network

  2. Open a browser and enter http://192.168.1.1 in the address bar, and press enter.

  3. Enter your password

  4. The password is the same as your original wireless password. You can find it on the sticker on the back of the router after **WIFI**.   
**Note:** If you have changed the password to the menu yourself, enter the one you
have chosen.

## Set up Guest Network

  1. Press on WiFi settings

  2. Select Guest WiFi

  3. Press the switch to the right of Guest WiFi

  4. You can now enter the desired name and password for the new network, as well as choose the desired duration (before it turns off automatically)

  5. Press Save
