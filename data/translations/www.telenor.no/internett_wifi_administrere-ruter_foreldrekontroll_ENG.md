# Parental Control

Here you will find information on how to set up parental control rules
in your WiFi router.

## How to do it

There are several ways you can set up rules. You can set up your own rules
for an entire network, so that everyone who uses it will follow the rules that are
set. You can also [create one or more extra wireless
networks](/kundeservice/internett/wifi/administrere-ruter/gjestenett/), for
example, a separate network that only the children should use.

You can also set up your own rules for just one computer and/or a
mobile phone if you want to have separate rules for the youngest in the family.

### Create a rule for a wireless network

This procedure is best if you have, for example, set up a separate
wireless network for your children, and want this to be turned off at specific
times.

  1. Go to <https://wifi.telenor.no> and log in

  2. Click your way to _Parental Control_

  3. Click on +Create new schedule

  4. Enter a name for the rule, for example "youth"

  5. In the schedule, mark the time period you want the wireless network to be available. The time period you choose will be highlighted in green.

    * Tip: You can press and drag the mouse pointer over the desired area to mark multiple hours/days at the same time

  6. Press _Choose members_

  7. On the network for which the rule should apply, select the rule you created below in the drop-down menu under schedule (far right)

  8. Then press _Save rule._ You have now created Parental Control.

### Create a rule for devices

This can be used if, for example, you want the youngest child in the house to
have their own rules on a mobile phone or computer.

  1. Go to <https://wifi.telenor.no> and log in

  2. Click your way to _Parental Control_

  3. Click on +Create new schedule

  4. Enter a name for the rule, for example "youth"

  5. In the schedule, mark the time period you want the wireless network to be available

  6. Press _Choose members_ and scroll down to _Connected devices_

  7. In the drop-down menu far to the right, select the schedule for the devices (the list shows mobiles, PCs and other equipment that has been connected) that should be a member

  8. Then press _Save._ You have now created Parental Control.

 **NOTE:**  
The schedule is linked to the device's MAC address. Some devices may change their MAC-
address, for example when switching from wired to wireless network, or
to another wireless network. You should therefore check if the device in question
appears multiple times in the list and that all variants have been added as members to
the rule/schedule you have created.
