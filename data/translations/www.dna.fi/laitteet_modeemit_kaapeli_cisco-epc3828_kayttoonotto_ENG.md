## Getting Started

## Modem Installation

Connect the modem as shown in the picture. The white antenna cable is connected to the antenna socket. A splitter is used if the antenna socket does not have its own data socket and you want to use cable television or a set-top box at the same time. Finally, connect the power cable to the modem and the wall, and turn on the power from the modem's main power switch. A computer or other device can be connected to the modem wirelessly or with an Ethernet cable.

  

  
Registration to the DNA cable network usually takes about 10 minutes, maximum 2 hours. If the connection fails to open, call DNA's [customer service](https://www.dna.fi/asiakaspalvelu). The connection is available when the modem lights (1. Power, 2. DS, 3. US and 4. Online) are lit continuously. Now you can start using the internet.  

## Enabling Wireless Network (WiFi)

You can find the WiFi factory settings of the modems on the sticker on the bottom of the modem.  
  

**SSID (network name): number from the SSID box**

**Password: number series from the PRE-SHARED KEY section**

DNA broadband modems are pre-encrypted in terms of wireless WiFi network. You can find the name and password of the wireless network on the bottom or back of the device, or in some cases on the device packaging. If the modem is reset, these original settings will be restored. Find the wireless WiFi network according to the instructions, using the wireless network search function of your computer or other terminal. If the network is not found, make sure that the computer's wireless connection is turned on. Enter the WiFi network password into the terminal (you can find the correct password on the bottom, back or packaging).

Windows 10

**Here's how to enable a wireless network connection (WiFi) in Windows 10:**

  1. Press the WiFi icon in the lower right corner of the Windows desktop, near the clock.  
  

  2. Then select the network whose name is on the sticker on the back of the modem (SSID). Check the box "Connect automatically" and press Connect.  
  
  

  3. Enter the WiFi password (security key, SSID) in the open field. You can find the WiFi password on the sticker on the modem. Accept the connection by pressing next.  
  
  
If you want to share files between devices, select Yes. If you do not want to share files between devices, select No.  
  

  4. The computer searches for a connection to the network and the wireless connection is now ready to use.

Windows 8

**Here's how to enable a wireless network connection (WiFi) in Windows 8:**

  1. Move the mouse cursor to the upper right corner of the computer screen. Then select the gear icon (settings).  

  2. Select signal bars next.  

  3. Then select the network whose name is on the sticker on the back of the modem (SSID). Check the box "Connect automatically" and press Connect.  

  4. Enter the WiFi password (security key, SSID) in the open field. You can find the WiFi password on the sticker on the modem. Accept the connection by pressing next.  
  
  
  
If you want to share files between devices, select the lower option. If you do not want to share files between devices, select the upper option.  

  5. The computer searches for a connection to the network and the wireless connection is now ready to use.

Windows 7 / Vista

**Here's how to enable a wireless network connection (WiFi) in Windows 7 / Vista:**

  1. Press the WiFi icon in the lower right corner of the Windows desktop, near the clock.  
  

  2. Then select the network whose name is on the sticker on the back of the modem (SSID). Check the box **"Connect automatically"** and press **Connect.**  

  3.   

  4. Enter the WiFi password (security key, SSID) in the open field. You can find the WiFi password on the sticker on the modem. Accept the connection by pressing **OK.**  
  

  5. The computer searches for a connection to the network and the wireless connection is now ready to use.

Mac OS X

  1. Press the WiFi icon in the upper corner.  
  
  

  2. Select your own network (SSID).  
  
  

  3. Enter the WiFi password (security key, SSID) in the open field. You can find the WiFi password on the sticker on the modem. Select "Remember this network" and press OK.  
  

Android Tablet

**Enabling a wireless network connection (WiFi) on an Android tablet:**

  1. Go to the view where you see all the apps.  

  2. Select Settings.  

  3. Select WiFi (Wireless & networks in older Android tablets).  

  4. Wait a while for the tablet to search for networks. Then select the network whose name is on the sticker on the back of the modem (SSID).  

  5. Next, your tablet will ask for the wireless network password. Enter the password that is on the sticker on the back of the modem (security key, SSID) in the open field.
  6. Press Connect. Now the internet connection works.

Apple iPad

  1. Select settings from the desktop.  

  2. Select WiFi (WLAN in older iPad devices) from the settings.  

  3. Wait a while for the iPad to search for networks. Then select the network whose name is on the sticker on the back of the modem (SSID).  

  4. Next, the iPad will ask for the wireless network password. Enter the password that is on the sticker on the back of the modem (security key, SSID) in the open field.
  5. Press Join. Now the internet connection works.

**Forgot the password?** You can restore the factory settings by pressing and holding the RESET button on the back of the device for over 15 seconds.

Restoring the factory settings will erase all changes made to the device's settings. You can then start modifying the modem's factory settings from scratch, using an Ethernet connection or by connecting to the wireless network. You can find the network name and password on the modem sticker.
