#  Call over wifi

Avoid poor indoor coverage by calling over the WiFi network. This means
you can make and receive calls even if you have no mobile coverage.
The service is included at no extra cost in all our mobile subscriptions and prepaid cards.

## Mobiles that have wifi calling

To make wifi calling work, you need a mobile that supports the service.  

All **iPhone models** from iPhone 6 and with software update iOS
12.1 or later support wifi calling (as well as VoLTE calling).

Most mobile phones with **Android** as the operating system that were launched
after 2018 and are intended for use in the Nordic countries support both VoLTE
and wifi calling. However, there may be exceptions.

**Remember that you need to be connected to a Swedish wifi network that supports
calls.**

## Frequently asked questions about wifi calling

  * How do I make a wifi call?

You call as usual with the only difference being that the call goes over
wifi. [You can find more information about wifi
calling here](/link/bc2556b175044d2a980f1376de2c6a66.aspx).

If you want to forward your calls, you do so in the [My Telenor
app](/link/a4531ddbfeef48d3a256e369df95234d.aspx).

  * How do I get wifi calling?

Wifi calling is available in [our
mobile subscriptions](/link/a96eaee9166b475194e657db89f197b2.aspx). This means that
when you sign up for a new subscription, the wifi calling service is
included automatically.

To make wifi calling work, you need a mobile that supports the service.
On our page about wifi calling you can see [which mobiles
it is](/link/bc2556b175044d2a980f1376de2c6a66.aspx).

  * Does wifi calling work abroad?

No, wifi calling only works within Sweden at the moment.

  * How much does a wifi call cost?

It costs nothing extra. For subscriptions with free calls, wifi calling
will be included in your subscription. For subscriptions with variable
call charges, wifi calls are charged in the same way as in the mobile
network.

  * Can I both make and receive calls over wifi?

Yes, you can.

  * Does it work to call 112 via wifi calling?

If you call 112 (SOS Alarm), your phone will primarily choose
the mobile network. If the mobile network is not available, wifi calling
will be used. Wifi calling to 112 cannot be tracked geographically, which
means that it is not possible to see where the call is coming from.

  * Can I make wifi calls when the mobile is on Airplane mode?

Yes, you can make wifi calls as long as you are connected to a wifi
network.

  * Is data used during wifi calling?

No, it does not affect your data allowance.

  * Is the call dropped if I don't have wifi coverage?

As long as you have 4G coverage, the call will continue. However,
the call will be dropped if you only have 2G or 3G coverage.
