## Recording Programs

With the DNA TV service's recording feature, you can record an unlimited number
of programs from basic channels, and even from all basic channels at the same time.
Recording can also be started mid-program – and the recording will still begin
from the start of the program. Recordings are available for viewing for 2 years.

**Note**. Recording of pay channels is not supported. [See
the channel list](https://www.dna.fi/tuki/viihde/kanavalistat).

Recording a Program via the Program Guide

You can record programs via the program guide. Access the program guide
using the EPG button on your remote control. You can also find the program guide via the Menu
under **Program Guide**.

When you are in the program guide and press the **OK** button on your remote control
next to the program name, you will see more detailed information about the program. If the program description text does not
appear in its entirety, press the down arrow button on your remote control and the description will become fully
visible.

Selecting **Record Program** will record the program in question. The **Record Episodes**
option is visible if it is a series, and you can select all episodes of the series
to be recorded. If it is a series, you can see other episodes of the series from the **Episodes** tab.
In the same view, you can also remove the program
from recording.

Recording a Program Currently in Progress

Press the OK or arrow button on your remote control to display more detailed information about the program currently in progress. You can navigate the view using the arrow buttons on your remote control. Confirm your selection with the **OK** button. If the program is
recordable, you can start recording it by selecting the **REC**
icon. If the program is not recordable, REC will appear grayed out and will not be
selectable.

Viewing and Managing Recorded Programs

You can access recordings from the **Recordings** section in the **Menu**.

In the Recordings view, you can watch your recorded programs. Select
the program you want to watch with the **OK** button on your remote control and select **Watch** in the next
view. If it is a series, you can see other episodes of the series from the **Episodes** tab.

You can delete a recording from the **Recorded** tab.
