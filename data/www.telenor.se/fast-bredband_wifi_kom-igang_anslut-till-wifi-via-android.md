# Anslut till wifi via Android

  * ### Öppna app-menyn

Klicka på Inställningar och välj wifi.

  * ### Klicka på inställningar

  * ### Välj wifi

  * ### Aktivera ditt wifi

Det gör du genom att klicka på knappen.

  * ### Välj nätverk

Du hittar nätverkets namn på undersidan av din router. Titta vad det står
efter SSID. Om du använder vårt nätverk börjar det på TN.

  * ### Skriv in lösenordet

Skriv in ditt lösenord och klicka på Anslut. Lösenordet står på undersidan av
routern efter Wireless Key eller WPA.

  * ### Klart

Du kan nu surfa trådlöst.
