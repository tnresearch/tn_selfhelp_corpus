**Features**

  * Older modem for DSL and Ethernet connections
  * ADSL2+/VDSL2+ technology supported
  * Wireless connection: Wi-Fi 802.11b/g 2.4GHz
  * 4x 1Gb LAN ports (e.g., for a set-top box or computer), 1 WAN port allows use in Ethernet locations as well
  * IPv6 support
  * 1 USB port for sharing devices on the network
  * Firewall and NAT
  * DNA's customized settings

**Software Updates**

Attention users of very old versions, first see above how to update to a
newer version.

If an update is available for the device, a notification will appear on the
home page after logging in. Clicking the notification button will present
different options for updating the device.

  * **Yes** : Updates the software and retains user-made settings.
  * **No** : Updates the software and restores default settings.
  * **Cancel** : Does not update the latest software. The notification button remains visible to remind you of the update. The selection is made by clicking the desired button.

After selecting Yes/No, the modem downloads the update software from the
server, updates the software, and restarts.

The user can also search for updates themselves from the path system –
updates – update from server

**New version 3.16.9 released on 29.6.2021**

  * Minor fixes and security improvements

**New version 3.15.4 released on 25.9.2018**

Changelog:

  * IPv6 which was broken in the previous version
  * 2.4GHz 40MHz fixed
  * Internet status check changed from DNS ping to GW address
  * at the same time the interval time was increased to 30s (ipv4) and 300s (ipv6)
  * [vulnerability](https://www.viestintavirasto.fi/kyberturvallisuus/haavoittuvuudet/2018/haavoittuvuus-2018-020.html) patched

**New WLAN controller/mesh feature**

  * Supported on all Inteno iopsys devices: VG50, DG200, DG301, EG300
  * Extender mode activation
    * Hold down the extender device's WPS button (approx. 10s) until all lights come on
    * Press the WPS button once on another device
    * Connect the Ethernet cable from the extender's red port to the terminal's yellow port
  * Repeater mode activation
    * Similar to extender, but without the Ethernet cable
    * After activation, all SSID, password changes on the main router are automatically inherited by the repeaters/extenders behind them

The network map on the home page will now show the repeaters/extenders behind
it and their clients with information.
