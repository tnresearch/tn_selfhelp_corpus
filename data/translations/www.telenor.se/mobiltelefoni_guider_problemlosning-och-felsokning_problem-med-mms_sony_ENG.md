# Problems with MMS?

If you can't send or receive MMS with your Sony, you can often solve the problem yourself. Here we have collected a list of the most common troubleshooting steps.

  * If you have just acquired your mobile subscription with us, you must first send an MMS in order to be able to receive MMS in the future.
  * Restart your Sony and check if there are any updates available.
  * Make sure you are connected to the internet via a mobile data network or Wi-Fi.
  * Check that your phone's memory is not full.
  * Check your APN setting. Go to "Settings" > "More" > "Mobile networks" > Access Point Names. Go to "Telenor MMS", if it doesn't exist, press "+". The settings should be:  
 **Name:** Telenor SE  
 **APN:** services.telenor.se  
 **Proxy:** Should be empty  
 **Port:** Should be empty  
 **Username:** Should be empty  
 **Password:** Should be empty  
 **Server:** Should be empty  
 **MMSC:** http://mms  
 **MMS proxy:** 172.30.253.241  
 **MMS port:** 8799  
 **MCC:** 240  
 **MNC:** 08  
 **Authentication type:** PAP  
 **APN type:** mms  
 **APN protocol:** IPv4  
 **APN protocol when roaming:** IPv4  
 **Bearer:** Not specified
