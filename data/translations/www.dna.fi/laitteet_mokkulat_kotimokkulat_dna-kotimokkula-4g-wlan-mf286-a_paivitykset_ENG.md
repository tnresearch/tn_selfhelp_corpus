## Updates

The device's software is no longer actively updated. We recommend upgrading to a new device to ensure that security and performance are up to date.

### Instructions for updating:

  1. Open a web browser when you are connected to the DNA Home Modem's WiFi network or have connected the device with an Ethernet cable.
  2. Type <http://192.168.1.1> or http://dna.mokkula in the address bar
    * The default username is **admin**
    * The default password is **1234**
  3. If you cannot log in, hold down the reset button on the DNA Home Modem for 30 seconds and try logging in again.
  4. Select **advanced settings** at the bottom of the home page.
  5. Select **update** from the top menu.
  6. Select **check**.
  7. Follow the instructions in the user interface. Do not turn off or disconnect the power cord from the device during the update. The update may take 5-30 minutes.

  
If the update is not found or is interrupted unexpectedly, try resetting the device and clearing your browser's cache and try again.

**MF286 will receive a new update starting August 15, 2018**

Changes from the previous version:

  * GDPR notice
  * Fix for intermittent or restarting caused by the 2100 (B1) frequency
  * Fine-tuning for sleep mode

**New version: ZTE_DNA_MF286_B16**

  
DNA recommends clearing your browser's cache (cookies, offline files, etc.) and, if possible, resetting the device from the reset button on the top (30 seconds) after the update.

The update will happen gradually, meaning not everyone will receive the update at the same time. If the user updates the device from an older version (older than B13), the update may happen in two parts, meaning the user needs to update the device twice in a row.

**MF286 will receive a new update starting December 21, 2017**

Changes from the previous version:

  * Fixed a bug where settings disappear after restarting on some devices
  * Added a process that checks and repairs possible flash memory corruption (the repair process also happens during a reset)
  * Added selection/prioritization of carrier aggregation (CA)
  * Added selection for a backup connection over Ethernet
  * Telnet disabled
  * KRACK and other vulnerability fixes
  * Changes to the user interface
  * RSRQ, APN and eNB information added to the additional information field
  * Scheduled restart feature added
  * Fix for IPv6 allocation to a LAN device
  * 5 GHz WiFi disconnection in some rare situations fixed
  * The impact of a poor CA connection on mobile network stability fixed
  * CLAT functionality improved, please enable MTU 1400 and MSS 1360
  * Other minor fixes

**New version is: ZTE_DNA_MF286_B13**

**MF286 will receive a new update starting August 30, 2017**

**Changes from the previous version:**

  * Mobile user interface in DNA colors
  * Changes to update notifications
  * Text message does not force a number
  * "Force update" fixed (will only work with the next update)
  * 700Mhz lock added
  * CLAT support in trial (IPv4 > IPv6 conversion, found in APN settings)
  * USB support (FTP server) fixed
  * 802.11ac DFS channels added. Works only in automatic channel selection
  * RJ11 ports work, voice over CSFB. Note. in trial phase, SIM card must be voice-enabled
  * Virtual server function added
  * CPU and RAM information can be found in the system menu
  * Fix for a problem where some user devices connected to the LAN1 port caused interference with the mobile connection
  * Other user interface, security and usability fixes

**New version is: ZTE_DNA_MF286_B10**

**An update has been released for MF286 on November 10, 2016.**

Changes from the previous version:

  * Fixed DHCP behavior in bridge mode (makes it easier to use a third-party router)
  * Hardware acceleration now works in all situations
  * SSH connection over IPv6 fixed
  * DNA APNs added to the menu
  * Default APN changed to the future productization format
  * Information about the base station to which the device is connected added to the additional information menu
  * Translation fixes

**New version is: ZTE_DNA_MF286_B04**
