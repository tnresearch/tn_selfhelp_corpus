## Getting Started

## Installing the Modem

The DNA Modem 4G WLAN MF920V(A) uses a Micro-SIM card. Install the SIM card
into the slot on the bottom of the modem. Press the protective flap and slide
the SIM card into the slot. You can best see the correct orientation of the
SIM card by comparing one cut corner of the SIM card and the pattern on the
protective flap, as well as the image below. Make sure the SIM card stays in
the SIM card slot correctly and close the protective flap.

  
  
Registering to the DNA network takes a few minutes. If the connection fails
to open, call DNA customer service. The internet connection is available
when the power light and network status indicators are lit on the modem.

## Enabling the Wireless Network (WiFi)

DNA modems are encrypted in terms of wireless networks. You can find the
network name and password on the sticker on the back of the modem or on the
management page.

**SSID (network name)** : E.g. DNA-Modem-XXXXX

**Password:** E.g. 12345678901  
  

Windows 10

In Windows 10, click the WiFi network availability bars in the bottom right
corner of Windows.

Then select the network with the name on the back sticker (SSID). Check the
box next to **Connect automatically** and press **Connect.**

  

Next, the computer will ask for the wireless network password. You can find it
on the sticker on the back cover. Enter the password exactly as it is and
press **Next**. Now you can start using the internet.  

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then
select **Settings** (gear icon). Next, select the availability bars.

Then select the network with the name on the back of the modem (SSID). Check
the box next to **Connect automatically** and press **Connect.**

Next, the computer will ask for the wireless network password, or security
key. You can find it on the sticker on the back of the modem. Enter the
password exactly as it is and press **Next.**

  
If you want to share files between devices, select the lower option ("Yes,
enable sharing"). If you do not want to share files between devices, select
the upper option ("No, do not enable sharing").  

Windows 7 / Vista

In Windows 7 and Vista, click the WiFi network availability bars in the
bottom right corner of Windows. Then select the network with the name on the
back sticker (SSID).

  

Check the box next to **Connect automatically** and press **Connect**.

Next, the computer will ask for the wireless network password. You can find
the password on the sticker on the back of the modem. Enter the password
exactly as it is and press **OK**.  

  

You can start using the internet.

Mac OSX

Click the WiFi network icon at the top of the screen with the mouse. Then
select the network with the name on the sticker on the back of the modem
(SSID).

  

Next, the computer will ask for the wireless network password. The password,
or security key, can be found on the sticker on the back cover (WLAN-Key).
Enter the password exactly as it is on the sticker. Click "**Remember this
network**" and press **Join.**

You can start using the internet.

Apple iPad

Select Settings from the iPad home screen. From settings, select WiFi (WLAN in
older models).

Wait a moment while the iPad searches for networks. Then select the network
with the name on the sticker on the back of the home modem (SSID). Next, the
iPad will ask for the wireless network password. You can also find the
password on the sticker on the back of the modem.

Press **Join**. You can start using the internet.

Android Tablet

Go to the view where you see all the apps.

Select **Settings** and select **WiFi** from the menu (Wireless & networks in
older versions). Wait a moment while the tablet searches for networks. Then
select the network with the name on the sticker on the back of the home modem
(SSID). Next, the tablet will ask for the wireless network password. Then
select the password, which is on the sticker on the back of the home modem.

Press **Connect** and you can start using the internet.
