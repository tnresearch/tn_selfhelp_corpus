# Change Password

  * ## Log in to your software

Open your internet browser, e.g., Internet Explorer, and type
**<http://192.168.8.1>** and then press " **Enter** " on the keyboard.  
  

**Username:** admin  
 **Password:** admin  
  

Press " **Log in** ".

  * ## Change your password

Click on **Settings** > **Wlan** > **Basic WLAN settings**

  
1\. Under " **SSID** " you can change the wireless network name.  
2\. Security mode should always be set to **WPA2/PSK** by default.  
3\. **WPA Pre-Shared Key** is the code for the wireless network.
