#  Problem med täckning inomhus

Så kan du lösa det

Ett hus med tjocka väggar och/eller väggar av betong kan påverka täckningen
inomhus negativt. Det är också ett vanligare problem i nybyggda hus.  
  
Två enkla åtgärder för att förbättra täckningen, är att ringa via WiFi eller
ringa via 4G-nätet.  
  
[Läs mer om att ringa via WiFi](/support/mobiltelefoni/abonnemang/fler-
tjanster/wifi-samtal/)

[Läs mer om att ringa via 4G-nätet ](/support/mobiltelefoni/abonnemang/fler-
tjanster/volte-4g-samtal/)
