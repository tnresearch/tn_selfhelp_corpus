# Tips for Improving Coverage

## Improve Your Coverage

On a Mobile Phone

You can try to improve coverage by moving to another room in the building
or by trying coverage outdoors. You can also improve coverage by
installing an external antenna, for example, on the roof of the house.

Coverage can be affected by terrain features and the location of the
nearest base station, surrounding buildings and the building materials used
in them (for example, selective glass).

On Mobile Broadband

You can improve mobile broadband coverage with a base station and an external
antenna and by ensuring that your device is not locked to any specific
frequency.

DNA Kotimokkula 4G WLAN is a wireless local area network base station that
you use to create a wireless broadband connection. By placing the home
dongle in a location where the mobile network has the best coverage, you can
improve broadband coverage.

You can improve your mobile broadband connection with a DNA dongle antenna.
Learn more about antennas in the DNA Online Store.

Many devices can be locked to different frequencies, and this can be
beneficial for coverage in certain situations. However, if coverage
suddenly weakens, it is worth checking that the device is not locked to any
single frequency, as not all frequencies are available at all base stations
in the mobile network.

[DNA Dongles](https://www.dna.fi/mokkulat)

With an External Antenna

Indoor coverage problems are often caused by building materials. New
building materials such as thick concrete walls, metal structures and
energy-saving windows can weaken the strength of the radio signal.

You can improve coverage by installing an external antenna, for example, on
the roof of the house. It is advisable to leave the installation of an
external antenna to a professional if you do not have experience with
antenna installation.

#### Installation:

  1. Find out from DNA customer service in which direction the mobile station
    transmits the signal
  2. Attach the antenna as high as possible to a pole or wall. The antenna
    should point towards the nearest base station.
  3. Run the antenna cables into the room where the device is used.
  4. Connect the antenna cables to the antenna connectors of the device.

How do I know if there are coverage disturbances in my area?

If you notice that the mobile network coverage or operation has deteriorated,
it is worth checking for a possible fault situation, for example, on DNA's
disturbance map or monitoring disturbance notifications. You can find
disturbance notifications on this page under Disturbance Notifications and
on the [Disturbance Notifications](https://corporate.dna.fi/hairiotiedotteet)
page.

#### More Information from the Communications Regulatory Authority's Website

You can also find useful information on how to improve mobile phone coverage
on the Communications Regulatory Authority's
[advice page](https://www.viestintavirasto.fi/internetpuhelin/puhelin-
jalaajakaistaliittymantoimivuus/matkaviestinverkonkuuluvuus.html).

How do I improve mobile broadband coverage?

You can improve mobile broadband coverage with an additional antenna. Most
mobile devices can be connected to a separate additional antenna that
improves coverage indoors.

Dongle Antenna M: A magnetically attachable additional antenna can be
installed either on a table or outside on a windowsill. It is a good choice
if you need moderate 4G network enhancement. [Learn more.](https://kauppa4.dna.fi/Lis%C3%A4laitteet-ja-
tarvikkeet/4G-magneettiantenni-imukupeilla/p/UA00056)

Dongle Antenna 4G: If you need a more powerful additional antenna, you
should consider a directional antenna. It is directed towards the nearest or
best-serving base station. [Learn more.](https://kauppa4.dna.fi/Lis%C3%A4laitteet-ja-
tarvikkeet/DNA-Mokkula-antenni-4G-LTE-800-Mimo/p/UA00059)

DNA Stores sell various additional antennas to improve the operation of the
dongle. You can also contact [DNA customer service](https://www.dna.fi/yhteystiedot).
We will help you find the right antenna type and provide instructions for
the antenna's location and orientation.

Also see the Communications Regulatory Authority's
[advice page](https://www.viestintavirasto.fi/internetpuhelin/puhelin-
jalaajakaistaliittymantoimivuus/matkaviestinverkonkuuluvuus/ohjematkapuhelimenkuuluvuudenjamobiililaajakaistantoimivuudenparantamiseen.html).

What should I do if the disturbance persists?

If the disturbance persists, make a report. Fault and coverage reports are
accepted 24/7 at 044 144 044.

You can also submit a mobile network fault and coverage report by email to
palvelu@dna.fi

Everyone has the right to a working phone or a 2 Mbit/s broadband connection.

[Read more about DNA's universal service products.](https://www.dna.fi/dna-
yleispalvelulaajakaista)
