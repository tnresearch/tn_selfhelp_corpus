# How to Use Profiles with the T-We App

Profiles allow you to customize content for everyone in the family. Here we help
you create, change, or switch between profiles in the T-We App.

[More about profile types](/kundeservice/tv/t-we-app/profiler/#typer)[Switching between
profiles](/kundeservice/tv/t-we-app/profiler/#bytte)[Give your family access to
the T-We App](/kundeservice/tv/t-we-app/profiler/#app)

## Create a New Profile

  1. Select **☰ More**

  2. Tap **Access and profiles**

  3. Select **+** to create a new profile

  4. Enter **PIN code**

  5. Give the profile a name and select a profile type.

  6. Tap **Next**

  7. Settings such as language, age restriction, and permissions can be set before you tap **Next**, or you can go back and change the settings later.

  8. Tap **Confirm**

NB!** If you want to prevent access to the profile, the **PIN-protected**
option must be set to **Yes**. You will then also be required to enter the PIN code when you log in
to the profile.

## Switching Between Profiles

To switch profiles, select "More" and tap the profile you want to switch
to. The active profile is marked with a checkmark.

Note that you will automatically be logged in to the profile you were last in
when you start the app.

## Profile Types in T-We

The first time you start the T-We App, you have access to two profiles: Owner and Kids.
Owner is an administrator profile, while Kids is tailored for children.

All profiles except Kids have access to use a PIN code. You will be prompted to enter this when you need to change certain settings, rent a movie, or
unlock content that is restricted for other reasons.

The profile type and age restriction you have chosen determine what access you have.

## Owner

Has access to all content with a PIN code. The profile cannot be changed or
deleted.

## Kids

Does not have access to content that requires a PIN code. If prompted for a PIN, you must
switch to Owner or the standard profile.

## Standard

Has access to all content with a PIN code except settings in the Owner
profile.
