easy. We do almost everything for you. All you need to do is order a new DNA
Entertainment Box to your home and then contact us. You can also conveniently

# Updates

Update DNA TV and the Entertainment Box – this is how you keep the service and device up to date

DNA TV and the Entertainment Box are constantly updated, and with that, its
features and the applications contained in the Entertainment Box are also updated. During use, the Entertainment Box checks for available updates and offers them
automatically. Follow the instructions on the screen.

It is important to accept and install updates so that your device is always
up to date in terms of features and functionality. During the update, the
device may restart automatically.

## Latest Updates for the Entertainment Box (Hubi 1.0)

DNA TV app update 2.14 for Hubi devices (starting 5.6.2023)

The new DNA TV app update is being distributed to DNA Hubi devices in stages starting June 5th.

Included in the update:

**Updated Store Appearance**

  * The appearance of the internal Store within the DNA TV app has been clarified and refreshed.

**Other Changes**

  * A problem in the program guide that sometimes slowed down its use has been fixed.
  * Other minor improvements to the app's visual appearance.

DNA TV app update 2.13 for Hubi devices (starting 17.4.2023)

The new DNA TV app update is being distributed to DNA Hubi devices in stages starting April 17th.

Included in the update:

**Updated Appearance**

  * DNA's new brand colors have been updated to the user interface, and other changes have been made to modernize the appearance.
  * The Live TV image is hidden in the background while browsing menus.

**System Settings can now be found in the DNA TV app**

With the update, you can access Android system settings directly through the DNA TV
app. From system settings, the user can:

  * Make changes to network and internet settings.
  * Add a Google account or change its login details.
  * Make changes to installed applications.
  * Change other settings of the DNA Hubi device.
  * Connect other devices to the Hub via Bluetooth connection.

**New Features for DNA Hubi 2.0 Device**

  * Timeshift: If a hard drive is connected to the device, pausing and rewinding the current program is possible.
  * Return to the previous channel using the 0 key on the remote control.

Android TV operating system update 10.1.0.120 for DNA Hubi (2nd generation)
device (starting 30.1.2023 in stages)

An operating system update is being made to DNA Hubi (2nd generation) devices, it
is being distributed to devices in stages starting January 30th. When the device offers an update, it is important to accept the update, as it significantly improves the use and performance of the device, and includes the latest security updates.

**Note.** The update does not apply to the DNA Hubi (1st generation) device.

DNA TV app update 2.12 for Hubi devices (starting 9.1.2023)

#### A new DNA TV app update is being distributed to DNA Hubi devices in stages
starting January 9th.

**Included in the update:**

**My Apps**

  * Apps downloaded by the user to their Hubi device can now be found directly in the main menu.
  * Through My Apps, you can also easily download new apps and manage existing ones.

**New Home Page**

  * Changes have been made to the Home page and its content has been updated to better meet user needs.
  * The Home page now includes, for example, the latest own recordings, own apps, and the most watched programs on live channels.
  * The background of the Home page has been dimmed to calm browsing.

**Revised Menu**

  * Store and Program Guide have been added to the main menu.
  * From the Store you can order the most popular channel packages and streaming services, the DNA Hubi 2.0 device and manage your own subscriptions.
  * You can now also access your own subscriptions directly through the settings menu.

**Starting Playback on the Hub from Another Device**

  * As a new feature, the user can start playback of DNA TV content (channel, recording, watch later and Rental or Entertainment Library content) on the Hub device directly from another device.
  * In the first phase, playback can be started from the DNA TV web service dnatv.dna.fi.

DNA TV app update 2.11 for DNA Hubi device (starting 3.10.2022)

A new DNA TV app update is being distributed to DNA Hubi devices in stages starting October 3rd.

Included in the update:

  * Deleted and upcoming recordings
  * Deleted recordings can now be found in the recycle bin, from where they can be restored to your own recordings within 30 days. At the same time, a separate section for upcoming recordings has been added to the recording view.

Update to Hubi 2.0 remote control

  * The update fixes a problem related to the battery level, where a fully charged remote control did not work in some situations.
  * After the update, the remote control should work normally regardless of the charger used to charge it.

Android TV operating system update RC7.1.1.113 for DNA Hubi device
(starting 30.5.2022 in stages)

An operating system update is being made to the first generation DNA Hubi device,
it is being distributed to devices in stages starting May 30th. When the device offers an update, it is important to accept the update, as it significantly improves the use of the device. With the update, the device's reliability and stability improve.

Note. The update does not apply to the DNA Hubi (2nd generation) device.

## Android TV operating system update on the Entertainment Box

See instructions

  1. Select the Android home menu
  2. Select "**Settings**"
  3. Proceed down the menu with the arrow buttons on the remote control and select "**About**"
  4. Select "**System Update**"
  5. Select "**Check for Updates**"
  6. DNA Hubi checks for available updates. If an update is available, install the update according to the instructions on the screen.
