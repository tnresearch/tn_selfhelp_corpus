## Internet Connection

?

#### E0120No Network Connection

The error code indicates that the decoder is not connected to the internet via a network cable. Check that the network cable is securely connected at both ends, and that it is connected to the correct outlet.

?

#### E0130No Network Connection

With this error code, the decoder, router, and cable modem/fiber box must be restarted.

  1. Unplug the power to the equipment, and wait 10 seconds before plugging it back in.

  2. Also, check that all cables are connected correctly.

The error may also be due to problems with your cable or misconfigured equipment (e.g., using a router not provided by Telenor).  
Go to [Problems with Cables or Third-Party Equipment](/kundeservice/tv/kabler-og-nettverksutstyr/) for further troubleshooting.

If the error persists, note down as much information as possible about what you were doing when the error occurred. Examples of information you can note are: title, time, date, episode, channel, etc.

[Contact Customer Service.](/kundeservice/kontakt-oss/) with the information. This makes it easier to find a solution to the problem.

#### E0170No Network Connection

**The decoder is not connected to the internet.**

You can set up the internet manually by following the instructions below:

  1. Select Menu/MENU on the remote control

  2. Select Settings

  3. Select Installation and enter the PIN code (this is 1-2-3-4 by default)

  4. Select Connect to Network

Check that the internet is working on, for example, your computer or mobile phone. If it works normally, you should check that you are using the correct cable and that they are connected as they should be. See more information here: [Information about Cables and Network Equipment](/kundeservice/tv/kabler-og-nettverksutstyr/)

#### E0181No Network Connection

The decoder is not connected to the internet.

You can set up the internet manually by following the instructions below:

  1. Select Menu/MENU on the remote control
  2. Select Settings
  3. Select Installation and enter the PIN code (this is 1-2-3-4 by default)
  4. Select Connect to Network

 _Note: Do you have a T-We Box, and are you using an antenna cable with a screw-on connector at both ends for the internet?_ Check that HFC Network Configuration is set to 'On'. This option will appear after you have entered the PIN code during Installation.

**Reset Decoder**

If you still get an error code, you can set up the internet again by resetting the decoder. As long as you are connected to the internet with a network cable, the internet will be set up automatically during installation.

Resetting the decoder involves returning it to its original settings.

  1. Press Menu/MENU on the remote control
  2. Select Settings and press OK
  3. Select Installation and enter the PIN code (this is 1-2-3-4 by default)
  4. Select Factory Settings and press OK
  5. Select whether you want to delete or keep saved recordings
  6. Press Continue

#### E0171Platform Selection Failed

No internet connection when selecting the IPTV Platform. This error message may appear if you have TV over Fiber.

  * Check that the network cable is securely connected at both ends. 

  * The network cable should go from the decoder to your router. 

  * Alternatively, the network cable can go from the decoder directly into the fiber box, or a wall outlet for the internet.

  * If you have recently replaced equipment, you should also replace the cable (if one was included with the equipment)

If you are unsure whether the cable is connected correctly, you can select your equipment and [see the connection guide here.](/kundeservice/tv/dekodere-og-fjernkontroller/indexer.page)

#### CE104Unable to Contact T-We Services

The error message CE104 is caused by the decoder being unable to contact T-We services. Reasons may be equipment that has been cancelled, that you have recently changed TV box or unpaid bills.  

**Restart the decoder by unplugging the power cord.** Wait a few seconds before plugging the power back in.  
Note: It is not sufficient to turn off the decoder with the remote control. This puts the decoder into sleep mode rather than turning it off completely.  

If restarting the decoder does not solve the problem, write down the serial number of the TV box and contact Customer Service for further assistance.

[See opening hours and contact information](https://www.telenor.no/kundeservice/kontakt-oss/index.page)

#### CE202Problem with Local Network

Check if the internet is working on your computer or mobile phone.  
If the internet is working normally, check the cabling between the TV box and the router. Also, restart the TV box and router, and try again.

If the error has lasted for more than 2 hours, you can [contact customer service](/kundeservice/kontakt-oss/) so they can investigate the problem further.
