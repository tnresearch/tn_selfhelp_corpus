## Settings

Managing the travel modem and changing settings

You can access the software management page of the DNA Travel Modem 4G WLAN E5577 by entering the address http://dna.mokkula (or alternatively 192.168.8.1) into the web browser of the device you are using.  A connection requires that you have joined the travel modem's WiFi network or that a USB cable is connected to the computer. The default username for the management page is **admin** and the default password is **1234**.  

From the management page you can do things such as:

  * Change the WiFi network name, password and encryption type.
  * Select a connection method.
  * Lock the travel modem to a 4G or 3G network or to specific frequencies.

Locking the modem to a 4G or 3G network

By default, the travel modem is locked to select either a 4G or 3G network. The easiest way to set the frequency lock is directly from the device's screen via the path Menu -> network mode.  Selecting the network via the management page happens as follows:

  1. Open a web browser.
  2. Type http://dna.mokkula into the browser's address bar.
  3. Select **Settings** from the top.
  4. Enter 1234 as the password.
  5. Select **Modem** on the left.
  6. Select **Mobile Network Settings** under Modem and from there next to **Preferred Mode**: 
    * 4G or 3G: The travel modem will select a 4G or 3G network by default.
    * Only 4G: If you want to force the travel modem to a 4G network.
    * Only 3G: If you want to force the travel modem to a 3G network.
    * Auto: The travel modem automatically selects the fastest available network. If a 4G or 3G network is not available, the modem will select a 2G network.

From the same menu, you can directly lock the desired 4G LTE frequency: 800/1800/2600. DNA recommends using automatic selection and frequency lock only for troubleshooting or in special problem situations.

Changing the WiFi network name and password

  1. Open a web browser when you are connected to the travel modem either via USB or wirelessly.
  2. Type http://dna.mokkula into the browser's address bar
  3. Select **Settings** from the top.
  4. Enter 1234 as the password.
  5. Select **Settings** from the top bar and then **WLAN** on the left and then **WLAN Basic Settings**.
  6. The **SSID** field changes the WLAN network name and the **WPA Pre-Shared Key** field changes the WLAN network password. Select Show Password if you want to see the password as characters. 
  7. Finally, press **Apply**.

  
Note! If you change the WiFi network name or password, the connection will no longer work on devices that are connected to the travel modem. If you changed the WiFi network name, select the new WiFi network from the device. If you changed the WiFi network password, but the WiFi network name remained the same, first select "forget network" from the device and then reconnect the device to the Travel Modem's WiFi network.  

Forced shutdown of the travel modem

If the travel modem does not respond to button presses in any way, you can force it to shut down by pressing the power button for five seconds or by disconnecting the travel modem's battery.

Reset to factory settings

Open the back cover and press the **Reset** button with a sharp pen tip. Count slowly to five and release the button.

Updating the travel modem

A notification will normally appear automatically on the web user interface and on the travel modem's screen when a new update is available for download.

Changing the modem management password

You can change the modem management password if you wish. If you forget the changed management password, you can reset the modem to factory settings.  

  1. Open a web browser when you are connected to the home modem's WiFi network.
  2. Type http://dna.mokkula or http://192.168.1.1 into the address bar. 
    * The default username is **admin** and the default password is **1234**.
  3. Select **Settings** from the top.
  4. Select **System** on the left and **Change Password** from the menu below. 
    * Current password is **1234**.
    * **New password** : Enter the password you want.
    * **Confirm password** : Confirm the password you want.
  5. Press **Apply**.

Entering the PIN code

If the SIM card uses a PIN code other than 1234, the PIN code must be entered the first time in the modem settings.

  1. Open a web browser when you are connected to the travel modem's WiFi network.
  2. Type http://dna.mokkula into the browser's address bar 
  3. Select **Settings** from the top.
  4. Enter **1234** as the password.
  5. The travel modem will now ask for the PIN code. Enter the SIM card's PIN code and press **OK**.
