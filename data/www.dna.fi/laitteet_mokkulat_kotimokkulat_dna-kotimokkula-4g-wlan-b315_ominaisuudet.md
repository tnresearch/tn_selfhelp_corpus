## Ominaisuudet

**Tuotenimi: Huawei B315**  
  
DNA Kotimokkula 4G WLAN B315 on kiinteään asennukseen tarkoitettu WLAN-
mokkula.  
Siinä on 4 Ethernet-porttia ja se jakaa 4G- tai 3G-yhteyden myös WiFi-verkon
avulla.  
Mokkula toimii tarvittaessa myös kiinteän yhteyden reitittimenä.

  * 4G LTE enimmäisnopeus 150 Mbit/s
  * 3G DC enimmäisnopeus 42 Mbit/s 
  * HSPA+ enimmäisnopeus 21,1 Mbit/s
  * WiFi b/g/n 
  * USB
  * 4 kpl Ethernet-liitäntää, max 1000 Mbit/s
  * 32 WLAN-laitetta 
  * Kaksi liitäntää ulkoisille antenneille, liitäntätyyppi SMA
  * Normaalikokoinen SIM-kortti

### Laitteistovaatimukset / Tuetut käyttöjärjestelmät:

  * RJ45 ethernet
  * WiFi: 802.11b/g/n
  * Tuetut käyttöjärjestelmät: Windows XP SP2/SP3, Vista SP1/SP1, Windows 7, Windows 8 / 8.1, Windows 10, MAC 10.5
  * Internetselain USB-liitännän tai WLAN:n kautta: Microsoft Internet Explorer 6.0 tai uudempi, Firefox 2.0 tai uudempi, Safari 4.0 tai uudempi, Opera 10.0 tai uudempi, Chrome 5.0 tai uudempi
