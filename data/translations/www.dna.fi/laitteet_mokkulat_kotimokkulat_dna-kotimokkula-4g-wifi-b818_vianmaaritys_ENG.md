## Troubleshooting

How to restore factory settings?

When the modem is on, press the Reset/Restore button with a sharp object for about 10 seconds, or until the power indicator light turns off. After this, the lights will start flashing and the device's factory settings will be restored. Restoring factory settings will reset the settings to their defaults. You can reconfigure them after the modem has been restored to factory settings.

What should I do if I forget the WiFi password or username, as well as the password for the web-based management page?

Restore the modem to factory settings and try again using the default WiFi password, username, and login password found on the information label.

What should I do if the Status indicator light is red or I cannot connect to the internet?

  1. Check that the micro-SIM card is in place. See "Getting Started" > "Modem Installation" for the SIM card size and correct installation method.
  2. If the problem does not go away, restore the modem to factory settings and try again.
  3. Check with DNA to see if the SIM card has been deactivated.

What should I do if the internet speed is slow?

  1. Check the modem's signal indicator lights. If the signal is weak, adjust the router's position or move it closer to the window to improve signal reception.
  2. If the device is connected to the modem via WiFi, try moving the device to get a better signal.
  3. Switch to the WiFi 5 GHz band if your device supports it.
  4. Restart the modem and device and try again.

How do I connect the modem with WiFi Protected Setup (WPS)?

  1. Make sure WiFi is enabled on the device.
  2. 2. Hold down the router's Hi/WPS button for at least one second and then release it; the WiFi indicator light will start flashing.

Why can't I use the modem's web-based management page?

  1. Make sure the computer is connected to the modem with an Ethernet cable or WiFi connection.
  2. Make sure the computer is set to obtain the IP address and DNA server address automatically.
  3. Restart the browser or try a different web browser or device.
  4. If the problem does not go away, restore the modem to factory settings.

Why is the content on the web-based management page not up to date?

If the content on the management page is not up to date, try clearing the browser's cache manually (for example, open the browser and select **Internet Settings > General > Browsing History > Delete**) and restart the web-based management page.

Does the modem support 5 GHz WiFi? How do I connect to it?

  1. Your modem supports 5 GHz WiFi, which is faster and less susceptible to interference. However, it does not penetrate walls as well as 2.4 GHz WiFi and can only be used with devices that support 5 GHz WiFi.
  2. If you have enabled the feature that prioritizes 5 GHz on your router, the 2.4 GHz and 5 GHz networks share the same network name and the connection is automatically made to the faster network. If this feature is disabled, two WiFi network names will be displayed. Connect to the WiFi network whose name ends with "_5GHz". You can manage this feature on the modem's web-based management page.

If you are having problems with the modem:

  1. Restart the modem.
  2. Restore the modem to factory settings.
  3. See the help section on the web-based management page.
  4. Contact DNA.
