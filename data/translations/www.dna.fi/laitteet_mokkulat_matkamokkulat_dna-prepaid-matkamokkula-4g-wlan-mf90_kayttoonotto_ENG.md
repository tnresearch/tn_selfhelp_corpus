## Getting Started

## Installing the Modem

Slide and carefully remove the back cover.

Install a standard-size Mini-SIM card into the card slot.

Note! The device does not support micro- or nano-SIM cards, or any other SIM cards that are not standard. Do not use such cards or any card holders, as this may damage the device.

Install a microSDHC memory card if needed.

Insert the battery.

Close the back cover.

Registering to the DNA network takes a few minutes. If the connection fails to open, call DNA's [customer service](https://www.dna.fi/yhteystiedot#asiakaspalvelu).

The internet connection is available when the power light and network status indicator (in a color other than red) are lit on the modem.

##  
Enabling Wireless Network (WLAN)

DNA modems are encrypted in terms of wireless network. The network name (SSID) and password are printed on a label on the device. The label can be found when you remove the back cover.

Windows 10

Click the WLAN network availability bars in the lower right corner of Windows 10. Then select the network named **DNA-Modem-XXXXXX**. You can find the exact network name (SSID) on the modem's label. The X letters are unique to each subscription.

Check the box next to **Connect / Yhdistä**.

The computer will then ask for the wireless network security key. See the security key on the label under the modem's back cover.

Enter the security key exactly as it is and press **OK.**

You can start using the internet.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select **Settings** (gear icon). Next, select the availability bars.

Then select the network named **DNA-Modem-XXXXXX**. You can find the exact network name (SSID) on the modem's label. The X letters are unique to each subscription. Check the box next to **Connect automatically / Yhdistä automaattisesti** and press **Connect / Yhdistä.**

The computer will then ask for the wireless network security key. See the security key on the label under the modem's back cover.

Enter the security key exactly as it is and press **Next.**

Windows 7 / Vista

Click the WLAN network availability bars in the lower right corner of Windows 7 and Vista. Then select the network named **DNA-Modem-XXXXXX**. You can find the exact network name (SSID) on the modem's label. The X letters are unique to each subscription.

Check the box next to **Connect / Yhdistä.**

The computer will then ask for the wireless network security key. See the security key on the label under the modem's back cover. Enter the security key exactly as it is and press **OK.**

You can start using the internet.

Mac OSX

Click the WLAN network icon at the top of the screen with the mouse. Then select the network named **DNA-Modem-XXXXXX.** You can find the exact network name (SSID) on the modem's label. The X letters are unique to each subscription.

The computer will then ask for the wireless network security key. See the security key on the label under the modem's back cover. Enter the security key exactly as it is and press **OK.**

You can start using the internet.

Apple iPad

Select Settings from the iPad home screen. Select Wi-Fi (WLAN in older models) from Settings.

Wait a moment while the iPad searches for networks. Then select the network named **DNA-Modem-XXXXXX.** You can find the exact network name (SSID) on the modem's label. The X letters are unique to each subscription.

The iPad will then ask for the wireless network password. See the password on the label under the modem's back cover. Enter the password exactly as it is and press Join. You can start using the internet.

Android Tablet

**Go to the view where you see all the apps**.

Select **Settings** and select **Wi-Fi** (Wireless & networks in older versions) from the menu. Wait a moment while the tablet searches for networks. Then select the network named **DNA-Modem-XXXXXX**. You can find the exact network name (SSID) on the modem's label. The X letters are unique to each subscription.

The tablet will then ask for the wireless network password. See the password on the label under the modem's back cover. Enter the password exactly as it is and press **Join.** You can start using the internet.

Using a USB cable

1\. Connect the modem to the computer with a USB cable.

2\. Turn on the modem. The computer's operating system will detect and recognize the new device and automatically install the software.

Note! If the system does not recognize the device and start the installation automatically, install the software by double-clicking the device's installation icon in the My Computer window.

3\. Wait for the computer to connect to the modem.
