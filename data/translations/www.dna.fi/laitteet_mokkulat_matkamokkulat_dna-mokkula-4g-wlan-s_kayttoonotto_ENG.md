## Getting Started

## Installing the Modem

Open the back cover, remove the battery, and place the SIM card under the battery. Put the battery
back in place and close the cover.

Place the modem as close to the window as possible. The closer the modem is to the window, the better
the connection speed it usually gets. If the apartment is new, we recommend an external antenna
installed outside the window. You can find more information about antennas from DNA Store or DNA
Customer Service.

Registering to the DNA network takes a few minutes. If the connection fails to open, call DNA
Customer Service.

The internet connection is available when the power light and network status indicator (in a color
other than red) are lit on the modem. If the modem has a display, you will see an icon indicating
the signal on the display.

## Connect to the Internet

Turn on the modem by pressing the power button on the front panel. The modem display now reads SIM
locked, go to http://dna.mokkula and enter the PIN code. Press the navigation button on the front
panel of the modem once (symbol "-" on the button) and you will see the WiFi network name and network
password on the modem display.

Select the WiFi network from your computer. The network is in the format Mokkula-1234 (the numbers
vary). The network password is under WiFi password. If you do not see the network name or password,
press the navigation button again.

You can optionally disable the PIN code. In this case, the modem will automatically establish an
internet connection when it is turned on.

1. Go to the modem management page at http://dna.mokkula.

2. Enter the management password (12345) and press **Submit.**

3. Now the modem will ask for the PIN code. Enter the code 1234 and leave the checkmark in the
**Remove SIM card PIN code request** field. Press **Submit.**

4. Press Ok. You have disabled the PIN code and the modem will automatically establish an internet
connection when it is started.

## Enabling Wireless Network (WiFi)

We recommend using the modem with a WiFi connection. If, for example, your computer does not have a
wireless internet connection, you can also use the modem with a USB connection.

Windows 10

Click the WLAN network coverage bars in the lower right corner of Windows 10 on your computer. Then
select the network named **DNA-Modem-XXXXXX.** You can find the exact network name (SSID) on the
modem label. The X letters are unique to each subscription.

Check the box next to **Connect / Connect.**

Next, your computer will ask for the wireless network password. You can see the password on the
modem's LCD screen when you press the power button. Type the password exactly as it is and press **OK.**

You can start using the internet.

Windows 8

Move the mouse cursor to the upper right corner of the computer screen. Then select **Settings** (gear
icon). Next, select the coverage bars.

Then select the network named **Modem xxxxxxx**. You can find the exact network name (SSID) on the
modem screen. The X letters are unique to each subscription.

Check the box next to **Connect automatically / Connect automatically** and press **Connect / Connect.**

Next, your computer will ask for the wireless network password. You can see the password on the
modem's LCD screen when you press the power button. Type the password exactly as it is and press **OK.**

Windows 7 / Vista

Click the WLAN network coverage bars in the lower right corner of Windows 7 and Vista on your computer.
Then select the network named **Modem xxxxxx**. You can find the exact network name (SSID) on the
modem screen. The X letters are unique to each subscription.

Check the box next to **Connect / Connect.**

Next, your computer will ask for the wireless network password. You can see the password on the
modem's LCD screen when you press the power button. Type the password exactly as it is and press **OK.**

You can start using the internet.

Mac OSX

Click the WLAN network icon at the top of the screen with the mouse. Then select the network named
**Modem xxxxxx.** You can find the exact network name (SSID) on the modem screen. The X letters are
unique to each subscription.

Next, your computer will ask for the wireless network password. You can see the password on the
modem's LCD screen when you press the power button. Type the password exactly as it is and press **OK.**

You can start using the internet

Apple iPad

Select Settings from the iPad home screen. Select the Wi-Fi section from the settings (WLAN in older
models).

Wait a moment while the iPad searches for networks. Then select the network named **Modem xxxxxx.** You
can find the exact network name (SSID) on the modem screen. The X letters are unique to each
subscription.

Next, the iPad will ask for the wireless network password. See the password on the modem screen. Type
the password exactly as it is and press **Join.**

You can start using the internet.

Android Tablet

**Go to the view where you see all applications.**

Select Settings and select **Wi-Fi** from the menu (Wireless & networks in older versions). Wait a
moment while the tablet searches for networks. Then select the network named **Modem xxxxxx**. You can
find the exact network name (SSID) on the modem screen. The X letters are unique to each
subscription.

Next, the tablet will ask for the wireless network password. You can find the exact network name
(SSID) on the modem screen. The X letters are unique to each subscription.

USB cable

We recommend using the modem via a WiFi connection. However, you can also use the modem with a USB
connection. You can use both the WiFi connection and the USB cable at the same time.

Using the USB connection is done by connecting the USB cable to the computer and installing the
connection software according to the instructions on the computer screen. Once the connection software
is installed, the internet connection will work automatically. USB connection is supported in Windows
XP and Mac 10.5 or newer operating systems. Make sure you have the latest version of these operating
systems on your computer.

## PIN code

1. Start the modem and connect to the WiFi network or use the modem with a USB connection.

2. Type http://dna.mokkula in the address bar of your web browser

3. Enter the password (default 12345)

4. Enter the PIN code in the field where the PIN code is requested and press submit. The default code
is 1234.

Note! If the SIM card PIN code request is on, the PIN code must be entered each time you start the
modem. You can get the PIN code request off with your phone or from the modem as follows:

1. Type http://dna.mokkula in the address bar of your web browser

2. Enter the password (default 12345)

3. Select **Advanced Settings** -> **WAN** -> **SIM**. Select **Disable.**

4. The modem will ask for the current PIN code. Enter the code and then the connection will be
established automatically every time you start the modem.
