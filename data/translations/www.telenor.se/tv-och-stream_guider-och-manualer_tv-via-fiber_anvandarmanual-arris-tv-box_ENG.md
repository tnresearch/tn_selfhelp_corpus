# Arris TV Box User Manual

We are now improving the experience for those of you who watch TV via your Arris box.

Therefore, there are currently two user guides for the Arris box. Which one will help you depends on what it looks like when you turn on the TV.

Previous User Interface

Does it look like this when you use the TV box? Then [this manual applies](https://mediearkivet.telenor.se/Data/mw/Pdf/TA921040.pdf) (pdf that opens in a new window)

New User Interface
