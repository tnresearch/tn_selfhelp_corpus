## Troubleshooting

If the Home Modem seems to be intermittent or functioning abnormally, first try the following steps:

  1. Check for updates and update the device if possible (see the Updates section)
  2. Reset the device (see the Resetting section). In version B13, resetting also activates repair mode. It is recommended to reset twice in a row.
  3. Clear your browser's cache and history from your browser settings (offline files, cookies, etc.).
  4. Update your user device (tablets, phones, TVs; all devices connected to the Modem).
  5. It is recommended to restart a Windows 10 computer while holding down the shift key, and to restart tablets by keeping the power off for over 30 seconds.
  6. If the problem disappears when using an Ethernet cable (and has not been fixed by the above instructions), the fault is very likely in the wireless WiFi network. In this case, it is worth trying to check the operating frequency of the WiFi channel, verify the settings of the user devices, and in certain situations lock the WiFi channel. More information at www.dna.fi/tuki-wlan. You can also find information on the speeds that can be achieved with an AC 2x2 device with compatible devices on the same link.
  7. If the problem persists on WiFi and Ethernet cable (and has not been fixed by the above instructions), it may be a problem on the network side. In this case, it is advisable to contact customer service. Here you can be advised on the approximate locations of base stations and the possible 4G frequencies used. However, the user can try different ways to improve the network connection. More information at www.dna.fi/tuki-netti.

**In short:**

  * Try placing the modem on a window facing the nearest base station
  * Try locking a specific frequency in the Modem settings, e.g. 800, 1800, 2600
  * In areas with poor coverage, consider purchasing an external antenna
  * Make sure there is no active fault notification in the disturbance notifications
  * Make sure there are no obstacles blocking the signal between the Modem and the base station

**Note.** The Modem's user interface offers a more limited mobile view by default on mobile devices. You can also switch to computer view on mobile devices, which will display all the settings page settings.
