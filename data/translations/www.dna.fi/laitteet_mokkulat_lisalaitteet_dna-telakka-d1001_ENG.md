## DNA Dock D100

### Product Description

The first Dock that allowed the user to share a USB Modem connection with multiple devices via USB or Ethernet cable. The product has not received updates for a long time and therefore does not support the latest modems.

### Manufacturer's Product Name

Manufacturer's product name: Huawei D100

### Package Contents

  * DNA Dock D100
  * Power adapter
  * Ethernet cable
  * Quick guide

### Technical Specifications

  * Dimensions: 112 mm × 91 mm × 27 mm
  * Weight: < 200g (excluding power adapter)
  * Color: black
  * Connections: One Ethernet cable connection (RJ45), power adapter and USB connection
  * Antenna: built-in
  * WLAN encryption: WEP 64/128, WPA, WPA2
  * DHCP, NAT DNS
  * Internet connection sharing for up to 32 users via WLAN network
  * English user interface
  * Supported wireless standards: 802.11b/802.11g
  * Compatible with DNA Modems.
  * Operating voltage 12V
