# Return Slip for Equipment Returns

Here you will find guidance on ordering a return slip when you need to send
fixed-line equipment back to us.

NB: This return slip applies only to TV and broadband equipment (including
Wireless Broadband), such as WiFi Routers, TV boxes and WiFi Boosters.

  
If you are returning a mobile phone or mobile equipment, you can read more about this
here:  
**[Help with the Online Store](/kundeservice/mobil/hjelp-med-nettbutikken/)**

## How to Order a Return Slip

[Order Return with
Bring](https://retur.bring.no/?q=0065Inselo-2&ref=Telenorutstyr%20retur
"Order Return with Bring")

##

  1. **Order Return Slip**

    * Go to Bring's return page

    * Fill in name, address, email address and number of packages

    * Press **Create Return Label**

  2.  **Choose how you want to print the return label**

    * Print by pressing **Print Return Label** or use the QR code on your mobile phone and have the label printed at the Post Office. Find the nearest drop-off location [here](https://www.posten.no/kart)

  3.  **Deliver the Package**

    * Remember to pack the equipment securely before sending

    * If you have printed the label yourself, attach it to the package and deliver it to a drop-off location

    * If you are using a QR code, have your mobile phone ready for scanning when you deliver the package

  
✉️ The QR code and return slip are also sent to your email.
