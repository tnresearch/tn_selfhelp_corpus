## Contacts

In webmail, you can import contact lists you have from other email clients,
create groups to send emails to multiple recipients at once, and create
appointments directly from the contact list.

  * #### Adding, changing, or deleting contacts

    1. Go to **Contacts** in the main menu on the left

    2. Press the **Create new** **contact** icon

    3. Fill in the contact information on the **New contact** screen. Only the name is required to save a new contact

    4. Select **Save**  

 **How to change/edit a contact**

    1. Go to **Contacts** in the main menu on the left

    2. Search for the contact or find it in the address book

    3. Select the contact name from the preview pane. This opens an **Edit contact** screen on the right.

    4. Make changes to the contact information and select **Save**  

 **How to delete a contact:**

    1. Go to **Contacts** in the main menu on the left

    2. Find the contact you want to remove and press on it

    3. Click on the trash can icon

    4. Click on **Delete** in the confirmation dialog box

  * #### Creating a group

    1. Select **Contacts** in the main menu 

    2. On the Groups row, press the plus icon

    3. Enter a title for the group

    4. Enter the email address of the contacts you want to add, and press Add

    5. Once all contacts are added, press Save in the upper right corner

    6. Now you can select the group as the recipient by typing the group name when writing an email or creating an event in the calendar 

  * #### Importing contacts

    1. Go to **Contacts** in the main menu on the left

    2. Press then **More**

    3. Select **Import** from the dropdown menu

    4. Select which address book you want the contacts to be added to

    5. Select a file format from **File format**

    6. If you are not importing contacts from a CSV file you have exported from another email client, select **Custom**

    7. Select character set. In most cases, this will be **Unicode (UTF-8)**, but there are also several other languages to choose from

    8. Click on **Upload** to select the file you want to import. **Note:** When saving a contact list, you must make sure to save it as a CSV file.

    9. Select **Next**

    10. Check the information and select **Next.** **Note:** Field names are columns in the CSV file, such as first name, last name, and email address. 

    11. Then you link each field in the CSV file to the correct field in the address book. Make sure you are accurate and select the fields that match the fields in the CSV file.

    12. Finally, select **Import**. You will find the imported contacts in the address book you selected.

  * #### Exporting contacts

 **How to export contacts:**

    1. Go to **Contacts** in the main menu on the left

    2. Press then **More**

    3. Select **Export** in the dropdown menu

    4. Under **File format** select either **CSV** or **vCard**. This is the format the contact(s) will be exported as

    5. Select **Export**

 **How to export address books or groups:**

    1. In the **Address book** or **Groups** dropdown lists, select the address book or group you want to export

    2. Click the **Export contacts** button

  * #### Merge duplicates in the contact list

    1. Go to **Contacts** in the main menu on the left

    2. Press **More**

    3. Select **Find duplicates**

    4. If you have duplicates, they will now be displayed on the screen. If you want to merge them, press **Save and next**

    5. Select which of the contacts is the main contact and press **Save and merge** to complete the merge
