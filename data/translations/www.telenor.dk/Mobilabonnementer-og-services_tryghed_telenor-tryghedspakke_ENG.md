# Telenor Security Package

You may know Telenor Security Package as NetSikker, but because it is much
more than online security, we have changed the name. Telenor Security Package
provides the same good coverage as NetSikker – and a little more.

Telenor Security Package gives you legal advice and assistance if you are
subjected to online fraud or digital violations. In addition, filters are now
included that protect you from fake emails and SMS messages.
The Security Package is included in mobile subscriptions and internet subscriptions* from
Telenor.

Telenor Security Package is a collaboration between Telenor and HELP Insurance.

* Applies to 5G internet and internet via fiber.

What does Telenor Security Package cover?

With Telenor Security Package, you get your money back if you are scammed by
a webshop, for example. In addition, you get any legal costs covered.

You get legal advice and help with filing a police report if you are violated
online - and skilled lawyers take care of your case from start to
finish. Violations can be, for example, digital bullying, hacking, fake profiles and
unwanted sharing of private images.

The Security Package also includes a service that blocks websites with
viruses, fraud and harmful content, as well as filters that protect you from fake
emails and SMS messages. Read more about what Telenor Security Package covers
[here](/shop/telenor-tryghedspakke/).

How do I get Telenor Security Package?

You are automatically covered by Telenor Security Package if you have a mobile or
internet subscription with Telenor.

If you have a mobile subscription, Telenor Security Package covers the user of
the subscription. If you have an internet subscription, Telenor Security Package covers the whole
family.

I have been scammed, hacked or violated, how do I use Telenor
Security Package?

You can contact HELP by phone **39 90 09 00** or by sending an email to
**kontakt@helpforsikring.dk**. They can help with advice, and if necessary, a lawyer will take care of your case from start to finish.

**HELP's opening hours are:**
Monday – Friday: 08-20
Saturday: 09-17
Sunday: 10-15

You can always call if you need help with a specific case, or if
you have questions regarding digital violations, e.g. digital bullying, fake
profiles or unwanted sharing of private images. You can read more about
the collaboration with HELP Insurance [here](https://helpforsikring.dk/hvem-er-
vi/telenor).
